
# Course Discord & Support

---

## How to Get Support

> [!important]
> Course support is available **24/7** exclusively via the TCM Discord Server.
> No support is offered through any other platform.

**Discord Link:** [https://discord.gg/tcm](https://discord.gg/tcm)

---

## Getting Started on Discord

1. **Join** the server using the link above
2. **Read the server rules** in the `#rules` channel
3. **Navigate** to the `#start-here-academy` channel
4. **Click** the 🙃 (upside-down smiley face) emoji under your respective course to unlock course support

> [!warning]
> Course support is a **luxury of course access**. Violating server rules can lead to a **ban**, which means permanent loss of course support.
