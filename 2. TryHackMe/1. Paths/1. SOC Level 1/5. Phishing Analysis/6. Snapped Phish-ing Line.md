# 🧠 THE CORE MINDSET (Burn this in)

Whenever you see a phishing kit:

👉 **There are ONLY 3 things attackers care about**

1. **Where data comes from** → forms (`email`, `password`)
2. **Where data goes** → `mail()`, API, webhook
3. **What they hide** → obfuscation, flags, backup logic

Everything you do = trace these 3.
