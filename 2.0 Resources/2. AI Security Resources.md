# AI Models

## Hugging Face

- **dealignai/GLM-5.3-CYBERSECURITY-FP8** [Link](https://huggingface.co/dealignai/GLM-5.3-CYBERSECURITY-FP8)
### How to actually access the GLM-5.3 cybersecurity model

Three realistic options:

**Option A — Rent a GPU server (best for this model)**
Rent cloud GPUs and run the model using vLLM. The model card's tested serving configuration uses eight H200 GPUs.
- Start with a provider such as [RunPod](https://www.runpod.io/) or [Hugging Face Inference Endpoints](https://endpoints.huggingface.co/).
- Check that the provider can actually host this specific modified checkpoint.
- Deploy the model and obtain an API endpoint.
- Send prompts from your Windows machine or Kali VM.

> ⚠️ **Cost warning:** RunPod's published H200 rates vary; a recent listed rate was $5.29/GPU-hour. Eight GPUs at that rate would be ~$42.32/hour if all eight are billed. Illustrative only — not a confirmed quote.

**Option B — Your own GPU server**
If you have a compatible multi-GPU server with sufficient VRAM, install a compatible vLLM release, download the checkpoint, and launch locally. More control over data and integrations, but substantial hardware requirements. An ordinary Kali VM is not enough.

**Option C — Use another hosted model for now**
The HF page says this checkpoint is not currently deployed by an Inference Provider, so you cannot just click a hosted inference button. To experiment without paying for a large GPU cluster, use an available hosted coding model or a smaller cybersecurity model while you decide if you need this exact checkpoint.

## AI Hacking / Red Team Tools

1. **Promptfoo** — Acquired by OpenAI (March 2026). Used by 300,000+ developers and 127 Fortune 500 companies. Tests LLMs against 50+ vulnerabilities including prompt injection and jailbreaks. [github.com/promptfoo/promptfoo](https://github.com/promptfoo/promptfoo)
2. **Garak** — NVIDIA's LLM vulnerability scanner, the "nmap for LLMs." 50+ probes for prompt injection, jailbreaks, data leakage, and toxicity. [github.com/NVIDIA/garak](https://github.com/NVIDIA/garak)
3. **NeMo Guardrails** — NVIDIA's framework for programmable LLM safety rails. Learn both sides — build guards AND break them. [github.com/NVIDIA-NeMo/Guardrails](https://github.com/NVIDIA-NeMo/Guardrails)
4. **PyRIT** — Microsoft AI Red Team's official toolkit. Tied to the Microsoft AI bounty program. [github.com/microsoft/PyRIT](https://github.com/microsoft/PyRIT)
5. **AI-Infra-Guard** — Tencent Zhuque Lab's full-stack AI red team platform. Covers infrastructure, agents, and MCP servers. [github.com/Tencent/AI-Infra-Guard](https://github.com/Tencent/AI-Infra-Guard)
6. **LLM Guard** — Protect AI's production-grade LLM firewall. Input/output scanners for prompt injection, PII leakage, and data exfiltration. [github.com/protectai/llm-guard](https://github.com/protectai/llm-guard)
