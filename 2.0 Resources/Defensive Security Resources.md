CompTIA CySA+ : 
Your real-world experience might conflict with CompTIA’s exact text-book definitions. Drill the things you cannot guess using common sense:
- **The Incident Response Phases:** Memorize the exact steps of the **NIST SP 800-61 r2** (Preparation, Detection & Analysis, Containment/Eradication/Recovery, Post-Incident Activity). The exam will ask what an analyst should do _next_ according to this lifecycle.
- **DNS Records & Mail Security:** Make sure you can instantly read **SPF, DKIM, and DMARC** configurations in a text block, as well as identify malicious **REST API requests**. [[1](https://www.reddit.com/r/CompTIA/comments/vys22p/taking_cysa_in_a_week_today_how_to_prepare/)]
- **Framework Metrics:** Refresh your memory on **CVSS v3.1** vector strings (e.g., `CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:H`). You need to know what metrics like _Attack Vector (AV)_ or _User Interaction (UI)_ mean in a scenario.
