
## About this lab

Utilize enumeration and web enumeration techniques to identify vulnerabilities. Engage in privilege escalation strategies and harness the abuse of sudo permissions to enhance your access. This lab is designed to capitalize on your skills in vulnerability exploitation.

## Learning Objectives

**After completion of this lab, learners will be able to:**

- Enumerate the target to identify exposed web services and directories.
- Locate and extract credentials from misconfigured files.
- Log in to a database management interface, enumerate tables, and retrieve sensitive credentials.
- SSH into the target system using the discovered credentials.
- Modify a root-owned script to escalate privileges and reboot the lab to trigger the script.
- Exploit the updated script to gain root access by leveraging SUID permissions on a binary.

## Lab Description

This lab is exploited by discovering database credentials and using them to retrieve a user's password. Privilege escalation is achieved by abusing a user-modifiable script that runs as root, combined with the ability to reboot the system using sudo.
