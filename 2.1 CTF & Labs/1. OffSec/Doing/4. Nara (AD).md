
## About this lab

In this challenge, we will conduct comprehensive enumeration, starting with SMB enumeration to identify shared resources. We will then perform LDAP enumeration to gather directory information, followed by the enumeration of certificates to uncover additional insights or vulnerabilities.

## Learning Objectives

**After completion of this lab, learners will be able to:**

- Enumerate SMB shares on the target server (nara-security.com) to identify the nara share.
- Leak NTLMv2 hashes using a malicious .lnk file and Impacket's smbserver.
- Crack the hash with hashcat to retrieve credentials for Tracy.White.
- Use BloodHound and LDAP enumeration to identify GenericAll permissions on the Remote Access group.
- Request a vulnerable certificate for the Administrator account using certipy (ESC4 scenario).
- Authenticate as the Administrator using the certificate to gain Domain Admin access.

## Lab Description

This lab demonstrates chaining multiple techniques to escalate privileges from a low-level user to Domain Administrator. Initial access is achieved by leaking SMB hashes through a crafted .lnk file. BloodHound analysis identifies the ESC4 and ESC1 vulnerabilities in the Certificate Authority (CA), allowing learners to request and abuse a certificate for the Administrator account, granting full domain control. This lab highlights SMB exploitation, CA misconfigurations, and hash abuse for privilege escalation.

The main **SMB ports** are:

|Port|Protocol|Purpose|
|---|---|---|
|**445/TCP**|SMB over TCP|Modern SMB — most important|
|**139/TCP**|NetBIOS Session Service|Older SMB over NetBIOS|

For OSCP, remember:

```
445 → SMB
139 → SMB over NetBIOS
```

A quick scan:

```
nmap -p 139,445 -sV <IP>
```

If **445** is open, SMB enumeration is usually one of the first things to investigate.
