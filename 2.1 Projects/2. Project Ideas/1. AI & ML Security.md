## Core build ideas

### AI Prompt Security Gateway (AI Firewall)
Build a proxy that sits between the user and an AI model (using **OpenRouter** free models).

**Workflow**
```
User
   ↓
Prompt
   ↓
Your Security Engine
   ↓
Checks if prompt is malicious
(Prompt Injection, Jailbreak, Malware, Sensitive Data, etc.)
   ↓
Safe? ── Yes ──► OpenRouter LLM
        │
        No
        │
     Block & Log
```

**What it does**
- Receives every user prompt.
- Uses a free LLM from **OpenRouter** to classify whether the prompt is **safe or malicious**.
- If the prompt is safe → forwards it to the target AI model.
- If malicious → blocks it and logs the reason.
- Acts as an **AI Firewall / AI Security Gateway** for LLMs.

**In one line:** An AI-powered security proxy that scans prompts using OpenRouter before they reach an LLM, blocking malicious prompts such as prompt injection, jailbreaks, and other unsafe requests.

## AI Security Projects (curated: Beginner → Advanced)

### Beginner

**1. LLM Prompt Injection Attack Lab**
- **Description:** Craft prompt injection payloads against open-source LLMs and document how they bypass safety guardrails.
- **Tools/Tech Stack:** Python, Ollama, LangChain, Burp Suite

**2. AI-Powered Phishing Detection Tool**
- **Description:** Build a classifier that detects phishing emails using NLP and compare it against traditional rule-based filters.
- **Tools/Tech Stack:** Python, Scikit-learn, HuggingFace, Gmail API

**3. Malware Classification With Machine Learning**
- **Description:** Train a model to classify malware families from static features and benchmark detection accuracy.
- **Tools/Tech Stack:** Python, Scikit-learn, VirusTotal API, Pandas

### Intermediate

**4. Jailbreak-as-a-Service Threat Landscape Study**
- **Description:** Map and categorize real-world LLM jailbreak techniques and publish a structured threat taxonomy.
- **Tools/Tech Stack:** Python, GPT-4 API, Claude API, MITRE ATLAS

**5. AI Agent Security Testing Lab**
- **Description:** Deploy an autonomous AI agent and attack its tool-use layer, file access, API calls, and memory injection.
- **Tools/Tech Stack:** Python, LangChain or AutoGPT, Docker, Burp Suite

**6. RAG Poisoning Attack Simulation**
- **Description:** Poison a retrieval-augmented generation pipeline with malicious documents and measure output manipulation.
- **Tools/Tech Stack:** Python, LangChain, ChromaDB, OpenAI API

### Advanced

**7. Steganographic Prompt Injection in Vision Models**
- **Description:** Embed hidden instructions inside images and exploit VLMs to execute attacker-controlled commands.
- **Tools/Tech Stack:** Python, OpenCV, GPT-4V, Claude Vision, PIL

**8. LLM Container Escape & Isolation Testing**
- **Description:** Test whether a compromised LLM deployment can break out of its container boundary into the host.
- **Tools/Tech Stack:** Docker, Kubernetes, Python, Trivy, Falco

**9. Adversarial Attack on AI-Based IDS**
- **Description:** Craft adversarial inputs that fool an ML-based intrusion detection system without triggering alerts.
- **Tools/Tech Stack:** Python, TensorFlow or PyTorch, Foolbox, NSL-KDD Dataset

**10. AI Red Team Full Exercise**
- **Description:** Run a complete red team operation against an LLM-powered application — prompt injection, data exfiltration, and model abuse.
- **Tools/Tech Stack:** Python, Burp Suite, Garak, PyRIT, MITRE ATLAS
