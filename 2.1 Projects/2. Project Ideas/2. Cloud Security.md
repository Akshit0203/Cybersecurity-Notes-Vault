# Cloud Security

Cloud posture, IAM, and cloud attack/defense labs across AWS, Azure, and GCP.

---

## Beginner
1. **IAM Misconfiguration Hunter** — Scan an AWS account for over-permissioned roles and policies, then document privilege escalation paths. 🛠 Python, AWS CLI, Boto3, Prowler
2. **S3 Bucket Exposure Scanner** — Build a tool that detects publicly exposed buckets and classifies the sensitivity of leaked data. 🛠 Python, Boto3, AWS S3 API, Pandas
3. **Cloud Logging & Detection Lab** — Set up CloudTrail and GuardDuty, simulate attacks, and build detection rules around suspicious API calls. 🛠 AWS CloudTrail, GuardDuty, Athena, Python

## Intermediate
4. **Serverless Function Attack Lab** — Deploy a vulnerable Lambda function and exploit injection, secrets leakage, and over-privileged execution roles. 🛠 AWS Lambda, Python, IAM, Pacu
5. **Kubernetes Threat Modeling Lab** — Stand up a cluster, attack pod security, RBAC, and the API server, then map findings to MITRE. 🛠 Kubernetes, kube-hunter, Trivy, Falco
6. **CSPM Tool From Scratch** — Build a cloud security posture management scanner that benchmarks against CIS standards. 🛠 Python, Boto3, CIS Benchmarks, ScoutSuite

## Advanced
7. **Cloud Privilege Escalation Chain** — Map a full attack path from initial access to account takeover across chained IAM misconfigs. 🛠 Pacu, AWS CLI, Python, CloudMapper
8. **Multi-Cloud Attack Simulation** — Run coordinated attacks across AWS, Azure, and GCP and compare their security control gaps. 🛠 Pacu, Stratus Red Team, Python, Terraform
9. **CI/CD Pipeline Compromise Lab** — Poison a build pipeline to inject malicious artifacts and exfiltrate cloud credentials. 🛠 GitHub Actions, Docker, Trivy, gitleaks
10. **Cloud Red Team Full Exercise** — Run a complete cloud red team op: recon, initial access, privilege escalation, persistence, and exfiltration. 🛠 Pacu, Stratus Red Team, CloudGoat, MITRE ATT&CK Cloud

## Cloud Misconfiguration Scanner (Hackathon — Computer & Network Security)
Develop a tool to audit cloud infrastructure configurations and detect security misconfigurations across AWS, Azure, and GCP environments, enabling early identification of risky exposures.

**Exact Deliverables:**
- Rules engine for cloud configuration checks (aligned with CIS benchmarks and IaC tools like Terraform).
- Automated detection of common misconfigurations (e.g., open storage buckets, insecure security groups).
- Validation tests by spawning misconfigurations and measuring time-to-detect vs. baseline scanners.
- Dashboard to visualize findings and generate compliance reports.

**Milestones, Evolution Parameters:**
- Phase 1: Build a basic rules engine for misconfig detection.
- Phase 2: Integrate with IaC pipelines and validate against seeded misconfig libraries.
- Phase 3: Develop visualization and compliance reporting features.
- KPIs: Detection coverage, false positives, detection latency, compliance readiness.

**Additional Information:**
- Focus on scalability to multi-cloud environments.
- Ensure the scanner is modular, supporting integration with CI/CD pipelines.
- Students should study major breaches caused by cloud misconfigs to design realistic test cases.
