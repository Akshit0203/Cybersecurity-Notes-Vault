## Privacy-preserving systems (Hackathon)

### Privacy Preserving KYC Verification System (Cryptography)
Design a privacy-preserving KYC verification system leveraging applied privacy-enhancing technologies (PETs), such as zero-knowledge proofs (ZKPs), that allows users to prove identity attributes (e.g., 'over 18', 'valid Aadhaar') without revealing sensitive PII.
**Exact Deliverables:**
- Prototype of a privacy-preserving KYC system with user-friendly verification interfaces.
- Integration of selective-disclosure or zero-knowledge proof mechanisms.
- Performance benchmarking report comparing latency and usability against traditional e-KYC.
- Demonstration of compliance with India's DPDP Act (2023) requirements.
**Milestones, Evolution Parameters:**
- Phase 1: Basic prototype with ZKP-based "age over 18" verification.
- Phase 2: Expand to multi-attribute verification (e.g., address, Aadhaar validity).
- Phase 3: Integration with mock financial/telecom onboarding systems.
- KPIs: Verification latency vs. e-KYC, PII exposure reduction score, user adoption experience (mock testing).
**Additional Information:** Benchmark against Aadhaar e-KYC APIs and privacy-preserving identity protocols (e.g., Hyperledger Indy, W3C Verifiable Credentials); focus on usable, intuitive interfaces; balance compliance with practicality; prefer lightweight, scalable implementations.

### Consent Management System (Cyber Security Governance, Operations & Services and Privacy)
Design a transparent, user-friendly platform that helps individuals track, grant, and revoke consent for data sharing in compliance with India's DPDP Act and global regulations such as GDPR.
**Exact Deliverables:**
- Prototype consent manager with receipts, purpose binding, and granular revocation.
- SDKs or APIs for integration with web and mobile applications.
- Audit log functionality to demonstrate compliance with DPDP and GDPR.
- Test results showing interoperability across multiple applications.
**Milestones, Evolution Parameters:**
- Phase 1: Build core consent grant/revoke flow with logging.
- Phase 2: Add purpose binding and interoperability testing across apps.
- Phase 3: Deploy SDK/API prototype for integration into web/mobile apps.
- KPIs: Processing latency, error rate in consent revocation, user satisfaction scores, compliance audit readiness.
**Additional Information:** Emphasize usability for non-technical users; lightweight SDKs enhance adoption; study both DPDP (India) and GDPR (EU) for future-proof solutions; consult India's governance and regulatory bodies.

## Post-quantum security (Hackathon)

### Lightweight Post-Quantum Messaging (Security in Futuristic Technologies)
Build lightweight and efficient post-quantum secure messaging systems suitable for mobile and IoT environments, ensuring confidentiality and forward secrecy in the quantum era.
**Exact Deliverables:**
- Prototype messaging app or protocol implementation using NIST PQC algorithms (e.g., Kyber, Dilithium).
- Lightweight key exchange protocol optimized for mobile/IoT constraints.
- Performance benchmarking reports against classical TLS messaging.
- Demonstration of secure communication across constrained devices.
**Milestones, Evolution Parameters:**
- Phase 1: Implement baseline PQC-based key exchange.
- Phase 2: Optimize for mobile and IoT environments.
- Phase 3: Integrate into prototype messaging app and benchmark against TLS.
- KPIs: Latency, throughput, energy usage, interoperability with existing systems.
**Additional Information:** Prioritize usability (PQC adoption fails if UX is degraded); explore hybrid protocols (classical + PQC) for transition; align with emerging international PQC standards (NIST FIPS-203/204).

### Hybrid Post-Quantum Encryption (from Bitten Tech "Cyber Projects for Future")
Prepares systems for the quantum computing era by implementing a dual-layer encryption model using both classical and post-quantum cryptographic keys (**Kyber** and **Dilithium**).
