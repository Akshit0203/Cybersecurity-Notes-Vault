## Common Hackathon Deliverables (Cyberthon.ai 2025)
Expected deliverables for all problem statements:
- Working prototype or MVP (Minimum Viable Product)
- Pitch deck explaining problem-solution fit, user flow, tech stack
- Codebase with documentation (share GitHub repo URL)
- Demo video (3–5 minutes max) or presentation as per template
- Presentation to jury with use-case relevance to Chandigarh Police and Master-Hacks
- Optional: Dataset, scalability roadmap, or plan for pilot deployment (future roadmap)
