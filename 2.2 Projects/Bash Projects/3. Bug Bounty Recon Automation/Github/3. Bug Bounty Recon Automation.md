# Bug Bounty Recon Automation

> **Goal:** Build a Bash script that automates the initial reconnaissance phase of bug bounty — subdomain enumeration, filtering, live-host resolution, JS file discovery, subdomain takeover checks, and directory fuzzing — all in one run.

## Pipeline Overview

```
1. Documentation   → Create a target directory
2. Subdomains      → Enumerate with Sublist3r + Assetfinder
3. Sort & Filter   → Remove duplicates with sort | uniq
4. Resolve         → Find live hosts with httprobe
5. JS Files        → Extract JS endpoints with subjs
6. Takeover Check  → Audit with subjack
7. Directory Fuzz  → Brute-force paths with dirsearch
```

---
## Final Script (with Color Output)

```bash
#!/bin/bash

target=$1

REDCOLOR="\e[31m"
GREENCOLOR="\e[32m"

if [ ! -d $target]
then
	mkdir $target
fi

cd $target

echo -e "$REDCOLOR [+] Finding subdomains with Sublist3r..."

python3 /home/kali/Downloads/subwalker/tools/Sublist3r/sublist3r.py -d $target -t 25 -o subdomains.txt

echo -e "$REDCOLOR [+] Finding subdomains with Assetfinder..."

python3 /home/kali/Downloads/subwalker/tools/assetfinder/assetfinder -subs-only $target >> subdomains.txt

echo -e "$REDCOLOR [+] Sorting and Filtering..."

cat subdomains.txt | sort | uniq > subdomains

echo -e "$REDCOLOR [+] Finding live subdomains with httprobe..."

cat subdomains | httprobe > alive.txt

echo -e "$REDCOLOR [+] Finding JS files..."

cat alive.txt | subjs > jsfiles

echo -e "$REDCOLOR [+] Finding Subdomain takeovers..."

subjack -w subdomains -c /home/kali/goc/github.com/haccer/subjack/fingerprints.json -t 25 -ssl -o takeovers.txt

echo -e "$REDCOLOR [+] Fuzzing for directories..."

while read -r line
do
	dirsearch -u "$line" -w /usr/share/wordlists/dirb/common.txt -o directory_fuzzing.txt
done < alive.txt

echo -e "$GREENCOLOR [+] Done"
```

## 1 — Documentation Structure

Before anything, create a folder per target to keep all output organized:

```bash
target=$1

if [ ! -d "$target" ]; then
    mkdir "$target"
fi

cd "$target"
```

- `$1` = first command-line argument (the target domain)
- `-d` checks if the directory already exists to avoid errors

## 3 — Sorting & Filtering

Multiple tools produce duplicate subdomains. Pipe through `sort | uniq` to deduplicate:

```bash
cat subdomains.txt | sort | uniq > subdomains
```

> [!tip] Use `>` (overwrite) here, not `>>` (append), since we're creating the clean deduplicated file.

## 4 — Resolving Live Hosts with `httprobe`

Not all subdomains are alive. `httprobe` probes for working HTTP/HTTPS servers.

https://github.com/tomnomnom/httprobe

![](attachments/Pasted%20image%2020260922203429.png)

**Install:**

```bash
apt install httprobe
```

or:

```bash
go install github.com/tomnomnom/httprobe@latest
```

**Basic usage** — accepts line-delimited domains on stdin:

```
▶ cat recon/example/domains.txt
example.com
example.edu
example.net
▶ cat recon/example/domains.txt | httprobe
http://example.com
http://example.net
http://example.edu
https://example.com
https://example.edu
https://example.net
```

**In the script:**

```bash
cat subdomains | httprobe > alive.txt
```

## 5 — JavaScript File Discovery with `subjs`

`subjs` fetches JavaScript files from a list of URLs or subdomains. Analyzing JS files can reveal undocumented endpoints, secrets, and more.

https://github.com/lc/subjs

**Install from binary:**

```bash
tar xvf subjs_1.0.0_linux_amd64.tar.gz
mv subjs /usr/bin/subjs
```

**In the script:**

```bash
cat alive.txt | subjs > jsfiles
```

## 6 — Subdomain Takeover Check with `subjack`

https://github.com/haccer/subjack

> [!note] **What is subdomain takeover?**
> When a subdomain has a CNAME record pointing to a third-party service (Shopify, GitHub Pages, AWS S3, etc.) and that resource is deleted/unclaimed, an attacker can register the unclaimed resource. Because the CNAME still points there, the attacker's content is served on the target's subdomain. This is a critical vulnerability.

**Install:**

```bash
apt install subjack
```

or:

```bash
go install github.com/haccer/subjack@latest
```

**Flags:**

| Flag       | Description                                                              | Default |
| ---------- | ------------------------------------------------------------------------ | ------- |
| `-d`       | Single domain to check                                                   |         |
| `-w`       | Path to wordlist of subdomains                                           |         |
| `-t`       | Number of concurrent threads                                             | 10      |
| `-timeout` | Seconds to wait before connection timeout                                | 10      |
| `-o`       | Output results to file (use `.json` extension for JSON output)           |         |
| `-ssl`     | Force HTTPS connections (may increase accuracy)                          | false   |
| `-a`       | Send requests to every URL, not just those with identified CNAMEs        | false   |
| `-m`       | Flag dead CNAME records even if the domain is not available for registration | false   |
| `-r`       | Path to a list of DNS resolvers (one IP per line)                        |         |
| `-ns`      | Check for NS takeovers (expired NS domains + dangling cloud DNS)         | false   |
| `-ar`      | Check for stale A records pointing to dead IPs                           | false   |
| `-axfr`    | Check for zone transfers (AXFR) including NS bruteforce                  | false   |
| `-mail`    | Check for SPF include and MX record takeovers                            | false   |
| `-v`       | Display more information per request                                     | false   |

**Example:**

```bash
subjack -w subdomains.txt -t 100 -timeout 30 -o results.txt -ssl
```

**In the script:**

```bash
subjack -w subdomains -c /home/kali/goc/github.com/haccer/subjack/fingerprints.json -t 25 -ssl -o takeovers.txt
```

> [!warning] The `-c` flag must point to the `fingerprints.json` file in your Go installation path. Many users face errors when this path is wrong.

## 7 — Directory Fuzzing with `dirsearch`

https://github.com/maurosoria/dirsearch

**Install:**

```bash
apt install dirsearch
```

**Example usage:**

```bash
dirsearch -u offsec.com -w /usr/share/wordlists/dirb/common.txt -o directory_fuzzing.txt
```

**In the script — loop through every alive host:**

```bash
while read -r line
do
    dirsearch -u "$line" -w /usr/share/wordlists/dirb/common.txt -o directory_fuzzing.txt
done < alive.txt
```
