✈️ GPS Spoofing Is Actively Happening Across India — Here’s My Aviation Security Research Using SDR, HackRF, and DragonOS

Over the last few weeks, India has been witnessing unusual GPS spoofing incidents affecting flight paths, maritime systems, and critical navigation services.
As someone passionate about cybersecurity and wireless systems, I decided to study the threat hands-on — inside a safe, RF-isolated test environment — to understand exactly how these attacks work and how they can disrupt aviation systems.

🚀 What I Built & Researched

1️⃣ GPS Spoofing Demonstration (HackRF One + GPS-SDR-SIM)
Using DragonOS, NASA satellite ephemeris data, and HackRF One (Mayhem firmware), I generated realistic GPS L1 signals (1575.42 MHz) and simulated the aircraft’s location near IGI Airport, New Delhi.
🔧 Steps included:
• Downloading real NASA BRDC ephemeris data
• Generating spoofed coordinates using GPS-SDR-SIM
• Transmitting the GPS signal in a controlled RF environment
➡️ Result: The spoofed GPS completely overpowered real GNSS inside the test setup.

2️⃣ Real-Time Aircraft Tracking (ADS-B & Mode S Decoding)
I built a real-time flight tracking system using SDR Angel + HackRF One + Portapack H2+.
What I decoded on 1090 MHz:
✈️ Aircraft position
✈️ Altitude
✈️ Velocity
✈️ Heading
✈️ ICAO transponder ID (Mode S)

3️⃣ Combining Both: Injecting Spoofed GPS Data Into ADS-B
When a GPS receiver accepts spoofed coordinates:
➡️ ADS-B automatically broadcasts those fake coordinates
➡️ SDR receivers and ATC-style systems both accept and display the spoofed positions.

⚠️ Meaning:
Spoofed GPS = Spoofed aircraft telemetry.

This directly impacts:
• Air traffic situational awareness
• Collision avoidance systems
• Flight tracking tools
• Navigation-assisted landings
• ATC monitoring systems

❌ ADS-B has no encryption, authentication, or GNSS integrity validation.

🛩️ Why This Matters Today
GPS spoofing is increasing globally, causing sudden jumps in aircraft and ship locations.

My project highlights the need for:
✔ Stronger GNSS security and multi-constellation navigation (GPS + Galileo + NavIC)
✔ Navigation anomaly detection & backup systems (INS, DME/VOR)

Aviation cybersecurity is no longer theoretical — it’s happening right now.
