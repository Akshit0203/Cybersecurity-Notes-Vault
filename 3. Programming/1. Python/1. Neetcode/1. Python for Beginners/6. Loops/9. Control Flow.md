
Python provides control statements to alter the execution of loops.

- `break`: Exits the loop immediately.
- `continue`: Skips the remaining code inside the loop for the current iteration and moves to the next iteration.
- `pass`: Acts as a placeholder and does nothing. We cannot have empty loops, so we use `pass` to avoid errors. It can also be used in conditional statements and functions.

Here's an example demonstrating `pass`:

```python
for i in range(1, 8):
    pass

if True:
    pass

def unfinsished_function():
    pass
```

None of the above code will actually do anything, but it also won't cause an error.

Here's an example demonstrating the `break` and `continue` control statements:

```python
for i in range(1, 8):
    if i == 3:
        continue
    elif i == 6 :
        break
    print(i)
```

The output would be:

```plaintext
1
2
4
5
```

Notice that the output is missing some numbers?

Thats because when `i` was equal to `3` the `if` statements block of code executed causing the loop to `continue` to the next iteration of the loop, before reaching the `print(i)` line.

When `number` was equal to `6` the loop exited, because the `break` statement executed.

For the numbers where neither condition executed, the `print(i)` line was reached.

Control flow statements are commonly used, but they are not usually required. They are generally used to make code more readable.

## 1. `pass` — do nothing

```
for i in range(1, 8):    pass
```

- `range(1, 8)` generates numbers from `1` to `7`.
    
- The loop runs 7 times.
    
- `pass` does absolutely nothing each time.
    

Why use it? Python requires an indented block after a `for` loop, `if` statement, or function definition. `pass` lets you leave that block empty without causing an error.

For example:

```
if True:    pass
```

The condition is true, so Python enters the block, executes `pass` (nothing happens), and continues.

You also have:

```
def unfinsished_function():    pass
```

This defines a function that currently does nothing. You can fill it in later.

Important: `pass` doesn't stop a loop or skip an iteration. It simply does nothing and moves to the next statement.

If `pass` does nothing, why does Python even have it?

Because Python doesn't allow you to leave certain code blocks completely empty. `pass` acts as a placeholder when you want to write the structure of your code now and implement the logic later.

## 1. Without `pass` — you get an error

Imagine you're creating a function but haven't decided what to put inside it yet.

```
def greet():
```

Python raises an `IndentationError` because it expects an indented function body.

## 2. With `pass` — your code works

```
def greet():    passgreet()print("Program continues")
```

Output:

```
Program continues
```

The function exists, you can call it, and the program runs without errors. The function simply does nothing for now.

## 3. When would you actually use it?

Example A: Building a program step by step

```
def login():    passdef register():    passdef logout():    pass
```

You can define your program's structure first and implement each function later.

Example B: Handling a condition later

```
if user_is_admin:    passelse:    print("Access denied")
```

Here, you're reserving the admin branch for logic you haven't implemented yet.

Example C: Creating a class for later development

```
class SecurityScanner:    pass
```

This creates a valid, empty class that you can expand later.

## 4. Why not just use `break` or `continue`?

|Keyword|Purpose|
|---|---|
|`pass`|Do nothing; continue normally|
|`break`|Exit the current loop|
|`continue`|Skip the rest of the current loop iteration|

For example, if you use `pass` inside a loop, the loop still runs every iteration. If you use `break`, it stops immediately.

The main takeaway: `pass` exists so you can write syntactically valid Python while leaving a block empty. It's especially useful when planning or developing code incrementally. You won't need it in every program, but it's useful when you do.
