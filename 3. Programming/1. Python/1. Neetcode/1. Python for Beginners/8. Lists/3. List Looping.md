
We can also loop through lists similar to how we loop through strings.

By using the length of the list:

```python
my_list = [1, 2, 3, 4, 5]

length = len(my_list)

for i in range(length):
    print(my_list[i])
```

Or by using the `in` operator:

```python
my_list = [1, 2, 3, 4, 5]

for element in my_list:
    print(element)
```

Both of these methods will print each element of the list on a separate line. If we don't need the index of the element, the second method is generally preferred since it is more concise.

#### Challenge

Implement the function `count_x(nums: List[int], x: int) -> int`. It accepts a list of integers `nums` and an integer `x`. The function should return the number of times the integer `x` appears in the list `nums`.

```
from typing import List # used to add type hint for List

def count_x(nums: List[int], x: int) -> int:
        return nums.count(x)

# do not modify below this line
print(count_x([1, 2, 5, 6, 5], 5))
print(count_x([4, 3, 6, 1, 6], 5))
print(count_x([4, 7, 7, 6, 7, 6], 7))
```

Let's break down `return nums.count(x)` step by step so you understand exactly how Python executes it.

## 1. What does `nums.count(x)` mean?

Suppose you have this list:

```
nums = [1, 2, 3, 2, 2, 4]x = 2
```

Python lists have a built-in method called `.count()`.

When you write:

```
nums.count(x)
```

Python counts how many times the value stored in `x` appears in `nums`.

Since `x = 2`, Python effectively evaluates:

```
nums.count(2)
```

The number `2` appears three times, so the result is the integer `3`.

## 2. What does `return` do?

Now look at the complete function:

```
def count_x(nums, x):    return nums.count(x)
```

When you call:

```
result = count_x([1, 2, 3, 2, 2, 4], 2)print(result)
```

Here's what happens:

Step 1: Call the function `count_x([1, 2, 3, 2, 2, 4], 2)`

Step 2: Count occurrences `nums.count(x)` → `nums.count(2)` → `3`

Step 3: Return the result `return 3`

Step 4: Store and print `result = 3` → prints `3`

## 3. Could you write it without `.count()`?

Yes! The following code does the same job manually:

```
def count_x(nums, x):    count = 0    for num in nums:        if num == x:            count += 1    return count
```

Here, you start with `count = 0`, examine each number, and increase `count` whenever `num == x`.

Both versions return the same result.

## Remember these three things

- `nums` is the list.
    
- `.count(x)` counts how many times `x` occurs in that list.
    
- `return` sends that count back to whoever called the function.
    

The key idea: `return nums.count(x)` is a shortcut for counting occurrences and returning the result in one line. You don't need to create a loop yourself because Python already provides `.count()`.
