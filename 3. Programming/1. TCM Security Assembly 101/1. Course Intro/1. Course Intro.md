
# Course Intro — Assembly 101

## Course Curriculum

| # | Module | Focus |
|---|--------|-------|
| 1 | Introduction to Computer Engineering | How processors execute low-level machine code (ones and zeros) as electrical signals |
| 2 | Assembly Basics in x86-16 | Learning assembly fundamentals using a 16-bit emulator |
| 3 | Interrupts and Syscalls | System-level communication with the CPU |
| 4 | Branches, Loops and Functions | Control flow in assembly |
| 5 | Writing and Reading x86-64 Assembly | Transitioning to native 64-bit assembly on a Linux VM |
| 6 | Memory Safety, Shellcoding & Exploiting Stack Overflows | Stack overflow vulnerabilities, custom shellcode, mitigations (stack canaries, secure code design) |

## System Requirements

- A computer capable of running an **x86-64 virtual machine**
- First half of course uses a **cross-platform emulator**; second half requires direct **x86-64 code compilation**
    - ⚠️ Users on newer **Apple Silicon Macs** may face architecture compatibility constraints
- **Recommended specs**:
    - 64-bit 2.0 GHz processor
    - ≥ 8 GB RAM
    - 50–100 GB free storage

---

## Key Takeaways

- **Why write assembly?** — Modern compilers handle most assembly generation, but learning to write it builds foundational understanding of how high-level code compiles and operates at the hardware layer
- **Foundation for cybersecurity** — Serves as a primer for **reverse engineering**, **malware analysis**, and **binary exploitation**
- Designed to fill the resource gap for beginner-level assembly education
