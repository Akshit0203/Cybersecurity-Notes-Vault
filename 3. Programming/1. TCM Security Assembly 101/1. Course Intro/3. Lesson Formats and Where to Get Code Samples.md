
# Lesson Formats & Where to Get Code Samples

---

## Lesson Type Emoji Legend

| Emoji | Lesson Type | What to Do |
|-------|-------------|------------|
| 🧑‍🏫 | **Lecture / Presentation** | PowerPoint or whiteboard — follow along and take notes; no hands-on activity |
| 💻 | **Hands-On Computer Lesson** | Follow along on your own computer and perform the same tasks |
| 🔢 | **Coding Challenge** | Instructions are given → pause the video → attempt it yourself → then watch the solution |
| ✏️ | **Check-in Quiz** | 5-question multiple choice / true-false quiz per section |
| 📎 | **Code Download** | ZIP file containing all code written in that section |

---

## Lesson Format Details

### Lectures (🧑‍🏫)
- Mostly concentrated in the first section (Intro to Computer Engineering)
- ~95% of the course is hands-on keyboard writing code

### Check-in Quizzes (✏️)
- One 5-question quiz per section (multiple choice or true/false)
- **Scores are not recorded** — not visible to instructor; purely for self-assessment of core fundamentals

### Hands-On Lessons (💻)
- You should be ready to follow along on your computer and perform the tasks being demonstrated

### Coding Challenges (🔢)
- The instructor gives challenge details → suggests you **pause the video** → try writing it yourself → then shows his solution
- Solution code is placed in a **separate lesson** so scrolling doesn't spoil it

---

## Where to Get Code Samples

1. **Below each video** — scroll down past the video player; most lessons include:
    - Code samples you can copy
    - Relevant links mentioned in the lesson
2. **ZIP downloads (📎)** — at the end of each coding section, a downloadable ZIP file contains every program written in that section
