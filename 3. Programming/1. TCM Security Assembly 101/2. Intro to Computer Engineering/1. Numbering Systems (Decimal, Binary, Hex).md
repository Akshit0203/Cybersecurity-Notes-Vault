
# Numbering Systems (Decimal, Binary, Hex)

> We rely heavily on binary and hexadecimal when working at low levels of the computer. Converting between them should become second nature.

---

## Decimal (Base 10)

- Each digit can be one of **10** values: `0–9`
- Digit positions are powers of 10

### Example — 217 in decimal

$$
(2 \times 10^2) + (1 \times 10^1) + (7 \times 10^0) = 200 + 10 + 7 = 217
$$

**Terminology:**
- **Least Significant Digit (LSD)** — furthest right (contributes least)
- **Most Significant Digit (MSD)** — furthest left (contributes most)

---

## Binary (Base 2)

- Each digit can be `0` or `1`
- Computers use binary because it maps to two electrical states: **high voltage (1)** / **low voltage (0)**

### Example — 217 in binary: `11011001`

Position numbering (right to left, starting at 0):

$$
(1 \times 2^7) + (1 \times 2^6) + (0 \times 2^5) + (1 \times 2^4) + (1 \times 2^3) + (0 \times 2^2) + (0 \times 2^1) + (1 \times 2^0)
$$
$$
= 128 + 64 + 0 + 16 + 8 + 0 + 0 + 1 = 217
$$

### Binary → Decimal conversion (4-bit examples)

Place values for 4-bit binary are always: `8  4  2  1`
Just **add the values where there is a `1`**.

| Binary | Calculation | Decimal |
|--------|-------------|---------|
| `1111` | 8+4+2+1 | **15** |
| `1101` | 8+4+0+1 | **13** |
| `1001` | 8+0+0+1 | **9** |

---

## Hexadecimal (Base 16)

- 16 digits: `0–9` then `A=10, B=11, C=12, D=13, E=14, F=15`
- Much more compact than binary — hex is used as a human-friendly replacement for binary

### Example — 217 in hex: `D9`

$$
(13 \times 16^1) + (9 \times 16^0) = 208 + 9 = 217
$$

---

## Bits, Bytes, and Nibbles

| Term | Size | Notes |
|------|------|-------|
| **Bit** | 1 binary digit | Smallest unit |
| **Nibble** | 4 bits | = exactly **1 hex digit** (because $2^4 = 16$) |
| **Byte** | 8 bits | = 2 nibbles = **2 hex digits** |

---

## Binary ↔ Hex Conversion (4-bit Nibble Method)

> **Every 4 binary bits = exactly 1 hexadecimal digit**

Split the binary number into nibbles, then convert each independently:

### Full 4-bit → Hex lookup table

| Binary | Hex | | Binary | Hex | | Binary | Hex | | Binary | Hex |
|--------|-----|-|--------|-----|-|--------|-----|-|--------|-----|
| `0000` | `0` | | `0100` | `4` | | `1000` | `8` | | `1100` | `C` |
| `0001` | `1` | | `0101` | `5` | | `1001` | `9` | | `1101` | `D` |
| `0010` | `2` | | `0110` | `6` | | `1010` | `A` | | `1110` | `E` |
| `0011` | `3` | | `0111` | `7` | | `1011` | `B` | | `1111` | `F` |

### Worked examples

**217 decimal = `11011001` binary → hex:**

```
1101  1001
 ↓      ↓
 D      9       →  D9
```

- Right nibble `1001`: 8+1 = 9 → hex **9**
- Left nibble `1101`: 8+4+1 = 13 → hex **D**

**`10110011` binary → hex:**

```
1011  0011
 ↓      ↓
 B      3       →  B3
```
