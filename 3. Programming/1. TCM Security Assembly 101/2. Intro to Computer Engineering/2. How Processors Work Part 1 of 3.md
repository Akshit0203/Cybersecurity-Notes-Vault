Let's convert **`10110011` binary → hexadecimal**.

### Step 1: Split into groups of 4

```
1011  0011
```

### Step 2: Convert each group

```
1011 = B
0011 = 3
```

Therefore:

101100112=B316\boxed{10110011_2 = B3_{16}}

✅ **Answer: `B3`**
