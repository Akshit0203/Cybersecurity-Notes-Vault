
# Intro to the Intel 8086

> The Intel 8086 is the processor we'll use (via emulator) for the first half of this course to learn assembly fundamentals.

---

## Why the 8086?

1. **Easier to learn on** — older, simpler architecture makes assembly more approachable for beginners
2. **x86 instruction set is still dominant** — the 8086 introduced the **x86** instruction set, which is still the most widely used CPU instruction set today
    - All **Intel** and **AMD** CPUs still use x86
    - Evolved: x86-16 → x86-32 → x86-64
    - **x64** is just shorthand for **x86-64-bit**
3. **Foundational skills transfer** — basic instructions from x86-16 are reused in modern x86-64
4. **Course progression** — we start on the emulator, then transition to writing **modern x86-64 assembly** that runs directly on a modern computer (no emulator needed)

---

## Historical Context

- Released by Intel in the **mid-1970s**
- 16-bit microprocessor
- One of the processors that put Intel on the map as a leading manufacturer
- Datasheet below is from September 1990, but the chip itself is ~50 years old
