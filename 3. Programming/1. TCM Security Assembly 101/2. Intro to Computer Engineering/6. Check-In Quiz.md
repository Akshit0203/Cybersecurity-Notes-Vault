What is 212 in binary?

11010100

11110111

0101

01010111

We want to convert:

**212 → binary**

### Step 1: Remember these numbers

Binary uses:

```
128  64  32  16  8  4  2  1
```

We ask: **Can I subtract this number from 212?**

---

### Step 2

Start with **128**.

Can we take 128 from 212?

✅ Yes.

```
212 - 128 = 84
```

Write **1**.

---

### Step 3

Next is **64**.

Can we take 64 from 84?

✅ Yes.

```
84 - 64 = 20
```

Write **1**.

---

### Step 4

Next is **32**.

Can we take 32 from 20?

❌ No.

Write **0**.

---

### Step 5

Next is **16**.

Can we take 16 from 20?

✅ Yes.

```
20 - 16 = 4
```

Write **1**.

---

### Step 6

Next is **8**.

Can we take 8 from 4?

❌ No → write **0**

Next is **4**.

Can we take 4 from 4?

✅ Yes → write **1**

Now remaining = **0**.

So the rest are `0`.

---

### Put the 1s and 0s together

```
Numbers:  128  64  32  16  8  4  2  1
           ↓   ↓   ↓   ↓   ↓  ↓  ↓  ↓
Binary:    1   1   0   1   0  1  0  0
```

Therefore:

# **212 = 11010100**

### The easiest way to think about it:

```
212
 ↓
Can take 128? YES → 1
Can take 64?  YES → 1
Can take 32?  NO  → 0
Can take 16?  YES → 1
Can take 8?   NO  → 0
Can take 4?   YES → 1
Can take 2?   NO  → 0
Can take 1?   NO  → 0

          ↓
     11010100
```

That's all you're doing: **YES = 1, NO = 0.**

What is 212 in hex?

0x212

0x120

0x32

0xD4

The correct answer is:

✅ **`0xD4`**

Let's do it simply.

We know:

```
212 decimal
```

Divide by **16**:

```
212 ÷ 16 = 13 remainder 4
```

Now convert each number to hexadecimal:

```
13 = D
4  = 4
```

So:

```
212 decimal = D4 hexadecimal
```

Therefore:

# ✅ **0xD4**

Quick check:

```
D = 13

13 × 16 + 4
= 208 + 4
= 212
```

**Answer: `0xD4`** 🎯

What is the name for the code which can be represented only in 1s and 0s (or its representation) which is what is directly read by the processor?

Assembly Code

Machine Code

C Code

Low Level Code

✅ **Correct answer: Machine Code**

### Simply:

**Machine code** is the code represented as **1s and 0s** that the processor directly works with.

For example:

```
11010100
```

Think of the levels like this:

```
Python / C
    ↓
Assembly
    ↓
Machine Code (1s and 0s)
    ↓
CPU
```

So the answer is:

### 🎯 **Machine Code**
