## Step 2 — Install Docker Engine

> [!WARNING]
> You must install the **official Docker Engine** — unofficial `apt` packages (`docker.io`, `docker-compose`) will **not** work properly with `docker compose`.

### Documentation Links

| Platform | Install Guide |
|---|---|
| **Ubuntu** | [https://docs.docker.com/engine/install/ubuntu/](https://docs.docker.com/engine/install/ubuntu/) |
| **Debian / Kali** | [https://docs.docker.com/engine/install/debian/](https://docs.docker.com/engine/install/debian/#install-using-the-repository) |

### Remove Conflicting Packages

```bash
sudo apt remove $(dpkg --get-selections docker.io docker-compose docker-compose-v2 docker-doc docker-buildx podman-docker containerd runc | cut -f1)
```

### Set Up Docker's `apt` Repository

```bash
# Add Docker's official GPG key:
sudo apt update
sudo apt install ca-certificates curl
sudo install -m 0755 -d /etc/apt/keyrings
sudo curl -fsSL https://download.docker.com/linux/ubuntu/gpg -o /etc/apt/keyrings/docker.asc
sudo chmod a+r /etc/apt/keyrings/docker.asc

# Add the repository to Apt sources:
sudo tee /etc/apt/sources.list.d/docker.sources <<EOF
Types: deb
URIs: https://download.docker.com/linux/ubuntu
Suites: $(. /etc/os-release && echo "${UBUNTU_CODENAME:-$VERSION_CODENAME}")
Components: stable
Architectures: $(dpkg --print-architecture)
Signed-By: /etc/apt/keyrings/docker.asc
EOF

sudo apt update
```

### Install Docker Packages

```bash
sudo apt install docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin
```

### Verify Installation

```bash
sudo docker run hello-world
```

You should see: `Hello from Docker! This message shows that your installation appears to be working properly.`

## Step 3 — Fix Rust Version (if needed)

If the build fails due to a Rust version issue, update the Dockerfile:

```bash
nano Dockerfile
```

Find:

```
FROM rust:1.84.0
```

Change to:

```
FROM rust:1.85.1
```

Save: **Ctrl + O → Enter → Ctrl + X**

Rebuild:

```bash
sudo docker compose build --no-cache
```

## Step 4 — Launch the Emulator

From inside the project folder:

```bash
sudo docker compose up
```

> [!NOTE]
> First-time build takes approximately **10 minutes** to download and compile all resources. Subsequent starts are fast.

Wait until you see: `project is running` with port 3000.

### Verify the Container is Running

In another terminal:

```bash
sudo docker compose ps
```

Look for:

```
PORTS
0.0.0.0:3000->3000/tcp
```

### Open in Browser

```
http://127.0.0.1:3000/8086-emulator-web/
```

## Step 5 — Stopping the Emulator

> [!CAUTION]
> Don't just close the terminal — this can leave containers hanging and cause issues on next launch.

Always stop properly:

```bash
sudo docker compose down
```

> [!TIP]
> If you can't bring the emulator up after an improper shutdown, run `sudo docker compose down` first — this cleans up hanging containers and usually fixes the issue.
