# 8086 Web Emulator — Interface Introduction

---

## Quick Start Commands

```bash
# Start
sudo docker compose up

# Open in browser
http://127.0.0.1:3000/8086-emulator-web/

# Stop (run in another terminal)
sudo docker compose down
```

## Code Editor / Compiler

![](attachments/Pasted%20image%2020261005231028.png)

### Tutorial

Click the **question mark icon** (❓) to run the built-in tutorial explaining the interface.

### Workflow

1. **Write** assembly code in the editor panel.
2. **Compile** — click the compile button (required before running).
3. **Run** — execute the full program, or:
   - **Next** — step through code line-by-line.
   - **Stop** — halt execution.

### Interface Panels

- **Registers** — displays all register values (AX, BX, CX, DX, etc.)
- **Pointers** — shows pointer register values (SP, BP, SI, DI)
- **Flags** — displays CPU flag states
- **Memory** — inspect memory contents
- **Output** — shows program output (e.g., printed strings)
- **Input** — field for keyboard input capture
- **Download** — save your code as a `.s` file

> [!TIP]
> The web compiler does **not** auto-save code. Always use the **download button** to save your work as a `.s` file. Open saved files in VS Code for editing outside the browser.
