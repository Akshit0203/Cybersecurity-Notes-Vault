### **[Section 1: Navigating the 8086 Web Emulator Interface & Tutorial]**

Now that we've got the emulator installed, we can take a look at some of its features and how to navigate through it before we actually start writing some of our own assembly code. Let's hop over to the computer now and take a look. The browser is still open with the emulator. Once landing on the page, there are two places to go: click "try online 8086 compiler" to jump to the actual emulator, or take a look at the instruction set. Jumping straight over to the compiler allows running through code, with options to navigate to the instruction set from there. When opening the page, the tutorial may start automatically; if not, clicking the question mark icon runs the tutorial, which explains writing code in the editor.

---

### **[Section 2: Executing, Stepping Through Code, and Inspecting Registers & Memory]**

Compiling is required to run the actual code—an interesting term used here because assembly code is assembled rather than compiled. Regardless of terminology, clicking compile is necessary before running. From there, options include running the full script or stepping through it line-by-line using "next," or halting execution using "stop". The interface displays all registers, pointer values, flags, and memory inspection options, as well as a download button for saving code. Running through the sample "hello" program demonstrates these controls, even if the underlying code isn't fully understood yet.

---

### **[Section 3: Running Sample Program, Exporting Code, and Editing in VS Code]**

After compiling, stepping through the instructions using "next" executes the program until the bottom line prints "hello world" in the output panel. Keyboard input can also be captured via the designated input field. Because the web compiler does not save code internally, downloading a local copy as `my assembly code.s` preserves the work. Opening the containing folder allows opening the file in Visual Studio Code. Selecting a color theme like "light modern" makes the interface clearer for screen recordings. Marking the setup steps as done confirms the saved `.s` assembly file. Saving code samples throughout the course allows revisiting them later.

---

### **[Section 4: Accessing the Instruction Set, Theme Configuration, & Wrap-Up]**

Clicking the "I" icon on the instructions page navigates to the instruction set reference. The top of the page lists common terms used throughout the course, while scrolling down reveals detailed instruction categories like arithmetic operations (e.g., `add`) with usage examples. Clicking the chip image returns the view back to the compiler page. A theme toggle allows switching between light and dark themes. This completes the introduction to the 8086 web emulator and wraps up this section of the course, setting up the next section on writing assembly code.
