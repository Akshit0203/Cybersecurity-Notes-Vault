### **Transcript: General Syntax for x86 Assembly**

In this lesson, we're going to learn about the general syntax for x86 assembly. Let's hop over to the whiteboard now and take a look.

In x86 assembly, there are two different types of syntax. The first one is called Intel, like the company, and the other one is actually another company as well—AT&T. In this course, we're just going to be focusing on Intel syntax. However, AT&T is used for some things like the binaries in Linux, where all the GNU binaries are in AT&T syntax. Ultimately, it really doesn't make a huge difference. AT&T is just the reverse order of Intel. Ultimately, if you write it in AT&T or Intel, you can just tell the assembler which one it is, and it will be able to figure it out. This will make more sense once we do some examples.

The general format for Intel syntax is that we first put the instruction that we want to perform, then the destination, and then the source. The destination and the source are referred to as the operands of the instruction. You can think of those like inputs or the parameters of the instruction.

One thing to keep in mind is that not all instructions have operands. Some have no operands, some only have a destination, some only have a source, and of course, some will use both a destination and a source.

An example of this: we already talked about the `mov` instruction, which we use to move data, and we can write something like `MOV AX, BX`. Our destination is `AX` and our source is `BX`. This moves the contents of `BX` into `AX` because `AX` is the destination.

One thing to keep in mind with the operands is they can only be one of three things:

- A **register** (in this case, using the register `BX`).
- **Memory**.
- An **immediate value** (a specific numeric value, like 6, `0x01`, or a binary value).

So the syntax is actually pretty straightforward for the instructions in that we're just able to pass in a destination and a source, and those operands can only be one of these three things. There are some other modifiers—like for example, if we're working with memory, the size of memory that we want (whether it's a byte or a word), which we'll learn about more—but ultimately, this is pretty much the basic gist of how assembly syntax works.

Just really quickly regarding AT&T syntax: the equivalent of `MOV AX, BX` in Intel would be `MOV BX, AX` in AT&T syntax. We're saying that we're going to move `BX` into `AX`. In some ways, it's maybe even a little bit easier to read because you know you're moving `BX` into `AX`, but ultimately it's just the reverse of Intel.

That's going to wrap up this quick lesson on assembly syntax. We'll see you over in the next lesson where we start writing our first assembly and taking a deeper look into the `mov` instruction.
