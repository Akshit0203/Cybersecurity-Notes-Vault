
# Table Related Queries

## `CREATE TABLE`

```sql
CREATE TABLE table_name (
    column_name1 datatype constraint,
    column_name2 datatype constraint
);
```

This defines the **schema** (design) of the table — which columns it has, their data types, and any constraints.

![](../Apna%20College%20Youtube/attachments/Pasted%20image%2020260723214124.png)

### Example

```sql
CREATE TABLE student (
    rollno INT PRIMARY KEY,
    name VARCHAR(50)
);
```

![](../Apna%20College%20Youtube/attachments/Pasted%20image%2020260723214134.png)

| Column | Type | Constraint | Notes |
| --- | --- | --- | --- |
| `rollno` | `INT` | `PRIMARY KEY` | Always **NOT NULL** and **UNIQUE** |
| `name` | `VARCHAR(50)` | — | Up to 50 characters |

After execution, refresh Schemas → `student` table appears with columns `rollno` and `name`:

![](../Apna%20College%20Youtube/attachments/Pasted%20image%2020260723215110.png)

## `DROP TABLE`

Deletes a table and all its data.

```sql
DROP TABLE student;
```

![](../Apna%20College%20Youtube/attachments/Pasted%20image%2020260723214432.png)

---

## Primary Key Rules

A **PRIMARY KEY** has two properties:

1. **NOT NULL** — the value cannot be empty
2. **UNIQUE** — every row must have a different value

---

## Summary

| Command | Purpose |
| --- | --- |
| `CREATE TABLE table_name (...);` | Create a new table with defined columns |
| `DROP TABLE table_name;` | Delete a table permanently |
