
# WHERE Clause

The `WHERE` clause **filters rows** based on a condition. Only rows that satisfy the condition are returned.

> A **clause** is an additional rule/condition applied to a SQL statement.

```sql
SELECT column(s) FROM table_name WHERE condition;
```

---

## Example 1 — Filter by Marks

![577](../Apna%20College%20Youtube/attachments/Pasted%20image%2020260821223543.png)

```sql
SELECT *
FROM student
WHERE marks > 80;
```

![487](../Apna%20College%20Youtube/attachments/Pasted%20image%2020260821223729.png)

Returns only students with marks greater than 80. Students with roll numbers 101 (marks 78) and 105 (marks 12) are excluded because they don't satisfy the condition.

---

## Example 2 — Filter by City

```sql
SELECT *
FROM student
WHERE city = "Mumbai";
```

![540](../Apna%20College%20Youtube/attachments/Pasted%20image%2020260821224109.png)

Returns only students whose city equals "Mumbai".

---

## Example 3 — Combining Conditions with AND

```sql
SELECT *
FROM student
WHERE marks > 80 AND city = "Mumbai";
```

![559](../Apna%20College%20Youtube/attachments/Pasted%20image%2020260821224329.png)

Returns students where **both** conditions are true — marks > 80 **and** city = Mumbai.

> Multiple conditions can be combined using operators like `AND`, `OR`, `NOT` — covered in detail in [[19. Operators]].
