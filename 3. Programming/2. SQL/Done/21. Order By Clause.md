
# ORDER BY Clause

`ORDER BY` sorts the result set in **ascending (ASC)** or **descending (DESC)** order.

```sql
SELECT column(s) FROM table_name
ORDER BY column_name ASC|DESC;
```

> Default is **ascending** (`ASC`) if not specified.

---

## Example 1 — Ascending by Marks

```sql
SELECT *
FROM student
ORDER BY marks ASC;
```

![](../Apna%20College%20Youtube/attachments/Pasted%20image%2020260822224902.png)

Marks appear in increasing order: 12, 78, 82, 85, 93, 96.

---

## Example 2 — Descending by Marks

```sql
SELECT *
FROM student
ORDER BY marks DESC;
```

![](../Apna%20College%20Youtube/attachments/Pasted%20image%2020260822225053.png)

Marks appear in decreasing order: 96, 93, 85, 82, 78, 12.

---

## Example 3 — Combining ORDER BY + LIMIT (Top N Pattern)

**Use case:** Find the top 3 students in the class.

```sql
SELECT *
FROM student
ORDER BY marks DESC
LIMIT 3;
```

![](../Apna%20College%20Youtube/attachments/Pasted%20image%2020260822225137.png)

1. Sort all students by marks in **descending** order (highest first)
2. **Limit** to the first 3 rows → gives us the top 3 students

> Result: Dhruv (96), Bhumika (93), Chetan (85).

---

## Ordering Text Columns

When ordering by a text column (e.g., city), sorting is **alphabetical**:

```sql
SELECT * FROM student ORDER BY city ASC;
```

Delhi → Mumbai → Pune (alphabetical order).

> **Real-world use:** Colleges can find top N students for scholarships or prizes without manually checking marks — just `ORDER BY marks DESC LIMIT N`.
