## Q1: Average Marks per City (Ascending Order)

> Write the query to find the average marks in each city in ascending order.

### Solution

```sql
SELECT city, AVG(marks)
FROM student
GROUP BY city
ORDER BY AVG(marks);
```

![461](../Apna%20College%20Youtube/attachments/Pasted%20image%2020260822233106.png)

> `ORDER BY` defaults to **ascending** if `ASC`/`DESC` is not specified.

### Descending Variant

```sql
SELECT city, AVG(marks)
FROM student
GROUP BY city
ORDER BY AVG(marks) DESC;
```

![502](../Apna%20College%20Youtube/attachments/Pasted%20image%2020260822233128.png)

> For descending order, you **must** explicitly write `DESC`.

## Q2: Total Payments per Payment Method

> Given a `payment` table with columns: `customer_id`, `customer`, `mode`, `city` — find the total number of payments for each payment method.

![](../Apna%20College%20Youtube/attachments/Pasted%20image%2020260822233606.png)

![](../Apna%20College%20Youtube/attachments/Pasted%20image%2020260822233617.png)

### Approach

1. **Identify the grouping column:** We need to group by `mode` (net banking, credit card, debit card)
2. **Count per group:** Use `COUNT(customers)` to count payments in each group

### Solution

```sql
SELECT mode, COUNT(customers)
FROM payment
GROUP BY mode;
```

## Q3: Students per Grade (Sorted)

> Find how many students got each grade, sorted alphabetically.

### Solution

```sql
SELECT grade, COUNT(rollno)
FROM student
GROUP BY grade
ORDER BY grade;
```

![156](../Apna%20College%20Youtube/attachments/Pasted%20image%2020260823080033.png)

| Grade | Count |
| --- | --- |
| A | 2 |
| B | 2 |
| C | 1 |
| F | 1 |

### Approach

1. `GROUP BY grade` → creates one group per unique grade
2. `COUNT(rollno)` → counts students in each group (use `rollno` instead of `name` since names can repeat)
3. `ORDER BY grade` → sorts grades alphabetically

> **Tip for GROUP BY problems:** Always start by asking: *"On what basis do I need to create the group?"* — that column goes in `GROUP BY`.
