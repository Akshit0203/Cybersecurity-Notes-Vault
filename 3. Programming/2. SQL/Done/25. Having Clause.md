
# HAVING Clause

`HAVING` applies conditions **on groups** (created by `GROUP BY`), whereas `WHERE` filters **individual rows**.

| Clause | Filters | Used With |
| --- | --- | --- |
| `WHERE` | Individual **rows** | Before `GROUP BY` |
| `HAVING` | **Groups** | After `GROUP BY` |

---

## Why Not Just Use WHERE?

`WHERE` cannot use aggregate functions. You **cannot** write:

```sql
-- ❌ INVALID: WHERE cannot use MAX()
SELECT city, COUNT(rollno)
FROM student
WHERE MAX(marks) > 90
GROUP BY city;
```

Aggregate functions like `MAX()`, `COUNT()`, `AVG()` only make sense **after grouping**, so you must use `HAVING` instead.

---

## Example — Count Students in Cities Where Max Marks > 90

> Count the number of students in each city, but only for cities where the maximum marks exceed 90.

### Step-by-Step

**Step 1:** Group by city and count students

```sql
SELECT city, COUNT(rollno)
FROM student
GROUP BY city;
```

This gives: Pune (1), Mumbai (2), Delhi (3).

**Step 2:** Add the HAVING condition

```sql
SELECT city, COUNT(rollno)
FROM student
GROUP BY city
HAVING MAX(marks) > 90;
```

### Result

| City | Count | Max Marks | Included? |
| --- | --- | --- | --- |
| Mumbai | 2 | 93 | ✅ (93 > 90) |
| Delhi | 3 | 96 | ✅ (96 > 90) |
| Pune | 1 | 78 | ❌ (78 < 90) |

Pune is excluded because its maximum marks (78) don't exceed 90.

> **Rule:** `WHERE` filters rows *before* grouping. `HAVING` filters groups *after* grouping.
