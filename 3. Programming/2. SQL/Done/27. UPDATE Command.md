
# UPDATE Command

`UPDATE` modifies **existing rows** in a table.

```sql
UPDATE table_name
SET col1 = val1, col2 = val2
WHERE condition;
```

> **Rule:** Without a `WHERE` clause, `UPDATE` changes **every row** in the table.

---

## Safe Update Mode

MySQL has a **safe update mode** enabled by default that prevents accidental mass updates. If you get `Error 1175: You are using safe update mode`, disable it first:

```sql
SET SQL_SAFE_UPDATES = 0;
```

| Value | Meaning |
| --- | --- |
| `0` | Safe mode **OFF** |
| `1` | Safe mode **ON** (default) |

---

## Example 1 — Update by Matching Value

Change all `A` grades to `O` (Outstanding):

```sql
UPDATE student
SET grade = "O"
WHERE grade = "A";
```

## Example 2 — Update a Specific Row

Change marks for a specific student by roll number:

```sql
UPDATE student
SET marks = 82
WHERE rollno = 101;

SELECT * FROM student;
```

---

## Example 3 — Update with BETWEEN

Set grade to `B` for all students with marks between 80 and 90:

```sql
UPDATE student
SET grade = "B"
WHERE marks BETWEEN 80 AND 90;

SELECT * FROM student;
```

## Example 4 — Update All Rows (No WHERE)

Increase every student's marks by 1 (e.g., one MCQ was incorrect in the exam):

```sql
UPDATE student
SET marks = marks + 1;

SELECT * FROM student;
```

![](../Apna%20College%20Youtube/attachments/Pasted%20image%2020260823173616.png)

> When no `WHERE` is specified, the update applies to **all rows** — here every student's marks increase by one.
