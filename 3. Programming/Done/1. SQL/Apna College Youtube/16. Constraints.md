
# Constraints

SQL constraints are **rules applied to columns** that control what kind of data can be stored.

---

## 1. NOT NULL

The column **cannot have a NULL (empty) value** — a value must always be provided.

```sql
col1 INT NOT NULL
```

---

## 2. UNIQUE

**All values in the column must be different** — no duplicate entries allowed.

```sql
col2 INT UNIQUE
```

### Example

```sql
CREATE DATABASE college;
USE college;

CREATE TABLE temp1 (
	id INT UNIQUE
);

INSERT INTO temp1 VALUES (101);  -- ✅ succeeds
INSERT INTO temp1 VALUES (101);  -- ❌ fails: duplicate entry

SELECT * FROM temp1;
```

---

## 3. PRIMARY KEY

Makes a column **UNIQUE + NOT NULL**. Only **one** primary key per table.

### Syntax — Inline

```sql
CREATE TABLE temp1 (
	id INT PRIMARY KEY
);
```

### Syntax — At the End (single column)

```sql
CREATE TABLE temp1 (
	id INT,
    name VARCHAR(50),
    age INT,
    city VARCHAR(20),
    PRIMARY KEY(id)
);
```

### Syntax — Composite Primary Key (multiple columns)

```sql
CREATE TABLE temp1 (
	id INT,
    name VARCHAR(50),
    age INT,
    city VARCHAR(20),
    PRIMARY KEY(id, name)
);
```

> With a **composite primary key**, individual columns *can* have duplicates, but the **combination** of both must always be unique.

---

## 4. FOREIGN KEY

**Links two tables together** by referencing the primary key of another table.

```sql
CREATE TABLE temp (
    cust_id INT,
    FOREIGN KEY (cust_id) REFERENCES customer(id)
);
```

**Syntax pattern:**

```
FOREIGN KEY (column_in_this_table) REFERENCES other_table(primary_key_column)
```

> `REFERENCES` means this column's values are defined by and refer to the primary key of the other table.

---

## 5. DEFAULT

Sets a **default value** for a column when no value is provided during INSERT.

```sql
salary INT DEFAULT 25000
```

### Example

![394](attachments/Pasted%20image%2020260821173523.png)

```sql
CREATE TABLE emp (
	id INT,
    salary INT DEFAULT 25000
);

INSERT INTO emp (id) VALUES (101);  -- salary not specified
SELECT * FROM emp;
```

![325](attachments/Pasted%20image%2020260821180750.png)

> Since no salary was given, the default value of `25000` was automatically inserted.

---

## 6. CHECK

**Limits the values allowed** in a column by applying a condition.

### Syntax — Named Constraint

```sql
CREATE TABLE city (
    id INT PRIMARY KEY,
    city VARCHAR(50),
    age INT,
    CONSTRAINT age_check CHECK (age >= 18 AND city = "Delhi")
);
```

### Syntax — Inline

```sql
CREATE TABLE newTab (
    age INT CHECK (age >= 18)
);
```

> The `CONSTRAINT constraint_name` part is optional — you can name your constraints for clarity, or skip the name entirely.

---

## Summary

| Constraint | Purpose |
| --- | --- |
| `NOT NULL` | Column cannot be empty |
| `UNIQUE` | All values must be different |
| `PRIMARY KEY` | Unique + Not Null (one per table) |
| `FOREIGN KEY` | Links to another table's primary key |
| `DEFAULT` | Auto-fills a value when none is provided |
| `CHECK` | Validates data against a condition before inserting |
