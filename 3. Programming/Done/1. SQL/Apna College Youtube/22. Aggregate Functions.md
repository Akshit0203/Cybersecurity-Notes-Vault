
# Aggregate Functions

Aggregate functions **perform a calculation on a set of values** and **return a single value**.

| Function | Purpose |
| --- | --- |
| `COUNT()` | Count the number of rows |
| `MAX()` | Find the maximum value |
| `MIN()` | Find the minimum value |
| `SUM()` | Calculate the total sum |
| `AVG()` | Calculate the average |

> Think of aggregate functions as buttons — each one has a fixed job. You give it many values, it returns one result.

---

## MAX — Maximum Value

```sql

FROM student;
```

---

## How They Work

1. Without an aggregate function: `SELECT marks FROM student;` → returns a **list** of all marks
2. With an aggregate function: `SELECT MAX(marks) FROM student;` → returns a **single value** (the maximum)

> Aggregate functions collapse many rows into one result. They are commonly used with `GROUP BY` to get per-group summaries (covered in [[23. Group By Clause]]).
