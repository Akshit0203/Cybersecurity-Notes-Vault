
# GROUP BY Clause

`GROUP BY` **groups rows that share the same values** into summary rows, then lets you apply aggregate functions to each group.

```sql
SELECT column(s), aggregate_function(column)
FROM table_name
GROUP BY column(s);
```

> Generally, `GROUP BY` is used **together with aggregate functions** (COUNT, MAX, MIN, AVG, SUM).

---

## Example 1 — Grouping by City

```sql
SELECT city
FROM student
GROUP BY city;
```

![177](attachments/Pasted%20image%2020260822231321.png)

Creates three groups (one for each unique city): Pune, Mumbai, Delhi.

---

## Example 2 — Count Students per City

```sql
SELECT city, COUNT(rollno)
FROM student
GROUP BY city;
```

![411](attachments/Pasted%20image%2020260822231925.png)

| City | Count |
| --- | --- |
| Delhi | 3 |
| Mumbai | 2 |
| Pune | 1 |

---

## Example 3 — Grouping by Multiple Columns

```sql
SELECT city, name, COUNT(rollno)
FROM student
GROUP BY city, name;
```

![444](attachments/Pasted%20image%2020260822232205.png)

When grouping by both `city` and `name`, each unique combination becomes its own group.

---

## Important Rule

> **Every column in `SELECT` that is NOT inside an aggregate function MUST appear in the `GROUP BY` clause.**

```sql
-- ❌ ERROR: 'name' is selected but not in GROUP BY
SELECT city, name, COUNT(rollno)
FROM student
GROUP BY city;

-- ✅ CORRECT: both 'city' and 'name' are in GROUP BY
SELECT city, name, COUNT(rollno)
FROM student
GROUP BY city, name;
```

> MySQL Error Code `1055` occurs if you violate this rule.

---

## Example 4 — Average Marks per City

```sql
SELECT city, AVG(marks)
FROM student
GROUP BY city;
```

| City | AVG(marks) |
| --- | --- |
| Pune | 78 |
| Mumbai | 89 |
| Delhi | 63.3 |

> Think of `GROUP BY` as: (1) split rows into groups → (2) apply aggregate function to each group → (3) return one summary row per group.
