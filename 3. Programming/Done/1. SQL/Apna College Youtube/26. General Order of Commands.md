
# General Order of Commands

SQL clauses must be written in a **specific order**:

```sql
SELECT column(s)               -- Which columns to view
FROM table_name                -- The table to query
WHERE condition                -- Filter individual rows (BEFORE grouping)
GROUP BY column(s)             -- Group rows with same values
HAVING condition               -- Filter groups (AFTER grouping)
ORDER BY column(s) ASC|DESC;   -- Sort the final output
```

---

## Two Golden Rules

1. **`WHERE` filters individual rows** — `HAVING` filters summary groups
2. **`WHERE` always comes BEFORE `GROUP BY`** — `HAVING` always comes AFTER `GROUP BY`

---

## Example 1

```sql
SELECT city
FROM student
WHERE grade = "A"
GROUP BY city
HAVING MAX(marks) > 90;
```

![129](attachments/Pasted%20image%2020260823082211.png)

1. `WHERE grade = "A"` → keeps only grade A students
2. `GROUP BY city` → groups remaining students by city
3. `HAVING MAX(marks) > 90` → keeps only groups where max marks exceed 90

---

## Example 2

```sql
SELECT city
FROM student
WHERE grade = "A"
GROUP BY city
HAVING MAX(marks) >= 93
ORDER BY city ASC;
```
