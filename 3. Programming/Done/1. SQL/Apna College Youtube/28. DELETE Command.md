
# DELETE Command

`DELETE` removes **existing rows** from a table.

```sql
DELETE FROM table_name
WHERE condition;
```

> **⚠️ Caution:** Once data is deleted from the database, it usually **cannot be recovered**. Always double-check your `WHERE` condition before executing.

---

## Example — Delete by Condition

Delete all students who scored less than 33 marks:

```sql
DELETE FROM student
WHERE marks < 33;

SELECT * FROM student;
```

## DELETE Without WHERE

If you omit the `WHERE` clause, **all rows** in the table are deleted:

```sql
DELETE FROM student;
```

> This removes all data but the table structure still exists (unlike `DROP TABLE`).

---

## DELETE vs DROP vs TRUNCATE

| Command | What It Removes |
| --- | --- |
| `DELETE FROM table WHERE …` | Specific **rows** matching the condition |
| `DELETE FROM table` | **All rows** (table structure remains) |
| `TRUNCATE TABLE table` | **All data** (table structure remains, faster) |
| `DROP TABLE table` | The **entire table** (structure + data) |
