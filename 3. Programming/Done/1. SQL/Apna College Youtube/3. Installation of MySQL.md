
# Installation of MySQL

> The different databases may have slightly different flavors of SQL, but the majority of things remain the same. What we learn in this course can be applied to any relational database.

---

![](attachments/Pasted%20image%2020260723143946.png)

![](attachments/Pasted%20image%2020260723144316.png)

17. The Workbench window opens — write queries in the middle editor area

![](attachments/Pasted%20image%2020260723144853.png)

### Increase the SQL Editor Font Size

1. Go to **Edit → Preferences**
2. Click **Fonts & Colors**
3. Increase:
    - **SQL Editor Font**
    - **Result Grid Font**
    - **Script Editor Font**
4. Recommended: **Font:** Consolas, **Size:** 16–18 pt
5. Click **Apply** → **OK** → Restart Workbench if needed.
