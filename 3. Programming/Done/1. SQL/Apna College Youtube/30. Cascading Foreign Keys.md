
# Cascading Foreign Keys

**Cascading** means that when a change happens in the **parent table**, the same change is **automatically reflected** in the **child table** through the foreign key.

---

## ON DELETE CASCADE

When the referenced row is **deleted** in the parent table, all referencing rows in the child table are **also deleted**.

## ON UPDATE CASCADE

When the referenced row is **updated** in the parent table, all referencing rows in the child table are **also updated**.

---

## Syntax

Add cascading when defining the foreign key:

```sql
CREATE TABLE teacher (
	id INT PRIMARY KEY,
	name VARCHAR(50),
	dept_id INT,
	FOREIGN KEY (dept_id) REFERENCES dept(id)
	    ON UPDATE CASCADE
	    ON DELETE CASCADE
);
```

> If you **do not** want changes to cascade, simply omit the `ON UPDATE CASCADE` and `ON DELETE CASCADE` clauses.

---

## Practical Demonstration

### Step 1 — Create Tables and Insert Data

```sql
CREATE TABLE dept (
	id INT PRIMARY KEY,
	name VARCHAR(50)
);

INSERT INTO dept
VALUES 
(101, "english"),
(102, "IT");

SELECT * FROM dept;
```

```sql
CREATE TABLE teacher (
	id INT PRIMARY KEY,
	name VARCHAR(50),
	dept_id INT,
	FOREIGN KEY (dept_id) REFERENCES dept(id)
	    ON UPDATE CASCADE
	    ON DELETE CASCADE
);

INSERT INTO teacher
VALUES
(101, "Adam", 101),
(102, "Eve", 102);

SELECT * FROM teacher;
```

### Step 2 — Update Parent and Watch the Cascade

Change the IT department's ID from `102` to `103` in the parent table:

```sql
UPDATE dept
SET id = 103
WHERE id = 102;
```

**Result:** Even though no manual changes were made to the `teacher` table, Eve's `dept_id` **automatically updated from 102 to 103**.

---

### Step 3 — Another Cascaded Update

Change the English department's ID from `101` to `111`:

```sql
UPDATE dept
SET id = 111
WHERE id = 101;
```

**Result:** Adam's `dept_id` in the teacher table **automatically changed to 111**.

---

## When to Use Cascading

> Wherever foreign keys are used, always consider whether cascading is needed. It is frequently required — for example, if a department code changes, every employee under that department should automatically reflect the new code.
