
# ALTER Command

`ALTER` changes the **schema** (structure) of a table — its columns, data types, and constraints.

---

## 1. ADD Column

Add a new column to an existing table:

```sql
ALTER TABLE table_name
ADD COLUMN column_name datatype constraint;
```

### Example

```sql
ALTER TABLE student
ADD COLUMN age INT;
```

A new `age` column is added with all values initially set to `NULL`.

---

## 2. DROP Column

Remove a column from a table:

```sql
ALTER TABLE table_name
DROP COLUMN column_name;
```

### Example

```sql
ALTER TABLE student
DROP COLUMN age;
```

---

## 3. RENAME Table

Change the name of an existing table:

```sql
ALTER TABLE table_name
RENAME TO new_table_name;
```

---

## Summary

| Operation | Syntax |
| --- | --- |
| **Add column** | `ALTER TABLE t ADD COLUMN col datatype;` |
| **Drop column** | `ALTER TABLE t DROP COLUMN col;` |
| **Rename table** | `ALTER TABLE t RENAME TO new_name;` |

> **Schema** = the table's design — which columns exist, their data types, and their constraints.
