
# Practice Questions

Perform the following operations on the `student` table.

---

## Part A — Rename a Column

> Change the name of column `name` to `full_name`.

Since this is a **schema change** (renaming a column), use `ALTER TABLE` with `CHANGE`:

```sql
ALTER TABLE student
CHANGE COLUMN name full_name VARCHAR(50);
```

```sql
SELECT * FROM student;
```

The column header now shows `full_name` instead of `name`.

---

## Part B — Delete Rows by Condition

> Delete all the students who scored marks less than 80.

Since this is a **data change** (removing rows), use `DELETE`:

```sql
DELETE FROM student
WHERE marks < 80;
```

After execution, only students with marks ≥ 80 remain.

---

## Part C — Delete a Column

> Delete the column for grades.

Since this is a **schema change** (removing a column), use `ALTER TABLE` with `DROP COLUMN`:

```sql
ALTER TABLE student
DROP COLUMN grade;
```

The `grade` column no longer exists in the table.

---

## Key Distinction

| Operation | Command | Why |
| --- | --- | --- |
| Rename a column | `ALTER TABLE … CHANGE` | Changes the **structure** (schema) |
| Delete rows | `DELETE FROM … WHERE` | Removes **data** (rows) |
| Delete a column | `ALTER TABLE … DROP COLUMN` | Changes the **structure** (schema) |

> **`ALTER` changes the structure of a table**, while **`DELETE` removes data (rows)**.
