
# MySQL Views

A **view** is a virtual table based on the result set of a `SELECT` statement. It does not store data itself — the database engine **recreates** it every time you query it, so it always shows **up-to-date data**.

---

## Creating a View

```sql
CREATE VIEW view1 AS
SELECT rollno, name FROM student;
```

### Querying the view

```sql
SELECT * FROM view1;
```

![](attachments/Pasted%20image%2020260826091419.png)

The view behaves like a regular table — you can use `WHERE`, `ORDER BY`, etc.:

```sql
SELECT * FROM view1
WHERE marks > 90;
```

![](attachments/Pasted%20image%2020260826091906.png)

> If the view needs to include additional columns, recreate it:
> ```sql
> CREATE VIEW view1 AS
> SELECT rollno, name, marks FROM student;
> ```

---

## Dropping a View

```sql
DROP VIEW view1;
```

This removes the view definition. The underlying table data is **not affected**.
