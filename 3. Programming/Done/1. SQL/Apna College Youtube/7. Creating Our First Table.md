
# Creating Our First Table

## `CREATE TABLE` Syntax

```sql
USE db_name;

CREATE TABLE table_name (
    column_name1 datatype constraint,
    column_name2 datatype constraint,
    column_name3 datatype constraint
);
```

When creating a table, you define its **schema (design)** by specifying the columns, their data types, and any constraints.

---

## Example: Student Table

```sql
CREATE TABLE student (
    id INT PRIMARY KEY,
    name VARCHAR(50),
    age INT NOT NULL
);
```

![](attachments/Pasted%20image%2020260723184447.png)

| Column | Datatype | Constraint | Meaning |
| --- | --- | --- | --- |
| `id` | `INT` | `PRIMARY KEY` | Integer; must be unique and not null |
| `name` | `VARCHAR(50)` | — | String up to 50 characters |
| `age` | `INT` | `NOT NULL` | Integer; cannot be empty |

After execution:

![](attachments/Pasted%20image%2020260723184820.png)

Refresh the Schemas panel → the `student` table appears under `college` → expanding **Columns** shows `id`, `name`, `age`.

---

## Inserting Data (Preview)

```sql
INSERT INTO student VALUES (1, "AMAN", 26);
INSERT INTO student VALUES (2, "SHRADHA", 24);
```

> **Primary Key** must always be **unique**. Inserting a duplicate ID causes an error: `Error Code: Duplicate entry '1'`.
