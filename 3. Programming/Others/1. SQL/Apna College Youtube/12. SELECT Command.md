
# SELECT Command

`SELECT` is a **DQL (Data Query Language)** command used to retrieve and view data from a table.

## Syntax

```sql
SELECT * FROM table_name;
```

- `*` (asterisk/star) = select **all columns and all rows**

## Example

```sql
SELECT * FROM student;
```

![](attachments/Pasted%20image%2020260723220907.png)

This prints the entire `student` table. If no data has been inserted yet, the table structure appears but with no rows.

> `SELECT` is extensive and has many features (filtering, sorting, grouping, etc.) — these are covered in detail in [[9. Types of SQL Commands]].
