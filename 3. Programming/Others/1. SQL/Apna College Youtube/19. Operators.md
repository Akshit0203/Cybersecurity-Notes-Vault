
# Operators

Operators are used with the `WHERE` clause to define conditions for filtering data.

---

## Types of Operators

| Type | Operators |
| --- | --- |
| **Arithmetic** | `+` (add), `-` (subtract), `*` (multiply), `/` (divide), `%` (modulus/remainder) |
| **Comparison** | `=`, `!=`, `>`, `>=`, `<`, `<=` |
| **Logical** | `AND`, `OR`, `NOT`, `IN`, `BETWEEN`, `ALL`, `LIKE`, `ANY` |
| **Bitwise** | `&` (AND), `\|` (OR) |

---

## Arithmetic Operators

Standard math operators. **Modulus (`%`)** returns the remainder of a division.

```sql
-- Students whose marks + 10 exceed 100
SELECT * FROM student WHERE marks + 10 > 100;
```

> `93 + 10 = 103 > 100` ✅ and `96 + 10 = 106 > 100` ✅ — only these two students are returned.

---

## Comparison Operators

Used to compare values:

```sql
-- Students with marks exactly equal to 93
SELECT * FROM student WHERE marks = 93;

-- Students with marks greater than 90
SELECT * FROM student WHERE marks > 90;
```

---

## Logical Operators (Detail)

### 1. AND

**Both** conditions must be true.

```sql
SELECT * FROM student WHERE marks > 90 AND city = "Mumbai";
```

> Only returns students where marks > 90 **and** city = Mumbai. If a student satisfies only one condition, they are excluded.

---

### 2. OR

**At least one** condition must be true.

```sql
SELECT * FROM student WHERE marks > 90 OR city = "Mumbai";
```

> Returns Bhumika (both true), Chetan (city true), and Dhruv (marks true). Any student satisfying *at least one* condition appears.

---

### 3. BETWEEN

Selects values within a **range** (inclusive on both ends).

```sql
SELECT * FROM student WHERE marks BETWEEN 80 AND 90;
```

> Returns students with marks from 80 to 90, **including** 80 and 90. Result: marks 85 and 82.

---

### 4. IN

Matches against **any value in a list**.

```sql
SELECT *
FROM student
WHERE city IN ("Delhi", "Mumbai", "Gurugram");
```

![](attachments/Pasted%20image%2020260822223126.png)

> Returns all students whose city matches any value in the list. If a listed city doesn't exist in the data (e.g., "Gurugram"), no error occurs — it simply finds no matches for that value.

---

### 5. NOT

**Negates** (reverses) a condition.

```sql
SELECT * FROM student WHERE city NOT IN ("Delhi", "Mumbai");
```

![](attachments/Pasted%20image%2020260822223252.png)

> Returns students who do **not** live in Delhi or Mumbai. Result: only the student from Pune.
