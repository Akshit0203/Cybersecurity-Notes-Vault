
# LIMIT Clause

`LIMIT` sets an **upper limit** on the number of rows returned.

```sql
SELECT column(s) FROM table_name
LIMIT number;
```

---

## Example 1 — Basic Limit

```sql
SELECT * FROM student LIMIT 3;
```

![](attachments/Pasted%20image%2020260822223615.png)

Returns only the **first 3 rows** of the student table (rollno 101, 102, 103).

---

## Example 2 — LIMIT with WHERE

```sql
SELECT *
FROM student
WHERE marks > 75
LIMIT 3;
```

![](attachments/Pasted%20image%2020260822223711.png)

First filters to students with marks > 75 (would return 5 students), then limits to only the **first 3** from that filtered set.

> All clauses (WHERE, ORDER BY, LIMIT, etc.) can be **combined** together in a single statement.
