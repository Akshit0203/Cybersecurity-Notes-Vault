
# CHANGE and MODIFY Commands

Both are used with `ALTER TABLE` to modify existing columns, but they serve different purposes.

| Command | Purpose |
| --- | --- |
| `CHANGE` | **Rename** a column (and optionally change its datatype/constraint) |
| `MODIFY` | **Change the datatype or constraint** of a column (name stays the same) |

---

## CHANGE COLUMN — Rename a Column

```sql
ALTER TABLE table_name
CHANGE COLUMN old_name new_name new_datatype new_constraint;
```

> Even if you only want to rename the column and keep the same type, you **must** re-specify the datatype.

---

## MODIFY COLUMN — Change Datatype or Constraint

```sql
ALTER TABLE table_name
MODIFY col_name new_datatype new_constraint;
```

---

## Walkthrough — Full Example

### Step 1 — ADD a Column with DEFAULT

Add an `age` column with a `NOT NULL` constraint and a default value of `19`:

```sql
ALTER TABLE student
ADD COLUMN age INT NOT NULL DEFAULT 19;

SELECT * FROM student;
```

![532](attachments/Pasted%20image%2020260823222319.png)

All existing students now have `age = 19` (the default value).

---

### Step 2 — MODIFY the Datatype

Change `age` from `INT` to `VARCHAR(2)`:

```sql
ALTER TABLE student
MODIFY age VARCHAR(2);
```

Existing values (`19`) fit within `VARCHAR(2)`, so no error occurs.

However, if you try to insert a student with `age = 100`, it fails:

```sql
INSERT INTO student
(rollno, name, marks, age)
VALUES
(107, "gargi", 68, 100);
```

> **Error:** `Data too long for column 'age'` — `100` is 3 characters, but `VARCHAR(2)` only allows 2.

---

### Step 3 — CHANGE the Column Name and Type

Rename `age` to `stu_age` and change its type back to `INT`:

```sql
ALTER TABLE student
CHANGE age stu_age INT;
```

Now the insert with `age = 100` succeeds:

```sql
INSERT INTO student
(rollno, name, marks, stu_age)
VALUES
(107, "gargi", 68, 100);
```

---

### Step 4 — DROP the Column

```sql
ALTER TABLE student
DROP COLUMN stu_age;
```

### Step 5 — RENAME the Table

```sql
ALTER TABLE student
RENAME TO stu;
```

![](attachments/Pasted%20image%2020260823230509.png)

The table is now called `stu`. To rename it back:

```sql
ALTER TABLE stu
RENAME TO student;

SELECT * FROM student;
```

## Summary

| Operation | Command | Syntax |
| --- | --- | --- |
| Rename column | `CHANGE` | `ALTER TABLE t CHANGE old new datatype;` |
| Change type/constraint | `MODIFY` | `ALTER TABLE t MODIFY col new_datatype;` |
| Add column | `ADD COLUMN` | `ALTER TABLE t ADD COLUMN col datatype;` |
| Drop column | `DROP COLUMN` | `ALTER TABLE t DROP COLUMN col;` |
| Rename table | `RENAME TO` | `ALTER TABLE t RENAME TO new_name;` |
