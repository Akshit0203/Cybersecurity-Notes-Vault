
# TRUNCATE Command

`TRUNCATE` deletes **all data** from a table but keeps the table structure intact.

```sql
TRUNCATE TABLE table_name;
```

---

## DROP vs TRUNCATE

| Command | Deletes | Table Still Exists? |
| --- | --- | --- |
| `DROP TABLE` | The **entire table** (structure + data) | ❌ No |
| `TRUNCATE TABLE` | Only the **data** (all rows) | ✅ Yes |

> After `TRUNCATE`, the table is empty but still exists — you can re-insert data into it immediately.

## When to Use

- **Need to remove all rows quickly?** → Use `TRUNCATE`
- **Need to remove the table entirely?** → Use `DROP TABLE`
- **Need to remove specific rows?** → Use `DELETE FROM … WHERE …`
