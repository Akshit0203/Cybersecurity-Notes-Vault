Create this sample table

```sql
CREATE DATABASE college;
USE college;

CREATE TABLE student (
	rollno INT PRIMARY KEY,
	name VARCHAR(50),
	marks INT NOT NULL,
	grade VARCHAR(1),
	city VARCHAR(20)
);
```


"The job of SELECT is that whenever we need to select and see some data from within the database, we use our SELECT command for that. So its basic syntax is that we write SELECT, and after that, whichever columns we want the data for, we write the names of those columns, then we write FROM, and then our table's name. So let's talk about it once for this table of ours. This is our table inside which roll number, name, marks, grade, city, etc., are stored for us. So let's select something from here; let's select, let's suppose, we want to see all students' names and we want to see all students' marks..."

"...from which table? From our student table. Let's highlight this much part and run it. So this table of ours has come up. Inside the table, the two columns we wrote, name and marks—so we got all the names and we got all the marks. So in this way, our SELECT works. If we want, we can write multiple things here, and if we want, we can also write a star here. **The star, which is our asterisk, does the job of selecting all columns**. So instead of writing the names of all the columns, we developed a short form..."

"...that **whenever we write star, star means select the data of all columns**. So now let's run this once. On running it, our entire table has come to us: roll numbers have come, names have come, marks have come, grades have come. If we want, we can expand it: our grades have come, and our cities have come to us. Now here, we can do one more thing. Let's suppose we wrote `SELECT city FROM student`. So when we execute this, we will get all the cities. Now here, we can use another special keyword, which is the **DISTINCT** keyword."

"If we write **SELECT DISTINCT city FROM student**. **DISTINCT means unique—meaning, the things that are repeating, the duplicate values, won't be visible; all unique values will be visible**. So with its help, we get unique values. So this time, under cities, only Pune, Mumbai, and Delhi are coming; things are not repeating. So whenever we need this kind of data where we don't want repetition or duplicate values, there we can also use the DISTINCT keyword along with it."
