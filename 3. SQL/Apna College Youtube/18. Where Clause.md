"Now next, we are going to talk about the **Where Clause**. Whenever we use SELECT, we can use several clauses along with SELECT. The meaning of a clause is like inside legal documents—if we have heard things related to lawyers, they have clauses inside them. Clause meaning condition—that we have applied some extra rule that this thing should also happen along with it, this extra condition must also be fulfilled. So this is the job of our clauses.

So we have multiple clauses inside SQL which are used with the SELECT statement. Among these, one clause of ours is the **Where Clause**. The job of the Where Clause is **to define some conditions**. Like, we write SELECT some columns FROM table, so it selects that much, but along with that, let’s suppose we want some condition—that we want to see students' marks, but we want to see only those students' marks whose marks are greater than 75. Like here we have taken an example:

```
SELECT * FROM student WHERE marks > 80;
```

This means we only want to show the data of those children whose marks are greater than 80.

Now, greater [than] is an operator of ours, a math operator. We have written greater [than] inside math, and we have written equal to inside math. So we write WHERE, and after that, we apply some of our conditions, based on which some output of ours is going to be returned. So let's try this once. We will write here: SELECT all—we are going to pronounce this star as 'all'—all FROM our student table WHERE our marks, the student's marks, must be greater than 80.

Now, if we want, we can write this statement in this way:

```
SELECT * FROM student WHERE marks > 80;
```

Let's highlight this much and execute. So all of our students have appeared, and all of these students' marks are 80+; this means that whatever students—four students have been printed—all four have marks that are 80+. Even though we had a lot of students inside our table, this student with roll number 105 and this student with roll number 101, their marks were not printed, and their details were not printed. Why? Because they do not satisfy our WHERE condition.

Similarly, we can write another condition:

```
SELECT * FROM student WHERE city = "Mumbai";
```

This means wherever the value of city is equal to Mumbai, all of those students' details should come. So let's change it right here, let's write `city =` and then our string `"Mumbai"`. Let's execute this part. So now, the information of only those students has come for whom the value of city is equal to Mumbai.

And if we want, we can also club multiple conditions together and write them. Like here, we can write that the marks should also be greater than 80, and our city should also be equal to Mumbai. Let's execute this once. So we got two students; both students' marks are also greater than 80, and both students' city is also equal to Mumbai.

Now, just like we clubbed these two conditions, there are several different ways to club—meaning, to connect—two conditions together. And here, we are going to study about our operators.
