
# What is a Table?

A table is a combination of **rows** and **columns**.

![](../Apna%20College%20Youtube/attachments/Pasted%20image%2020260723150903.png)

- **Columns** (vertical) define the **structure/schema** of the table — they tell us *what kind* of information is stored (e.g., roll number, name, class, DOB, gender, city, marks).
- **Rows** (horizontal) contain the **actual data** for each individual record — one row = one student's complete data.

### Schema = Design

The **schema** (or design) of a table is defined by its columns. By looking at the columns, you know what information the table stores.

> Whenever we create a table, we need to tell the database **which columns** it should have so the table's design is formed accordingly.
