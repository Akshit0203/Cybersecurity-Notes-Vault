# Limit Clause

Sets an upper limit on number of (tuples) rows to be returned

```
SELECT * FROM student LIMIT 3;
```

![](attachments/Pasted%20image%2020260822223615.png)


```
SELECT col1, col2 FROM table_name
LIMIT number;
```


```
SELECT *
FROM student 
WHERE marks > 75
LIMIT 3;
```

![](attachments/Pasted%20image%2020260822223711.png)

"Now next, we are going to talk about another interesting clause, which is our **Limit Clause**.

**Wherever we write limit, what it will do is apply a limit on our number of rows**. For example, if we want the data of only five students inside our database, or only two students' data, then what will it do? It will apply a limit there.

So, **if I wrote** **SELECT * FROM student LIMIT 3****, then I will get the data of only three students**. So we simply write our SELECT statement, after that we use our Limit Clause—meaning we write `LIMIT` and then we can define any number.

Like, here we can write SELECT all FROM student, and here let's apply our Limit Clause: `LIMIT` and here we write that we want the data of only three students. Let's select and execute this. **So the data of the first three students—101, 102, and 103—has come to us**.

We can also apply conditions on the limit if we want, like we can write here: WHERE, let's make it `marks > 75`. So what did this do? We are selecting the data of all those students and from them we are shortlisting those whose marks are greater than 75. So, with this, we would get all the students whose marks are greater than 75, but we only want three such students, so here we applied a limit of three.

So on executing this entire combined statement, we got three students whose marks are greater than 75. But if we hadn't applied the limit, then we might have gotten a lot of students. Let's execute this [without limit]: so in this case, we got five students.

**So in this way, our limit can be used with our Where Clause as well**. In fact, all the clauses we will study can be combined and used together inside a single statement."
