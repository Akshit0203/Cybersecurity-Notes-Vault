# Order By Clause

To sort in ascending (ASC) or descending order (DESC)


```
SELECT * FROM student ORDER BY city ASC;
```


```
SELECT col1, col2 FROM table_name
ORDER BY col_name(s) ASC;
```




```
SELECT *
FROM student 
ORDER BY marks ASC;
```

![](attachments/Pasted%20image%2020260822224902.png)

```
SELECT *
FROM student 
ORDER BY marks DESC;
```

![](attachments/Pasted%20image%2020260822225053.png)

```
SELECT *
FROM student 
ORDER BY marks DESC
LIMIT 3;
```

"Now next, the clause we are going to talk about is our **Order By Clause**.

Sometimes it happens with us that **we need data either in ascending order or in descending order**. For example, when we have many numbers, we want data in an increasing order like `1, 2, 3, 4, 5` or we want data in a decreasing order like `5, 4, 3, 2, 1`. We call the increasing order 'ascending' and the decreasing order we call 'descending'. **So, we pick a few of their initial letters and accordingly we can order our data**. To order means to arrange that data in any ascending or descending fashion.

Like, let's suppose we want our students' data, but we want it to come in ascending order according to city—so that **the city starting with 'A' comes first, the one starting with 'B' comes later, and the one starting with 'C' comes after that**.

So, if we want data in ascending order like this, for that we can write:

```
SELECT * FROM student ORDER BY city ASC;
```

This means—what should the order be? We should have ascending order according to the city. So in that, **Delhi will come first, then our Mumbai will come, and then our Pune will come**.

Let's select and run this. So first, all of our Delhi students have come, then Mumbai students have come, and then our Pune students have come. If we want, we can also apply ascending order on the basis of marks. Like, we applied it on the basis of marks, let's select this—so **all the marks have come in an increasing fashion. These are our increasing marks**.

Now let's suppose we want the data of the **top three students of the class**. What can we do for that?

We will select all of the students. Now, we don't know whether the maximum marks are 75, or 85, or 95—we have no idea. **So first of all, we will arrange the data in decreasing order so that we get the marks in a decreasing fashion—meaning the highest marks should appear at the very top**.

So we did this, and the highest marks came on top, and then they kept going down, down, down, down. Now what will we do? **On top of this itself, we can apply our limit**. Here we have applied a limit that we want only the top three students' marks. So, because the marks have come in a decreasing fashion at the top, we will pick the top three, and we will get the marks of the top three students.

Let's execute this:

```
SELECT * FROM student ORDER BY marks DESC LIMIT 3;
```

So what happened? **We got the marks of the top three students of the class—the marks of Dhruv, Bhumika, and Chetan**.

So this is how we arrange multiple clauses. And for real-life situations that can arise—like **it can happen that a college sometimes gives scholarships or sometimes offers some other prizes**—if the students' data is stored inside the database, the college doesn't know how many marks a student has got, but yes, from there, **finding the top three, or top five, or top ten students who got the maximum marks becomes very easy using SQL**.""Now next, the clause we are going to talk about is our **Order By Clause**.
