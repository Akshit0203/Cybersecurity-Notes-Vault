# Aggregate Functions

Aggregare functions perform a calculation on a set of values, and return a single value.

COUNT( )
MAX( )
MIN( )
SUM( )

AVG( )

Get Maximum Marks
```
SELECT max(marks)
FROM student;
```

"Now next, we are going to talk about **our aggregate functions**. Now, 'functions' is such a term that we will get to see inside SQL as well, and if you do other kinds of coding—such as inside C, C++, Java, or Python—there also you get to see functions. The basic job of functions is that we can think of a function like a box inside which some logic is written, and we tell the functions to do some work, and then they bring and give us some output of that work. So our functions are like a magic box, or we can think of them like a button, just like we have many buttons inside our house. Pressing some button turns on the lights, pressing some button starts our fan, and pressing some button starts our cooler. Every button has a specific, fixed job. Whenever you press that button, only the cooler will run; it is not like if you press that button today your light is turning on, and if you press it tomorrow your fan is running, unless and until someone has changed the actual wiring itself.

So, in the same way, we have aggregate functions inside SQL whose job is fixed, and they have only one job according to their names. Now, aggregate functions are those functions which perform some calculation. Here, it should be 'aggregate'—the basic meaning of saying 'aggregate' is to collect things together. So, aggregate functions take many values and return a single value.

The very first of our aggregate functions can be **COUNT**. What does `COUNT` do? It does the job of counting. We will give it many values—let's suppose we gave it three names: we gave it Aman, we gave it Shraddha, we gave it Rahul; in this way, we gave it three names. So, the `COUNT` function will tell the count of all three, meaning how many names it found. So the `COUNT` function will tell us that it found three names.

Similarly, if we give many values to the **MAX** (maximum) function, then the `MAX` function will tell us what is the maximum value among those values.

Similarly, we have our **MIN** (minimum) function.

We have **SUM**, which tells the sum of all values.

And we have **AVG**, which is the average function and tells the average of all values.

So, although there are many aggregate functions, these five are our most popular and commonly used aggregate functions.

Now, how do we use aggregate functions? There are several ways to use them, of which one of the simplest ways is with the SELECT statement. For example, if we have to find the maximum marks among all of our students, what can we write for that? First of all, we can find the marks of all the students. Let's suppose we wrote:

```
SELECT marks FROM student;
```

If we select this much part and execute it, then the marks of all of our students will come. But we want the maximum marks, so for that we can use our aggregate function. Whichever column's maximum we want, we put our function in front of that column. Since we want the maximum of marks, we can write `MAX` here and we will use parentheses—meaning these kinds of brackets—and inside these brackets, inside the parentheses, we will write `marks`.

Now what will this do? Because an aggregate function returns a single value—meaning it returns only one value—previously we got a list of all the marks, but now we will get only one value, which will be the maximum marks. Let's execute this, and it has told us that the maximum marks inside our table is equal to `96`.

In the same way, we can also find our minimum marks. So the minimum marks will come to us—this has come to us, minimum marks equal to `12`.

In the same way, if we want, we can also calculate the average of all the marks to see what was our class average this year. We executed this, so the class average was equal to `74.2`. So in this way, we got our class average.

And let's suppose we want the count of all of our students, meaning how many students we have. So we can write here `COUNT(name)`, indicating that however many names we have, or however many roll numbers we have, find their count.
