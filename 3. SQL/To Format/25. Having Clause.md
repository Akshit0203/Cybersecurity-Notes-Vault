# Having Clause

WHERE -> ROWS 
HAVING -> GROUPS

Similar to Where i.e. applies some condition on rows.
Used when we want to apply any condition after grouping.


GROUP BY - remove duplicates

Count number of students in each city where max marks cross 90.

```
SELECT count(name), city
FROM student
GROUP BY city
HAVING max(marks) > 90;
```


```
SELECT city , count(rollno)
FROM student
GROUP BY city
HAVING max(marks) > 90
```

"Now next, we are going to talk about our **Having Clause**.

The Having Clause of ours also works to define conditions. Now, to define conditions, we have already read another clause earlier, which is our Where Clause. So, the kind of job our Where Clause does, a very similar job is done by our Having Clause. Both of their jobs are that they are used to apply some conditions on our rows. But many times, such situations arise, many times we have to write such commands in SQL inside which we cannot use Where. So in those cases, we use our Having Clause.

So, what does Where do? **Where is used if we have to apply some condition on normal rows**. What does the Having Clause do? **The Having Clause is used to apply conditions on groups**. Like, let's suppose we have made many groups, now we have to apply a condition on those groups as well, so for that, we will use our Having Clause.

Like, let's suppose we have to count the number of students in each city where maximum marks cross 90. Meaning, we have one city Pune, we have one city Mumbai, we have one city Delhi. Inside all of them, some count of our students will come. It could be that inside this city there are some students, inside this city there are some students—so this is our count of students that we got. But we want the count of only those cities inside which students have gone up to at least 90, which are the maximum marks. Meaning, if only one child lives inside Delhi, and that child's marks remained 85, that child's marks—the maximum marks—are not 90, then in that case, I do not want to see Delhi's data at all.

So this kind of condition, or let's suppose inside Mumbai if one student got 75 marks, one got 95, then in that case, I want to see Mumbai's marks because the maximum marks are 95—meaning they have crossed 90. So if I have to see data in this manner, based upon maximum marks crossing 90, then in that case, we can use our Having Clause.

So let's understand this step-by-step. First of all, we group based on our city:

```
SELECT city FROM student GROUP BY city;
```

So, our three cities Pune, Mumbai, and Delhi have come. Now we have to count all the students—how many students are in each city—so for that, we can apply count on our roll number or name. So we did count, executed it, and we got Pune has one child, Mumbai has two students, and Delhi has three students. So the count of all the cities has come.

But what did we want? We wanted those cities in which the maximum marks cross 90. So for that, we can use our Having Clause:

```
HAVING MAX(marks) > 90;
```

Meaning, where our maximum marks are above 90.

Now let's select and execute this. So now, only two cities came: Mumbai has two children, Delhi has three children. This is because inside Mumbai, our maximum marks are equal to 93, and inside Delhi, our maximum marks are equal to 96. But inside Pune, there is only one student whose marks are 78, so the maximum marks never went above 90. So in that case, we got the data of only two cities; the data of Pune was not displayed to us.

Now, this condition that was applied—this condition that maximum marks are greater than 90—was applied to each group. Now, if we wanted: `WHERE MAX(marks) > 90`, and if we remove HAVING from here and think that we will apply this condition using WHERE itself, then that thing won't be possible. This is because: 'where maximum of marks'—where are we looking at the maximum of marks? So this situation won't make any sense. So, this is a situation inside which we cannot use WHERE. That is why in this situation, we use our Having Clause to apply some condition or another on our data".
