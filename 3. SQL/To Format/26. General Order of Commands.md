Based on the chapter we just covered, here is a quick, practical cheat sheet of the **General Order of Commands** in SQL to summarize how these clauses fit together:

```
SELECT column1, column2...       -- Which columns you want to view
FROM table_name                  -- The table to retrieve data from
WHERE condition                  -- Filters individual rows (must be written BEFORE Group By)
GROUP BY column_name             -- Groups rows sharing the same values
HAVING group_condition           -- Filters groups (must be written AFTER Group By)
ORDER BY column_name ASC/DESC;   -- Sorts the final output in ascending/descending order
```

**Two Golden Rules to Remember:**

1. **WHERE** **filters individual rows**, while **HAVING** **filters the summary groups** created by `GROUP BY`.
2. **WHERE** **always comes before** **GROUP BY**, and **HAVING** **always comes after** **GROUP BY**.
