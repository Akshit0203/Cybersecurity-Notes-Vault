# Tools to Install

> Throughout this course we use **three coding environments** — VS Code, Anaconda, and Jupyter Notebook — introduced progressively so the transition is smooth.

---
## Tools Used in the Course

| Tool                  | When Introduced                        | Purpose                                   |
| --------------------- | -------------------------------------- | ----------------------------------------- |
| **VS Code + Python**  | Week 1 — install before the first lecture | Writing & running Python code             |
| **Anaconda**          | Later — when the data/ML section starts  | Python distribution with data-science libs |
| **Jupyter Notebook**  | Later — alongside Anaconda               | Interactive notebooks for ML & data work  |

- **Alternative IDEs** (PyCharm, JetBrains, etc.) are also fine if you already use them.
- Anaconda & Jupyter can technically be installed right away and used without VS Code, but VS Code is covered first on purpose.

> [!NOTE]
> **Why multiple tools?** Exposure to different environments builds versatility — a valuable skill in the industry.

---
## Prerequisites

Before the first lecture, ensure you have:

1. A **laptop / desktop computer**
2. A working **internet connection** (to watch lectures and download tools)
3. **Python** installed
4. **Visual Studio Code (VS Code)** installed

> [!TIP]
> Installation of both Python and VS Code is straightforward. Anaconda & Jupyter installation instructions will be provided later when needed.

---
## Why VS Code?

- One of the **most widely used** code editors in the industry.
- **Open-source** and developed by **Microsoft** (which also owns GitHub and Visual Studio IDE).
- Supports **virtually every programming language** — useful beyond Python if you switch languages later in your career.
- Knowing VS Code is an important **professional skill** for any programmer.
