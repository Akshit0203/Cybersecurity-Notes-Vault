## Linux Commands

### Navigation & File Management

| #  | Command                  | Description                              |
| -- | ------------------------ | ---------------------------------------- |
| 1  | `ls` (switches)          | List directory contents                  |
| 2  | `pwd`                    | Print working directory                  |
| 3  | `cd` (`../` `.`)         | Change directory                         |
| 9  | `touch`                  | Create empty files                       |
| 10 | `rm`                     | Remove files                             |
| 11 | `mkdir`                  | Create directories                       |
| 12 | `rmdir`                  | Remove empty directories                 |
| 14 | `cp`                     | Copy files/directories                   |
| 15 | `mv`                     | Move or rename files/directories         |
| 16 | `cat`                    | Display file contents                    |

### Networking

| #  | Command     | Description                              |
| -- | ----------- | ---------------------------------------- |
| 4  | `ifconfig`  | Display/configure network interfaces     |
| 5  | `ping`      | Test network connectivity                |
| 20 | `hostname`  | Display/set system hostname              |
| 21 | `netstat`   | Network statistics and connections       |

### System & Utilities

| #  | Command                     | Description                                  |
| -- | --------------------------- | -------------------------------------------- |
| 6  | `clear`                     | Clear terminal screen                        |
| 7  | `apt` / `apt-get`           | Debian distro package manager                |
| 8  | `history`                   | Show command history                         |
| 13 | `man` / `-h` / `--help`     | View manual/help pages                       |
| 17 | `curl`                      | Transfer data from/to a server               |
| 18 | `echo`                      | Print text to terminal                       |
| 19 | `grep`                      | Search text using patterns                   |
| 22 | `sort`                      | Sort lines of text                           |
| 23 | Redirection (`>`) and pipes (`\|`) | Redirect output / chain commands       |

### User Administration

| #  | Command    | Description                                  |
| -- | ---------- | -------------------------------------------- |
| 1  | `uname` (switches) | System information                  |
| 2  | `adduser`  | Add a new user                               |
| 3  | `passwd`   | Change user password                         |
| 4  | `sudo`     | Execute as superuser                         |
| 5  | `who`      | Show who is logged in                        |
| 6  | `whoami`   | Display current username                     |
| 7  | `id`       | Display user/group IDs                       |
| 8  | `userdel`  | Delete a user                                |

### File Permissions

| #  | Command       | Description                              |
| -- | ------------- | ---------------------------------------- |
| 1  | `chmod` (numbers / `+x`) | Change file permissions        |
| 2  | `chown`       | Change file owner                        |
| 3  | `chgrp`       | Change file group                        |
| 4  | Prompt type   | `#` = root, `$` = normal user            |

## Useful Linux Files

| File              | Purpose                                |
| ----------------- | -------------------------------------- |
| `/etc/passwd`     | User account information               |
| `/etc/shadow`     | Encrypted user passwords               |
| `/etc/os-release` | OS identification data                 |

| 9  | `cls`              | Clear screen                             |

| 11 | `move`             | Move files                               |

| #  | Command      | Description                              |
