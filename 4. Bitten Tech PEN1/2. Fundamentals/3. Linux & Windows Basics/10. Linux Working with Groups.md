### **Part 6: Deleting Users and Removing them from Groups (`deluser` vs. `userdel`)**

So, now our adding part is done. What do we have to do now? Now we have to delete. We have to remove a user from the group. How do we do that?

If we want to remove a user, there is a command here, `deluser`. Just like `adduser`, there is `deluser`. Keep one thing in mind here. There are two commands here: `deluser` and `userdel`. When is `userdel` used? When you want to delete a user from the system. But when is `deluser` used? When you want to delete a user from a group. Do not get confused. A lot of people get confused by this. So remember, `userdel` is for the system—specifically, when you want to delete a user—while `deluser` is for groups.

So, here I am deleting user1. I want to delete user1. From which group? tech hacker. So, the group name. Let's hit enter. Now, here it says: "Removing user user1 from group tech hacker... Done". It is done. Let's check the file again. You can see user1 is gone from here. Okay? So, that's how it works here. And if I want to do it for user2, I can do that as well.
