# Linux — Working with Groups

> Groups allow multiple users to share the same permissions on files and directories. This is essential for **multi-user collaboration** — instead of setting permissions per user, set them once for the group.

---

## Why Use Groups?

- A shared file/directory needs to be accessible by multiple users
- All users in a group get the **same permissions** on that resource
- Easier management than assigning permissions individually

---

## Creating a Group

### `groupadd` — Create a New Group

```bash
groupadd -h
```

| Option | Description |
| ------ | ----------- |
| `-f` | Exit successfully if group already exists |
| `-g GID` | Specify a custom Group ID |
| `-p PASSWORD` | Set an encrypted password for the group |
| `-r` | Create a system account |
| `-U USERS` | Comma-separated list of users to add as members |

### Example: Create a Group with Custom GID

```bash
groupadd techhacker -g 2000
```

- If you don't specify `-g`, the system auto-assigns a GID (typically after 1000)

---

## Verifying Group Creation

### `/etc/group` — Groups Database File

All groups are stored in `/etc/group` (similar to how users are in `/etc/passwd`).

```bash
cat /etc/group
```

```
root:x:0:
kali:x:1000:
kaboxer:x:119:kali
techhacker:x:2000:
```

Format: `group_name:password:GID:members`

- `techhacker:x:2000:` → group exists but has **no members** yet

## Adding Users to a Group

### Step 1: User Must Exist First

If the user doesn't exist, create them:

```bash
adduser user1
```

```
New password:
Retype new password:
passwd: password updated successfully
Changing the user information for user1
Enter the new value, or press ENTER for the default
        Full Name []:
        Room Number []:
        ...
Is the information correct? [Y/n] y
```

> **Note:** When you create a user, a **default group with the same name** is automatically created for them.

### Step 2: Add User to the Group

```bash
adduser user1 techhacker
```

### Verify

```bash
cat /etc/group
```

```
root:x:0:
kali:x:1000:
techhacker:x:2000:user1
user1:x:1001:
```

- `techhacker:x:2000:user1` → user1 is now a member
- `user1:x:1001:` → user1's own default group still exists separately

### Adding Multiple Users

```bash
adduser user2 techhacker
```

After adding user2:

```
techhacker:x:2000:user1,user2
```

Multiple users are listed as **comma-separated** values.

---

## Removing Users from Groups

### `deluser` vs `userdel` — Know the Difference

| Command | Purpose |
| ------- | ------- |
| `deluser <user> <group>` | Remove a user **from a group** |
| `userdel <user>` | Delete a user **from the system entirely** |

> [!WARNING]
> Don't confuse these! `userdel` removes the entire user account; `deluser` only removes group membership.

### Example: Remove user1 from techhacker

```bash
deluser user1 techhacker
```

```
Removing user user1 from group techhacker... Done
```

### Verify

```bash
cat /etc/group
```

```
techhacker:x:2000:
user1:x:1001:
```

user1 is gone from the techhacker group, but the user account still exists.

---

## Deleting a Group

### `groupdel` — Delete an Entire Group

```bash
groupdel techhacker
```

- Deletes the group regardless of how many users are in it
- You do **not** need to remove all users from the group first

### Verify

```bash
cat /etc/group
```

The `techhacker` line is gone.

---

## Quick Reference

| Task | Command |
| ---- | ------- |
| Create a group | `groupadd <name>` |
| Create group with specific GID | `groupadd <name> -g <GID>` |
| Create a user | `adduser <username>` |
| Add user to group | `adduser <user> <group>` |
| Remove user from group | `deluser <user> <group>` |
| Delete user from system | `userdel <username>` |
| Delete a group | `groupdel <group>` |
| View all groups | `cat /etc/group` |
