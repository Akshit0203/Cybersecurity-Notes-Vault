# Linux File System

---

## What is a File System?

- A set of rules used to decide how data is **stored and fetched** in a storage device (hard drive, flash drive, etc.)
- The entire Linux directory structure starts at the top — the **`/` (root)** directory
- Storage format types include: **EXT3, EXT4, BTRFS, XFS**, etc.
- **Mounting:** A mount point is simply a directory created as part of the root filesystem. The Linux root filesystem is mounted on `/`

## `/` — Root Filesystem

- **Top-level directory** of the filesystem
- Contains all files required to boot the Linux system before other filesystems are mounted
- Includes all required executables and libraries to boot the remaining filesystems

---

## Directory Structure

| Directory  | Description                                                                      |
| ---------- | -------------------------------------------------------------------------------- |
| `/bin`     | User executable files                                                            |
| `/boot`    | Static bootloader, kernel executable, and configuration files required to boot   |
| `/dev`     | Device files for every hardware device attached to the system                    |
| `/etc`     | Local system configuration files for the host computer                           |
| `/home`    | Home directory storage for user files — each user has a subdirectory in `/home`  |
| `/lib`     | Shared library files required to boot the system                                |
| `/media`   | Mount point for external removable media (e.g., USB thumb drives)               |
| `/mnt`     | Temporary mount point for regular filesystems                                    |
| `/root`    | Home directory for the **root user**                                             |
| `/tmp`     | Temporary files used by the OS and programs                                      |
| `/usr`     | Shareable, read-only files — executable binaries, libraries, man files, docs     |
