### Part 1: Getting Started with Windows Command Prompt (CMD)

In this, we are going to see some Windows DOS shell commands that are important. If you work in Windows, and if you want to work in Windows in the future too, and if you want this whole course in Windows, then in that case, it is essential for you to know these commands. Even if you do not use Windows, you should still know them [1]. I will tell you some basic shell commands, and as many as you need to know in this course—I cannot tell you all of them. No one can tell you all of them. But you will have to search on your own to see how many and how you can use the rest of the commands [1].

So, let's start. First of all, when we want to type commands, you know we have to open CMD here, CMD. Now, see here, it says Command Prompt. Now, you can run this as administrator or open it directly [1]. If you run as administrator, you will have the maximum privileges on those commands, whichever you run, because some commands—like changing passwords or adding a user—such privileged commands can only be given by an administrator [1, 2]. So, in that case, if you are an administrator, it is a very good thing, and running it like this will make it much easier for you [2].

Now here, look at this—this is my black screen. This is our command prompt. This is basically the shell of my Windows system, you could say [2]. But in terminology, we use 'shell' in the case of Linux; we don't use 'shell' here. We call it CMD here, or Command Prompt. So, this is my prompt. Why are we calling it a prompt? Because it is showing me here that "I am waiting for your command." So, I have to enter a command here [2]. It is asking to provide an input, you could say. So, first of all, see here, it is showing the version of your Windows, and the company and all that is also there. So, look at my directory here. Right now, I am in the C drive. Inside that, there is a Windows folder, and inside that is the System32 folder. If I open it as administrator, it starts from inside System32 because that is a privileged folder where all your Windows files are [2, 3]. So you should not mess with it [3]. But if I had opened it as a normal user, it would have opened from where my user account is stored [3]. This is the administrator's, so it is opening here for me [3].

### Part 2: Changing Directories and Drives (`cd`)

So what do we have to do now? We have to see what we are going to do here [3]. First of all, find out how you go from one place to another here. This is my directory, okay? System32. Now, if I want to go forward from here, or go backward, or if I want to change this directory, how will I do it? [3] The very first command you will have to type here is CD. CD means Change Directory. You type CD [3]. So, the output that is coming—I have given CD as input here—and its output will be shown to me on this very screen. This is its output. Meaning, it is telling you which is your current directory [3]. So, this is standard input and standard output. Meaning, I am seeing the output here on this very screen and on the monitor [3]. So, this is standard—meaning, you can call it std [3, 4].

This is the CD command. Do you know what the main job of CD is? Changing the directory—as the name suggests, change. So, we haven't changed anything yet. Just writing CD won't do anything [4]. After CD, we have to specify where we want to go. So, we do CD here. After that, you have to specify which drive you want to go to [4]. You will have many drives. Like, I have a C drive here, D, E. So, like that, I have to specify [4]. Now, a special thing in Windows is that if you directly write the drive's name, like C, D, E, and then put a colon, it directly goes to that drive [4]. You don't need to put CD. So, if I write D colon here, it shows me D but doesn't go there. Since it hasn't gone there, I directly have to write just D, D colon, so it comes to the D drive [4]. Now, if you want to go to another drive directly, you write F here, and it will come to the F drive. So, changing the drive is simple, you don't need to write anything else [4].

### Part 3: Listing Directory Contents (`dir`) and Switches

Now, there are many commands here. Now, many commands have different ways, and every command has options. Every command has a switch [5]. So, by that, I mean that if you type any command, then after that, if you are doing it in Windows, a forward slash and then a question mark (`/?`) [5, 6]. So, with this, you will get all the help for that command. You hit enter and you will be told why this command is used [6]. A forward slash and then a question mark. So, here, this `/P` is "pause after each screenful of information." Once the information fills one screen, it will pause [6]. When you move it, it will bring the next information, and `/Q` gives the owner of the file [6].

So, if I try typing any switch here, like `DIR /Q`, so it is showing who is the owner of which file [6, 7]. You can see here that this is the owner. On the desktop, `Desktop\ansh_b` is its owner [7]. Now, let's talk about the next command. For example, I come here to my E drive. This is my E drive. Now, I want to make a new folder here. It has been made. Now, let's see if it has been made or not. Do DIR [8].

Yes, and keep one more thing in mind here—the commands I am changing here, they are changing automatically. Meaning, I am just pressing the Up key [8].
