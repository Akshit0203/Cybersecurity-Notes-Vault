# Basic DOS Commands (Windows CMD)

> Essential Windows command prompt commands for file management, system information, and everyday tasks. Use `/?` after any command to view its full help and switches.

---

## Navigating Directories

### `cd` — Change Directory

```
C:\Windows\System32>cd
C:\Windows\System32
```

- `cd` alone → shows the current directory
- `cd <path>` → navigate to that directory
- Switching drives: just type the drive letter with a colon

```
C:\Windows\System32>D:
D:\>
```

> **Tip:** When CMD opens as Administrator, it starts in `C:\Windows\System32`. As a normal user, it opens in your user profile folder.

---

### `dir` — List Directory Contents

```
D:\>dir
 Volume in drive D is New Volume
 Volume Serial Number is 5C09-35DE

 Directory of D:\

30-06-2026  10:10 PM    <DIR>          1 Portfolio
31-03-2026  01:49 PM    <DIR>          3 Cybersecurity
23-02-2025  10:45 AM               643 aws passwords.txt
03-08-2026  08:19 PM    <DIR>          Obsidian
               2 File(s) 117,520,651,743 bytes
               8 Dir(s)  267,966,955,520 bytes free
```

- `<DIR>` = directory, otherwise it's a file
- Shows date, time, size, and name

#### Useful `dir` Switches

| Switch | Description |
| ------ | ----------- |
| `dir /?` | Show full help |
| `dir /Q` | Show file **owner** |
| `dir /S` | List files in **all subdirectories** recursively |
| `dir /B` | Bare format (names only, no headers/summary) |
| `dir /P` | **Pause** after each screenful |
| `dir /O:N` | Sort by **name** |
| `dir /O:D` | Sort by **date** |

#### List Files from a Different Path

```
D:\>dir C:\
```

> Shows all files and folders inside the C: drive without changing to it.

#### Show File Owner

```
D:\>dir /Q
 DESKTOP-2ER5CUI\Akshit Obsidian
 NT AUTHORITY\SYSTEM    Program Files
```

## Creating & Removing Directories

### `mkdir` / `md` — Create Directory

```
C:\Users\Akshit\Downloads>mkdir test
C:\Users\Akshit\Downloads>md test
```

Both commands do the same thing.

### `rmdir` / `rd` — Remove Directory

```
C:\Users\Akshit\Downloads>rmdir test
C:\Users\Akshit\Downloads>rd test
```

Both commands do the same thing. Directory must be empty.

## File Creation & Output Redirection

### `echo` — Print Text

```
C:\Users\Akshit\Downloads\test>echo "Hello World"
"Hello World"
```

### `>` — Redirect Output to File (Overwrite)

```
C:\Users\Akshit\Downloads\test>echo "Hello World" > sample.txt
```

Creates `sample.txt` with "Hello World" inside it. **Overwrites** any existing content.

![](attachments/Pasted%20image%2020260815110323.png)

### `>>` — Append to File (No Overwrite)

```
C:\Users\Akshit\Downloads\test>echo "adding new lines" >> sample.txt
C:\Users\Akshit\Downloads\test>echo adding new stuff >> sample.txt
```

Appends to the end of the file without overwriting.

> **Note:** Quotes are optional with `echo`. Text after `echo` is output as-is.

### Redirecting Command Output to a File

```
C:\Users\Akshit\Downloads\test>dir C:\ > sample.txt
```

The full `dir` listing of `C:\` is saved into `sample.txt` instead of being displayed on screen.

## Viewing, Renaming & Clearing

### `type` — Display File Contents

```
C:\Users\Akshit\Downloads\test>type sample.txt
 Volume in drive C is Windows
 ...
```

Works with any text file, not just `.txt`.

### `rename` — Rename a File

```
C:\Users\Akshit\Downloads\test>rename sample.txt sample_new.txt
```

![](attachments/Pasted%20image%2020260815111015.png)

### `cls` — Clear Screen

```
C:\Users\Akshit\Downloads\test>cls
```

Clears all text from the command prompt. Start fresh from the top.

## Copying & Moving Files

### `copy` — Copy a File

```
C:\Users\Akshit\Downloads\test>copy sample_new.txt C:\Users\Akshit\Downloads\sample.txt
        1 file(s) copied.
```

![](attachments/Pasted%20image%2020260815111149.png)

#### Useful `copy` Switches

| Switch | Description |
| ------ | ----------- |
| `/V` | Verify new files are written correctly |
| `/Y` | Suppress overwrite confirmation prompts |
| `/-Y` | Prompt before overwriting |
| `/Z` | Copy networked files in restartable mode |

### `move` — Move (Cut-Paste) a File

```
C:\Users\Akshit\Downloads\test>move sample_new.txt C:\Users\Akshit\Downloads\sample.txt
Overwrite C:\Users\Akshit\Downloads\sample.txt? (Yes/No/All): yes
        1 file(s) moved.
```

- If a file with the same name exists at the destination, it asks for confirmation
- **Rename trick:** `move` in the same directory works as a rename

```
move sample_new.txt sample_newest.txt
```

## Date, Time & Volume Label

### `date` — Display/Set Date

```
C:\>date
The current date is: 15-08-2026
Enter the new date: (dd-mm-yy)
```

Press Enter to skip without changing.

### `time` — Display/Set Time

```
C:\>time
The current time is: 11:17:27.81
Enter the new time:
```

### `label` — Change Drive Label

```
C:\>label D:
```

Changes the volume name (e.g., "Local Disk" → "Tech Hacker").

## Getting Help

### `help` — List All Available Commands

```
C:\>help
```

Displays a list of all built-in CMD commands with descriptions. Key commands listed:

| Command | Description |
| ------- | ----------- |
| `ASSOC` | Display/modify file extension associations |
| `ATTRIB` | Display/change file attributes |
| `CHKDSK` | Check disk and display status report |
| `COMP` | Compare contents of two files |
| `DISKPART` | Display/configure disk partition properties |
| `FIND` | Search for text string in files |
| `FINDSTR` | Search for strings in files |
| `ROBOCOPY` | Advanced file/directory copy utility |
| `SCHTASKS` | Schedule commands and programs |
| `TASKLIST` | Display all currently running tasks |
| `TASKKILL` | Kill a running process |
| `TREE` | Graphically display directory structure |
| `XCOPY` | Copy files and directory trees |
| `WMIC` | Display WMI info inside command shell |

### `/?` — Command-Specific Help

```
dir /?
copy /?
```

> **Always use `/?`** after any command to see its full syntax, switches, and usage examples.

## Quick Reference Summary

| Task | Command |
| ---- | ------- |
| Show current directory | `cd` |
| Change directory | `cd <path>` |
| Switch drive | `D:` |
| List files | `dir` |
| Create directory | `mkdir <name>` or `md <name>` |
| Remove directory | `rmdir <name>` or `rd <name>` |
| Create/write file | `echo text > file.txt` |
| Append to file | `echo text >> file.txt` |
| View file contents | `type <file>` |
| Rename file | `rename <old> <new>` |
| Copy file | `copy <source> <dest>` |
| Move file | `move <source> <dest>` |
| Clear screen | `cls` |
| Get help | `help` or `<command> /?` |
| System info | `systeminfo` |
| Date/Time | `date` / `time` |
| Volume label | `label <drive:>` |

> **Tip:** Press the **Up arrow key** to recall previously typed commands without retyping them.
