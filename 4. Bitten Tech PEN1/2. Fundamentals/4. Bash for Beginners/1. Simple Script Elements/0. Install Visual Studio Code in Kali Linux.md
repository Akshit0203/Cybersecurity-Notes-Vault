

go to visual studio website and download .deb file

![](attachments/Pasted%20image%2020260816134513.png)

Since you already have the `.deb` file in your current directory, install it with `apt`.

### Recommended method

```
sudo apt install ./code_1.133.0-1786487972_amd64.deb
```

The `./` is important because it tells `apt`:

> "Install this `.deb` file from my current directory."

You'll be prompted for your Kali password. Type it and press **Enter**.

### Then verify

```
code --version
```

You should see something like:

```
1.133.0

...
```

### Then launch VS Code

From the terminal:

```
code
```

Or open a specific folder:

```
code .
```

Since you're currently in the directory containing the `.deb`, after installation you can `cd` into your Bash scripting workspace and run:

```
mkdir ~/bash-scripts

cd ~/bash-scripts

code .
```

That gives you a nice workspace for learning Bash.
