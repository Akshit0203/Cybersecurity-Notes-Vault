# DNS Zone Transfer using `host` Command

## Test Domain

**zonetransfer.me** — a deliberately vulnerable/training DNS domain created to demonstrate unauthorized zone transfers (AXFR).

- Website: https://digi.ninja/projects/zonetransferme.php
- Safe to practice zone transfers against

![ZoneTransfer.me website](attachments/Pasted%20image%2020260907160616.png)

---

## Step 1: Find Name Servers

```bash
host -t ns zonetransfer.me
```

```
zonetransfer.me name server nsztm1.digi.ninja.
zonetransfer.me name server nsztm2.digi.ninja.
```

→ Two name servers found. Try each one to see which allows zone transfer.

## Step 2: `host` Command Reference

```bash
host -h
```

```
Usage: host [-aCdilrTvVw] [-c class] [-N ndots] [-t type] [-W time]
            [-R number] [-m flag] [-p port] hostname [server]
   -a is equivalent to -v -t ANY
   -A is like -a but omits RRSIG, NSEC, NSEC3
   -c specifies query class for non-IN data
   -C compares SOA records on authoritative nameservers
   -d is equivalent to -v
   -l lists all hosts in a domain, using AXFR
   -m set memory debugging flag (trace|record|usage)
   -N changes the number of dots allowed before root lookup is done
   -p specifies the port on the server to query
   -r disables recursive processing
   -R specifies number of retries for UDP packets
   -s a SERVFAIL response should stop query
   -t specifies the query type
   -T enables TCP/IP mode
   -U enables UDP mode
   -v enables verbose output
   -V print version number and exit
   -w specifies to wait forever for a reply
   -W specifies how long to wait for a reply
   -4 use IPv4 query transport only
   -6 use IPv6 query transport only
```

> [!tip] Key Flag
> **`-l`** = list all hosts in a domain using **AXFR** (full zone transfer)

## Step 3: Perform Zone Transfer

```bash
host -l zonetransfer.me nsztm2.digi.ninja
```

**Syntax:** `host -l <domain> <nameserver>`

## Key Takeaways

- `host -l` performs an **AXFR zone transfer** and lists all hosts
- The output shows **every domain and record** within the zone — both public and confidential
- `host` provides a simplified view; `nslookup` and `dig` provide more detailed output
- **zonetransfer.me is intentionally configured** to allow this — not all domains will respond to zone transfer requests
