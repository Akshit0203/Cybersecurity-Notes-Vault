# `nslookup` Tool

## What is `nslookup`?

**nslookup** = **Name Server Lookup** — an interactive tool to query DNS name servers.

```
man nslookup

NAME
     nslookup - query Internet name servers interactively

SYNOPSIS
     nslookup [-option] [name | -] [server]
```

- Available on **both Windows and Linux**
- Provides its own **interactive prompt** for running DNS queries
- By default returns **A records**; use `set type=` to change

## Interactive Mode

Enter the interactive prompt by typing `nslookup` with no arguments:

```bash
nslookup
>
```

### Querying CNAME Records

```
> set type=cname
> google.com
Server:         192.168.60.2
Address:        192.168.60.2#53

Non-authoritative answer:
*** Can't find google.com: No answer

Authoritative answers can be found from:
google.com
        origin = ns1.google.com
        mail addr = dns-admin.google.com
        serial = 977033011
        refresh = 900
        retry = 900
        expire = 1800
        minimum = 60
```

→ No CNAME record exists for google.com (expected — it's the canonical name itself).

## Quick Reference

| Command                | Purpose                         |
| ---------------------- | ------------------------------- |
| `nslookup <domain>`    | Quick A record lookup           |
| `set type=a`           | Query A records (IPv4)          |
| `set type=ns`          | Query name server records       |
| `set type=mx`          | Query mail exchanger records    |
| `set type=cname`       | Query CNAME (alias) records     |
| `set type=any`         | Query all record types          |
| `server <nameserver>`  | Change the DNS server to query  |

> [!tip] Interactive vs Non-Interactive
> Use **non-interactive** mode for quick lookups. Use **interactive** mode when you need to run multiple queries or set specific options like server or record type.
