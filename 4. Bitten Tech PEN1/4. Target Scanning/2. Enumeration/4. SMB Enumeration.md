## What is SMB?

**SMB = Server Message Block**

Simply:

> **SMB is a protocol that allows computers to share files, folders, printers, and other resources over a network.**

Imagine you have:

```
PC-A                         PC-B
┌──────────┐                ┌──────────────┐
│          │   SMB          │              │
│          │ ─────────────► │ Shared Folder│
│          │                │              │
└──────────┘                └──────────────┘
```

PC-A can access a folder on PC-B like:

```
\\PC-B\Shared
```

This is called an **SMB share**.

---

## What is SMB actually used for?

### 1. File sharing

For example, an organization might have:

```
\\FILESERVER\Finance
\\FILESERVER\HR
\\FILESERVER\Public
```

Employees access those folders through SMB.

### 2. Printer sharing

SMB can also be used to access network printers.

### 3. Windows administration

SMB is involved in several Windows administrative mechanisms and is very important in Windows/AD environments.

### 4. Authentication

SMB can use Windows authentication mechanisms such as **NTLM** and **Kerberos** depending on the environment and operation.

That's one reason SMB becomes extremely interesting during penetration testing.

---

# SMB ports

The two ports you should remember:

|Port|Purpose|
|---|---|
|**445/TCP**|SMB directly over TCP|
|**139/TCP**|SMB over NetBIOS|

Modern Windows systems primarily use:

```
TCP 445
```

So if you scan a machine and see:

```
445/tcp open  microsoft-ds
```

**SMB should immediately be on your enumeration checklist.**

---

# SMB vs NetBIOS

This is where it can get confusing.

Think:

```
OLD Windows networking:

SMB
 ↓
NetBIOS
 ↓
TCP 139
```

Modern networking:

```
SMB
 ↓
TCP 445
```

So:

**NetBIOS ≠ SMB**

but historically they were commonly used together.

---

# Why is SMB VERY relevant to OSCP?

This is the important part.

When you find:

```
445/tcp open
```

you can potentially discover:

- Host/domain information
- SMB shares
- Share permissions
- Anonymous access
- Users/groups
- SMB version/dialect
- Misconfigurations
- Sensitive files
- Credentials
- Potential vulnerabilities
- Information useful for lateral movement

For example:

```
nmap -p445 --script smb-enum-shares <IP>
```

could reveal something like:

```
Share        Access
-----        ------
ADMIN$       denied
C$           denied
Public       READ
Backup       READ/WRITE
```

Now you've potentially found a place containing useful information.

# Why SMB can become dangerous

Suppose you discover:

```
\\192.168.1.50\Backup
```

and you have read access.

You might find:

```
backup.zip
passwords.txt
web.config
database.sql
```

That could give you credentials or information that leads to another attack.

Or suppose you have **write access**:

```
Public       READ/WRITE
```

That can potentially become much more interesting depending on how that share is used.

---

# SMB and vulnerabilities

SMB itself has also had major vulnerabilities.

One famous example is **EternalBlue**, which targeted a vulnerability in older SMBv1 implementations.

That's why you'll often see security scanners checking:

```
445/TCP
SMB version
SMB signing
SMB vulnerabilities
```

However, don't make the mistake of thinking:

> "445 open = vulnerable."

An open SMB port simply means:

> **There is an SMB service to enumerate.**

You still need to determine what is actually exposed.
