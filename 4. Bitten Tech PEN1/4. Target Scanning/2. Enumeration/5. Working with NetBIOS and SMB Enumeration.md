## 1. NetBIOS Enumeration with `nbtstat` (Windows)

### Help / Usage

```cmd
C:\Users\Akshit>nbtstat

Displays protocol statistics and current TCP/IP connections using NBT
(NetBIOS over TCP/IP).

NBTSTAT [ [-a RemoteName] [-A IP address] [-c] [-n]
        [-r] [-R] [-RR] [-s] [-S] [interval] ]

  -a   (adapter status) Lists the remote machine's name table given its name
  -A   (Adapter status) Lists the remote machine's name table given its
                        IP address.
  -c   (cache)          Lists NBT's cache of remote [machine] names and their IP addresses
  -n   (names)          Lists local NetBIOS names.
  -r   (resolved)       Lists names resolved by broadcast and via WINS
  -R   (Reload)         Purges and reloads the remote cache name table
  -S   (Sessions)       Lists sessions table with the destination IP addresses
  -s   (sessions)       Lists sessions table converting destination IP
                        addresses to computer NETBIOS names.
  -RR  (ReleaseRefresh) Sends Name Release packets to WINS and then, starts Refresh

  RemoteName   Remote host machine name.
  IP address   Dotted decimal representation of the IP address.
  interval     Redisplays selected statistics, pausing interval seconds
               between each display. Press Ctrl+C to stop redisplaying
               statistics.
```

### Querying a Remote Machine's Name Table

```cmd
nbtstat -A <ip address>
```

**Example — Querying Windows 7 (192.168.1.6) from Windows 10:**

![nbtstat output showing NetBIOS name table](attachments/Pasted%20image%2020260906110203.png)

![nbtstat additional output](attachments/Pasted%20image%2020260906110407.png)

**What the output reveals:**

| Field          | Value         | Meaning                              |
| -------------- | ------------- | ------------------------------------ |
| Name           | `WIN`         | NetBIOS name of the Windows 7 system |
| Type           | `UNIQUE`      | Unique name on the network           |
| Status         | `REGISTERED`  | Name is actively registered          |
| `WORKGROUP`    | Group name    | The workgroup the system belongs to  |
| `MSBROWSE`     | —             | A shared resource/browse service     |
| MAC Address    | Displayed     | Physical address of the NIC          |

**Example — Reverse query from Windows 7 targeting Windows 10 (192.168.1.16):**

```cmd
nbtstat -A 192.168.1.16
```

Shows: NetBIOS name `DESKTOP-HQ...`, type, status, `WORKGROUP` group, and MAC address.

> [!tip] Pentest Reports
> Even if NetBIOS info isn't directly exploitable, extracting it is valuable for pentest documentation — it adds weight to your report and demonstrates thorough enumeration.

## 2. SMB Enumeration with `smbclient` (Kali Linux)

### Help / Usage

```bash
└─$ smbclient
Usage: smbclient [-?EgqBNPkV] [-?|--help] [--usage] [-M|--message=HOST]
        [-I|--ip-address=IP] [-E|--stderr] [-L|--list=HOST]
        [-T|--tar=<c|x>IXFvgbNan] [-D|--directory=DIR] [-c|--command=STRING]
        [-b|--send-buffer=BYTES] [-t|--timeout=SECONDS] [-p|--port=PORT]
        [-g|--grepable] [-q|--quiet] [-B|--browse]
        [-d|--debuglevel=DEBUGLEVEL] [--debug-stdout]
        [-s|--configfile=CONFIGFILE] [--option=name=value]
        [-l|--log-basename=LOGFILEBASE] [--leak-report] [--leak-report-full]
        [-R|--name-resolve=NAME-RESOLVE-ORDER]
        [-O|--socket-options=SOCKETOPTIONS] [-m|--max-protocol=MAXPROTOCOL]
        [-n|--netbiosname=NETBIOSNAME] [--netbios-scope=SCOPE]
        [-W|--workgroup=WORKGROUP] [--realm=REALM]
        [-U|--user=[DOMAIN/]USERNAME[%PASSWORD]] [-N|--no-pass]
        [--password=STRING] [--pw-nt-hash] [-A|--authentication-file=FILE]
        [-P|--machine-pass] [--simple-bind-dn=DN]

        [--use-winbind-ccache] [--client-protection=sign|encrypt|off]
        [-k|--kerberos] [-V|--version] [OPTIONS] service <password>
```

### Listing SMB Shares

```bash
smbclient -L <ip address>
```

**Example output when anonymous login succeeds:**

![smbclient listing shares](attachments/Pasted%20image%2020260906111018.png)

![smbclient share details](attachments/Pasted%20image%2020260906111248.png)

> [!warning] Anonymous Login
> In older SMB versions (SMBv1), **anonymous login may be allowed by default**. If it isn't disabled, any attacker can read SMB information. The output shows `Anonymous login successful` — this is a finding worth reporting.

**What the output reveals:**
- **Sharename** — resources being shared on the network (e.g., disks C/D, printers)
- **Type** — Disk, Printer, IPC, etc.
- **Comment** — Description of the share
- **Workgroup** and **Master** server name

## 3. SMB Enumeration with Nmap

### Aggressive Scan on Port 445

```bash
nmap -p445 -A <ip address>
```

![Nmap SMB scan results](attachments/Pasted%20image%2020260906111508.png)

![Nmap SMB OS discovery](attachments/Pasted%20image%2020260906111444.png)

**What the output reveals:**
- **SMB OS Discovery**: OS version (e.g., `Windows 7 Home Basic`)
- **NetBIOS computer name**
- **Workgroup**
- **SMB Security Mode**: guest account, authentication level, message signing status
- **SMBv2 Security Mode**: signing enabled/required

### Nmap NSE Scripts for SMB

List available SMB scripts:

```bash
ls /usr/share/nmap/scripts | grep smb
```

Key scripts available:

```
smb-brute.nse                  smb-enum-domains.nse
smb-enum-groups.nse            smb-enum-processes.nse
smb-enum-services.nse          smb-enum-sessions.nse
smb-enum-shares.nse            smb-enum-users.nse
smb-os-discovery.nse           smb-protocols.nse
smb-security-mode.nse          smb-system-info.nse
smb-vuln-ms08-067.nse          smb-vuln-ms17-010.nse
smb-double-pulsar-backdoor.nse smb-vuln-webexec.nse
smb2-capabilities.nse          smb2-security-mode.nse
```

### Running NSE Scripts

**Enumerate users:**

```bash
nmap --script=smb-enum-users <ip address>
```

![Nmap smb-enum-users output](attachments/Pasted%20image%2020260906111721.png)

**Enumerate shares:**

```bash
nmap --script=smb-enum-shares <ip address>
```

May reveal accounts like `Admin`, `C$`, `IPC$`, `Users` — even when full authentication fails, **anonymous access read** may succeed.

> [!tip] When smbclient Fails
> If `smbclient` fails to provide information, **Nmap NSE scripts** are an excellent fallback. Other useful tools include `smbmap` and `enum4linux`.
