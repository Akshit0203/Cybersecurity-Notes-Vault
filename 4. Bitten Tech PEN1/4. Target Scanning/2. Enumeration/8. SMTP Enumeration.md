### SMTP — Simple Mail Transfer Protocol

**SMTP is the protocol used to send email.**

Think of it as the **postal service for outgoing email**.

Example:

```
You → Gmail SMTP server → Recipient's mail server → Recipient
```

### What is it used for?

SMTP handles **sending/relaying email**, not normally reading it.

|Protocol|Main purpose|
|---|---|
|**SMTP**|Send email 📤|
|**IMAP**|Read/synchronize email 📥|
|**POP3**|Download email 📥|

### Common SMTP ports

- **25** → SMTP, traditionally server-to-server mail transfer
- **587** → Mail submission, commonly used by email clients
- **465** → SMTP over implicit TLS

### Why is SMTP relevant in OSCP?

**Very relevant during enumeration.**

If you find:

```
25/tcp open smtp
```

you should investigate the SMTP service.

You may be able to learn things such as:

- Mail server software/version
- Valid email/usernames
- Domain information
- Mail configuration
- Whether the server allows certain forms of relay
- Potentially useful information from SMTP commands

For example:

```
nc <IP> 25
```

You might receive:

```
220 mail.example.com ESMTP Postfix
```

Now you've learned:

**SMTP server = Postfix**

You can then enumerate further.

### Important SMTP commands

Once connected, you'll commonly encounter:

```
EHLO
HELO
MAIL FROM:
RCPT TO:
DATA
QUIT
```

For example:

```
EHLO kali
```

asks the server to identify its capabilities.

### 🧠 OSCP mental model

When Nmap gives you:

```
25/tcp   open   smtp
```

think:

> **"This is an email server. What can SMTP tell me about the machine, users, domains, software, and configuration?"**

So just like:

**SMB → users/shares/files**

**SNMP → system/network information**

**LDAP → directory/users/domain information**

**SMTP → mail server/domain/user information**

That's the useful way to remember it for OSCP.
