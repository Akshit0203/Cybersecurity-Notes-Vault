AD -> use nxc to find shares, winrm, rdp rights. Get a foothold and set up ligolo. Run bloodhound, check for any outgoing rights, kerberoast, asrep roast, look for sus files that may contain credentials. If nothing, try windows priv esc, if nothing look at other services, maybe a FTP, MSSQL, MySQL or something and see if theres any low hanging fruits. Rinse and repeat till youre DC.

**Tools in my GOAT list**
1. Ligolo-ng for pivoting and port forwarding, super good
2. nxc >>> crackmapexec. The wiki is super good, I reckon you could do 90% of boxes if you use nxc well.
3. bloodhound -> so useful for AD, cant do anything without it

for AD I'd put most of your time into Hacker Blueprint's AD chains, Derron C, and GOAD. HB chains things the way the OSCP does. GOAD is free and has a ton of attack paths in one environment.

a few things people mess up on the AD set:

you start with creds, so use them immediately. run bloodhound and throw nxc at every host on smb, winrm, mssql and rdp to see where they work. any time you get a new password or hash, spray it against everything again and keep a running list, because a lot of the time you're stuck only because you never tried a cred you already had on the right box

kerberoast and asreproast every time, it should be muscle memory

once you're admin somewhere dump everything with secretsdump or mimikatz, then actually go through user folders, powershell history and random scripts/configs. creds sitting in some file is super common

like Lain said, enumerate each AD machine like a standalone too (ports, services, shares) instead of only thinking in AD attacks

and get pivoting down before exam day. ligolo-ng is way less painful than proxychains imo

if you can afford one paid thing after that, a lab extension is a lot cheaper than rebuying the course. but HBlueprint + GOAD + Lain's list covers most of it. you'll get it
