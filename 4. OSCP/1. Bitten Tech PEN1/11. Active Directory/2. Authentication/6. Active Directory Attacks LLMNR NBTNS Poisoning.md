# LLMNR / NBT-NS Poisoning

---

## Protocol Overview

| Protocol | Full Name | Port | Purpose |
|---|---|---|---|
| **LLMNR** | Link-Local Multicast Name Resolution | UDP 5355 | Fallback host resolution when DNS fails (IPv6-era successor to NBT-NS) |
| **NBT-NS** | NetBIOS Name Service | UDP 137 | Legacy fallback host resolution when DNS fails |

- Both are **Microsoft proprietary** protocols used as **fallback mechanisms** when DNS cannot resolve a hostname.
- An attacker can **spoof responses** to LLMNR/NBT-NS broadcasts and trick victims into sending their **NTLMv2 (or v1) hash**.

---

## Attack Flow

```
1. User mistypes a hostname (e.g., \\hackm instead of \\hackme)
2. DNS on the Domain Controller fails to resolve the name
3. Client broadcasts LLMNR/NBT-NS query to the local network:
   "Does anyone know where 'hackm' is?"
4. Attacker (running Responder) intercepts the broadcast
5. Attacker responds: "I am 'hackm' — send me your credentials"
6. Client automatically sends its NTLMv2 hash
7. Attacker captures the hash for offline cracking
```

> [!NOTE]
> This attack is analogous to **ARP spoofing** — the attacker impersonates a resource on the local network.

## Triggering the Attack (Victim Side)

On the Windows victim machine, the user navigates in File Explorer to an invalid UNC path or the attacker's IP:

```
\\192.168.75.131
```

DNS fails → client broadcasts → Responder intercepts and captures the NTLMv2 hash.

## Cracking the Captured Hash

### Save the Hash

Copy the full NTLMv2 hash string from Responder output and save it to a file:

```bash
nano hash.txt
# Paste the complete hash string
```

### With Hashcat (NetNTLMv2 — Mode 5600)

```bash
# Find the correct mode
hashcat --help | grep -i NTLM

# Crack
hashcat -m 5600 hash.txt rockyou.txt --force -O

# View cracked password
hashcat -m 5600 hash.txt rockyou.txt --show
```

### With John the Ripper (SAM / NT hashes)

```bash
john --wordlist=/usr/share/wordlists/rockyou.txt hash.txt --format=nt
```

> Format: `RID : LM hash : NT hash`

## Mitigations

| Mitigation | How |
|---|---|
| **Disable LLMNR** | GPO → `Computer Configuration → Administrative Templates → Network → DNS Client` → **Turn off Link-Local Multicast Name Resolution** = Enabled |
| **Disable NBT-NS** | Network Adapter Properties → TCP/IPv4 → Advanced → WINS tab → **Disable NetBIOS over TCP/IP** |
| **Network Access Control** | Deploy NAC, network segmentation, and firewalls to prevent rogue devices |
| **Strong Passphrases** | Enforce complex domain passphrases of **16+ characters** to resist offline cracking |
