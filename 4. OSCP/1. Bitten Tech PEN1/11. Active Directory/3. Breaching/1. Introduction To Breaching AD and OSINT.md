## Lab Setup

### 1. Connect to the Special VPN

This room uses a **dedicated VPN segment** — standard TryHackMe OpenVPN configs will not work.

1. Navigate to the TryHackMe Access page → select the **Breaching AD** network pack.
2. Download the custom OpenVPN config file.
3. Connect:

```bash
sudo openvpn breaching_ad.ovpn
```

4. Verify your connection shows **Connected** with an assigned internal IP.

![415](attachments/Pasted%20image%2020261005085933.png)

### 2. Configure DNS

Connecting to the VPN alone is insufficient — local DNS must resolve lab domain names.

1. Open **Advanced Network Configuration** in Kali.

![277](attachments/Pasted%20image%2020261005104322.png)

2. Double-click your connection name.

![432](attachments/Pasted%20image%2020261005104450.png)

3. Go to **IPv4 Settings**.

![459](attachments/Pasted%20image%2020261005104545.png)

4. In **Additional DNS Servers**, enter the DC IP first, then Google DNS for internet access:

```
10.200.70.101, 8.8.8.8
```

![505](attachments/Pasted%20image%2020261005104653.png)

![509](attachments/Pasted%20image%2020261005104836.png)

5. Save, then restart NetworkManager:

```bash
sudo systemctl restart NetworkManager
```

## Initial Access Vectors

### 1. OSINT (Open Source Intelligence)

OSINT is used to discover publicly disclosed credentials and information:

- **Stack Overflow / Public Forums**: Users posting questions that inadvertently contain credentials, connection strings, or API keys.
- **GitHub / Public Repos**: Developers uploading scripts with hardcoded credentials. Tools like **GitLeaks** and **TruffleHog** help identify these.
- **Breach Aggregation Platforms**:
  - [Have I Been Pwned](https://haveibeenpwned.com/) — check if work emails were exposed in data breaches.
  - [DeHashed](https://www.dehashed.com/) — search for leaked credentials from historical breaches.

> [!IMPORTANT]
> OSINT credentials may be outdated. Found credentials must be **validated** against live services (e.g., NTLM-authenticated web apps) to confirm they are still active.

### 2. Phishing

- **Credential Harvesting**: Malicious web pages mimicking legitimate login portals to capture user credentials.
- **RAT Deployment**: Emails with malicious attachments or macros that install a Remote Access Trojan (RAT) running under the victim's AD context.

> [!TIP]
> Phishing is especially powerful because a RAT executes in the **user's AD context**, immediately allowing impersonation of their domain account.
