
## Lab Setup

tryhackme Persisting Active Directory
https://tryhackme.com/room/persistingad

1. Download the room-specific VPN and connect.
2. Set DNS so you can resolve the AD domain:
   - Network Manager → Advanced Network Configuration → Your Connection → IPv4 Settings
   - Set DNS to the **THMCHILDDC** IP from the network diagram.
   - Add a second DNS (e.g. `1.1.1.1`) to keep internet access.
   - `sudo systemctl restart NetworkManager`, then test DNS.
3. Request a credential pair at [http://distributor.za.tryhackme.loc/creds](http://distributor.za.tryhackme.loc/creds) → **Get Credentials**.

These credentials give RDP + SSH access to **THMWRK1.za.tryhackme.loc**, the jump host (simulated foothold). Use Remmina/any RDP client (domain `za.tryhackme.loc`), or SSH (faster):

```
ssh za.tryhackme.loc\\<AD Username>@thmwrk1.za.tryhackme.loc
```
