# Introduction to User Access Control (UAC)

---

## What is UAC?

User Access Control is a Windows security feature that forces **all applications and processes to run at Medium integrity level** (non-admin context) by default — even for Administrator accounts.

- Explicit consent is required every time an admin action is needed
- **Admin user** → simple Yes/No **consent prompt**
- **Non-admin user** → must enter Administrator **credentials** (username + password)
- If UAC is disabled → High integrity is granted directly (insecure)

> [!IMPORTANT]
> If you get a reverse shell as an admin user with UAC enabled, your shell will still be at **Medium integrity level**. You do NOT get High integrity automatically.

| Scenario | What Happens |
|----------|-------------|
| Admin attempts admin task | Consent prompt (Yes/No) → desktop dims (Secure Desktop mode) |
| Non-admin attempts admin task | Credential prompt (username + password of an admin account) |
| Admin opens normal CMD | Runs at **Medium** integrity |
| Admin right-clicks CMD → "Run as Administrator" | UAC prompt → Yes → runs at **High** integrity |

## UAC Slider Levels

![406](attachments/Pasted%20image%2020260923115509.png)

![700](attachments/Pasted%20image%2020260923115413.png)

| Slider Position | Behavior |
|----------------|----------|
| **Always Notify** (highest — recommended) | Prompts for ALL changes — apps installing software AND user modifying Windows settings |
| **Default** (second from top) | Notifies only when **apps** attempt changes; does NOT prompt when user changes settings |
| **Lower positions** | Reduced prompting — less secure |
| **Never Notify** (lowest) | UAC effectively disabled — everything runs at High integrity |

> [!TIP]
> From a security standpoint, **"Always Notify"** (top position) is recommended. It forces verification for every change.

## Why UAC Matters for PrivEsc

- In a pentest, your reverse shell runs at Medium integrity even if the account is in `Administrators`
- You have no GUI to click "Yes" on UAC prompts in a reverse shell
- **UAC Bypass** techniques are used to escalate from Medium → High integrity without GUI interaction
- Understanding UAC slider levels and integrity token mechanics is essential for UAC Bypass exploitation (covered in later modules)
