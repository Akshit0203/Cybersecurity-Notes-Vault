# Introduction to Enumeration

---

## Manual vs Automated Enumeration

| | Manual | Automated |
|---|--------|-----------|
| **Strengths** | More control on vectors, More accuracy & depth, Less noisy, Fewer false positives | Efficiency & speed, Documentation support, Broader coverage |
| **Weaknesses** | Time consuming, Prone to oversight | More noisy, More false positives |

---

## Manual Enumeration — Command Quick Reference

### User Enumeration

```cmd
whoami
net user
net user <username>
```

### Group Enumeration

```cmd
net localgroup
net localgroup <group name>
```

### Hostname

```cmd
hostname
```

### Operating System

```cmd
systeminfo
systeminfo | findstr /B /C:"OS Name" /C:"OS Version" /C:"System Type"
```

### Process & Service Enumeration

```cmd
tasklist
tasklist /SVC
```

### Network Enumeration

```cmd
ipconfig /all
route print
netstat -ano
```

### Firewall Enumeration

```cmd
netsh advfirewall show currentprofile
netsh advfirewall firewall show rule name=all
```

### Scheduled Tasks

```cmd
schtasks /query /fo LIST /v
```

### Installed Software

```cmd
wmic product get name, version, vendor
wmic qfe get Caption, Description, HotFixID, InstalledOn
```

### Readable/Writable Files

```cmd
accesschk.exe -uws "Everyone" "C:\Program Files"
```

```powershell
Get-ChildItem "C:\Program Files" -Recurse | Get-ACL | ?{$_.AccessToString -match "Everyone\sAllow\s\sModify"}
```

### Mounted File Systems

```cmd
mountvol
```

### Drivers & Modules

```powershell
driverquery.exe /v /fo csv | ConvertFrom-CSV | Select-Object 'Display Name', 'Start Mode', Path
```

```powershell
Get-WmiObject Win32_PnPSignedDriver | Select-Object DeviceName, DriverVersion, Manufacturer | Where-Object {$_.DeviceName -like "*VMware*"}
```

### AutoElevate Binaries (AlwaysInstallElevated)

```cmd
reg query HKEY_CURRENT_USER\Software\Policies\Microsoft\Windows\Installer
reg query HKEY_LOCAL_MACHINE\Software\Policies\Microsoft\Windows\Installer
```
