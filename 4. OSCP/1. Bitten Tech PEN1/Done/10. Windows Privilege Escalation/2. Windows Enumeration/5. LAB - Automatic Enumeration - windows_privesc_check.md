## Tool Overview

**windows-privesc-check** is a standalone Python-compiled executable that finds misconfigurations allowing local unprivileged users to escalate privileges. It can run as a normal user or as Administrator (better results as Admin).

---

## Usage

### Help menu

```cmd
.\windows-privesc-check2.exe --help
```

### Key modes

| Mode | Description |
|------|-------------|
| `--dump` | Dumps raw info for manual analysis |
| `--dumptab` | Tab-delimited output format |
| `--audit` | Identifies and reports security weaknesses |
| `--pyshell` | Interactive Python shell |

### Key check flags

| Flag | Check |
|------|-------|
| `-a` | All simple checks (non-slow) |
| `-A` | All files and directories (slow) |
| `-S` | Windows Services |
| `-R` | Processes |
| `-r` | Registry settings + permissions |
| `-G` | Groups |
| `-U` | Users |
| `-H` | Shares |
| `-I` | Installed software |
| `-j` | Scheduled tasks |
| `-k` | Kernel drivers |
| `-D` | Drives |
| `-e` | Misc security-related registry keys |
| `-t` | PATH |
| `-L` | Logged in users |
| `-P` | Program Files directory tree |

### Report options

| Flag | Description |
|------|-------------|
| `-o <stem>` | Output filename stem (generates `.txt` and `.html`) |
| `-c` | Report only issues for current user |
| `-v` | Verbose output |

---

## Recommended Commands

### Complete audit (current user only)

```cmd
.\windows-privesc-check2.exe --audit -a -c -o privesc-report
```

### Dump all info

```cmd
.\windows-privesc-check2.exe --dump -a
```

### Audit services only

```cmd
.\windows-privesc-check2.exe --audit -S -o services-report
```

### Include slow filesystem checks

```cmd
.\windows-privesc-check2.exe --audit -A -o privesc-report
```

### View report

```cmd
type privesc-report.txt
```

## Why Not to Use This Tool

| Issue | Detail |
|-------|--------|
| No color coding | Raw monochrome text output |
| Verbose/noisy | Dumps raw values without meaningful analysis |
| Slow | `-a` can take 10-15+ minutes |
| Technical jargon | Uses Windows internal labels without explanation |
| No actionable findings | Doesn't highlight exploitable misconfigurations |
| Redundant | Everything it does, WinPEAS does better |

> [!TIP]
> **Use WinPEAS instead.** If you want a second opinion tool after WinPEAS, consider **PowerUp.ps1** or **PrivescCheck** rather than this.
