# LAB — Insecure GUI Apps

> **Lab**: [TryHackMe — Windows 10 PrivEsc](https://tryhackme.com/room/windows10privesc)
> **Concept**: GUI applications running as Administrator can be hijacked through built-in File → Open dialogs to spawn elevated shells

---

## Theory

### What Are Insecure GUI Apps?

- Some applications **require** administrative privileges by design (updaters, installers, backup tools, network utilities, virtualization software)
- These run in a **high integrity** context even when the logged-in user is low-privileged
- The user is granted permission to **run the application** but not full administrator rights — they temporarily elevate only for that specific task
- If such an application provides a **File → Open** dialog, it can be used to launch `cmd.exe` or PowerShell at the app's elevated privilege level

### Exploitation Logic

1. Identify a GUI application running as Administrator
2. Use its **File → Open** dialog to navigate to `C:\Windows\System32\cmd.exe`
3. Open `cmd.exe` → it spawns in the **same elevated context** as the application

---

## Enumeration

Identify which user context running applications are executing under:

```cmd
tasklist /V | findstr <app_name>
```

Example:
```cmd
tasklist /v | findstr /i paint
```

The output shows `mspaint.exe` is running under the **admin** user context.

## Exploitation — MS Paint

### Setup

On the desktop there is an "Admin Paint" shortcut that launches MS Paint with admin privileges:

![](attachments/Pasted%20image%2020260930103458.png)

When clicked, a cmd window briefly flashes, then Paint opens:

![](attachments/Pasted%20image%2020260930103549.png)

### Steps

1. Open the Paint application (already running as admin)

2. Click **File → Open**

   ![](attachments/Pasted%20image%2020260930104512.png)

3. In the File Open dialog, type the full path in the **File Name** field:

   ```
   C:\Windows\System32\cmd.exe
   ```

   ![](attachments/Pasted%20image%2020260930104828.png)

4. Press **Enter** → a command prompt spawns with admin privileges:

   ![](attachments/Pasted%20image%2020260930104934.png)

> [!TIP]
> If the file type filter is set to "All Picture Files", `cmd.exe` won't appear in the file browser. Change the filter to **All Files** or simply type `cmd.exe` directly in the File Name field.

## Alternative — File Explorer

If File Explorer is running in an elevated context:

1. Go to **File → Open Windows PowerShell → Frequent Places: Desktop**
2. Navigate back and repeat — you'll get the option **"Open Windows PowerShell as Administrator"**

## Integrity Level Considerations

After spawning the elevated `cmd.exe`, check the integrity level:

```cmd
whoami /all
```

> [!WARNING]
> If **UAC** is enabled, the spawned shell may still be at **Medium Integrity** despite belonging to the admin account. You would then need to perform a **UAC bypass** to reach High Integrity. However, gaining access to the admin user context is the primary milestone — UAC bypass from there is straightforward.

---

## Key Takeaways

- Always check running process contexts using `tasklist /V` alongside automated tools like WinPEAS
- Look for GUI apps with **File → Open** dialogs running as elevated users
- Common exploitable applications: **MS Paint**, **Internet Explorer/Edge file dialogs**, **Task Manager (Run New Task)**, **Help Viewer (CHM files)**, **File Explorer**
- This vector is **rare** but effective when present
- After gaining admin context, perform a **UAC bypass** if the shell is at Medium Integrity
