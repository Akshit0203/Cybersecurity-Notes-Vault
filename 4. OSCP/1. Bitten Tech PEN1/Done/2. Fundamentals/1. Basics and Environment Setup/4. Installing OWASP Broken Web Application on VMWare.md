# Installing OWASP Broken Web Application on VMWare


---

## What is OWASP BWA?

**OWASP BWA is a pre-configured Virtual Machine** (similar to Metasploitable) — a **complete, all-in-one web penetration testing environment**. It comes pre-installed with a vast collection of intentionally vulnerable web applications:

- **bWAPP**
- **DVWA** (Damn Vulnerable Web Application)
- **OWASP Juice Shop**
- **OWASP Mutillidae**
- **OWASP WebGoat** (an independent web application by OWASP)
- **Realistic vulnerable projects** (such as the Vicnum project)
- **Vulnerable CMS** — older, exploitable versions of **WordPress** (Broken WordPress) and **Joomla**

> [!TIP]
> Installing this single VM covers all your basic web application penetration testing needs — no need to install each platform individually.

---

## Installation Steps

### 1. Download and Extract

Download the VM from the official source website. Extract the archive folder — inside you'll find a **`.vmx` file** (the virtual machine configuration file).

![](attachments/Pasted%20image%2020260710215347.png)

![](attachments/Pasted%20image%2020260710215405.png)

### 2. Open in VMWare

Open the `.vmx` file in VMWare.

![](attachments/Pasted%20image%2020260710230617.png)

### 3. Start the VM

Power on the virtual machine. If prompted during first boot, click **"I copied it"**. It may take some time to load all web services and background processes during initial startup.

### 4. Login

Once services are running, log in with root credentials:

```
username: root
password: owaspbwa
```

### 5. Find the VM's IP Address

```bash
ifconfig
```

![](attachments/Pasted%20image%2020260710230831.png)

---

## Accessing the Lab Environment

1. Open a web browser on your **host Windows machine**
2. Type the VM's IP address into the URL bar (e.g., `192.168.1.16`)
3. The main **OWASP BWA web portal** will load, displaying all available training applications

From this central portal, you can click on any application (bWAPP, DVWA, WebGoat, Joomla, etc.) to jump straight into testing. You can also choose specific attack categories matching the **OWASP Top 10** list.
