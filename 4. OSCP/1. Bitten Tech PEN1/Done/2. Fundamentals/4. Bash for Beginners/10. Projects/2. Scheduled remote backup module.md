# Scheduled Remote Backup Module

> **Goal:** Write a Bash script (under 10 lines) that creates a timestamped `.tar` backup of a local directory, copies it to a remote server via `scp`, and runs automatically on a cron schedule.

```bash
#!/bin/bash

filename="backup_`date +%d_%m_%Y_%H_%M_%S`.tar"

echo $filename

tar -cvf /home/kali/Downloads/code/backups/${filename} /home/kali/Downloads/code

scp /home/kali/Downloads/code/backups/${filename} kali@192.168.60.139:/home/kali/Downloads/linux_backups
```

---

## 1 — Timestamped Filename with `date`

Append a timestamp to the filename to keep every backup unique. Avoid spaces and colons — use underscores.

### Basic `date` (has spaces — unusable as a filename)

```bash
#!/bin/bash

filename="backup_`date`.tar"

echo $filename
```

```
$ ./code.sh
backup_Tue, Sep 22, 2026 2:54:03 PM.tar
```

> [!tip] There **must** be a space between `` `date `` and `+` when using format specifiers.

### Formatted `date` (clean filename)

```bash
#!/bin/bash

filename="backup_`date +%d_%m_%Y_%H_%M_%S`.tar"

echo $filename
```

```
$ ./code.sh
backup_22_09_2026_14_54_17.tar
```

## 3 — Remote Backup via `scp` + Passwordless SSH

### 3.1 — `scp` Syntax

```
scp <local_file> <user>@<server_ip>:<remote_path>
```

```

           [-i identity_file] [-J destination] [-l limit] [-o ssh_option]
           [-P port] [-S program] [-X sftp_option] source ... target
```

### 3.2 — Prepare the Remote Server (second Kali machine)

Create a directory on the remote server to receive backups:

```
┌──(kali㉿kali)-[~/Downloads]
└─$ mkdir linux_backups

┌──(kali㉿kali)-[~/Downloads/linux_backups]
```

Make sure SSH is running on the remote server:

```bash
sudo systemctl status ssh     # or sshd on some distros
sudo systemctl start ssh      # start if stopped
sudo systemctl enable ssh     # start at boot
```

## 4 — Automating with Cron Jobs

### Crontab Syntax

```
[Minute] [Hour] [Day of Month] [Month] [Day of Week]  <user>  <command>
```

| Schedule        | Meaning             |
| --------------- | ------------------- |
| `0 2 * * *`     | Daily at 2:00 AM    |
| `*/5 * * * *`   | Every 5 minutes     |
| `0 0 20 * *`    | 20th of every month at midnight |
| `* * * * *`     | Every minute (testing) |

> Use https://crontab.guru/ for easy schedule building.

### Adding the Cron Job

Edit the system-wide crontab:

```bash
nano /etc/crontab
```

![](attachments/Pasted%20image%2020260922180325.png)

Add this line (runs every minute for testing):

```
* * * * * kali /home/kali/Downloads/code/code.sh
```

![](attachments/Pasted%20image%2020260922181834.png)

> [!warning] `/etc/crontab` vs `crontab -e`
>
> | Crontab Type                    | Username Field? |
> | ------------------------------- | --------------- |
> | `crontab -e` (user crontab)    | **No**          |
> | `/etc/crontab` (system-wide)   | **Yes**         |
>
> If you forget the username field in `/etc/crontab`, cron will misparse the line and the job won't run.

### Alternative: explicitly invoke Bash

```
* * * * * kali /bin/bash /home/kali/Downloads/code/code.sh
```

### Ensure the script is executable and cron is running

```bash
chmod +x /home/kali/Downloads/code/code.sh
sudo systemctl status cron
```

## Quick Reference

### Final Script

```bash
#!/bin/bash

filename="backup_`date +%d_%m_%Y_%H_%M_%S`.tar"

echo $filename

tar -cvf /home/kali/Downloads/code/backups/${filename} /home/kali/Downloads/code

scp /home/kali/Downloads/code/backups/${filename} kali@192.168.60.139:/home/kali/Downloads/linux_backups
```

### Workflow Summary

```
1. date           → generate timestamped filename
2. tar -cvf       → create local .tar archive
3. scp            → copy archive to remote server (passwordless SSH)
4. crontab        → schedule the script to run automatically
```

### Key Commands Cheat Sheet

| Task                        | Command                                              |
| --------------------------- | ---------------------------------------------------- |
| Generate SSH key pair       | `ssh-keygen`                                         |
| Copy public key to server   | `ssh-copy-id -i ~/.ssh/id_ed25519.pub user@host`    |
| Create tar archive          | `tar -cvf dest.tar source_dir`                       |
| Extract tar archive         | `tar -xf file.tar`                                   |
| Inspect tar contents        | `tar -tf file.tar`                                   |
| Edit system crontab         | `nano /etc/crontab`                                  |
| Edit user crontab           | `crontab -e`                                         |
| Check cron service          | `sudo systemctl status cron`                         |
