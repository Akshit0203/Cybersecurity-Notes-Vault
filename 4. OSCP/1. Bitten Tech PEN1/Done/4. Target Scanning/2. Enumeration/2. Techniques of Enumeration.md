# Techniques of Enumeration

## Common Enumeration Techniques

- Extract **usernames** using email IDs
- Extract information using **default passwords** (manufacturer-set credentials left unchanged — easy to find, can yield direct access)
- Extract **usernames** using SNMP
- **Brute force Active Directory** (critical for corporate pentests — 90% of companies use Windows Server + AD)
- Extract **user groups** from Windows
- Extract information using **DNS Zone Transfer**

> [!important] Default Passwords
> Default passwords from manufacturers are often never changed. Finding one gives **direct access** without any hacking — and in bug bounty, this can pay well for very little effort.

## Services & Ports to Enumerate

| Port          | Protocol | Service                                         |
| ------------- | -------- | ----------------------------------------------- |
| **53**        | TCP/UDP  | DNS Zone Transfer                               |
| **135**       | TCP/UDP  | Microsoft RPC Endpoint Mapper                   |
| **137**       | UDP      | NetBIOS Name Service (NBNS)                     |
| **138**       | UDP      | NetBIOS Datagram Service                        |
| **139**       | TCP      | NetBIOS Session Service (SMB over NetBIOS)      |
| **445**       | TCP/UDP  | SMB over TCP (Direct Host)                      |
| **161**       | UDP      | Simple Network Management Protocol (SNMP)       |
| **162**       | TCP/UDP  | SNMP Trap                                       |
| **389**       | TCP/UDP  | Lightweight Directory Access Protocol (LDAP)    |
| **3268**      | TCP/UDP  | Global Catalog Service                          |
| **25**        | TCP      | Simple Mail Transfer Protocol (SMTP)            |

> [!tip] OSCP Relevance
> SMB, NetBIOS, DNS, and SNMP are the **backbone of enumeration** — essential for OSCP, CTFs, and real-world penetration testing. If enumeration reveals misconfigurations or credentials, you may not even need to proceed to exploitation.
