# NetBIOS Enumeration

## What is NetBIOS?

**NetBIOS (Network Basic Input/Output System)** is an API that allows applications on different computers to **communicate within a Local Area Network (LAN)**.

> **NetBIOS = a way for Windows machines to identify themselves and find/talk to other Windows machines.**

- Created by **IBM**, adopted and implemented by **Microsoft**
- Works through **TCP/IP** (originally ran on NetBEUI)
- Provides an **identity** to systems on a network
- Microsoft created NetBIOS as an API layer on top of TCP/IP — NetBIOS data is embedded directly into TCP/IP packets
- **Deprecated after Windows 7**, but still encountered in older/legacy networks

> [!note] IPv6 Limitation
> NetBIOS name resolution is **not supported** for IPv6.

---

## NetBIOS Name

- A **unique 16-character ASCII string** used to identify network devices over TCP/IP
- **15 characters** = device name
- **16th character** = reserved for service or name record type

### Simple Example

```
PC-A (Name: SALES-PC)
PC-B (Name: HR-PC)

NetBIOS query: "Who is HR-PC?" → "That's 192.168.1.20"
```

## NetBIOS Ports

| Port    | Protocol | Purpose                      | Memory Trick   |
| ------- | -------- | ---------------------------- | -------------- |
| **137** | UDP      | NetBIOS Name Service (NBNS)  | **Names**      |
| **138** | UDP      | NetBIOS Datagram Service     | **Datagrams**  |
| **139** | TCP      | NetBIOS Session Service      | **Sessions**   |

You'll commonly see **139 alongside 445** during SMB enumeration.

## NetBIOS vs SMB

```
NetBIOS → Provides naming/session services
SMB     → File/printer sharing protocol
```

Historically, **SMB ran over NetBIOS** using TCP 139. Modern Windows uses **SMB directly over TCP 445**.

## What Can Attackers Obtain via NetBIOS Enumeration?

### Information Gathered
- List of **computers** that belong to a domain
- List of **shares** on individual hosts in the network
- **Policies and passwords**

### Actions an Attacker Can Perform
- **Read/Write** to shared resources (depending on share availability)
- Launch **DoS** (Denial of Service) attacks on the target
- Enumerate **password policies**

## Enumeration Tool: `nbtstat` (Windows)

`nbtstat` is a built-in Windows utility that displays NetBIOS over TCP/IP (NetBT) protocol statistics, NetBIOS name tables, and name cache.

### Key Commands

```cmd
nbtstat -c
```
→ Get contents of the **NetBIOS name cache** (names and their resolved IPs)

```cmd
nbtstat -A <IP address>
```
→ Get the **NetBIOS name table** of a remote computer using its IP

```cmd
nbtstat -a <hostname>
```
→ Get the **NetBIOS name table** of a remote computer using its hostname

```cmd
nbtstat -n
```
→ List **local** NetBIOS names

## Is NetBIOS Still Relevant Today?

**Yes**, but mostly as a **legacy technology**:

| Where You'll Encounter It                                 |
| --------------------------------------------------------- |
| **Windows/Active Directory environments** (especially older/poorly hardened) |
| **SMB enumeration** (reveals hostnames, workgroup/domain info) |
| **CTFs / OSCP labs** (intentionally expose legacy services) |
| **Internal penetration tests** (ports 137, 138, 139)      |

> **Modern mental model:** NetBIOS = older Windows naming/session technology that you may still find around, especially in internal networks.

### OSCP Rule of Thumb

If Nmap shows:

```
139/tcp open  netbios-ssn
445/tcp open  microsoft-ds
```

→ Investigate **Windows/SMB** immediately.

You can enumerate:
- Host/computer names
- Workgroup/domain information
- SMB shares
- Users and sessions
- OS information

### Quick Enumeration Commands

```bash
nmap -sV -p 139,445 <IP>
```

```bash
nbtscan <IP>
```
