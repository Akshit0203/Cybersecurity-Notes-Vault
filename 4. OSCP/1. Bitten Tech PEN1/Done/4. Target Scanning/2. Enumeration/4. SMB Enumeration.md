# SMB Enumeration

## What is SMB?

**SMB (Server Message Block)** is a protocol for sharing resources like **files, printers, and other network resources** between computers.

> **SMB = a protocol that allows computers to share files, folders, printers, and other resources over a network.**

```
PC-A                         PC-B
┌──────────┐                ┌──────────────┐
│          │   SMB          │              │
│          │ ─────────────► │ Shared Folder│
│          │                │              │
└──────────┘                └──────────────┘

Access: \\PC-B\Shared  ← This is an "SMB share"
```

- **Natively available in Windows** (no third-party software needed)
- For **Linux**, you must install the **Samba server** (Linux's SMB implementation)
- Operates at **Layer 7** (Application Layer) of the OSI model
- **Much more relevant than NetBIOS** today, especially for Windows/AD and OSCP

---

## SMB Ports

| Port        | Purpose                    | Era        |
| ----------- | -------------------------- | ---------- |
| **139/TCP** | SMB over NetBIOS           | Old        |
| **445/TCP** | SMB directly over TCP      | Modern     |

```
OLD:     SMB → NetBIOS → TCP 139
MODERN:  SMB → TCP 445
```

> **NetBIOS ≠ SMB** — but historically they were commonly used together.

---

## What is SMB Used For?

### 1. File Sharing
```
\\FILESERVER\Finance
\\FILESERVER\HR
\\FILESERVER\Public
```

### 2. Printer Sharing
Access network printers via SMB.

### 3. Windows Administration
SMB is involved in several Windows administrative mechanisms — critical in Windows/AD environments.

### 4. Authentication
SMB uses **NTLM** and **Kerberos** authentication, making it extremely interesting during pentesting.

Important implementations include: **CIFS, Samba, NQ, MoSMB, Tuxera SMB, Likewise**

## Why is SMB Relevant for OSCP?

When you find `445/tcp open`, you can potentially discover:

| Category           | Information                               |
| ------------------ | ----------------------------------------- |
| Infrastructure     | Host/domain info, SMB version/dialect     |
| Access             | SMB shares, share permissions, anonymous access |
| Identity           | Users/groups                              |
| Security           | Misconfigurations, sensitive files, credentials |
| Exploitation       | Potential vulnerabilities, lateral movement paths |

### Example: Share Enumeration

```bash
nmap -p445 --script smb-enum-shares <IP>
```

Could reveal:

```
Share        Access
-----        ------
ADMIN$       denied
C$           denied
Public       READ
Backup       READ/WRITE
```

### Why SMB Can Be Dangerous

If you discover a **readable share** like `\\192.168.1.50\Backup`, you might find:

```
backup.zip
passwords.txt
web.config
database.sql
```

→ Credentials or information leading to another attack.

A **writable share** opens even more possibilities depending on how that share is used.

---

## SMB Vulnerabilities

SMB itself has had major vulnerabilities. One famous example: **EternalBlue** (targeting SMBv1).

Security scanners commonly check:
- 445/TCP status
- SMB version
- SMB signing
- Known SMB vulnerabilities

> [!warning] Common Mistake
> **445 open ≠ vulnerable.** An open SMB port simply means there is an SMB service to enumerate. You still need to determine what is actually exposed.

## OSCP Mental Model

When Nmap gives you:

```
139/tcp open  netbios-ssn
445/tcp open  microsoft-ds
```

Follow this workflow:

```
        SMB FOUND
            │
            ▼
     Enumerate SMB
            │
     ┌──────┼──────┐
     ▼      ▼      ▼
  Shares   Users  Version
     │
     ▼
Permissions?
     │
 ┌───┴────┐
 ▼        ▼
READ     WRITE
 │        │
 ▼        ▼
Files   Potential
        attack paths
```

> **SMB = Windows network resource-sharing protocol.**  
> **445/TCP = modern SMB.**  
> **139/TCP = SMB over NetBIOS.**  
> **If 445 is open → enumerate SMB.**
