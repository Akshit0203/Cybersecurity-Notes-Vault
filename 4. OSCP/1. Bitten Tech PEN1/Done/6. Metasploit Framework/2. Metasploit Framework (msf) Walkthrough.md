# Metasploit Framework (msf) Walkthrough

## Starting Metasploit

```bash
msfconsole
```

---

## Searching for Exploits

Search by keyword, service name, or version:

```
msf > search windows
```

---

## Getting Info on an Exploit

View full details — description, references, targets, options:

```
msf > info exploit/multi/http/vbulletin_widget_template_rce
```

---

## Selecting an Exploit

```
msf > use exploit/multi/http/vbulletin_widget_template_rce
```

---

## Viewing & Configuring Options

```
msf exploit(multi/http/vbulletin_widget_template_rce) > show options
```


---

## Setting Required Options

Set all options marked `Required = yes`:

```
set RHOSTS <target_ip>
```

> [!IMPORTANT]
> The main option you **must** set is `RHOSTS` (the victim's IP address). `LHOST` (your IP) and `LPORT` (your listening port) are typically required for reverse payloads.
