# LAB — Pivoting With Socat

## Concept: Port Forwarding With Socat

> Socat can perform port forwarding when SSH is unavailable. It is simpler but less flexible than SSH or Chisel. One disadvantage: you must **transfer the socat binary** to the pivot host, making it more detectable.

### Basic Syntax

```bash
socat TCP4-LISTEN:<listen_port>,fork TCP4:<target_ip>:<target_port>
```

- `fork` — spawns a new process for each connection (handles multiple concurrent connections)
- Without `fork`, socat closes after the first connection ends

> [!IMPORTANT]
> Socat opens the listening port on the **pivot machine** — NOT on the attacker. This is a key difference from Chisel (with `--reverse`).

### Example: Forward RDP Through Pivot

**On Pivot (PC-1):**

```cmd
socat TCP4-LISTEN:3389,fork TCP4:3.3.3.3:3389
```

![SOCAT port forwarding 1](https://cdn-images.tryhackme.com/user-uploads/5ed5961c6276df568891c3ea/room-content/d7128a0e5d344785ed570c2b8b90c775.png)

### Example: Expose Attacker's Web Server to Internal Network

**On Pivot (PC-1):**

```cmd
socat TCP4-LISTEN:80,fork TCP4:1.1.1.1:80
```

PC-1 spawns port 80 and forwards connections to port 80 on the attacker:

![SOCAT port forwarding 2](https://cdn-images.tryhackme.com/user-uploads/5ed5961c6276df568891c3ea/room-content/4874c8eb2e92a55b93c3dbbc2409e54b.png)

### Firewall Rule (If Needed)

Since a port is opened on the pivot host, you may need:

```cmd
netsh advfirewall firewall add rule name="Open Port 3389" dir=in action=allow protocol=TCP localport=3389
```

## Dynamic Port Forwarding With SSH + SOCKS

When you need to scan many ports/hosts through a pivot, use **dynamic port forwarding** with a SOCKS proxy instead of individual forwards.

**On Pivot (PC-1) — reverse dynamic port forwarding via SSH:**

```cmd
ssh tunneluser@1.1.1.1 -R 9050 -N
```

This starts a SOCKS proxy on port `9050` on the SSH server (attacker), forwarding connections through the SSH tunnel.

**Configure Proxychains** — `/etc/proxychains.conf`:

```
[ProxyList]
socks4  127.0.0.1 9050
```

**Use Proxychains to route tools:**

```bash
proxychains curl http://pxeboot.za.tryhackme.com
```

> [!NOTE]
> Some tools like `nmap` may not work well with SOCKS and can show altered results.
