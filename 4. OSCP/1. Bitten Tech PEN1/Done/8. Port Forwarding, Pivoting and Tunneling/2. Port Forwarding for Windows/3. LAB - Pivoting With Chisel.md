
### Step 5 — Connect to Target via Chisel Tunnel (From Kali)

```bash
xfreerdp /v:127.0.0.1:3389 /u:t1_thomas.moore /p:MyPazzw3rd2020
```

> [!IMPORTANT]
> With Chisel, target `127.0.0.1` (localhost on Kali) — **NOT** the pivot's IP. Chisel forwards directly to your attacker machine, unlike Socat which opens the port on the pivot.

Now we are on **THM-IIS** through the Chisel tunnel.

### Step 6 — Verify

Run `hostname` inside the RDP session — it returns `THM-IIS`, confirming the tunnel works.

### Step 7 — Termination Test

After closing the Chisel tunnel, reconnection fails — proving access was purely through the port forward.

---

## Key Difference: Chisel vs Socat

| Aspect | Chisel | Socat |
|---|---|---|
| Port opens on | **Attacker** (`127.0.0.1`) | **Pivot** machine |
| Connect to | `127.0.0.1:<port>` | `<pivot_ip>:<port>` |
| Port in example | `3389` on localhost | `13389` on JMP2 |
