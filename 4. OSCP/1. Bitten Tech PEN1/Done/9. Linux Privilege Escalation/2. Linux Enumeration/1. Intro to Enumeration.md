# Introduction to Linux Enumeration

---

## What is Enumeration?

Enumeration is the **detailed, active analysis** of a system after gaining access to it. The goal is to **identify and map the attack surface** for privilege escalation.

### Reconnaissance vs Enumeration

| Aspect | Reconnaissance | Enumeration |
|---|---|---|
| **When** | Before initial access | After initial access (or deep pre-access analysis) |
| **Depth** | Surface-level — discover what the target is | Deep — discover how the target operates internally |
| **Type** | Active or passive | Almost always active (95%) |
| **Focus** | IP ranges, OS, ports, services, tech stack | Users, groups, kernel, processes, file permissions, configs |
| **Analogy** | Getting to know someone at surface level | Understanding someone deeply after spending time together |

> [!tip] Enumeration is a **critical step** in the privilege escalation workflow. Before trying any exploit, you must perform thorough enumeration to know **how** to escalate and **which** technique to apply.

## Manual vs Automated Enumeration

### Manual Enumeration

| Strengths | Weaknesses |
|---|---|
| **More control** over vectors and commands | **Time consuming** — one vector at a time |
| **Higher accuracy** — you analyze real I/O directly | **Human oversight** — may miss subtle details or edge cases |
| **Deeper analysis** — go as deep as needed | |
| **Less noisy** — targeted commands, minimal detection | |
| **Fewer false positives** — no signature-based guessing | |

> [!important] Manual enumeration should **always be your top priority**. Only use automated tools if manual analysis fails, you're stuck, or you're time-constrained (e.g., OSCP exam).

### Automated Enumeration

| Strengths | Weaknesses |
|---|---|
| **Fast & efficient** — scans all components at once | **More noisy** — triggers IDS/blue team alerts |
| **Documentation support** — redirect output to report files | **More false positives** — signature-based, can mislead |
| **Comprehensive coverage** — built from years of research | |

> [!warning] **Never rely blindly on automated tool output.** Always manually verify findings before pursuing an exploit, or you will waste time on false positives.

## Manual Enumeration Checklist

### 1. User Enumeration

| Method | Command / File |
|---|---|
| Current user | `whoami` |
| User ID, groups | `id` |
| All users | `cat /etc/passwd` |
| Home directories | `ls /home` |

### 2. Group Enumeration

| Method | Command / File |
|---|---|
| Current groups | `id` |
| All groups | `cat /etc/group` |

### 3. Hostname Enumeration

| Method | Command |
|---|---|
| Hostname | `hostname` |
| Full system info | `uname -a` |

### 4. Operating System Enumeration

| Method | Command / File |
|---|---|
| OS info | `cat /etc/issue` |
| Release details | `cat /etc/*-release` |
| Kernel version | `uname -a` |

### 5. Process & Service Enumeration

| Method | Command |
|---|---|
| Current session processes | `ps` |
| All processes (all users) | `ps aux` |
| Real-time process monitor | `top` |

### 6. Network Enumeration

| Method | Command |
|---|---|
| Active connections & listeners | `netstat -ano` |
| Socket statistics (modern) | `ss -anp` |
| IP addresses | `ip a` / `ifconfig` |
| Routing table | `/sbin/route` / `ip route` |

### 7. Firewall Enumeration

| Method | Command / File |
|---|---|
| Firewall rules | `iptables -L` |
| Firewall config | `/etc/iptables` |

### 8. Scheduled Tasks

| Method | Command / File |
|---|---|
| Cron jobs | `crontab -l` |
| System crons | `cat /etc/cron*` |

### 9. Installed Software

| Method | Command |
|---|---|
| Debian/Ubuntu | `dpkg -l` |
| Red Hat/CentOS | `rpm -qa` |

### 10. Readable/Writable Files

| Method | Command |
|---|---|
| World-writable dirs | `find / -writable -type d 2>/dev/null` |

### 11. Mounted File Systems

| Method | Command / File |
|---|---|
| Current mounts | `mount` |
| Block devices | `/bin/lsblk` |
| Filesystem table | `cat /etc/fstab` |

### 12. Drivers & Modules

| Method | Command |
|---|---|
| Loaded modules | `lsmod` |
| Module info | `/sbin/modinfo <module>` |

### 13. SUID Binaries

| Method | Command |
|---|---|
| Find SUID files | `find / -perm -u=s -type f 2>/dev/null` |

## Automated Enumeration Tools

| Tool | Description |
|---|---|
| **LinPEAS** | Best overall tool — color-coded, modular, links to HackTricks docs, actively maintained |
| **LinEnum** | Reliable shell script — good color output, keyword search, report export |
| **unix-privesc-check** | Checks file permissions heavily — Standard & Detailed modes, raw output |
| **linux-exploit-suggester** | Kernel-focused — compares kernel version against known CVEs |
| **linuxpriveschecker.py** | Python-based enumeration script |

> [!tip] **Recommended workflow:** Run manual enumeration first → then run LinPEAS to cross-validate and catch anything you missed.
