1. The proof file contents.
2. The target's IP address.

Final report upload — exact file format and procedure**

This is the submission process specified in the current Exam Guide.

Filename must be exact

Suppose your OSID is represented by `OS-XXXXX` in the following examples.

**Step 1 — Export your report as PDF**
```
OSCP-OS-XXXXX-Exam-Report.pdf
```
**Step 2 — Compress it into a 7z archive**
```
OSCP-OS-XXXXX-Exam-Report.7z
```
**Step 3 — Check the archive**
- Only the PDF report should be inside.
- Maximum size: 200 MB.
- Do not password-protect the archive.
- Include your scripts and PoC code as text inside the PDF, not as separate files.

**Step 4 — Upload**
**OffSec Exam Report Upload**
## [**upload.offsec.com**](https://upload.offsec.com?utm_source=chatgpt.com)

Official report submission portal

1. Log in.
2. Upload your `.7z` archive.
3. Check the MD5 hash displayed by OffSec.
4. Compare it with the MD5 hash of your local archive.
5. If they match, click **Submit File**.
6. Wait for the submission confirmation email.

**This is extremely important:** Uploading the archive alone is not sufficient. You must click the final **Submit File** button.
