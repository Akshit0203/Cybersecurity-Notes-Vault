Since you want to audit the Windows machine for privilege escalation weaknesses, use the following command based on the help output you provided.

### 1. Run a complete audit

```
.\windows-privesc-check2.exe --audit -a -o privesc-report
```

What it does:

|Option|Meaning|
|---|---|
|`--audit`|Identifies and reports security weaknesses|
|`-a`|Runs all simple checks (non-slow)|
|`-o privesc-report`|Saves the report using this filename stem|

It should generate report files such as:

```
privesc-report.txt
privesc-report.html
```

### 2. Audit only issues affecting your current user

```
.\windows-privesc-check2.exe --audit -a -c -o privesc-report
```

- `-c` → Reports privilege escalation issues relating to the current user.

### 3. Include slower file and directory checks

```
.\windows-privesc-check2.exe --audit -A -o privesc-report
```

- `-A` → Checks files and directories (slow).
    
- Use this when you want additional filesystem permission checks.
    

### Recommended OSCP command

Start with:

```
.\windows-privesc-check2.exe --audit -a -c -o privesc-report
```

Then inspect the generated report:

```
type privesc-report.txt
```

Tip: If the tool reports that a file already exists or requires a different output path, use another report filename, such as `audit1`.

Windows-privesc-check is standalone executable that runs on Windows systems. It tries to find misconfigurations that could allow local unprivileged users to escalate privileges to other users or to access local apps (e.g. databases).

It is written in python and converted to an executable using pyinstaller so it can be easily uploaded and run (as opposed to unzipping python + other dependencies). It can run either as a normal user or as Administrator (obviously it does a better job when running as Administrator because it can read more files).
