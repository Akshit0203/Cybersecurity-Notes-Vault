# Linux Package Manager — `apt`

> `apt` (Advanced Package Tool) is the default package manager for Debian-based distributions (Kali, Ubuntu, etc.). It handles installing, updating, upgrading, and removing software packages from repositories.

---

## Repositories & `sources.list`

Packages are downloaded from **remote repositories**. The repository URLs are stored in:

```
/etc/apt/sources.list
```

- This file must contain the **correct, up-to-date repository URLs** for your distribution
- For Kali Linux, get the latest repository entries from **kali.org** → search for "Kali rolling repositories"

### Example entries:

```
deb http://http.kali.org/kali kali-rolling main non-free-firmware
deb-src http://http.kali.org/kali kali-rolling main non-free-firmware
```

Paste these into `/etc/apt/sources.list` if they're missing or outdated.

## Getting Help — `man` (Manual Pages)

```bash
man apt      # Full manual for apt
man ls       # Full manual for ls
```

- `man <command>` → opens a detailed manual page with name, synopsis, description, and all options
- Press `Enter` to scroll, `q` to quit
- More comprehensive than `--help`

---

## `apt` vs `dpkg` vs `apt-get`

| Tool | Description |
| ---- | ----------- |
| `dpkg` | Low-level package manager (older, manual) |
| `apt-get` | Full-featured CLI tool (more options, more verbose) |
| `apt` | Modern, user-friendly wrapper around `apt-get` (shorter commands) |

> For everyday use, `apt` is sufficient. Use `apt-get` when you need advanced options.

## Essential `apt` Commands

### Update the Package Database

```bash
apt update
# or
apt-get update
```

- Downloads the **latest package index** from repositories
- Does **not** install or upgrade anything — only refreshes what's available
- **Always run this first** after a fresh install or before installing new packages

> [!TIP]
> If `apt update` fails, check that your system's **date and time** are correct. Incorrect timestamps cause SSL/certificate errors.

### Install a Package

```bash
apt install <package_name>
```

Example:

```bash
apt install geany
```

- If the package is already installed, it will **upgrade** it to the latest version
- To install **without upgrading**: `apt install <package> --no-upgrade`

### Search for a Package

```bash
apt search python
```

- Lists all packages matching the search term
- Useful when you don't remember the exact package name

### Remove a Package

```bash
apt remove <package_name>
```

### Upgrade All Installed Packages

```bash
apt upgrade
```

- **Updates** = refresh the database (what versions exist)
- **Upgrade** = actually download and install newer versions of installed packages

---

## Update vs Upgrade — Key Difference

| Command | What It Does |
| ------- | ------------ |
| `apt update` | Refreshes the **package database** — finds out what new versions are available |
| `apt upgrade` | **Downloads and installs** newer versions of all installed packages |

> Always run `apt update` **before** `apt upgrade` to ensure you're pulling the latest versions.
