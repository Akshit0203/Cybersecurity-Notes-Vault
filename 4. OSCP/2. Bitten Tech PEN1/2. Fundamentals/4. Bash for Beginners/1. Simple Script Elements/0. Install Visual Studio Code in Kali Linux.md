# Install Visual Studio Code in Kali Linux

---

## Download

Go to the [Visual Studio Code website](https://code.visualstudio.com/) and download the `.deb` file.

![](attachments/Pasted%20image%2020260816134513.png)

---

## Install

Since you already have the `.deb` file in your current directory, install it with `apt`:

```bash
sudo apt install ./code_1.133.0-1786487972_amd64.deb
```

> The `./` is important — it tells `apt`: "Install this `.deb` file from my current directory."

You'll be prompted for your Kali password. Type it and press **Enter**.

---

## Verify

```bash
code --version
```

Expected output:

```
1.133.0
...
```

---

## Launch

From the terminal:

```bash
code
```

Or open a specific folder:

```bash
code .
```

---

## Set Up a Bash Workspace

```bash
mkdir ~/bash-scripts
cd ~/bash-scripts
code .
```

This gives you a dedicated workspace for learning Bash.
