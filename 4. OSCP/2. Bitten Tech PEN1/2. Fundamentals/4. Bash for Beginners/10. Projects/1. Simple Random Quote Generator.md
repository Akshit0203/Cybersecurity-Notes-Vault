# Simple Random Quote Generator

> **Goal:** Build a Bash script that displays a random motivational quote every time you open a terminal.

---

## 1 — `$RANDOM`: Pseudo-Random Numbers in Bash

```bash
└─$ echo $RANDOM
19134
```

`$RANDOM` is called **pseudo-random** because Bash doesn't get each number from a truly unpredictable physical source. Instead, Bash uses an **algorithm** to calculate the next number.

When you do:

```bash
echo $RANDOM
```

Bash produces a number between:

```
0 → 32767
```

For example:

```
18472
2931
30122
847
```

Conceptually:

```
previous internal state
        ↓
   mathematical
    algorithm
        ↓
   next number
        ↓
    $RANDOM
```

The sequence is just:

```
state → algorithm → number → new state → algorithm → number → ...
```

### Why Is It Called "Pseudo"?

Because **the sequence is deterministic if you know the internal state/seed**.

Imagine a very simplified generator:

```
seed = 7

7 → algorithm → 42
42 → algorithm → 18
18 → algorithm → 91
91 → algorithm → 63
```

You see:

```
42, 18, 91, 63...
```

It _looks_ random.

But if someone knows the algorithm **and the starting state**, they can reproduce the exact same sequence:

```
7 → 42 → 18 → 91 → 63...
```

> **Pseudo-random = appears random, but is generated deterministically.**

### Why Isn't `$RANDOM` Suitable for Passwords?

Because `$RANDOM` is designed for ordinary scripting, not cryptography.

Don't use:

```bash
password=$RANDOM
```

for generating a security-sensitive password, token, session ID, encryption key, etc.

## 5 — Version 1: Basic Script (No Colors)

```bash
#!/bin/bash

i=0

while read -r line
do 
	arr[$i]=$line
	i=$((i+1))
done < quotes.txt

random=$((RANDOM%i))

echo -e "----------------------------------"
echo -e "======= WELCOME back `whoami`! ======="
echo ${arr[$random]}
echo -e "----------------------------------"
```

## 6 — Adding Colors with ANSI Escape Codes

> Reference: https://dev.to/ifenna__/adding-colors-to-bash-scripts-48g4

By using ANSI color escape codes, we can add color to output strings. The escape sequence format is `\e[COLORm`.

### Foreground & Background Color Codes

| Color         | Foreground Code | Background Code |
| ------------- | --------------- | --------------- |
| Black         | 30              | 40              |
| Red           | 31              | 41              |
| Green         | 32              | 42              |
| Yellow        | 33              | 43              |
| Blue          | 34              | 44              |
| Magenta       | 35              | 45              |
| Cyan          | 36              | 46              |
| Light Gray    | 37              | 47              |
| Gray          | 90              | 100             |
| Light Red     | 91              | 101             |
| Light Green   | 92              | 102             |
| Light Yellow  | 93              | 103             |
| Light Blue    | 94              | 104             |
| Light Magenta | 95              | 105             |
| Light Cyan    | 96              | 106             |
| White         | 97              | 107             |

### Text Style Codes

| Code | Description     |
| ---- | --------------- |
| 0    | Reset/Normal    |
| 1    | Bold text       |
| 2    | Faint text      |
| 3    | Italics         |
| 4    | Underlined text |

### How to Use

The `echo` command prints out text. We need to tell it that we're working with special ANSI codes, not just regular characters. This can be accomplished by adding a `\e` at the beginning to form an escape sequence. The escape sequence for specifying color codes is `\e[COLORm` (COLOR represents our color code in this case). By default, `echo` does not support escape sequences. We need to add the `-e` option to enable their interpretation.

To print red text:

```bash
echo -e "\e[32mRed text\e[0m"
```

The `\e[0m` means we use the special code 0 to reset text color back to normal. Without this, all other text you print out after this would be red.

### Using Variables for Readability

```bash
RED="\e[31m"
ENDCOLOR="\e[0m"

echo -e "${RED}Red text${ENDCOLOR}"
```

### Multi-Color Example

```bash
#! /usr/bin/env bash

RED="\e[31m"
GREEN="\e[32m"
ENDCOLOR="\e[0m"

echo -e "${RED}This is some red text, ${ENDCOLOR}"
echo -e "${GREEN}And this is some green text${ENDCOLOR}"
```

## 11 — Deep Walkthrough: How the Core Logic Works

Let's trace the script step-by-step with a small example `quotes.txt`:

```
Believe in yourself.
Never give up.
Keep learning.
Stay curious.
```

---

### Step 1: `i=0`

```bash
i=0
```

Bash creates a variable. We use `i` as the **array index**.

```
arr
 ↓
[0] ?
[1] ?
[2] ?
[3] ?
```

---

### Step 2: `while read -r line`

```bash
while read -r line
```

> Keep running the loop as long as `read` successfully reads another line.

`read` reads **one line at a time**. `line` is the variable that holds the current line.

When Bash reads the first line:

```
Believe in yourself.
```

it does essentially:

```bash
line = "Believe in yourself."
```

Then the loop body executes.

---

### Step 3: Where Does `read` Get the Lines From?

```bash
done < /home/kali/Downloads/code/quotes.txt
```

The `<` means:

> Take the contents of this file and provide them as the loop's standard input.

Instead of:

```
keyboard → read
```

you have:

```
quotes.txt → read
```

Therefore:

```
quotes.txt
    ↓
    read
    ↓
   line
```

---

### Step 4: First Iteration

Initially: `i = 0`

The first line is read: `line = "Believe in yourself."`

```bash
arr[$i]=$line
```

Bash first expands `$i`:

```bash
arr[0]=$line
```

Then `$line`:

```bash
arr[0]="Believe in yourself."
```

Array becomes:

```
arr
 │
 └── [0] → "Believe in yourself."
```

---

### Step 5: `i=$((i+1))`

```bash
i=$((i+1))
```

Arithmetic expansion: `0 + 1 = 1` → `i=1`

---

### Step 6: Second Iteration

Read: `Never give up.` → `line="Never give up."`, `i=1`

```bash
arr[1]="Never give up."
```

Array:

```
arr
 │
 ├── [0] → "Believe in yourself."
 └── [1] → "Never give up."
```

Then: `i=2`

---

### Step 7: Third Iteration

Read: `Keep learning.` → `line="Keep learning."`, `i=2`

```bash
arr[2]="Keep learning."
```

Array:

```
arr
 │
 ├── [0] → "Believe in yourself."
 ├── [1] → "Never give up."
 └── [2] → "Keep learning."
```

Then: `i=3`

---

### Step 8: Fourth Iteration

Read: `Stay curious.` → `line="Stay curious."`, `i=3`

```bash
arr[3]="Stay curious."
```

Array:

```
arr
 │
 ├── [0] → Believe in yourself.
 ├── [1] → Never give up.
 ├── [2] → Keep learning.
 └── [3] → Stay curious.
```

Then: `i=4`

The file has no more lines. `read` fails → the `while` loop stops.

### Why Is `i=4`?

Because there are **4 lines**. `i` started at 0:

```
first line  → index 0 → i becomes 1
second line → index 1 → i becomes 2
third line  → index 2 → i becomes 3
fourth line → index 3 → i becomes 4
```

So:

```
i = number of elements
```

while the last valid index is:

```
i - 1
```

---

### Step 9: `random=$((RANDOM%i))`

```bash
random=$((RANDOM%i))
```

Suppose Bash gives: `RANDOM = 19134` and `i = 4`

```
19134 % 4
```

`%` means **remainder**.

```
19134 ÷ 4 = 4783 remainder 2
```

Therefore: `random=2`

### Why `% i`?

The array has indices `0, 1, 2, 3`. We need a random index from `0 → 3`.

`RANDOM` itself can be `0 → 32767`, so:

```
RANDOM % 4
```

Possible results: `0, 1, 2, 3` — never 4. Exactly what we need.

```
RANDOM
  ↓
large number
  ↓
% 4
  ↓
0–3
  ↓
valid array index
```

---

### Step 10: Printing the Quote

```bash
echo -e "${QUOTECOLOR}${arr[$random]}\n"
```

Suppose `random=2`. Bash sees `${arr[$random]}`:

1. Evaluates `$random → 2`
2. Becomes `${arr[2]}`
3. `arr[2]` contains `Keep learning.`
4. The command becomes: `echo -e "${QUOTECOLOR}Keep learning.\n"`
5. `echo` prints the quote with color.

### Summary: The Three Variables

```
i
↓
Tells us WHERE to put the next quote.

line
↓
Contains the CURRENT quote being read.

random
↓
Tells us WHICH quote to retrieve at the end.
```
