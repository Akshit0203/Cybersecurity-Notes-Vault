# Bash `case` Statement

---

## Why `case` over `elif` Ladders?

- **Readability** — Cleaner than long chains of `elif` with `==` comparisons.
- **Maintainability** — Easy to add/remove options.
- **Best for** — Menu-driven scripts, option parsing, calculator-type programs.

---

## Syntax

```bash
case expression in 

	pattern1|pattern2)
		commands
		;;

	pattern3)
		commands
		;;

	*)
		commands
		;;

esac
```

| Element | Purpose |
|---------|---------|
| `case ... in` | Start the case block; evaluate the expression |
| `pattern)` | A value to match against |
| `pattern1\|pattern2)` | Match **multiple** patterns (pipe `\|` = OR) |
| `;;` | **Required** — terminates each pattern block |
| `*)` | **Default case** — runs if no pattern matches (like `else`) |
| `esac` | End the case block (`case` spelled backwards) |

---

## Example — Shell Calculator

```bash
#!/bin/bash

read -p "Enter first number:" a
read -p "Enter second number:" b

read -p "Enter operation (+,-,x,/):" op 

case $op in 

	+)
		echo $((a+b))
		;;

	-)
		echo $((a-b))
		;;

	x)
		echo $((a*b))
		;;

	/)
		echo $((a/b))
		;;

	*)
		echo "Operation not permitted"
		;;

esac
```

> **`read -p "prompt"`** — Displays the prompt string and reads input in one line (no separate `echo` needed).

### Test Runs

**Addition:**

```
└─$ ./new.sh 
Enter first number:10
Enter second number:20
Enter operation (+,-,x,/):+
30
```

**Invalid operation → default case:**

```
Enter first number:1
Enter second number:1
Enter operation (+,-,x,/):r
Operation not permitted
```

> ⚠️ **Why `x` instead of `*` for multiplication?** The `*` symbol is already used as the **default/wildcard** pattern in `case`. Using `*` for multiply would catch *everything* and break the logic.

> 💡 **Integer division note:** `$((10 / 20))` outputs `0` because Bash does integer-only math. For decimal results, pipe to `bc`: `echo "10 / 20" | bc -l`

## Multi-Pattern Matching with Pipes (`|`)

Handle case-sensitivity or synonyms by grouping patterns:

```bash
windows | Windows | WINDOWS)
    echo "You chose Windows"
    ;;
```

This matches all three casing variations in a single block — useful since Bash is **case-sensitive**.
