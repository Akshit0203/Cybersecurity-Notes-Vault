# Bash `if` Statement

---

## Syntax

```bash
if [ expression/condition ]; then
	commands
fi
```

- **Square brackets** `[ ]` with **spaces** on both sides are required.
- **`;`** before `then` is only needed if `then` is on the **same line** as `if`.
- The block ends with **`fi`** (reverse of `if`).

If `then` is on a new line, no semicolon is needed:

```bash
if [ condition ]
then
	commands
fi
```

---

## String Comparison — `if` / `if-else`

### Simple `if`

```bash
#!/bin/bash

echo "Enter your password:"
read pass

if [ $pass == "secret" ]
then

	echo "Login successful"

fi
```

```
└─$ ./new.sh
Enter your password:
secret
Login successful
```

### `if-else`

```bash
#!/bin/bash

echo "Enter your password:"
read pass

if [ $pass == "secret" ]
then

	echo "Login successful"

else 

	echo "Login not successful"

fi
```

```
└─$ ./new.sh
Enter your password:
test
Login not successful
```

> `if` and `else` are **mutually exclusive** — exactly one branch always executes.

## Numeric Comparison Operators

| Operator | Meaning |
|----------|---------|
| `-lt` | Less than |
| `-gt` | Greater than |
| `-le` | Less than or equal to |
| `-ge` | Greater than or equal to |
| `-eq` | Equal to |
| `-ne` | Not equal to |

### Example — Less Than (`-lt`)

```bash
#!/bin/bash

echo "Enter your number:"
read int

if [ $int -lt 100 ]
then

	echo "$int is less than 100"

else 

	echo "$int is greater than 100"

fi
```

```
└─$ ./new.sh
Enter your number:
12
12 is less than 100
```

### Example — Greater Than (`-gt`)

```bash
#!/bin/bash

echo "Enter your number:"
read int

if [ $int -gt 100 ]
then

	echo "$int is greater than 100"

else 

	echo "$int is less than or equal to 100"

fi
```

```
└─$ ./new.sh
Enter your number:
101
101 is greater than 100
```

### Example — Greater Than or Equal To (`-ge`)

```bash
#!/bin/bash

echo "Enter your number:"
read int

if [ $int -ge 100 ]
then

	echo "$int is greater than or equal to 100"

else 

	echo "$int is less than 100"

fi
```

```
Enter your number:
100    
100 is greater than or equal to 100
```

## Logical Operators — AND (`&&`) and OR (`||`)

### Method 1 — Single Brackets with External `&&`

Each condition gets its own `[ ]` block, connected by `&&` or `||` outside:

```bash
#!/bin/bash

echo "Enter your number:"
read int

if [ $int -le 100 ] && [ $int -gt 90 ]
then

	echo "Grade A"

else 

	echo "Grade not A"

fi
```

```
└─$ ./new.sh
Enter your number:
89
Grade not A

└─$ ./new.sh
Enter your number:
91
Grade A

└─$ ./new.sh
Enter your number:
101
Grade not A
```

### Method 2 — Double Brackets with Internal `&&`

`[[ ]]` allows `&&` and `||` **inside** a single expression block:

```bash
#!/bin/bash

echo "Enter your number:"
read int

if [[ $int -le 100 && $int -gt 90 ]]
then

	echo "Grade A"

else 

	echo "Grade not A"

fi
```

```
Enter your number:
95
Grade A

└─$ ./new.sh
Enter your number:
90
Grade not A
```

## Single Brackets `[ ]` vs Double Brackets `[[ ]]`

| Feature | `[ ]` (Single) | `[[ ]]` (Double) |
|---------|----------------|-------------------|
| POSIX compliant | ✅ Yes | ❌ No |
| Logical operators inside | ❌ Need separate `[ ]` per condition | ✅ `&&` and `||` inside one block |
| Portability | ✅ Works on all Unix/POSIX shells | ⚠️ Bash/Zsh-specific |
| Pattern matching | ❌ | ✅ |

> **Best practice:** Use single brackets `[ ]` or `test` for maximum portability (especially if you work across BSD, legacy, or minimal systems). Use `[[ ]]` for convenience in Bash-only scripts.

## The `test` Command — Alternative to `[ ]`

`test` is functionally identical to single brackets — it's the POSIX-standard way:

```bash
#!/bin/bash

echo "Enter your number:"
read int

if test $int -lt 100
then

	echo "Grade A"

else 

	echo "Grade not A"

fi
```

```
Enter your number:
89
Grade A
```

> `[ condition ]` is literally syntactic sugar for `test condition`.

## `elif` Ladder

```bash
#!/bin/bash

echo "Enter your number:"
read int

if [ $int -le 100 ] && [ $int -gt 90 ] 
then
        
	echo "Grade A"

elif [ $int -le 90 ] && [ $int -gt 80 ]
then 

	echo "Grade B" 

elif [ $int -le 80 ] && [ $int -gt 70 ]
then 

	echo "Grade C" 

else 

	echo "Grade not A"

fi
```

```
Enter your number:
75
Grade C

└─$ ./new.sh
Enter your number:
85
Grade B
```

> Add as many `elif` blocks as needed. The final `else` is the default/fallback.

## Nested `if` Statements

**Use case:** Finding the greatest of three numbers.

```bash
#!/bin/bash

echo "Enter first number:"
read a
echo "Enter second number:"
read b
echo "Enter third number:"
read c

if [ $a -gt $b ] 
then 

	if [ $a -gt $c ]
	then 

		echo "$a is greatest"

	else 

		echo "$c is greatest"
	fi

else 

	if [ $b -gt $c ]
	then 

		echo "$b is greatest"

	else 

		echo "$c is greatest"
	fi

fi
```

```
Enter first number:
5
Enter second number:
10
Enter third number:
15
15 is greatest
```

> ⚠️ Remember to close **every** inner `if` with its own `fi`.

## Complex Multi-Condition Expressions

Combine `&&` and `||` in a single `[[ ]]` expression:

```bash
#!/bin/bash

echo "Enter first number :"
read num

if [[ $num -gt 10 && $num -lt 100 || $num -lt 10 && num -gt 0 ]]
then 
	echo "True"
fi
```

```
Enter first number :
9
True

└─$ ./new.sh
Enter first number :
10
                  # (no output — 10 excluded by strict < and >)

└─$ ./new.sh
Enter first number :
11
True

└─$ ./new.sh
Enter first number :
101
                  # (no output — above 100)
```

> **Logic:** Prints "True" if `num` is between 0–10 (exclusive) **OR** between 10–100 (exclusive). The value `10` itself is excluded because both conditions use strict `>` and `<`.

> Use `-eq` if you need to include boundary values.
