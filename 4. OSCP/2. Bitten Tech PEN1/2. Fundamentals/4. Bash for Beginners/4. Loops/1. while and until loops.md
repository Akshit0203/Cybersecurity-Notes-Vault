### **Part 1: Introduction to Loops and** **for** **Loops in Bash**

Hello friends. In this video, we will talk about **loops**[1]. So regarding loops, the first loop we have is the **for** **loop**[1]. We will talk about it in this video[1]. You probably know about loops: whenever you need to repeat something multiple times or iterate through a range, you use loops[1]. Meaning, there is a piece of code, and you want to run it repeatedly—as many times as the user specifies, like 10 times, 20 times, or if you have an entire file, and you need to perform an operation on every single element in that file[1]. Meaning, you want to perform multiple operations together, or if there is a number range you need to print—say a range from 100 to 200, or from 1 to 1000—and you want to perform an operation across that whole range[1]. Or if you have many files, many files have been given to you, and you need to perform some operation on them or make web requests or anything—like deleting multiple files quickly—if you need to handle many things together, you have to use loops[1].

### **Part 2:** **for-in** **Method and Bash Loop Syntax**

I assume you have already studied loops and have some programming knowledge, so I won't go too deep into that[2]. But today, we will talk about how loops are used in Bash[2]. There are two types of loops in Bash: **for** and **while**[2]. In this video, we will discuss the `for` loop[2]. You can declare a `for` loop in two ways in Bash: one is the **for-in** **method**, and the second is the **C-style method**[2]. First, let's look at the `for-in` method[2]. I have created a separate file here[2]. You can create any simple program; I am just creating one as an example to show you[2].

The syntax in Bash is: `for`, followed by what you can call a placeholder or variable, then `in`, and here you specify that it's an **iterable**[2][3]. Here you provide a range[2]. You know that in a `for` loop, you provide a range rather than a condition[2]. You know that "I need to run from here to here," so when the range is known, you use a `for` loop[2].

Here you provide the iterable[3]. You can provide any range[3]. For example, as I showed you once before, what was the way to give a range? Inside curly braces `{ }`, write the starting number, two dots `..`, and the ending number `{1..10}`[3]. That creates a full range from 1 to 10[3]. You might have read in Python what iterables are[3]. If you want to specify step increments, add two more dots and the step value[3]. Right now, I am not giving a step[3].

The variable name can be anything; you can introduce a new variable, like `i` here[3]. So that is my syntax, but the syntax is not finished yet[3]. Similar to conditional `if` statements, if you write it on the same line, you must put a semicolon `;`, followed by **do**[3]. Just as `if` used `then`, `for` uses `do`[3]. And it ends with **done**[3]. Any commands placed inside will execute within the `for` loop[3].

### **Part 3: Executing Range Iteration and String Iteration**

I will write the commands here[4]. The inner commands execute per value[4]. Since I provided 1 to 10, these commands will run 10 times[4]. Now, if you place `do` on the next line, you don't need a semicolon—just put `do` on the new line[4]. So that is the complete syntax for my `for` loop[4].

Now, I want to print numbers from 1 to 10, so I will simply `echo $i`[4]. The dollar sign `$` is used to access the variable value[4]. This will print numbers from 1 to 10[4]. Let's make it executable and run it: 1, 2, 3... up to 10[4]. That is the simplest form of a loop[4]. You can also specify step sizes—for instance, step 2 will print 1, 3, 5, 7, 9[4][5].

That is one way to provide an iterable[5]. We can also work with strings[5]. Let's declare a string variable: `STR="Hello World this is dash"`[5]. To iterate through this sentence, you have two choices when iterating through a string: iterate by words or by lines[5]. If you want to iterate by words, simply write `$STR`[5]. It will iterate through each word—first `Hello`, then `World`, then `this`, then `is`—taking one word at a time and printing it[5].

Output: `Hello`, `World`, `this`, `is`, `dash`—it takes one word at a time[6]. Many times, you might have a file containing words on each line, like a wordlist, where words are separated by newlines rather than spaces[6]. To iterate line by line, you enclose the variable in **double quotes** **"$STR"**[6]. Double quotes treat newlines as the separator[6]. Also, put double quotes around `"$i"` in the `echo` command[6]. If you don't use double quotes, space acts as the separator; if you use double quotes, newlines act as the separator[6]. Running it prints each line separately[7].

### **Part 4: C-Style** **for** **Loop Syntax**

Now, let's return to numbers[7]. The `for-in` method was one way[7]. The second style is the **C-style method**[7]. If you have studied C, you will understand this: you partition three expressions[7]. First, define the initial value `i=1`, then a semicolon, then the ending condition `i&lt;=10`, and then the increment/decrement `i++`[7].

Syntax: `for (( i=1; i&lt;=10; i++ ))`[7]. It reads numbers from 1 to 10, incrementing one by one[7]. Printing it produces the exact same output as before with no difference[7][8]. These are the two ways to declare a `for` loop in Bash[8].

### **Part 5: Loop Control Keywords:** **break** **and** **continue**

There are two additional keywords that provide extra functionality: **break** and **continue**[8]. You have likely encountered these in most programming languages[8].

- **break**: Breaks the loop execution[8]. When the loop is running and hits a `break` statement, it exits that specific loop immediately[8]. If you have nested loops, it exits only the inner loop where `break` was triggered, and execution moves past it[8]. Let's test `break`: inside the loop, we add an `if` condition: `if [ $i -eq 5 ]; then break; fi`[8][9]. Running this prints only up to 4[9]. When `i` equals 5, it breaks out of the loop[9]. This is useful when taking user input in an infinite loop and breaking upon receiving a specific input[9].
- **continue**: Skips the rest of the current iteration and moves directly to the next iteration[9]. If the condition evaluates to true and `continue` is hit, nothing below it in the current iteration will run; the loop jumps directly to the next value[9]. If we write `if [ $i -eq 5 ]; then continue; fi` before the `echo` statement, the number 5 will not be printed[9][10]. It skips 5 and jumps directly to 6[10]. Make sure to place `continue` before your main commands; placing it at the very end of the loop block makes it redundant[10].

### **Part 6: Infinite Loops and** **sleep** **Command**

Another concept is the **infinite loop**, where a loop never terminates unless you press `Control+C` or a user provides a specific exit value[10][11]. You will use infinite loops often when creating menu-driven programs[11].

To write an infinite C-style loop, omit the initialization, condition, and increment expressions, leaving just double semicolons inside double parentheses: **for (( ;; ))**[11]. It has no start or end boundaries, so it runs indefinitely[11].

Be careful: printing continuously in an infinite loop can exhaust system memory and freeze your system[11]. To manage this, insert a delay using the **sleep** command—for example, `sleep 2` pauses execution for 2 seconds per iteration[11].

Let's increment a counter: set `count=1` initially, and inside the loop, increment it using arithmetic expansion `count=$((count + 1))`[12]. Running `for (( ;; ))` with `sleep 2` prints "infinite loop count 1", "2", "3"... running indefinitely until you press `Control+C` to terminate[12].
