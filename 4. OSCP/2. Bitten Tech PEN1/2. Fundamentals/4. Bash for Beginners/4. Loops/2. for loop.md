### **[Part 1: Introduction to Loops and** **for** **Loops in Bash]**

Hello friends. In this video, we will talk about **loops**[1]. The first loop we are going to discuss in this video is the **for** **loop**[1]. You probably know about loops: whenever you need to repeat a piece of code multiple times or iterate through a range of values, you use loops[1]. Whether you need to run a task as many times as specified by a user (like 10 or 20 times), iterate through every element in an entire file to execute multiple operations, print a range of numbers (such as 100 to 200 or 1 to 1000), or perform bulk actions across multiple files (like web requests or fast file deletions), you use loops to handle these repetitive tasks together[1].

---

### **[Part 2:** **for-in** **Method and Bash Loop Syntax]**

Assuming you already have foundational programming knowledge about loops, we will focus directly on how loops function in Bash[2]. Bash supports two primary loop types: **for** and **while**[2].

In Bash, a `for` loop can be declared using two distinct syntaxes:

1. The **for-in** **method**[2]
2. The **C-style method**[2]

First, let's look at the `for-in` method[2]. In Bash, the basic syntax begins with the keyword `for`, followed by a variable name (or placeholder) like `i`, the keyword `in`, and then an **iterable or range**[2][3]. Because a `for` loop is used when the exact start and end range is known in advance, you supply an iterable range rather than a conditional expression[2].

To specify a numerical range, you can use curly brace expansion `{1..10}`, which generates a range from 1 to 10[2][3]. Step increments can also be added using two additional dots `{1..10..2}`[2][3]. If the loop statement is written on a single line, you must place a semicolon `;` before the keyword **do**[3]. The loop body contains the commands to execute, and the entire block concludes with the keyword **done**[3]. If `do` is placed on a new line below `for`, the semicolon can be omitted[3][4].

---

### **[Part 3: Executing Range Iteration and String Iteration]**

The commands placed inside the `do...done` block execute once per item in the iterable range[3][4]. For example, iterating across `{1..10}` executes the inner block 10 times[4]. To print the current iteration value, run `echo $i`, using the `$` symbol to access the variable value[3][4]. Executing this script outputs numbers 1 through 10 sequentially[4]. Adding a step size of 2 `{1..10..2}` prints `1`, `3`, `5`, `7`, `9`[4].

Beyond numerical ranges, `for-in` loops can iterate through **strings**[5]. Consider a string variable: `STR="Hello World this is dash"`[5].

When iterating through a string, you can iterate word-by-word or line-by-line[5]:

- **Word-by-word iteration**: Referencing `$STR` without quotes iterates through each word separated by spaces, printing `Hello`, `World`, `this`, `is`, `dash` on separate lines[5].
- **Line-by-line iteration**: Wrapping the variable in double quotes `"$STR"` uses newlines as the separator rather than spaces[5]. Placing double quotes around `"$i"` inside `echo` ensures multi-line strings or line-separated wordlists are processed line by line[5].

---

### **[Part 4: C-Style** **for** **Loop Syntax]**

The second syntax option in Bash is the **C-style** **for** **loop**[2]. If you are familiar with C programming, this structure partitions three expressions inside double parentheses:

1. **Initialization**: `i=1`
2. **Condition**: `i&lt;=10`
3. **Increment/Decrement**: `i++`

The command is written as: `for (( i=1; i&lt;=10; i++ ))`

This loop initializes `i` at 1, evaluates whether `i` is less than or equal to 10, executes the loop body, and increments `i` by 1 after each pass, producing the exact same output (1 through 10) as the `for-in` range method.

---

### **[Part 5: Loop Control Keywords:** **break** **and** **continue** **]**

Bash provides two essential keywords to control loop execution flow:

- **break**: Instantly terminates the loop execution[1]. When encountered inside a loop (such as inside an `if` check `if [ $i -eq 5 ]; then break; fi`), execution immediately exits the current loop block[1]. This is commonly used in infinite loops to break execution upon receiving a specific user input[1].
- **continue**: Skips the remainder of the current iteration and jumps directly to the start of the next pass[1]. If a condition triggers `continue` (e.g., `if [ $i -eq 5 ]; then continue; fi` placed before `echo $i`), the rest of the loop body is bypassed for that specific value (skipping number 5) and proceeds to 6[1].

---

### **[Part 6: Infinite Loops and** **sleep** **Command]**

An **infinite loop** runs continuously without terminating until forcefully interrupted (e.g., via `Ctrl+C` or a break condition)[1]. Infinite loops are widely used when constructing interactive, menu-driven command scripts[1].

To write an infinite loop in C-style syntax, omit all three expressions inside the double parentheses, leaving only double semicolons: `for (( ;; ))`[1].

Because an unconstrained infinite loop executing `echo` continuously can consume excessive CPU/memory resources, you should introduce execution delays using the **sleep** command (e.g., `sleep 2` pauses execution for 2 seconds per cycle)[1]. Combining `count=$((count + 1))` with `sleep 2` inside an infinite loop allows steady, controlled execution until manually terminated[1].

---

### **[Conclusion]**

That covers the core fundamentals of `for` loops in Bash scripting, including `for-in` range expansion, string word/line iteration, C-style syntax, `break`/`continue` flow controls, and infinite loop management.
