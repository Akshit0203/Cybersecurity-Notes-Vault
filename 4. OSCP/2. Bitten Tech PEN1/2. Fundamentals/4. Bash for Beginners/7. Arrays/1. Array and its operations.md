# Arrays and Array Operations

> Bash supports **indexed arrays** (numbered) and **associative arrays** (key-value). Unlike full programming languages, Bash does **not** support multi-dimensional arrays. Arrays can hold mixed data types (heterogeneous).

---

## Array Types

| Type                | Declaration Flag | Index Type         | Example Key     |
| ------------------- | ---------------- | ------------------ | --------------- |
| **Indexed Array**   | `declare -a`     | Numerical (0, 1…)  | `arr[0]`        |
| **Associative Array** | `declare -A`   | String keys        | `arr[first]`    |

---

## Declaring and Initializing

### Indexed Arrays

```bash
#!/bin/bash

declare -a arr
arr=('my' 'name' 'is' 'akshit')
```

- `declare -a` is optional — assigning values in `()` automatically creates an indexed array.
- Elements are separated by **spaces**, not commas.

Alternatively, assign element-by-element:

```bash
arr[0]="my"
arr[1]="name"
arr[2]="is"
arr[3]="akshit"
```

### Associative Arrays

Associative arrays **must** be explicitly declared with `declare -A` (uppercase):

```bash
#!/bin/bash

declare -A assoc_arr
assoc_arr=(
	[first]='orange'
	[second]='apple'
	[third]='banana'
)
```

---

## Accessing Elements

Use parameter expansion syntax: `${array[index_or_key]}`

### Indexed Array Access

```bash
#!/bin/bash

declare -a arr
arr=('my' 'name' 'is' 'akshit')

echo ${arr[0]}
echo ${arr[1]}
echo ${arr[-1]}
```

```
my
name
akshit
```

> **Reverse indexing:** `${arr[-1]}` returns the **last** element.

### Associative Array Access

```bash
#!/bin/bash

declare -A assoc_arr
assoc_arr=(
	[first]='orange'
	[second]='apple'
	[third]='banana'
)

echo ${assoc_arr[first]}
echo ${assoc_arr[@]}
echo ${assoc_arr[*]}
```

```
orange
apple orange banana
apple orange banana
```

## Iterating Over Arrays

### `@` vs `*` — The Critical Difference

| Syntax               | Behavior                                                    |
| -------------------- | ----------------------------------------------------------- |
| `${arr[@]}`          | Expands each element as a **separate word/argument**        |
| `"${arr[*]}"`        | Merges all elements into a **single concatenated string**   |

### Example — Iterate Element by Element (`@`)

```bash
#!/bin/bash

declare -a arr
arr=('my' 'name' 'is' 'akshit')

for i in ${arr[@]}
do
	echo $i
done
```

```
my
name
is
akshit
```

### Example — All Elements as One String (`*`)

```bash
#!/bin/bash

declare -a arr
arr=('my' 'name' 'is' 'akshit')

for i in "${arr[*]}"
do
	echo $i
done
```

```
my name is akshit
```

> **Best practice:** Always use `"${arr[@]}"` (with double quotes) in `for` loops so elements containing spaces are preserved as distinct items.

---

## Extracting Keys/Indices (`!` Operator)

Place `!` before the array name to get **keys/indices** instead of values.

### With `*` — All Indices as One String

```bash
#!/bin/bash

declare -a arr
arr=('my' 'name' 'is' 'akshit')

for i in "${!arr[*]}"
do
	echo $i
done
```

```
0 1 2 3
```

### With `@` — Each Index Separately

```bash
#!/bin/bash

declare -a arr
arr=('my' 'name' 'is' 'akshit')

for i in "${!arr[@]}"
do
	echo $i
done
```

```
0
1
2
3
```

### Example — Print Index and Value Together

```bash
#!/bin/bash

declare -a arr
arr=('my' 'name' 'is' 'akshit')

for i in "${!arr[@]}"
do
	echo "the element at index $i is ${arr[$i]}"
done
```

```
the element at index 0 is my
the element at index 1 is name
the element at index 2 is is
the element at index 3 is akshit
```

> For associative arrays, `${!assoc_arr[@]}` returns the **string keys** (`first second third`).

---

## Array Length (`#` Operator)

Place `#` before the array name to get the **total number of elements**:

```bash
#!/bin/bash

declare -a arr
arr=('my' 'name' 'is' 'akshit')

declare -A assoc_arr
assoc_arr=(
	[first]='orange'
	[second]='apple'
	[third]='banana'
)

echo "the length of array is ${#arr[@]}"
echo "the length of array is ${#assoc_arr[@]}"
```

```
the length of array is 4
the length of array is 3
```

## Adding, Updating, and Deleting Elements

### Adding Elements

Assign a value to a new index/key:

```bash
#!/bin/bash

declare -a arr
arr=('my' 'name' 'is' 'akshit')

arr[4]="hello"
echo ${arr[@]}
```

```
my name is akshit hello
```

### Updating Elements

Assign a new value to an existing index/key:

```bash
#!/bin/bash

declare -a arr
arr=('my' 'name' 'is' 'akshit')

arr[1]='designation'
echo ${arr[@]}
```

```
my designation is akshit
```

### Deleting Elements (`unset`)

Use `unset` (without `$`) to remove elements:

```bash
#!/bin/bash

declare -a arr
arr=('my' 'name' 'is' 'akshit')

unset arr[2]
echo ${arr[@]}
```

```
my name akshit
```

> **Important:** Unsetting an element does **not** re-index the array. The index becomes sparse/vacant:

```bash
#!/bin/bash

declare -a arr
arr=('my' 'name' 'is' 'akshit')

unset arr[2]
echo ${arr[@]}
echo ${!arr[@]}
```

```
my name akshit
0 1 3
```

> Index `2` is gone — indices jump from `1` to `3`.

### Deleting an Entire Array

```bash
unset arr          # Wipes the entire indexed array
unset assoc_arr    # Wipes the entire associative array
```

## Quick Reference

| Operation             | Syntax                            | Notes                                |
| --------------------- | --------------------------------- | ------------------------------------ |
| Declare indexed       | `declare -a arr`                  | Optional if using `()`               |
| Declare associative   | `declare -A arr`                  | **Required** for key-value arrays    |
| Initialize            | `arr=('a' 'b' 'c')`              | Space-separated, no commas           |
| Access element        | `${arr[0]}` / `${arr[key]}`      | Use `[-1]` for last element          |
| All values            | `${arr[@]}` or `${arr[*]}`       | `@` = separate, `*` = single string |
| All keys/indices      | `${!arr[@]}`                      | `!` prefix extracts keys             |
| Array length          | `${#arr[@]}`                      | `#` prefix counts elements           |
| Add/update element    | `arr[idx]="value"`                | Overwrites if index exists           |
| Delete element        | `unset arr[idx]`                  | Does **not** re-index                |
| Delete entire array   | `unset arr`                       | Removes the whole array              |
