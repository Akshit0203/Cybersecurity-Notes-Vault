# Mapping Networks

**Network mapping** (visual mapping) involves creating a diagram of the target's network to understand its architecture, topology, and potential paths to targets.

---

## Why Map Networks?

- A **network diagram** reveals logical or physical paths to potential targets.
- Provides valuable information about the network architecture to the attacker.
- Helps identify choke points, segments, and high-value assets.

---

## Network Discovery Tools

| Tool | Description |
|---|---|
| **LANSurveyor** | Automated network discovery and mapping |
| **Network Topology Mapper** | Visual topology mapping (SolarWinds) |
| **OpManager** | Network monitoring and mapping (ManageEngine) |
| **NetworkView** | Network discovery and diagramming |
