# DNS Zone Transfer using `dig` Command

## The Primary Zone Transfer Tool

`dig` with `axfr` is the **most common and recommended** method for performing DNS zone transfers.

---

## Command Syntax

```bash
dig axfr @<nameserver> <domain>
```

| Part           | Purpose                                         |
| -------------- | ----------------------------------------------- |
| `axfr`         | Request a full zone transfer (AXFR)             |
| `@<nameserver>`| The DNS server to query (prefix with `@`)       |
| `<domain>`     | The target domain                               |

---

## Performing the Zone Transfer

### Step 1: Find Name Servers

```bash
dig zonetransfer.me -t ns +short
```

### Step 2: Execute AXFR

```bash
dig axfr @nsztm1.digi.ninja. zonetransfer.me
```

## Zone Transfer Tool Comparison

| Tool          | Platform       | Command                                         | Detail Level |
| ------------- | -------------- | ----------------------------------------------- | ------------ |
| **`host`**    | Linux          | `host -l <domain> <nameserver>`                 | Basic        |
| **`nslookup`**| Windows        | `ls -d <domain>` (after setting server + type)  | Medium       |
| **`dig`**     | Linux (primary)| `dig axfr @<nameserver> <domain>`               | **Full**     |

> [!tip] Use `dig` for Zone Transfers
> `dig axfr` is the **standard and most detailed** method. It shows TTL values, all record types including CERT, LOC, NAPTR, and transfer statistics. This is what you should use in OSCP and real-world pentests.
