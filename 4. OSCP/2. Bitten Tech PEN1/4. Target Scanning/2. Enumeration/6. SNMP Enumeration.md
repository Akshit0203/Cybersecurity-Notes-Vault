# SNMP Enumeration

## What is SNMP?

**SNMP (Simple Network Management Protocol)** is an application layer protocol that uses **UDP** to **monitor and manage network devices** remotely from a single location.

Managed devices include:
- Routers, Switches, Hubs, Bridges
- Servers, Computers, Printers
- Firewalls, UPS devices

> Think of SNMP as a way for an administrator to **ask a network device questions**:
> - "What is your hostname?"
> - "How much traffic is going through this interface?"
> - "How much CPU/memory are you using?"
> - "What interfaces do you have?"

### Why SNMP Exists

In large networks (50+ computers, 20+ servers, 30+ printers), manually checking each device for failures, performance, or maintenance is impractical. SNMP lets you **sit in one place** and get information about **every device** on the network.

---

## SNMP Architecture

```
SNMP Manager → sends requests → SNMP Agent (on device)
                                       ↓
                                 reads from MIB
                                       ↓
                              returns information
```

### Three Core Components

| Component                         | Description                                                          |
| --------------------------------- | -------------------------------------------------------------------- |
| **Manager (NMS)**                 | Monitoring system where the administrator sits — receives all info   |
| **Agent**                         | Small software installed on each managed device, converts info to SNMP format |
| **Managed Device**                | Any network node with SNMP enabled (router, switch, server, etc.)    |

### SNMP Ports

| Port        | Protocol | Purpose                  |
| ----------- | -------- | ------------------------ |
| **161**     | UDP      | SNMP queries             |
| **162**     | UDP      | SNMP traps/notifications |

## Community Strings (v1 & v2c Authentication)

SNMP v1 and v2c use **community strings** as passwords:

| String Type        | Default Value | Permission         |
| ------------------ | ------------- | ------------------ |
| **Read**           | `public`      | View device/system configuration |
| **Read/Write**     | `private`     | Remote editing of configuration  |

> [!warning] Default Community Strings
> If community strings are left at their defaults (`public` / `private`), an attacker can **read or modify** the entire device configuration remotely.

### How Authentication Works

1. **Manager** sends a request with the community string + target IP
2. If the string matches → session established, information returned
3. If the string doesn't match → **SNMP Trap** is generated and sent to a pre-configured Manager

## Management Information Base (MIB)

**MIB = a virtual hierarchical database** containing descriptions of all manageable objects on a device.

- Each object has a unique **OID (Object Identifier)** in numerical format
- MIB maps these numerical OIDs to human-readable names
- Objects include: CPU usage, RAM, hard disk space, services, applications, routing tables, ARP tables, etc.

### Two Types of Managed Objects

| Type       | Description                                  |
| ---------- | -------------------------------------------- |
| **Scalar** | Defines a single object instance             |
| **Tabular**| Groups multiple related objects into a table  |

## SNMP Enumeration — What Attackers Extract

Using default community strings, attackers can extract:

- Hostnames and system names
- OS information
- Network interfaces and IP addresses
- Routing information and ARP tables
- Running processes and installed software
- Traffic statistics
- Sometimes usernames and other sensitive details
- Information about hosts, routers, devices, and shares

> [!important] OSCP Mental Model
> **UDP 161 open → SNMP → try enumeration → potentially lots of system/network information.**

### Tools That Use SNMP

Network mapping tools like **Spiceworks, LanSurveyor, Network Topology Mapper (NTM), and LanState** all use SNMP to gather device information.

## SNMP Versions

| Version   | Authentication          | Security Level |
| --------- | ----------------------- | -------------- |
| **v1**    | Community string (plaintext) | Weak      |
| **v2c**   | Community string (plaintext) | Weak      |
| **v3**    | Username/password + encryption | Strong  |

> Unlike NetBIOS, **SNMP is still very much used** in real-world networks today, though modern deployments often use **SNMPv3** for better security.
