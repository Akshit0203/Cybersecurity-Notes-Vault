# Password Cracking with John the Ripper

> **Type:** Offline password cracker (hash-based)
> **Strength:** Suite of tools for extracting and cracking hashes from many formats
> **Target:** Weak passwords — the more complex the password, the longer it takes

---

## Three Cracking Modes

| Mode | Flag | Description | Speed |
|------|------|-------------|-------|
| **Single** | `--single` | Uses login names and GECOS info to generate candidates | ⚡ Fastest |
| **Wordlist** | `--wordlist=FILE` | Tests every entry in a provided wordlist | ⚡ Fast |
| **Incremental** | `--incremental` | Pure brute-force, tests every possible combination | 🐢 Slowest (100% success if given enough time) |

---

## Supported Hash Formats

DES-based, Unix crypt, FreeBSD MD5, Kerberos, Windows LM/NTLM, SHA variants, and many more.

> Full list: `john --list=formats`

## Practical Examples

### Example 1 — Cracking an Encrypted ZIP File

**Step 1:** Extract the hash using `zip2john`

```bash
zip2john test.zip > hashed.txt
```

> For RAR files, use `rar2john` instead.

**Step 2:** Crack the hash

```bash
john hashed.txt
```

> John auto-detects the format. You can also specify explicitly with `--format=zip`.

**Result:** Cracked `123456` almost instantly — weak passwords are extremely vulnerable.

---

### Example 2 — Cracking Linux User Passwords (`/etc/shadow`)

**Step 1:** Create a test user with a weak password

```bash
adduser usertest
# Set password to: 1234567
```

**Step 2:** Combine passwd and shadow files

> `/etc/shadow` alone is not in the format John expects. You must combine it with `/etc/passwd`:

```bash
unshadow /etc/passwd /etc/shadow > hashes.txt
```

**Step 3:** Crack the combined file

```bash
john hashes.txt
```

**Result:** Cracked `usertest`'s password `1234567` in seconds.

> ⚠️ Running `john /etc/shadow` directly may not work on many Linux setups because John expects the combined `unshadow` format.

## Hash Extraction Tools (John Suite)

| Tool | Purpose |
|------|---------|
| `zip2john` | Extract hash from encrypted ZIP files |
| `rar2john` | Extract hash from encrypted RAR files |
| `pdf2john` | Extract hash from encrypted PDF files |
| `ssh2john` | Extract hash from SSH private keys |
| `unshadow` | Combine `/etc/passwd` + `/etc/shadow` for John |

---

## Quick Command Reference

```bash
# Crack a hash file (auto-detect format)
john hashes.txt

# Specify format explicitly
john --format=zip hashed.txt

# Use a specific wordlist
john --wordlist=/usr/share/wordlists/rockyou.txt hashes.txt

# Show previously cracked passwords
john --show hashes.txt

# Combine shadow + passwd for Linux cracking
unshadow /etc/passwd /etc/shadow > hashes.txt
john hashes.txt
```

---

## Key Takeaways

- John works on **hashes** — not live login forms (use Hydra for that).
- John **stores cracked passwords** in a potfile; use `john --show` to view them.
- **Single mode** is fastest but needs some knowledge; **Incremental mode** is slowest but guarantees success.
- Always use `unshadow` to combine `/etc/passwd` and `/etc/shadow` before cracking Linux passwords.
- Weak passwords (`123456`, `1234567`) are cracked in seconds — always use complex, long passwords.
