to serach for an exploit of a version 
```
msf > search windows
```


to get info of an exploit 
what its about 
```
msf > info exploit/multi/http/vbulletin_widget_template_rce
```



to select an exploit 

```
msf > use exploit/multi/http/vbulletin_widget_template_rce

```
