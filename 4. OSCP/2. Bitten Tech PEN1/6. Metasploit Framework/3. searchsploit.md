# SearchSploit

SearchSploit is a command-line tool for searching the local copy of **Exploit-DB**.

---

## Exploit Database Location

```bash
ls /usr/share/exploitdb/exploits
```

> [!TIP]
> Keep the database updated regularly: `searchsploit -u`

---

## Searching for Exploits

```bash
searchsploit ftp

searchsploit <exploit name/version name>
```

---

## Copying an Exploit to the Current Directory

Use `-m` (mirror) to copy an exploit locally for editing:

```bash
searchsploit -m windows_x86-64/52298.py .
```

---

## Editing an Exploit

Open and modify the copied exploit:

```bash
gedit <exploit name>
```
