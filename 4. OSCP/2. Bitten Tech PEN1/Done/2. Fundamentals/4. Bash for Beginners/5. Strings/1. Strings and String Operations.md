# Strings and String Operations

> In Bash, a **string** is any sequence of characters enclosed in single or double quotes. Even numbers like `1234` become strings when quoted. This note covers comparison, length, substring extraction, and concatenation.

---

## Declaring Strings

```bash
str1='programming'         # Single-quoted string
str2="welcome to bash"     # Double-quoted string (allows variable expansion)
str3='1234'                # Numbers become strings when quoted
```

> Without quotes, `1234` is treated as an integer. Inside quotes, it becomes a string.

## String Comparison Operators

### Equality and Inequality

| Operator | Meaning          | Example                             |
| -------- | ---------------- | ----------------------------------- |
| `=`      | Equal to (POSIX) | `[ "$str1" = "$str2" ]`            |
| `==`     | Equal to (Bash)  | `[ "$str1" == "$str2" ]`           |
| `!=`     | Not equal to     | `[ "$str1" != "$str2" ]`           |

> `=` is the official POSIX standard. `==` works in Bash but is non-portable.

### Example — Equality Check

```bash
#!/bin/bash

str1='programming'
str2='programming'

if [ "$str1" = "$str2" ]
then
	echo "strings are equal"
fi
```

```
strings are equal
```

> **Always double-quote** string variables inside `[ ]` to prevent word-splitting errors. Without quotes, a string containing spaces (`"welcome to programming"`) causes `too many arguments` errors because Bash splits it into multiple words.

### Lexicographical Comparison (`<` and `>`)

Inside single square brackets `[ ]`, you **must escape** `<` and `>` with a backslash — otherwise Bash interprets them as file redirection.

```bash
#!/bin/bash

str1='programming'
str2='programming is fun'

if [ "$str1" \< "$str2" ]
then
	echo "$str2 is greater"
fi
```

```
programming is fun is greater
```

> Comparison is **lexicographical** (ASCII/alphabetical order), **not** by string length.

```bash
#!/bin/bash

str1='p'
str2='q'

if [ "$str1" \< "$str2" ]
then
	echo "$str2 is greater"
fi
```

```
q is greater
```

> `p` comes before `q` in ASCII, so `p < q` is true.

### Not Equal To

```bash
#!/bin/bash

str1='p'
str2='q'

if [ "$str1" != "$str2" ]
then
	echo "strings are not equal"
fi
```

> Operators like `<=`, `>=`, `-le`, `-ge` do **not** work with strings. You can construct workarounds using `!` (NOT) combined with `\>` to test for less-than-or-equal.

## Checking Empty and Non-Empty Strings

| Flag | Meaning                    | Example                              |
| ---- | -------------------------- | ------------------------------------ |
| `-z` | **Zero length** (empty)    | `[ -z "$str" ]` → true if empty     |
| `-n` | **Non-zero length** (set)  | `[ -n "$str" ]` → true if non-empty |

### Example — Empty String Check (`-z`)

```bash
#!/bin/bash

str1='programming'
str2=''

if [ -z $str2 ]
then
	echo "string is empty"
fi
```

```
string is empty
```

### Example — Non-Empty String Check (`-n`)

```bash
#!/bin/bash

str1='programming'
str2=''

if [ -n $str1 ]
then
	echo "string is non empty"
fi
```

```
string is non empty
```

## Finding String Length

Five methods to calculate string length:

```bash
# 1. ${#string}           ← Recommended (native parameter expansion)
# 2. expr length "$string"
# 3. expr "$string" : '.*'
# 4. echo -n "$str" | wc -c
# 5. echo "$str" | awk '{print length}'
```

### Method 1 — `${#string}` (Recommended)

```bash
#!/bin/bash

str1='programming'

echo "length of string $str1: ${#str1}"
```

```
length of string programming: 11
```

### Method 2 — `expr length`

```bash
#!/bin/bash

str1='programming'

echo "length of string $str1: `expr length $str1`"
```

```
length of string programming: 11
```

### Method 3 — Pipe to `wc -c`

```bash
#!/bin/bash

str1='programming'

len=`echo -n $str1|wc -c`
echo "length of string $str1: $len"
```

```
length of string programming: 11
```

> **Important:** `echo` appends a trailing newline `\n` by default, so `wc -c` returns length + 1. Use `echo -n` (suppress newline) to get the exact count.

## Substring Extraction (Slicing)

### Syntax

```
${VARIABLE:OFFSET:LENGTH}
```

| Parameter    | Description                                                              |
| ------------ | ------------------------------------------------------------------------ |
| `VARIABLE`   | The string variable name                                                 |
| `OFFSET`     | Zero-indexed starting position                                           |
| `LENGTH`     | *(Optional)* Number of characters to extract. If omitted, extracts to end |

### Example — Extract from Offset to End

```bash
#!/bin/bash

str1='welcome to programming'

substr="${str1:11}"
echo $substr
```

```
programming
```

### Example — Extract Specific Length

```bash
#!/bin/bash

str1='welcome to programming'

substr="${str1:11:1}"
echo $substr
```

```
p
```

### Example — Negative Offset (Count from End)

```bash
#!/bin/bash

str1='welcome to programming'

substr="${str1:(-11)}"
echo $substr
```

```
programming
```

> **`(-11)`** means "start 11 characters from the end." Parentheses are required to distinguish a negative offset from Bash's `:-` default-value syntax.

## String Concatenation

### Simple Concatenation

No special operators needed — just place variables side by side:

```bash
#!/bin/bash

str1='welcome to programming'
str2=' in bash'

echo "$str1$str2"
```

```
welcome to programming in bash
```

### Appending with `+=` in a Loop

```bash
#!/bin/bash

str3="1 2 3 4 5"
str4=''
for i in $str3
do
	str4+=$i
done

echo $str4
```

```
12345
```

> Each iteration appends the next element directly. To see the accumulation step by step:

```bash
#!/bin/bash

str3="1 2 3 4 5"
str4=''
for i in $str3
do
	str4+=$i
	echo $str4
done
```

```
1
12
123
1234
12345
```

### Concatenation with Spaces

By default, `+=` concatenates without spaces:

```bash
#!/bin/bash

str3="Apple Banana Orange"
str4=''
for i in $str3
do
	str4+=$i
	echo $str4
done
```

```
Apple
AppleBanana
AppleBananaOrange
```

To add spaces between words, append `"$i "` instead of `$i`:

```bash
#!/bin/bash

str3="Apple Banana Orange"
str4=''
for i in $str3
do
	str4+="$i "
	echo "$str4"
done
```

```
Apple 
Apple Banana 
Apple Banana Orange 
```

## Quick Reference

| Operation              | Syntax                          | Example Result        |
| ---------------------- | ------------------------------- | --------------------- |
| Declare string         | `str='text'`                    | —                     |
| Equality               | `[ "$a" = "$b" ]`              | true/false            |
| Not equal              | `[ "$a" != "$b" ]`             | true/false            |
| Less than (lex)        | `[ "$a" \< "$b" ]`             | true/false            |
| Empty check            | `[ -z "$str" ]`                | true if empty         |
| Non-empty check        | `[ -n "$str" ]`                | true if non-empty     |
| Length                 | `${#str}`                       | `11`                  |
| Substring (from idx)   | `${str:11}`                    | `programming`         |
| Substring (length)     | `${str:11:1}`                  | `p`                   |
| Substring (from end)   | `${str:(-11)}`                 | `programming`         |
| Concatenate            | `"$str1$str2"`                 | combined string       |
| Append                 | `str+="text"`                  | appended string       |
