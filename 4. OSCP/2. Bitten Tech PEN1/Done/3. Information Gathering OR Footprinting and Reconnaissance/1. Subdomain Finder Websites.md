# Subdomain Finder Websites

> [!info] Purpose
> Online tools that enumerate **subdomains** of a target domain — useful during the **passive reconnaissance** phase to map an organisation's external attack surface without directly touching the target.

---

## 1. Pentest-Tools — Find Subdomains

🔗 https://pentest-tools.com/information-gathering/find-subdomains-of-domain

- Web-based subdomain scanner (free tier available).
- Returns subdomains, IP addresses, and hosting info.

## 2. VirusTotal — Domain Relations

🔗 https://www.virustotal.com/gui/domain/instagram.com/relations

- Navigate to **Relations** tab for any domain to see discovered subdomains, resolutions, and communicating files.
- Great for passive recon — data is crowd-sourced from scans already performed by other users.
