# Introduction to Banner Grabbing

**Banner grabbing** (also called **OS fingerprinting**) is the method of determining the **operating system, software, or service version** running on a remote target. Identifying the OS and software allows an attacker to find known vulnerabilities and matching exploits.

---

## Types of Banner Grabbing

### Active Banner Grabbing

- **Specially crafted packets** are sent to the remote OS and responses are analyzed.
- Responses are compared against a database to determine the OS.
- Works because different OSes implement the TCP/IP stack differently, producing unique responses.

### Passive Banner Grabbing

| Method | Description |
|---|---|
| **Error messages** | Error pages reveal server type, OS, and SSL tools used. |
| **Network sniffing** | Capturing and analyzing packets from the target reveals the OS. |
| **Page extensions** | URL file extensions hint at the platform (e.g., `.aspx` → IIS + Windows). |
