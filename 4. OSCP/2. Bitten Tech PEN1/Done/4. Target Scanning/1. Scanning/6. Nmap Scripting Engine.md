# Nmap Scripting Engine (NSE)

The **Nmap Scripting Engine (NSE)** extends Nmap beyond port scanning into **vulnerability scanning, brute-forcing, and exploitation**. Scripts are written in **Lua** and stored at `/usr/share/nmap/scripts/`.

---

## Script Location & Discovery

### Where Scripts Are Stored

```
/usr/share/nmap/scripts
```

### Finding Scripts by Service

Use `grep` to filter scripts by service name:

```bash
# SSH scripts
ls /usr/share/nmap/scripts | grep ssh
```
```
ssh2-enum-algos.nse
ssh-auth-methods.nse
ssh-brute.nse
ssh-hostkey.nse
ssh-publickey-acceptance.nse
ssh-run.nse
sshv1.nse
```

```bash
# FTP scripts
ls /usr/share/nmap/scripts | grep ftp
```
```
ftp-anon.nse
ftp-bounce.nse
ftp-brute.nse
ftp-libopie.nse
ftp-proftpd-backdoor.nse
ftp-syst.nse
ftp-vsftpd-backdoor.nse
ftp-vuln-cve2010-4221.nse
tftp-enum.nse
tftp-version.nse
```

### Viewing Script Source & Usage

Open any script to see its usage, arguments, and Lua code:

```bash
nano /usr/share/nmap/scripts/ssh-brute.nse
```

![](attachments/Pasted%20image%2020260905093954.png)

- Usage instructions and supported arguments are documented inside the script.
- You can provide a custom wordlist or use the default one.
- Scripts can be edited if you know Lua.

## NSE Command Flags

```
SCRIPT SCAN:
  -sC: equivalent to --script=default
  --script=<Lua scripts>: comma separated list of directories, script-files or script-categories
  --script-args=<n1=v1,[n2=v2,...]>: provide arguments to scripts
  --script-args-file=filename: provide NSE script args in a file
  --script-trace: Show all data sent and received
  --script-updatedb: Update the script database.
  --script-help=<Lua scripts>: Show help about scripts.
```

## Running Custom Scripts (`--script`)

### SSH Brute Force

```bash
nmap 192.168.60.138 --script=ssh-brute.nse
```

- Brute-forces SSH login credentials using a default wordlist.
- If a default/common password exists, it will find it.
- The `.nse` extension is optional — `--script=ssh-brute` works the same way.

> [!TIP]
> Nmap brute-forcing is **slow**. For serious password attacks, use dedicated tools like **Hydra**.

### SSH Host Key Extraction

```bash
nmap 192.168.60.138 --script=ssh-hostkey.nse
```

- Retrieves all SSH host keys from the target.

## Quick Reference

| Task | Command |
|---|---|
| Run default scripts on all ports | `nmap <target> -sC` |
| Run default scripts on specific port | `nmap <target> -sC -p22` |
| Run a specific script | `nmap <target> --script=<script-name>` |
| Find scripts for a service | `ls /usr/share/nmap/scripts \| grep <service>` |
| View script usage/help | `nano /usr/share/nmap/scripts/<script>.nse` |
| Update script database | `nmap --script-updatedb` |
