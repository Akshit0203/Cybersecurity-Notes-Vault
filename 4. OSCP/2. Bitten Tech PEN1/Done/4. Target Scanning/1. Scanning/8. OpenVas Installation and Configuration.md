# OpenVAS Installation and Configuration

**OpenVAS** (now part of **GVM — Greenbone Vulnerability Management**) is a free, open-source vulnerability scanner. It is a good alternative to Nessus but has a more complex setup.

**Kali Tools Page:** https://www.kali.org/tools/gvm

## Which Finds More Vulnerabilities?

| Aspect | **Nessus Professional** | **OpenVAS / GVM** |
|---|---|---|
| Vulnerability coverage | ⭐⭐⭐⭐⭐ | ⭐⭐⭐⭐ |
| Detection accuracy | ⭐⭐⭐⭐⭐ | ⭐⭐⭐⭐ |
| New CVEs | Usually faster | Can lag depending on feed |
| False positives | Generally lower | Can be higher |
| Web app scanning | Limited in Pro | Depends on setup/version |
| Reporting | Excellent | Good |
| Ease of use | ⭐⭐⭐⭐⭐ | ⭐⭐⭐ |
| Price | Paid | Free / open source |

**Why Nessus tends to find more:** Tenable maintains a large commercial plugin ecosystem with frequent updates and additional detection logic beyond simply matching CVE numbers.

## Recommendation for OSCP Preparation

> **Nessus > OpenVAS** for most pentest learners.

Nessus is easier to operate and gives a polished vulnerability-scanning workflow. OpenVAS/GVM has many moving parts (PostgreSQL, Redis, `gvmd`, `ospd-openvas`, feeds, permissions) that can cause setup headaches.

### Recommended Workflow

1. **Nmap → Primary enumeration**
   ```bash
   nmap -sC -sV -p- <target>
   ```
2. **Nessus → Automated vulnerability discovery**
3. **Manual enumeration → Most important**
   - Web enumeration
   - SMB
   - LDAP / AD
   - FTP / SSH
   - SNMP
   - Misconfigurations
   - Version/service research
   - Privilege escalation

> [!IMPORTANT]
> **Do not become dependent on automated scanners.** In OSCP, automated scanners won't solve the machine for you. Manual enumeration is the critical skill.

> [!TIP]
> Keep **Nessus** as your main vulnerability scanner on Kali. Learn GVM/OpenVAS separately when you have time — it's valuable knowledge but not essential for exam prep.
