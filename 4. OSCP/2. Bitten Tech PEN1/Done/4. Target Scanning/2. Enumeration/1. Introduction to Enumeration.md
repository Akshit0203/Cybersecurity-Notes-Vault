# Introduction to Enumeration

## What is Enumeration?

Enumeration is the phase where an attacker creates **active connections** to a target system and performs **directed queries** to gain more information about it.

> [!tip] Key Distinction
> **Scanning** = finding an attack surface  
> **Enumeration** = expanding it

- Attacker establishes an active connection with the victim and tries to discover as many attack vectors as possible
- Enumeration techniques are conducted in an **intranet environment**
- Enumeration is the key to a successful penetration test

---

## Information Enumerated by Intruders

| Category              | Examples                              |
| --------------------- | ------------------------------------- |
| **Network**           | Network resources, shares, routing tables |
| **Services**          | Audit and service settings, SNMP and DNS details |
| **Identity**          | Machine names, users and groups       |
| **Applications**      | Applications and banners              |
