# SMTP Enumeration

## What is SMTP?

**SMTP (Simple Mail Transfer Protocol)** is the protocol used to **send email**.

> Think of it as the **postal service for outgoing email**.

```
You → Gmail SMTP server → Recipient's mail server → Recipient
```

- **SMTP is only for sending** — for receiving, use **POP3** or **IMAP**

| Protocol | Main Purpose          |
| -------- | --------------------- |
| **SMTP** | Send email 📤         |
| **IMAP** | Read/synchronize email 📥 |
| **POP3** | Download email 📥     |

---

## SMTP Ports

| Port    | Purpose                                      |
| ------- | -------------------------------------------- |
| **25**  | SMTP — traditionally server-to-server mail   |
| **587** | Mail submission — commonly used by clients   |
| **465** | SMTP over implicit TLS                       |

---

## SMTP Enumeration — Key Commands

SMTP provides **3 built-in commands** useful for enumeration:

| Command     | Purpose                                                  |
| ----------- | -------------------------------------------------------- |
| **VRFY**    | Validates whether a user exists                          |
| **EXPN**    | Reveals actual delivery addresses of aliases/mailing lists |
| **RCPT TO** | Defines recipients — can also reveal valid users         |

> [!important] Enumeration Technique
> The SMTP server **responds differently** to these commands for **valid vs. invalid users**. By brute-forcing usernames and comparing responses, you can determine which users exist on the server.

### Other Useful SMTP Commands

```
EHLO     → Identify yourself, request server capabilities
HELO     → Basic greeting
MAIL FROM: → Set sender address
DATA     → Begin message body
QUIT     → End session
```

## Why SMTP Matters for OSCP

If Nmap shows:

```
25/tcp open smtp
```

Investigate the SMTP service. You may learn:
- Mail server **software/version** (from the banner)
- **Valid email/usernames**
- **Domain information**
- Mail configuration
- Whether the server allows certain forms of relay

### Banner Grabbing Example

```bash
nc <IP> 25
```

Response:

```
220 mail.example.com ESMTP Postfix
```

→ You've learned: **SMTP server = Postfix**

## OSCP Mental Model

> **SMB → users/shares/files**  
> **SNMP → system/network information**  
> **LDAP → directory/users/domain information**  
> **SMTP → mail server/domain/user information**

When Nmap gives `25/tcp open smtp`, think:

> "This is an email server. What can SMTP tell me about the machine, users, domains, software, and configuration?"
