## Method 1: Manual Enumeration via Telnet

### Connecting to SMTP

```bash
telnet 192.168.60.138 25
```

```

Connected to 192.168.60.138.
Escape character is '^]'.
220 metasploitable.localdomain ESMTP Postfix (Ubuntu)
```

→ **Banner grabbed**: ESMTP Postfix running on Ubuntu

### Testing Invalid Commands

```
testcommand
502 5.5.2 Error: command not recognized
```

### User Verification with `VRFY`

**Invalid user → Error (550):**

```
VRFY testname
550 5.1.1 <testname>: Recipient address rejected: User unknown in local recipient table
```

**Valid users → Accepted (252):**

```
VRFY root
252 2.0.0 root

VRFY bin
252 2.0.0 bin

VRFY daemon
252 2.0.0 daemon
```

**Another invalid user → Error:**

```
VRFY testhello
550 5.1.1 <testhello>: Recipient address rejected: User unknown in local recipient table
```

> [!tip] Response Code Guide
> - **252** = user is valid/accepted
> - **550** = user unknown / rejected
> - **503** = need prerequisite command first (e.g., `MAIL FROM:` before `RCPT TO:`)

### User Verification with `RCPT TO:`

> [!note]
> `RCPT TO:` requires a `MAIL FROM:` command first, otherwise you get a 503 error.

```
RCPT TO:akshit
503 5.5.1 Error: need MAIL command

RCPT TO:root
503 5.5.1 Error: need MAIL command
```

After issuing `MAIL FROM:` first, `RCPT TO:` will return:
- **250** for valid users
- Error for invalid users

> [!warning] Limitation of Manual Enumeration
> Manually brute-forcing users via Telnet is slow and impractical when you don't know which users exist. This is where automated tools come in.

## Method 2: Automated Enumeration with Metasploit

### Starting Metasploit

```bash
msfconsole
```

### Searching for SMTP Modules

```
msf > search smtp
```

Key module found:

```
49  auxiliary/scanner/smtp/smtp_enum
```

### Loading the Module

```
msf > use auxiliary/scanner/smtp/smtp_enum
```
