#### ==🔵Kerberoasting : ==

Target : Accounts associated with Service Principal Names (SPNs)
What you obtain : An encrypted service ticket
Any authenticated domain user can request a Kerberos service ticket (TGS) for that SPN. Part of that ticket is encrypted with the service account’s password hash

(CAN SKIP)
