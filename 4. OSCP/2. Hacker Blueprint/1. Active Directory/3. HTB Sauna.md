# HTB Sauna

> **Platform:** Hack The Box
> **OS:** Windows (Active Directory)
> **Domain:** `EGOTISTICAL-BANK.LOCAL` — host `SAUNA`
> **Difficulty:** Easy

> **Note on the target IP:** the box was reset mid-session, so the address changed from `10.129.95.180` to `10.129.74.127`. Commands keep whichever IP was live at the time — substitute your own.

## Attack Path Overview

1. **Recon** – DC hosting an "Egotistical Bank" IIS site; SMB allows null auth.
2. **Username harvesting** – employee names from the website → AD username permutations → validate with Kerbrute → `fsmith`.
3. **AS-REP Roasting** – `fsmith` has pre-auth disabled; crack the AS-REP hash → `Thestrokes23`.
4. **Foothold** – WinRM as `fsmith` → user flag.
5. **Privilege escalation** – winPEAS finds AutoLogon credentials for `svc_loanmgr`.
6. **DCSync** – `svc_loanmgr` holds replication rights → `secretsdump` dumps the Administrator hash → Pass-the-Hash → root flag.

Turn those real names into AD username permutations (`fsmith`, `smithf`, `fergus.smith`, …) with an AD username generator — https://github.com/mohinparamasivam/AD-Username-Generator :


## 3. AS-REP Roasting → `fsmith` password

**Target:** accounts with Kerberos pre-authentication disabled (`DONT_REQ_PREAUTH`). For those, the KDC returns an AS-REP whose encrypted portion is derived from the account's password — crackable offline.

```bash
impacket-GetNPUsers EGOTISTICAL-BANK.LOCAL/ -dc-ip 10.129.95.180 -usersfile usernames.txt -no-pass
```

## Lessons Learned

- **Websites feed username lists.** Names → permutations → Kerbrute validation is the standard way to seed AS-REP/spray attacks.
- **AS-REP roasting** needs no credentials — only a valid username whose account has pre-auth disabled.
- **AutoLogon leaves plaintext passwords** in `HKLM\...\Winlogon`; winPEAS flags them automatically.
- **The AutoLogon username can differ from the real account name** (`svc_loanmanager` vs `svc_loanmgr`) — verify with `net user` before authenticating.
- **DCSync is the endgame** whenever a non-DA account has replication rights. `secretsdump`'s `rpc_s_access_denied` on remote registry is harmless when DRSUAPI succeeds.
