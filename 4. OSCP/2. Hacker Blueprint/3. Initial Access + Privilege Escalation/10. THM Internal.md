# THM Internal

A Linux box compromised through a **WordPress** admin login (brute-forced with WPScan), turned into RCE by planting a PHP web shell in the `404.php` theme template. Privilege escalation chains leaked credentials in `/opt/wp-save.txt` to pivot to `aubreanna`, then finishes with the **PwnKit (CVE-2021-4034 / pkexec)** local root exploit.

## Lessons Learned

- **A slow page with "looking up `<domain>`" is a vhost hint** — add the domain to `/etc/hosts` so WordPress serves the real site.
- **WPScan brute force** cracked `admin:my2boys` quickly against `rockyou.txt`.
- **Admin WordPress access → RCE via the Theme Editor.** Overwriting `404.php` with `<?=`$_GET[0]`?>` gives a command-execution endpoint; feed it a URL-encoded reverse shell.
- **Always read `wp-config.php` and poke around `/opt`.** The `/opt/wp-save.txt` note leaked `aubreanna`'s password for the next pivot.
- **Unpatched polkit = instant root (CVE-2021-4034 / PwnKit).** A near-universal Linux local privesc at the time; keep the compiled binary handy.
