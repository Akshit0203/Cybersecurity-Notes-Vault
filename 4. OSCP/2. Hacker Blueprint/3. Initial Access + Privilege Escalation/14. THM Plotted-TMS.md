# THM Plotted-TMS

A Linux box whose web app is served on an unusual port (**HTTP on 445**). Content discovery finds a **Task Management System** under `/management/`, which is exploited with a public login-bypass + shell-upload exploit for a `www-data` foothold.

> **Status:** these notes cover recon through the initial `www-data` foothold and start of enumeration; privilege escalation is not yet completed here.

## Lessons Learned

- **Don't trust port numbers for service identity.** Port 445 here was Apache/HTTP, not SMB (`smb2-time: Protocol negotiation failed` was the tell). Always run web content discovery against *every* HTTP port.
- **A `/management/` directory with `admin`, `classes`, `uploads` is a classic PHP "Task/Management System"** — map it to a public exploit (ExploitDB 50221).
- **An exploit can partially succeed.** Even when its interactive shell loop crashes (`MissingSchema`), the login bypass and file upload may have worked — drive the dropped web shell directly.
- **Use double extensions (`.jpg.php`)** to slip a PHP payload past naive upload filters.
