==A concise writeup for **PayDay** (an intermediate Linux machine) on [OffSec Proving Grounds Practice](https://infosecwriteups.com/oscp-proving-grounds-payday-6942ad48f071)==.

---

1. Reconnaissance & Enumeration

- **Nmap Scan:** Running a full TCP port scan reveals several open services:
    - **Port 22:** SSH (`OpenSSH 4.6p1`)
    - **Port 80:** HTTP (`Apache 2.2.4`, running **CS-Cart 1.3.3**)
    - **Ports 110, 995, 143, 993:** POP3/IMAP
    - **Ports 139, 445:** SMB (`MSHOME domain, PAYDAY PDC`) [[1](https://viperone.gitbook.io/pentest-everything/writeups/pg-practice/linux/payday), [2](https://medium.com/@ayxantanirverdiyev6/pg-practice-paydaywalkthrough-1d0bddff70f1)]

- **Web Enumeration:**
    - Directory scanning (using Gobuster or Dirb) identifies an admin login panel at `/admin` (or `/admin/login.php`).
    - Default administrative credentials work: `admin : admin`. [[1](https://medium.com/@ninadjagtap712/ctf-report-payday-0b66e1e252af), [2](https://github.com/Bsal13/Offensive-Security-Proving-Grounds-Boxes/blob/main/Payday%20\(Intermediate\)%20Linux%20Box.md), [3](https://medium.com/@ayxantanirverdiyev6/pg-practice-paydaywalkthrough-1d0bddff70f1)]

---

2. Exploitation (Authenticated RCE)

- **Vulnerability:** CS-Cart 1.3.3 allows authenticated users with access to the template/admin manager to upload or edit template files. [[1](https://medium.com/@ayxantanirverdiyev6/pg-practice-paydaywalkthrough-1d0bddff70f1)]

- **Gaining a Shell:**
    - Navigate to the template editor or file upload section in the admin dashboard.
    - Bypass the `.php` extension filter by naming the reverse shell payload with a `.phtml` extension (e.g., `reverse.phtml`).
    - Trigger/access the uploaded `.phtml` file via the web server to obtain a reverse shell as `www-data` (or `apache`). [[1](https://medium.com/@ninadjagtap712/ctf-report-payday-0b66e1e252af), [2](https://medium.com/@ayxantanirverdiyev6/pg-practice-paydaywalkthrough-1d0bddff70f1), [3](https://github.com/Bsal13/Offensive-Security-Proving-Grounds-Boxes/blob/main/Payday%20\(Intermediate\)%20Linux%20Box.md)]

---

3. Lateral Movement / User Pivot

- Check system users via `/etc/passwd`, which reveals a user named `patrick`.

- Test weak/default credentials for `patrick` (password matches the username: `patrick : patrick`).

- Log in or switch to `patrick` (via SSH or the shell) to grab the local user flag (`local.txt`). [[1](https://medium.com/@ninadjagtap712/ctf-report-payday-0b66e1e252af), [2](https://github.com/Bsal13/Offensive-Security-Proving-Grounds-Boxes/blob/main/Payday%20\(Intermediate\)%20Linux%20Box.md)]

---

4. Privilege Escalation (Root)

- Run `sudo -l` as user `patrick` to inspect sudo permissions:
    
    bash
    
    ```
    sudo -l
    ```
    
    Use code with caution.
    

- The configuration shows that `patrick` can run all commands or a root shell (`sudo /bin/bash` or `sudo su`) with no password or full privileges.

- Spawn a root shell:
    
    bash
    
    ```
    sudo /bin/bash
    ```
    
    Use code with caution.
    

- Retrieve the final proof flag (`proof.txt` / root flag) from `/root`. [[1](https://medium.com/@ninadjagtap712/ctf-report-payday-0b66e1e252af), [2](https://github.com/Bsal13/Offensive-Security-Proving-Grounds-Boxes/blob/main/Payday%20\(Intermediate\)%20Linux%20Box.md), [3](https://medium.com/@ayxantanirverdiyev6/pg-practice-paydaywalkthrough-1d0bddff70f1)]
