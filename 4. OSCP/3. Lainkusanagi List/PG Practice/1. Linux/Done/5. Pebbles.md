# Pebbles — Proving Grounds

> [!abstract] Summary
> The scan identifies FTP, SSH, and three HTTP services. Directory enumeration on port 80 finds `/zm/`, which is the ZoneMinder console. ZoneMinder 1.29.0 has a SQL injection in the `limit` parameter of a log query. The note also records PwnKit as a local privilege-escalation option. The captured log ends with the PwnKit download and execution commands; it does not include output from running either exploit or obtaining a shell.

**Target:** `192.168.143.52`

## Methodology

1. Scan all TCP ports and identify the exposed services.
2. Enumerate web directories and inspect the discovered `/zm/` application.
3. Follow up on the ZoneMinder exploit reference and the PwnKit privilege-escalation references.
4. Confirm the ZoneMinder version and test the `limit` parameter before choosing an exploitation route.

## Exploitation context

### ZoneMinder SQL injection

The `/zm/` path is also available on the HTTP service at port 3305. ZoneMinder 1.29.0 is vulnerable to SQL injection in the `limit` parameter of a log query. Capture the request to the log endpoint and test whether the parameter is injectable; a time delay can confirm that the database evaluates the injected expression. If confirmed, the injection may support command execution through MySQL file-write or a user-defined function, depending on the database permissions and server configuration. Verify each precondition before proceeding. The raw room log does not include the version check, captured request, SQL injection test, or successful RCE output.

### PwnKit note

PwnKit (`CVE-2021-4034`) is a local privilege-escalation route. It requires an existing shell on the host and a vulnerable `pkexec`/Polkit installation. The commands below assume a web server at `192.168.45.205` is already serving `CVE-2021-4034.py`. Check the target's `pkexec` installation and confirm the file is reachable before running the exploit. The raw log does not include a preceding foothold, transfer output, or execution result.

## Findings and lessons learned

- The scan found three web listeners (80, 3305, and 8080); checking only the primary HTTP site would have missed the additional services.
- Gobuster found `/zm/` on port 80. Confirm the ZoneMinder version and the SQL injection behavior on the target; those checks are not shown in the captured scan or directory-enumeration output.
- Keep remote application exploitation and local privilege escalation as separate stages. The ZoneMinder reference concerns the web application; PwnKit requires local execution on the host.
- When using the recorded `wget` command, verify the serving machine's IP and that the file is reachable from the target network. The log contains no transfer or execution output to confirm this step worked.
