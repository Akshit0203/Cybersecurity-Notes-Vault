## 9. Key takeaways – OSCP methodology

|Stage|Technique|What to learn|
|---|---|---|
|Enumeration|Nmap|Identify exposed services|
|Web enumeration|Gobuster|Discover hidden directories|
|Information disclosure|Git Dumper|Recover exposed source code|
|Credential discovery|Configuration analysis|Find leaked credentials|
|Initial access|CVE-2022-3552|Authenticated RCE|
|Privilege escalation|Sudo misconfiguration|NOPASSWD unrestricted access|

Important lessons:

1. Always check for exposed `.git` directories during web enumeration.
    
2. Inspect Git history, not just the latest source code.
    
3. Look for credentials in application configuration files.
    
4. Check exploit prerequisites before launching an exploit.
    
5. Always run `sudo -l` immediately after obtaining a Linux shell.
