##### ==🔵Uploading magic bytes  : ==

If the website code has : 

Reads the first two bytes of the uploaded file.
```
$magic=fread($F,2);
```
Searches for '4D5A' within the string $magicbytes. If '4D5A' is not found, strpos() will return false.  
```
if ( strpos($magicbytes, '4D5A') === false ) {
```
`4D5A` is the hexadecimal representation of:
```
MZ
```

How to do now : 
open the payload : 
```
gedit payload.sh
```
At the beginning of the file, add two uppercase A’s then save and close.
like this : 
```
AA #add this on top of file , before everything else
<?php
```
In hexadecimal this becomes 41. We can see this when we open the file again in a hex editor.
now open the payload in hexedit
```
hexedit payload.sh
```

currently it will be having something like this in starting top left : 
the `41 41` here is our `AA` which we added on top of your file
```
41 41 0A 3C 
```
We want to change this to match our whitelist
so we make it to 
```
4D 5A 0A 3C
```
If you look to the right in the hex editor, you can see that the ASCII value becomes ‘MZ’.
Press CTRL+X to close and save the file.
Now we should be able to upload or file

