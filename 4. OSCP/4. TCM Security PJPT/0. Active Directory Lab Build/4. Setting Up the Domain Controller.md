## Create the VM

In VMware (or VirtualBox), select **Create a new virtual machine**.

![](4.%20OSCP/4.%20TCM%20Security%20PJPT/0.%20Active%20Directory%20Lab%20Build/attachments/image-12.png)

Choose a **Typical** setup.

![410](4.%20OSCP/4.%20TCM%20Security%20PJPT/0.%20Active%20Directory%20Lab%20Build/attachments/image-13.png)

![](4.%20OSCP/4.%20TCM%20Security%20PJPT/0.%20Active%20Directory%20Lab%20Build/attachments/image-28.png)

![](4.%20OSCP/4.%20TCM%20Security%20PJPT/0.%20Active%20Directory%20Lab%20Build/attachments/image-19.png)

### Disk Configuration

Make sure the drive you're installing on has at least **60 GB** of free space. Select **Split virtual disk into multiple files** — this lets the disk start small (10–20 GB) and grow dynamically instead of consuming 60 GB upfront. Hit **Next** → **Finish**.

![](4.%20OSCP/4.%20TCM%20Security%20PJPT/0.%20Active%20Directory%20Lab%20Build/attachments/image-20.png)

![](4.%20OSCP/4.%20TCM%20Security%20PJPT/0.%20Active%20Directory%20Lab%20Build/attachments/image-21.png)

### VM Settings (Before First Boot)

Before powering on, click **Edit virtual machine settings**.

**Memory:** If your host has at least 16 GB of total RAM, set the VM to **4–8 GB**.

![](4.%20OSCP/4.%20TCM%20Security%20PJPT/0.%20Active%20Directory%20Lab%20Build/attachments/image-22.png)

**CD/DVD (SATA):** Under "Connection," choose **Use ISO image file** and browse to your Windows Server 2022 ISO. Ensure **Connected** and **Connect at power on** are checked. Click **OK**.

![](4.%20OSCP/4.%20TCM%20Security%20PJPT/0.%20Active%20Directory%20Lab%20Build/attachments/image-29.png)

![](4.%20OSCP/4.%20TCM%20Security%20PJPT/0.%20Active%20Directory%20Lab%20Build/attachments/image-23.png)

## Install Active Directory Domain Services (AD DS)

Once logged back in, Server Manager will load. To make this a domain controller, click **Manage** → **Add Roles and Features**.

![](4.%20OSCP/4.%20TCM%20Security%20PJPT/0.%20Active%20Directory%20Lab%20Build/attachments/image-65.png)

![](4.%20OSCP/4.%20TCM%20Security%20PJPT/0.%20Active%20Directory%20Lab%20Build/attachments/image-66.png)

Choose **Role-based or feature-based installation**.

![](4.%20OSCP/4.%20TCM%20Security%20PJPT/0.%20Active%20Directory%20Lab%20Build/attachments/image-67.png)

![](4.%20OSCP/4.%20TCM%20Security%20PJPT/0.%20Active%20Directory%20Lab%20Build/attachments/image-68.png)

### Promote to Domain Controller

After installation completes, click **Promote this server to a domain controller**.

![](4.%20OSCP/4.%20TCM%20Security%20PJPT/0.%20Active%20Directory%20Lab%20Build/attachments/image-77.png)

Select **Add a new forest** (we don't have an existing domain) and set the root domain name to `DC.local`.

![](4.%20OSCP/4.%20TCM%20Security%20PJPT/0.%20Active%20Directory%20Lab%20Build/attachments/image-78.png)

Leave the functional level at its default. Enter a **DSRM password** — you can reuse your admin password.

![](4.%20OSCP/4.%20TCM%20Security%20PJPT/0.%20Active%20Directory%20Lab%20Build/attachments/image-79.png)

![](4.%20OSCP/4.%20TCM%20Security%20PJPT/0.%20Active%20Directory%20Lab%20Build/attachments/image-80.png)

The **NetBIOS domain name** auto-populates.

![](4.%20OSCP/4.%20TCM%20Security%20PJPT/0.%20Active%20Directory%20Lab%20Build/attachments/image-81.png)

Leave the **NTDS** and **SYSVOL** paths at their defaults.

![](4.%20OSCP/4.%20TCM%20Security%20PJPT/0.%20Active%20Directory%20Lab%20Build/attachments/image-82.png)

![](4.%20OSCP/4.%20TCM%20Security%20PJPT/0.%20Active%20Directory%20Lab%20Build/attachments/image-83.png)

The system runs a **prerequisite check**. Once it passes, hit **Install**. The server will install AD DS and automatically reboot.

![](4.%20OSCP/4.%20TCM%20Security%20PJPT/0.%20Active%20Directory%20Lab%20Build/attachments/image-84.png)

![](4.%20OSCP/4.%20TCM%20Security%20PJPT/0.%20Active%20Directory%20Lab%20Build/attachments/image-85.png)

When the login screen returns, you'll see you're now logging in as **DC\Administrator** — your domain is live.

## Install Active Directory Certificate Services (AD CS)

Go to **Manage** → **Add Roles and Features**.

![](4.%20OSCP/4.%20TCM%20Security%20PJPT/0.%20Active%20Directory%20Lab%20Build/attachments/image-92.png)

![](4.%20OSCP/4.%20TCM%20Security%20PJPT/0.%20Active%20Directory%20Lab%20Build/attachments/image-93.png)

![](4.%20OSCP/4.%20TCM%20Security%20PJPT/0.%20Active%20Directory%20Lab%20Build/attachments/image-94.png)

![](4.%20OSCP/4.%20TCM%20Security%20PJPT/0.%20Active%20Directory%20Lab%20Build/attachments/image-95.png)

Select **Active Directory Certificate Services**. Certificate Services is used to verify identities and enable **LDAP Secure (LDAPS)** — a secure "phone book" for the domain. Installing this is standard practice and enables certain relay and abuse attacks later in the course.

![](4.%20OSCP/4.%20TCM%20Security%20PJPT/0.%20Active%20Directory%20Lab%20Build/attachments/image-96.png)

**Add Feature** → **Next**.

![](4.%20OSCP/4.%20TCM%20Security%20PJPT/0.%20Active%20Directory%20Lab%20Build/attachments/image-97.png)

![](4.%20OSCP/4.%20TCM%20Security%20PJPT/0.%20Active%20Directory%20Lab%20Build/attachments/image-98.png)

![](4.%20OSCP/4.%20TCM%20Security%20PJPT/0.%20Active%20Directory%20Lab%20Build/attachments/image-99.png)

![](4.%20OSCP/4.%20TCM%20Security%20PJPT/0.%20Active%20Directory%20Lab%20Build/attachments/image-100.png)

Ensure **Certification Authority** is checked → **Install**.

![](4.%20OSCP/4.%20TCM%20Security%20PJPT/0.%20Active%20Directory%20Lab%20Build/attachments/image-101.png)

![](4.%20OSCP/4.%20TCM%20Security%20PJPT/0.%20Active%20Directory%20Lab%20Build/attachments/image-102.png)
