# Introduction to the Course

## What is This Course?

- Understand the concepts, components, and architecture of modern Active Directory environments
- Understand, practice, and leverage modern AD attacks and threats offensively
- Learn to exploit a complete AD attack chain — from initial low-privilege access to becoming a Domain Administrator
- Learn to create your own Active Directory lab environment and practice with industry-standard tools
- Ace the OSCP exam and much more

---

## Why Active Directory?

- **95% of Fortune 500 companies** use Active Directory
- Large knowledge gap between security professionals and SysAdmins regarding AD security
- Windows pentesting is complex with incomplete and scattered resources
- AD concepts are overwhelming and require a different set of tools
- Lack of documentation due to closed-source nature of Windows

> [!important] OSCP Alignment
> Everything taught regarding Active Directory in the OSCP syllabus is fully covered in this course (and more). AD became a **mandatory exam component starting in 2022**.

## AD Attack Chain Overview

The standard Active Directory pentesting flow:

```
Initial Access (client machine)
        ↓
Local Privilege Escalation
        ↓
Enumeration
        ↓
Lateral Movement (client → client)
        ↓
Domain Controller Compromise
        ↓
Domain Admin / SYSTEM privileges
```

> [!tip] Why Build Your Own Lab?
> Building the lab yourself gives you deep internal understanding of **why** a specific service or misconfiguration is vulnerable and how the architecture is designed — rather than just running tools on a pre-configured cloud setup.

## Windows vs. Linux Pentesting

| Aspect | Linux | Windows |
|--------|-------|---------|
| Source model | Open-source | Closed-source |
| Documentation | Vast, public | Scattered, incomplete |
| Internal structures | Familiar utilities | Registry, SAM, complex auth mechanisms |
| Tool compilation | GCC is straightforward | Cross-compilation, DLL dependencies, 32/64-bit arch |
| Corporate prevalence | Less common for workstations | Dominant (servers + workstations + AD) |

Key Windows AD tools: **Mimikatz**, **PowerView**, specialized Windows binaries — these operate very differently than Linux utilities.
