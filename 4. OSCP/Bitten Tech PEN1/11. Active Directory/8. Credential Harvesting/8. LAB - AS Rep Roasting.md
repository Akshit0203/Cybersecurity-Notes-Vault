# LAB — Other Attacks (AS-REP Roasting, Kerberoasting, Relay/Poisoning)

> [!abstract] TL;DR
> Unlike earlier tasks (which assumed a foothold), these attacks harvest credentials **over the network**:
> - **Kerberoasting** — request a TGS for an **SPN account**, crack offline (Hashcat `-m 13100`).
> - **AS-REP Roasting** — for users with **"Do not require Kerberos pre-authentication"**, request the AS-REP and crack offline (Hashcat `-m 18200`). Needs only a **valid username list**.
> - **SMB Relay** & **LLMNR/NBT-NS Poisoning** — MITM attacks to capture NTLM hashes.

---

## Kerberoasting

A common AD attack to obtain AD tickets for persistence/privesc/lateral movement. Requires access to **SPN (Service Principal Name)** accounts (e.g. IIS user, MSSQL). You request a **TGT** then a **TGS** for the service account, and crack the TGS offline.

### 1. Enumerate SPN accounts (`GetUserSPNs.py`)

Use `THM.red/thm` with password `Passw0rd!`:

→ SPN account found: **`svc-user`**.

### 2. Request a TGS for the SPN account (`-request-user`)


## AS-REP Roasting

Retrieves password hashes for AD users whose account has **"Do not require Kerberos pre-authentication"** (`UF_DONT_REQUIRE_PREAUTH` / `DONT_REQ_PREAUTH`) set. Crack the hash offline to recover the password.

![[Pasted image 20261014193315.png]]

### How it works

In normal Kerberos, the client sends an **`AS-REQ`** containing an encrypted timestamp derived from their password (pre-authentication). The KDC replies with an **`AS-REP`** encrypted with a key derived from the user's password (NT hash transformation).

When pre-auth is **disabled**, anyone can send an `AS-REQ` for that user **without knowing the password**, and the KDC returns the encrypted AS-REP. An attacker who knows a **valid username** can request it, capture the AS-REP, and crack it offline to recover the cleartext password.

> [!note] Rare by default
> Pre-auth is enforced by default to prevent offline brute-forcing. The vulnerable setting is only found on legacy systems, misconfigured test environments, or where a legacy app requires it. **Prerequisite: a list of valid domain usernames** (from enumeration), since the attack queries the KDC per account.

### 1. Build a username list

```
nano users.txt
```

```
Administrator
admin
thm
test
sshd
victim
CREDS-HARVESTIN$
```

- **`-dc-ip`** — DC IP address

### 3. Crack the AS-REP offline

Save the hash string to a file (e.g. `victim_asrep`), then crack with John or Hashcat.

**John the Ripper:**

```
john victim_asrep --wordlist=/usr/share/wordlists/rockyou.txt
```

**Hashcat** — find the AS-REP mode, then crack with mode **18200** (Kerberos 5 AS-REP etype 23):

```
hashcat --help | grep -i asrep
hashcat -m 18200 -a 0 victim_asrep /usr/share/wordlists/rockyou.txt
```

> [!warning] Lab note
> In the lab the `victim` password is not crackable with the basic `rockyou.txt` wordlist, and there is no room question requiring it — the demo teaches the **extraction methodology**. John also fails to auto-detect the format; specify it explicitly (`--format=krb5asrep`) or use Hashcat mode `18200`. If the password is long/complex, offline dictionary cracking will not yield it.

## SMB Relay Attack

Abuses the NTLM challenge-response authentication. The attacker performs a **MITM** to capture SMB packets and extract hashes. **Requires SMB signing to be disabled** (SMB signing is an integrity check ensuring communication is between trusted sources). See *Exploiting AD* for details.

## LLMNR / NBT-NS Poisoning

**LLMNR** (Link-Local Multicast Name Resolution) and **NBT-NS** (NetBIOS Name Service) help local machines resolve names when DNS fails — a host broadcasts a multicast request asking others for the correct address.

**Poisoning:** the attacker spoofs an authoritative source and responds to LLMNR/NBT-NS traffic, tricking the victim. The end goal (shared with SMB relay) is to **capture NTLM authentication hashes** to access the victim's account/machine. See *Breaching AD*.

## AS-REP Roasting vs Kerberoasting — quick comparison

| | AS-REP Roasting | Kerberoasting |
|---|---|---|
| Tool | `GetNPUsers.py` | `GetUserSPNs.py` |
| Target | Users with pre-auth disabled | Accounts with an SPN (service accounts) |
| Ticket cracked | `AS-REP` | `TGS` |
| Hashcat mode | `18200` | `13100` |
| Needs creds? | No — just a username list | Yes — a valid domain user |
