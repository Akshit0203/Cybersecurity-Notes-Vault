# Return Statuses and Exit Codes

---

## What Are Exit Codes?

Every command/process in Unix returns an **exit status** (0–255) to its parent process upon completion. This tells the parent whether the command succeeded or what type of error occurred.

| Exit Code | Meaning |
|-----------|---------|
| `0` | **Success** — command executed without errors |
| `1` | General error (e.g., invalid option) |
| `127` | **Command not found** |
| `2–255` | Various error types (program-specific) |

> **Key rule:** Exit code `0` = success. **Anything else** = some kind of failure.

---

## Accessing the Exit Code — `$?`

`$?` is a special variable that holds the **exit code of the most recently executed command**.

### Example 1 — Successful Command

```bash
#!/bin/bash

name=$(who)

echo "Hello $name "
echo $?
```

```
└─$ ./new.sh
Hello kali     seat0        2026-08-21 02:13 (:0) 
0
```

Exit code `0` — the `echo` command ran successfully.

### Example 2 — Command Not Found (Exit Code 127)

```bash
#!/bin/bash

name=$(wh)
echo $?

echo "Hello $name "
echo $?
```

```
└─$ ./new.sh
./new.sh: line 3: wh: command not found
127
Hello  
0
```

- First `$?` → `127` because `wh` is not a valid command.
- Second `$?` → `0` because `echo "Hello $name "` itself succeeded (even though `$name` was empty).

> ⚠️ **`$?` always reflects the LAST command.** You must check it **immediately** after the command you care about.

### Example 3 — Invalid Option (Exit Code 1)

```bash
#!/bin/bash

name=$(who -y)
echo $?

echo "Hello $name "
```

```
└─$ ./new.sh
who: invalid option -- 'y'
Try 'who --help' for more information.
1
Hello  
```

Exit code `1` — the command exists but the option `-y` is invalid.

---

## Placing `$?` Correctly

**Wrong** — checking `$?` after an unrelated command:

```bash
name=$(wh)          # ← this fails (code 127)
echo "Hello $name " # ← this succeeds (code 0)
echo $?             # → prints 0, NOT 127!
```

**Right** — checking `$?` immediately after the command:

```bash
name=$(wh)          # ← this fails
echo $?             # → prints 127 ✅
echo "Hello $name "
```

## Exiting Scripts with Specific Codes

### `exit N` — Terminate with a Specific Code

```bash
#!/bin/bash

name=$(who -y)
echo $?

echo "Hello $name "
echo exit 5
echo exit 0
```

```
└─$ ./new.sh
who: invalid option -- 'y'
Try 'who --help' for more information.
1
Hello  
exit 5
exit 0
```

> **Note:** `echo exit 5` just *prints* the string "exit 5" — it doesn't actually exit. To exit with code 5, write `exit 5` (without `echo`).

### `exit $?` — Exit with the Last Command's Code

Writing `exit $?` at the **end** of a script passes through the exit code of the last command to the parent process. This is the standard practice:

```bash
#!/bin/bash

# ... your commands ...

exit $?
```

---

## Practical Use Case — `grep`

Exit codes are especially useful with commands like `grep`:

| Scenario | Exit Code |
|----------|-----------|
| Pattern found in file | `0` |
| Pattern **not** found | `1` |
| Input file doesn't exist | `2` |

This lets you detect **what type of error** occurred and handle each case differently in your scripts.
