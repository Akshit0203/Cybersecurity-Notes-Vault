# Introduction to AWK

---

## What is AWK?

`awk` is a Linux command-line tool and **interpreted programming language** designed for **processing structured text**. Named after its creators — **A**lfred Aho, Peter **W**einberger, and Brian **K**ernighan. On GNU/Linux it ships as `gawk` (GNU Awk).

> **Mental model:** AWK reads input line by line, splits each line into fields, and lets you perform operations on those fields.

### AWK vs grep

| Feature | `grep` | `awk` |
|---|---|---|
| Search / pattern match | ✅ | ✅ |
| Extract columns | ❌ | ✅ |
| Modify / transform text | ❌ | ✅ |
| Arithmetic on fields | ❌ | ✅ |
| Full programming (loops, if, vars) | ❌ | ✅ |

### Four Primary Use Cases

1. **Text Processing** — filtering and searching line by line
2. **Text Transformation & Substitution** — replacing and manipulating strings
3. **Arithmetic Operations** — calculations across columns (totals, averages, percentages)
4. **Formatted Reports** — producing structured output from raw data

---

## 1. Basic Syntax

```
awk 'pattern { action }' file
```

```bash
awk '{print}' colors.txt      # prints every line (no pattern = match all)
```

---

## 2. Field Variables — `$0`, `$1`, `$2`, …

AWK splits each line into **fields** using whitespace (by default).

Sample `students.txt`:

```
101 Akshit CSE
102 Rahul ECE
103 John ME
```

```
101 Akshit CSE
 ↑    ↑     ↑
 $1   $2    $3       $0 = entire line
```

```bash
awk '{print $1}' students.txt       # → 101 / 102 / 103
awk '{print $2}' students.txt       # → Akshit / Rahul / John
awk '{print $0}' students.txt       # → entire line
```

### Printing Multiple Columns

```bash
awk '{print $1, $2}' students.txt
```

```
101 Akshit
102 Rahul
103 John
```

AWK auto-inserts a space between `,`-separated arguments.

### Custom Output Format

```bash
awk '{print "ID:", $1, "Name:", $2}' students.txt
```

```
ID: 101 Name: Akshit
ID: 102 Name: Rahul
ID: 103 Name: John
```

---

## 3. Built-in Variables

### `NF` — Number of Fields

```bash
awk '{print NF}' students.txt       # → 3 / 3 / 3
```

### `$NF` — Last Column

```bash
awk '{print $NF}' students.txt      # → CSE / ECE / ME
```

`$NF` = the field whose number equals `NF` (field count) → always the last column.

### `NR` — Record (Line) Number

```bash
awk '{print NR, $0}' students.txt
```

```
1 101 Akshit CSE
2 102 Rahul ECE
3 103 John ME
```

---

## 4. Conditions (Pattern Matching)

Given `students.txt` with marks:

```
101 Akshit CSE 85
102 Rahul ECE 72
103 John CSE 91
104 Alex ME 65
```

### Numeric Condition

```bash
awk '$4 > 80 {print $2}' students.txt    # → Akshit / John
```

### String Condition

```bash
awk '$3 == "CSE" {print $2}' students.txt   # → Akshit / John
```

### Regex Matching (`~` and `!~`)

```bash
awk '$2 ~ /CSE/ {print $1}' students.txt     # field matches pattern
awk '$2 !~ /CSE/ {print $1}' students.txt    # field does NOT match
```

### Pattern Search (Whole Line)

```bash
awk '/Ashok/ { print $0 }' student.txt       # lines containing "Ashok"
```

---

## 5. `BEGIN` and `END` Blocks

```
awk 'BEGIN { … } { … } END { … }' file
```

| Block | Runs | Use For |
|---|---|---|
| `BEGIN` | Once, **before** reading any lines | Init variables, print headers |
| Body `{ }` | Once per line | Process each record |
| `END` | Once, **after** all lines processed | Print totals, summaries |

### Examples

```bash
# Header before data
awk 'BEGIN {print "Students"} {print $2}' students.txt
```

```
Students
Akshit
Rahul
John
Alex
```

```bash
# Count lines
awk 'END {print "Total lines:", NR}' students.txt    # → Total lines: 4
```

```bash
# Formatted report with header + footer
awk 'BEGIN { print "S.No\tName\tSubject\tMarks" } { print $0 } END { print "Program Completed" }' student.txt
```

---

## 6. Arithmetic / Calculations

Sample `marks.txt`:

```
Akshit 85
Rahul 72
John 91
Alex 65
```

```bash
# Total
awk '{sum += $2} END {print sum}' marks.txt             # → 313

# Average
awk '{sum += $2} END {print sum/NR}' marks.txt          # → 78.25
```

```bash
# Inline arithmetic
awk 'BEGIN { a=10; b=20; print "a + b =", a+b }'       # → a + b = 30
```

> **Important:** AWK variables don't use `$`. `$` in AWK means **field reference** — `$2` = second field, not a Bash variable.

---

## 7. Field Separator (`-F`)

By default AWK splits on whitespace. For other delimiters use `-F`:

### Colon-Separated

```
Akshit:21:CSE
Rahul:22:ECE
John:20:ME
```

```bash
awk -F ':' '{print $1, $3}' students.txt     # → Akshit CSE / Rahul ECE / John ME
```

### CSV Files

```
name,age,department
Akshit,21,CSE
Rahul,22,ECE
John,20,ME
```

```bash
awk -F ',' '{print $1, $3}' students.csv
```

### Skip the Header

```bash
awk -F ',' 'NR > 1 {print $1, $3}' students.csv
```

`NR = 1` → skip (header), `NR > 1` → process data rows.

---

## 8. AWK with Pipes

AWK doesn't need a file — it can receive piped input:

```bash
ls -l | awk '{print $9}'                   # filenames from ls -l
ps aux | awk '{print $1, $2, $11}'         # user, PID, command
```

---

## 9. Control Flow

### `if` / `else`

```bash
awk '{
    if ($4 >= 80)
        print $2, "Passed"
    else
        print $2, "Needs improvement"
}' students.txt
```

### `for` Loop

```bash
awk '{
    for (i = 1; i <= NF; i++)
        print $i
}' students.txt
```

For `101 Akshit CSE` → prints `101`, `Akshit`, `CSE` (one per line).

> `$i` where `i=1` → `$1`, `i=2` → `$2`, etc.

---

## 10. Standalone AWK Scripts

Save complex logic in a `.awk` file and run with `-f`:

```bash
awk -f commands.awk student.txt
```

## 11. Real-World Example — Port Scan Parsing

```
192.168.1.10 22 open
192.168.1.10 80 open
192.168.1.10 443 open
192.168.1.10 21 closed
```

```bash
# All ports
awk '{print $2}' scan.txt                        # → 22 / 80 / 443 / 21

# Only open ports
awk '$3 == "open" {print $2}' scan.txt            # → 22 / 80 / 443
```

## AWK Mental Model

```
              AWK
               │
        reads one line
               │
               ↓
     ┌───────────────────┐
     │  $0 = whole line  │
     │  $1 = field 1     │
     │  $2 = field 2     │
     │  …                │
     │  NF = field count │
     │  NR = line number │
     └───────────────────┘
               │
          condition?
          /       \
        yes        no
         ↓          ↓
      action       skip
```

---

## Quick Reference — Commands Worth Memorizing

| Command | What It Does |
|---|---|
| `awk '{print $1}' file` | First column |
| `awk '{print $NF}' file` | Last column |
| `awk '{print NR, $0}' file` | Line number + entire line |
| `awk '$3 == "CSE" {print $2}' file` | Filter based on column 3 |
| `awk -F ':' '{print $1}' file` | Use `:` as delimiter |
| `awk 'END {print NR}' file` | Count lines |
| `awk '{sum += $2} END {print sum}' file` | Column total |
| `awk '{sum += $2} END {print sum/NR}' file` | Column average |

> **`$1` in Bash** = first command-line argument. **`$1` in AWK** = first field of the current line. Don't confuse them — AWK has its own language inside the single quotes.

# Regex (Regular Expressions)

A regex is a **pattern used to search for text** — instead of searching for an exact string, you define rules that match many strings.

---

## 1. Literal Text

```bash
grep 'apple' file.txt
```

Matches lines containing `apple` (case-sensitive by default). Matches both `apple` and `pineapple`.

---

## 2. `.` — Any Single Character

```bash
grep 'c.t' file.txt
```

Matches: `cat`, `cut`, `cot`, `c9t`, `c-t`
Does NOT match: `cart` (two characters between c and t)

```
c . t
↑ ↑ ↑
c any t
```

---

## 3. `^` — Beginning of Line

```bash
grep '^Hello' file.txt
```

✅ `Hello World`, `Hello Akshit`
❌ `Say Hello`, `Hi Hello`

---

## 4. `$` — End of Line

```bash
grep 'world$' file.txt
```

✅ `Hello world`, `Beautiful world`
❌ `world is beautiful`

---

## 5. `^...$` — Exact Entire Line

```bash
grep '^Hello$' file.txt
```

Matches **only** a line that is exactly `Hello` — not `Hello World` or `Hello!`.

---

## 6. `[ ]` — Character Classes

Match **one character from a set**:

```bash
grep '[abc]' file.txt       # lines containing a, b, or c
```

### Ranges

| Pattern | Matches |
|---|---|
| `[a-z]` | Any lowercase letter |
| `[A-Z]` | Any uppercase letter |
| `[0-9]` | Any digit |

```bash
grep '[0-9]' file.txt       # lines containing at least one digit
```

---

## 7. `[^ ]` — Negated Character Class

```bash
grep '[^0-9]' file.txt      # lines with a non-digit character
```

> **Important distinction:** `^abc` = line starts with `abc`. `[^abc]` = character is NOT a/b/c.

---

## 8. Quantifiers

| Symbol | Meaning | Requires `-E`? |
|---|---|---|
| `*` | Zero or more of preceding | No (BRE) |
| `+` | One or more of preceding | Yes |
| `?` | Zero or one of preceding | Yes |
| `{n}` | Exactly n | Yes |
| `{n,m}` | Between n and m | Yes |

### `*` — Zero or More

`ab*` matches: `a`, `ab`, `abb`, `abbb`, …

### `+` — One or More

```bash
grep -E 'ab+' file.txt      # ab, abb, abbb — but NOT just 'a'
```

### `?` — Zero or One (Optional)

```bash
grep -E 'colou?r' file.txt  # matches both 'color' and 'colour'
```

### `{ }` — Exact Repetitions

```bash
grep -E '[0-9]{3}' file.txt       # exactly 3 digits
grep -E '[0-9]{2,4}' file.txt     # 2 to 4 digits
```

---

## 9. `|` — OR (Alternation)

```bash
grep -E 'apple|banana' file.txt   # lines with apple OR banana
```

---

## 10. `( )` — Grouping

```bash
grep -E '(cat|dog)+' file.txt     # cat, dog, catdog, dogcat, catcat…
```

---

## 11. POSIX Character Classes

Portable across all Linux tools:

| Class | Matches |
|---|---|
| `[[:digit:]]` | Digits |
| `[[:alpha:]]` | Letters |
| `[[:alnum:]]` | Letters + numbers |
| `[[:lower:]]` | Lowercase |
| `[[:upper:]]` | Uppercase |
| `[[:space:]]` | Whitespace |

```bash
grep -E '^[[:digit:]]+$' file.txt    # lines consisting ONLY of digits
```

> **Tip:** Prefer `[0-9]`, `[A-Za-z]`, `[[:space:]]` over `\d`, `\w`, `\s` — the shorthand forms aren't universally supported in POSIX tools.

---

## 12. Escaping Special Characters

These characters have special regex meaning:

```
. * + ? ^ $ [ ] ( ) { } |
```

To match them literally, escape with `\`:

```bash
grep '10\.50' file.txt    # literal dot, not "any character"
```

---

## 13. Basic vs Extended Regex

| Mode | Flag | Supports `+`, `?`, `|`, `()`, `{}` natively? |
|---|---|---|
| Basic (BRE) | `grep` / `sed` (default) | No — must escape: `\+`, `\?`, `\|` |
| Extended (ERE) | `grep -E` / `sed -E` | Yes |

> **Recommendation:** Use `grep -E` and `sed -E` when you need `+`, `?`, `|`, `()`, `{}`.

---

## 14. Practical Examples

### With `grep`

Given `data.txt`:

```
apple
banana
12345
hello123
Akshit
192.168.1.10
```

```bash
grep -E '[0-9]' data.txt          # lines containing a digit → 12345, hello123, 192.168.1.10
grep -E '^[0-9]' data.txt         # lines starting with digit → 12345, 192.168.1.10
grep -E '[0-9]$' data.txt         # lines ending with digit → 12345, hello123
```

### With `sed`

```bash
sed -E 's/[0-9]+/NUMBER/g' file.txt
```

`User123 logged in from 192.168.1.10` → `UserNUMBER logged in from NUMBER.NUMBER.NUMBER.NUMBER`

### With AWK

```bash
awk '$2 ~ /CSE/ {print $1}' students.txt      # field matches regex
awk '$2 !~ /CSE/ {print $1}' students.txt     # field does NOT match
```

### IPv4 Address Pattern

```bash
grep -E '[0-9]+\.[0-9]+\.[0-9]+\.[0-9]+' file.txt
```

```
[0-9]+  →  one or more digits
\.      →  literal dot
```

Matches `192.168.1.10`, `10.0.0.1`, `172.16.5.20`. (Note: doesn't enforce 0–255 range.)

---

## 15. Building Patterns Piece by Piece

> A line beginning with 3 digits followed by a dash:

```
^           → beginning
[0-9]       → digit
{3}         → three times
-           → literal dash
```

Final pattern: `^[0-9]{3}-`

```bash
grep -E '^[0-9]{3}-' file.txt
```

✅ `123-Akshit`, `456-Rahul`, `999-Test`
❌ `12-Test`, `abc-Test`, `1234-Test`

> **Core skill:** Don't memorize giant regexes — learn to **construct them piece by piece**.

## Regex Quick Reference

| Regex | Meaning |
|---|---|
| `.` | Any single character |
| `^` | Beginning of line |
| `$` | End of line |
| `[abc]` | `a` or `b` or `c` |
| `[^abc]` | Anything except a/b/c |
| `[a-z]` | Lowercase letter |
| `[0-9]` | Digit |
| `*` | 0 or more |
| `+` | 1 or more |
| `?` | 0 or 1 |
| `{3}` | Exactly 3 |
| `{2,5}` | 2 to 5 |
| `\|` | OR |
| `(abc)` | Group |
| `\.` | Literal `.` |
