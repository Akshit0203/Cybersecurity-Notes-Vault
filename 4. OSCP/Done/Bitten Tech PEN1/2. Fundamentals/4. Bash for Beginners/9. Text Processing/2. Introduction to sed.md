# Introduction to sed (Stream Editor)

> **`sed`** = Stream Editor — a line-by-line text editor for **finding, replacing, deleting, inserting, and modifying text**.

---

## sed vs grep vs AWK

| Feature | `grep` | `sed` | `awk` |
|---|---|---|---|
| Search / pattern match | ✅ | ✅ | ✅ |
| Replace / substitute text | ❌ | ✅ | ✅ |
| Delete / insert lines | ❌ | ✅ | ✅ |
| Column extraction | ❌ | ❌ | ✅ |
| Arithmetic / programming | ❌ | ❌ | ✅ |
| Speed / conciseness | Fast | Very fast & lightweight | Heavier |

**Rule of thumb:**
- `grep` → quick searching
- `sed` → search & replace, text transformations
- `awk` → columns, calculations, conditions, data processing

---

## General Syntax

```
sed [options] 'script' [input_file]
```

Internal script format:

```
[ADDRESS]COMMAND[OPTIONS]
```

| Part | Examples |
|---|---|
| **Address** | Line number (`2`), range (`1,3`), pattern (`/regex/`) |
| **Command** | `d` delete, `p` print, `s` substitute, `i` insert, `a` append, `c` change, `e` execute |
| **Options** | Flags like `g` (global), `I` (case-insensitive) |

---

## 1. The `s` Command — Substitute (Most Important)

```
sed 's/old/new/' file
```

```
s / old / new /
  ↑   ↑    ↑
  │   │    └── replacement
  │   └─────── text to find
  └─────────── substitute
```

### Example

```bash
sed 's/Hello/Hi/' file.txt
```

```
Hello World  →  Hi World
Hello Akshit →  Hi Akshit
Hello Linux  →  Hi Linux
```

> **`sed` does NOT modify the original file** by default — it outputs modified text to stdout.

---

## 2. First Occurrence vs Global (`g`)

By default, `sed` replaces only the **first occurrence on each line**:

```bash
# Input: Apple Apple Apple
sed 's/Apple/Orange/' file.txt         # → Orange Apple Apple
sed 's/Apple/Orange/g' file.txt        # → Orange Orange Orange
```

| Flag | Meaning |
|---|---|
| (none) | First match per line |
| `g` | All matches per line |

---

## 3. Case-Insensitive Replacement (`I`)

```bash
sed 's/apple/orange/gI' file.txt     # matches apple, Apple, APPLE
```

---

## 4. Targeting Specific Occurrences

```bash
sed 's/,/|/2' books.txt      # replace only the 2nd comma on each line
```

---

## 5. Restricting to Line Ranges

```bash
sed '2s/Apple/Orange/' file.txt        # line 2 only
sed '1,3s/Martin/Edwards/g' file.txt   # lines 1–3 only
```

---

## 6. Delete Lines — `d`

```bash
sed '2d' file.txt        # delete line 2
sed '2,4d' file.txt      # delete lines 2 through 4
sed '1d' file.txt        # delete first line (useful for removing headers)
```

### Delete by Pattern

```bash
sed '/Apple/d' file.txt     # delete all lines containing "Apple"
```

### Remove Blank Lines

```bash
sed '/^$/d' file.txt
```

`^$` = a line that starts and immediately ends = empty line.

---

## 7. Print Specific Lines — `-n` and `p`

Normally `sed` auto-prints every line. Adding `p` causes double-printing:

```bash
sed 'p' colors.txt       # each line printed TWICE
```

Use `-n` to **suppress auto-printing**, then `p` to print only what you want:

```bash
sed -n '3p' file.txt          # print only line 3
sed -n '2,4p' file.txt        # print lines 2 through 4
sed -n '/Alchemist/p' file.txt   # print only matching lines
```

---

## 8. Insert Before — `i`

```bash
sed '2i\Hello' file.txt
```

```
one           one
two     →     Hello
three         two
              three
```

---

## 9. Append After — `a`

```bash
sed '2a\Hello' file.txt
```

```
one           one
two     →     two
three         Hello
              three
```

> `i` → insert **BEFORE**. `a` → append **AFTER**.

---

## 10. Replace Entire Line — `c`

```bash
sed '2c\Hello' file.txt
```

```
one           one
two     →     Hello
three         three
```

---

## 11. Execute Shell Commands — `e`

```bash
sed '1e date' books.txt       # runs 'date' and prints output before line 1
sed '5e whoami' books.txt     # runs 'whoami' before line 5
```

---

## 12. Writing Matched Output to a File — `w`

```bash
sed -n '/Alchemist/w output_books.txt' books.txt
```

Writes only matched lines to `output_books.txt`.

---

## 13. In-Place Editing — `-i`

```bash
sed -i 's/Apple/Orange/g' file.txt      # modifies the actual file
```

⚠️ **Be careful** — this changes the original file permanently.

### Create a Backup

```bash
sed -i.bak 's/Apple/Orange/g' file.txt
```

Creates `file.txt.bak` with the original content before applying changes.

---

## 14. Alternative Delimiters

When patterns contain `/` (e.g., file paths), use a different delimiter to avoid escaping:

```bash
# Ugly:
sed 's/\/home\/kali\/old/\/home\/kali\/new/' file.txt

# Clean:
sed 's|/home/kali/old|/home/kali/new|' file.txt
```

Valid delimiters: `|`, `#`, `@`, or any consistent character.

---

## 15. Variables Inside `sed`

Use **double quotes** so Bash expands variables:

```bash
old="Apple"
new="Orange"
sed "s/$old/$new/g" file.txt
```

Single quotes would prevent variable expansion.

## sed Mental Model

```
                 file
                  ↓
                 sed
                  ↓
        ┌─────────────────┐
        │ read line       │
        │                 │
        │ pattern match?  │
        │       ↓         │
        │    command      │
        │       ↓         │
        │ modified line   │
        └─────────────────┘
                  ↓
                output
```

```
sed 'address command' file

sed '2d' file               sed 's/Apple/Orange/g' file
     ↑ ↑                          ↑   ↑      ↑
     │ └── delete                 │   │      └── all occurrences
     └──── line 2                 │   └───────── replacement
                                  └───────────── substitute
```

## Quick Reference — 10 Commands Worth Memorizing

| Task | Command |
|---|---|
| Replace (first) | `sed 's/old/new/' file` |
| Replace (all) | `sed 's/old/new/g' file` |
| Delete a line | `sed '2d' file` |
| Delete a range | `sed '2,5d' file` |
| Delete matching lines | `sed '/pattern/d' file` |
| Print one line | `sed -n '3p' file` |
| Print a range | `sed -n '2,5p' file` |
| Insert before | `sed '2i\text' file` |
| Append after | `sed '2a\text' file` |
| Edit file in place | `sed -i 's/old/new/g' file` |
