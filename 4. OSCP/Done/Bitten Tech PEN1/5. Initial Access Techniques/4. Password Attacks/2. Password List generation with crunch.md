# Custom Wordlist Generation with Crunch

> **Tool:** `crunch` — generates wordlists from character sets based on specified criteria
> **Pre-installed:** Kali Linux
> **Character Set File:** `/usr/share/crunch/charset.lst`

---

## Core Syntax

```
crunch <min-len> <max-len> [charset string] [options]
```

| Parameter | Description |
|-----------|-------------|
| `min-len` | Minimum password length (required) |
| `max-len` | Maximum password length (required) |
| `charset string` | Custom character set (optional; defaults to lowercase `a-z`) |

> **Character set order MUST be:** lowercase → uppercase → numbers → symbols. Use `+` as a placeholder for character types you want to skip.

---

## Pre-installed Wordlists in Kali

Kali ships with wordlists used by various tools:

| Path | Used By |
|------|---------|
| `/usr/share/wordlists/` | General wordlists |
| `/usr/share/wordlists/rockyou.txt.gz` | Most popular leaked password list (decompress with `gunzip`) |
| `/usr/share/nmap/` | Nmap NSE scripts |
| `/usr/share/metasploit-framework/data/wordlists/` | Metasploit modules |
| `/usr/share/dirbuster/wordlists/` | Directory brute-forcing |

> **rockyou.txt** is popular because it contains real passwords leaked from various websites. Decompressed size: ~133 MB.

## Key Options

| Option | Description |
|--------|-------------|
| `-o FILE` | Write output to file |
| `-f PATH CHARSET` | Use a charset from `/usr/share/crunch/charset.lst` |
| `-t PATTERN` | Pattern-based generation with wildcards |
| `-s STRING` | Start generating from this string (skip prior combinations) |
| `-e STRING` | Stop generating at this string |
| `-p CHARS` or `-p WORD1 WORD2 ...` | Generate permutations only (no repeats). **Must be last option.** |
| `-q FILE` | Read words from file and permute them |
| `-b SIZE[type]` | Split output into chunks (e.g., `20mib`). Types: `kb, mb, gb, kib, mib, gib` |
| `-c NUM` | Max lines per output file (requires `-o START`) |
| `-d NUM@` | Limit consecutive duplicate characters |
| `-i` | Invert output order |
| `-l PATTERN` | Treat pattern characters as literals (same length as `-t`) |
| `-r` | Resume a previous session (requires `-o`) |
| `-z TYPE` | Compress output (`gzip, bzip2, lzma, 7z`) |

---

## Pattern Wildcards (`-t`)

| Wildcard | Represents |
|----------|------------|
| `@` | Lowercase letters (`a-z`) |
| `,` | Uppercase letters (`A-Z`) |
| `%` | Numbers (`0-9`) |
| `^` | Symbols / special characters |

Any other character in the pattern is treated as a **literal** (fixed text).

> **Important:** When using `-t`, the `min-len` and `max-len` must **both equal** the total pattern length.

## Practical Examples

### Basic Wordlists

#### Default charset (lowercase `a-z`), lengths 3–4

```bash
crunch 3 4 -o wordlist1.txt
```

```
Crunch will now generate the following amount of data: 2355184 bytes
2 MB
Crunch will now generate the following number of lines: 474552
```

Output: `aaa` → `zzzz`

---

#### Custom charset `abcdefg`, lengths 1–6

```bash
crunch 1 6 abcdefg -o wordlist1.txt
```

Output: `a` → `gggggg` (only uses characters a through g)

---

#### Mixed letters and numbers

```bash
crunch 3 4 abc1234567890 -o wordlist1.txt
```

Output includes: `aaa`, `aab`, `aa1`, `aa2`, … `0009`, `0000`

---

#### Mixed case (lowercase + uppercase)

```bash
crunch 3 4 abc123ABC -o wordlist1.txt
```

```
Crunch will now generate the following number of lines: 7290
```

Output: `aaa` → `CCCC`

---

### Using `charset.lst` File

#### Hex-lower charset

```bash
crunch 3 4 -f /usr/share/crunch/charset.lst hex-lower -o wordlist1.txt
```

```
Crunch will now generate the following number of lines: 69632
```

Output: `000` → `ffff` (characters `0-9`, `a-f`)

---

### Pattern-Based Generation (`-t`)

#### 3 lowercase letters + fixed suffix `admin`

```bash
crunch 8 8 -t @@@admin -o wordlist1.txt
```

```
Crunch will now generate the following number of lines: 17576
```

Output: `aaaadmin` → `zzzadmin`

---

#### Same pattern, starting from `bbbadmin` (`-s`)

```bash
crunch 8 8 -t @@@admin -s bbbadmin -o wordlist1.txt
```

```
Crunch will now generate the following number of lines: 16873
```

Output: `bbbadmin` → `zzzadmin` (skipped `aaa`–`bba`)

---

#### Uppercase + Lowercase + Digit + fixed suffix

```bash
crunch 8 8 -t ,@%admin -o wordlist1.txt
```

```
Crunch will now generate the following number of lines: 6760
```

Output: `Aa0admin` → `Zz9admin`

- `,` → one uppercase letter (A-Z)
- `@` → one lowercase letter (a-z)
- `%` → one digit (0-9)

---

#### Same, starting from `Cc5admin`

```bash
crunch 8 8 -t ,@%admin -s Cc5admin -o wordlist1.txt
```

Output: `Cc5admin` → `Zz9admin` (6,215 passwords)

---

#### Appending a symbol at the end

```bash
crunch 9 9 -t ,@%admin^ -o wordlist1.txt
```

```
Crunch will now generate the following number of lines: 223080
```

Output: `Aa0admin!` → `Zz9admin ` (note: space is a valid symbol)

---

#### Inserting a digit in the middle of fixed text

```bash
crunch 10 10 -t ,@%ad%min^ -o wordlist1.txt
```

```
Crunch will now generate the following number of lines: 2230800
```

Output: `Aa0ad0min!` → `Zz9ad9min ` (23 MB file)

---

### Custom character sets with patterns

#### Lowercase + numbers + symbols using `+` placeholder

```bash
crunch 3 3 abc + 123 !@# -t @%^
```

Output: `a1!` → `c3#`

- First position: lowercase from `abc`
- Second position: number from `123`
- Third position: symbol from `!@#`
- `+` skips the uppercase charset slot

---

#### Reversed order

```bash
crunch 3 3 abc + 123 !@# -t ^%@
```

Output: `!1a` → `#3c`

---

#### Default charsets with partial overrides

```bash
crunch 4 4  + + 123 + -t %%@^
```

- `+` in lowercase slot → uses default `a-z`
- `+` in uppercase slot → uses default `A-Z`
- `123` in numbers slot → uses only `1`, `2`, `3`
- `+` in symbols slot → uses default symbols

Output: `11a!` → `33z ` (space at end)

---

### Word Permutations (`-p`)

#### Permute specific words

```bash
crunch 3 5 -p chocolate dairy milk
```

```
Crunch will now generate the following number of lines: 6
chocolatedairymilk
chocolatemilkdairy
dairychocolatemilk
dairymilkchocolate
milkchocolatedairy
milkdairychocolate
```

> With `-p`, min/max lengths are **ignored** (but still required in syntax). Output = `n!` permutations of the given words. No random characters are added.

---

### Literal Characters (`-l`)

#### Treat `@` as literal in pattern

```bash
crunch 7 7 -t p@ss,%^ -l a@aaaaa
```

Output: `p@ssA0!` → `p@ssZ9/`

> The `-l` flag tells crunch which positions are literals. Here, `@` in position 2 is treated as the literal character `@`, not as a wildcard.

---

### Duplicate Limiting (`-d`)

#### Limit consecutive lowercase duplicates to 2

```bash
crunch 5 5 -d 2@ -t @@@%%
```

Output: `aab00` → `zzy99` (no `aaa` or `zzz` — max 2 consecutive same letters)

---

### File Splitting (`-b`)

```bash
crunch 4 5 -b 20mib -o START
```

Generates multiple files: `aaaa-gvfed.txt`, `gvfee-ombqy.txt`, etc., each ≤ 20 MiB.

---

### Compression (`-z`)

```bash
crunch 1 5 -o START -c 6000 -z bzip2
```

Compression speed comparison:

| Format | Time | File Size |
|--------|------|-----------|
| `gzip` | 2.7s | 12K |
| `bzip2` | 3.4s | 3.8K |
| `lzma` | 43s | 1.1K |

> gzip = fastest / least compression. 7z/lzma = slowest / best compression.

---

### Piping to Other Tools

```bash
# Pipe directly to aircrack-ng (no file needed)
crunch 2 4 abcdefghijklmnopqrstuvwxyz | aircrack-ng /root/Mycapfile.cap -e MyESSID -w-

# Pipe to airolib-ng
crunch 10 10 12345 --stdout | airolib-ng testdb -import passwd -
```

## Character Set File Reference

The file `/usr/share/crunch/charset.lst` contains pre-defined character sets:

| Charset Name | Characters |
|-------------|------------|
| `hex-lower` | `0123456789abcdef` |
| `hex-upper` | `0123456789ABCDEF` |
| `numeric` | `0123456789` |
| `numeric-space` | `0123456789 ` |
| `symbols14` | `!@#$%^&*()-_+=` |
| `symbols-all` | `!@#$%^&*()-_+=~\`[]{}\|\\:;"'<>,.?/` |
| `ualpha` | `A-Z` |
| `ualpha-numeric` | `A-Z0-9` |
| `ualpha-numeric-symbol14` | `A-Z0-9!@#$%^&*()-_+=` |
| `lalpha` | `a-z` |
| `lalpha-numeric` | `a-z0-9` |
| `lalpha-numeric-all` | `a-z0-9` + all symbols |
| `mixalpha` | `a-zA-Z` |
| `mixalpha-numeric` | `a-zA-Z0-9` |
| `mixalpha-numeric-all` | `a-zA-Z0-9` + all symbols |

> Each charset also has `-space` variants that include the space character. Swedish (`-sv`) variants are also available with `åäö` / `ÅÄÖ`.

---

## Key Takeaways

- **Targeted wordlists save time** — use OSINT, password policies, and known patterns to constrain generation.
- **File sizes scale exponentially** — lengths 3–4 with default charset = 2 MB; lengths 3–6 with hex = 118 MB; full charsets with length 8+ = gigabytes/terabytes.
- **Pattern mode (`-t`)** is the most powerful feature for creating targeted lists when you know partial password structure.
- **Permutation mode (`-p`)** is ideal when you know specific words the target might use.
- Use `-s` to **resume** generation from a specific point without re-generating everything.
- Pipe output directly to tools like `aircrack-ng` to avoid writing massive files to disk.
