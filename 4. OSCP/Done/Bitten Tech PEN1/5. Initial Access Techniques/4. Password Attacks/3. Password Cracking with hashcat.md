# Password Cracking with Hashcat

> **Type:** Offline password cracker (hash-based)
> **Key Feature:** In-kernel rule engine, GPU acceleration (OpenCL/CUDA)
> **Claims:** World's fastest password cracker

---

## Quick Reference

### Syntax

```
hashcat [options] hash|hashfile [dictionary|mask|directory]
```

### Hash Modes (`-m`)

| Mode ID | Algorithm |
|---------|-----------|
| `0` | MD5 |
| `100` | SHA1 |
| `400` | $P$ (phpass) |
| `500` | $1$ (md5crypt) |
| `1000` | NTLM |
| `1400` | SHA256 |

> Full list: `hashcat --help` — supports MD4, MD5, SHA, NTLM, LM, HMAC, scrypt, WPA, Kerberos, Joomla, Drupal, WordPress, Django, OpenLDAP, and many more.

### Attack Modes (`-a`)

| Mode | Name | Description |
|------|------|-------------|
| `0` | **Straight** | Sequential dictionary/wordlist attack (default) |
| `1` | **Combination** | Combines entries from multiple wordlists |
| `3` | **Brute-force / Mask** | Tries raw character combinations using masks |
| `6` | **Hybrid Wordlist + Mask** | Appends mask patterns to wordlist entries |
| `7` | **Hybrid Mask + Wordlist** | Prepends mask patterns to wordlist entries |
| `9` | **Association** | Associates words with specific hashes |

### Built-in Charsets (for Mask mode)

| Placeholder | Charset |
|-------------|---------|
| `?l` | `a-z` (lowercase) |
| `?u` | `A-Z` (uppercase) |
| `?d` | `0-9` (digits) |
| `?h` | `0-9a-f` (hex lower) |
| `?H` | `0-9A-F` (hex upper) |
| `?s` | Special characters |
| `?a` | `?l?u?d?s` (all printable) |
| `?b` | `0x00 - 0xff` (all bytes) |

## Practical Examples

### Example 1 — Brute-Force Attack (`-a 3`) on MD5 Hash

```bash
# Create a hash file
echo "e10adc3949ba59abbe56e057f20f883e" > hash.txt

# Run brute-force attack
hashcat -m 0 -a 3 /home/kali/wordlists/hash.txt
```

**Output:**
```
e10adc3949ba59abbe56e057f20f883e:123456                   

Session..........: hashcat
Status...........: Cracked
Hash.Mode........: 0 (MD5)
Hash.Target......: e10adc3949ba59abbe56e057f20f883e
Time.Started.....: Wed Sep  9 10:23:14 2026 (0 secs)
Speed.#01........:   138.3 MH/s (12.37ms) @ Accel:447 Loops:1024 Thr:1 Vec:8
Recovered........: 1/1 (100.00%) Digests (total), 1/1 (100.00%) Digests (new)
```

> Cracked the 6-digit password `123456` in ~50 seconds on CPU. With a dedicated GPU, this would take a fraction of a second.

---

### Example 2 — Dictionary / Straight Attack (`-a 0`)

```bash
hashcat -m 0 -a 0 /root/Desktop/hash.txt /root/Desktop/wordlist.txt --force
```

- `--force` suppresses hardware/OpenCL warnings.
- If hashcat says `All hashes found in potfile`, the hash was already cracked previously (stored in `hashcat.potfile`).
- Use `-O` to enable **optimized kernel routines** for maximum speed.

### Example 3 — Custom Rules Attack

**Pre-built rules:** `/usr/share/hashcat/rules/` (e.g., `combinator.rule`, `best64.rule`)

#### Creating a Custom Rule File

```bash
cat > bitten.rule
:
l
u
c
si!
```

| Rule | Effect |
|------|--------|
| `:` | Try the word as-is |
| `l` | Convert to all lowercase |
| `u` | Convert to all uppercase |
| `c` | Capitalize first letter |
| `si!` | Substitute every `i` with `!` |

#### Running with Custom Rules

```bash
hashcat -a 0 -m 0 hash.txt wordlist.txt -r bitten.rule
```

> **Scenario:** Wordlist contains `bellicon`, but the actual password is `bell!con`. The rule `si!` dynamically replaces `i` → `!` during execution, successfully cracking the hash.

## Quick Command Reference

```bash
# Brute-force MD5
hashcat -m 0 -a 3 hash.txt

# Dictionary attack on MD5
hashcat -m 0 -a 0 hash.txt wordlist.txt --force

# Dictionary + rules
hashcat -a 0 -m 0 hash.txt wordlist.txt -r rules/best64.rule

# Combinator attack
hashcat -a 1 -m 0 hash.txt dict1.txt dict2.txt
```

## Key Takeaways

- Hashcat works **only with hashes** — not with live login forms (use Hydra for that).
- **Salted hashes** are harder to crack but still attackable; you must specify the salt.
- **Benchmarking** (`hashcat -b`) tells you hashes/second for your hardware to estimate crack time.
- **GPU acceleration** dramatically increases speed; ensure proper OpenCL/CUDA drivers are installed.
- Rules make dictionary attacks exponentially more powerful by generating mutations on the fly.
