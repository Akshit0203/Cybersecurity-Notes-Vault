
# What is a Database?

A **database** is a collection of interrelated data stored in a digital format that can be easily accessed, managed, and updated.

A **DBMS (Database Management System)** is software used to create, manage, and organize databases. Users never access the database directly — instead, they interact through the DBMS, which handles all operations (adding, deleting, updating, searching) in the backend.

**SQL** is the language we use to communicate with the DBMS.

```
User  →  DBMS  →  Database
```

> The user sends SQL queries to the DBMS, and the DBMS performs the operations on the database.
