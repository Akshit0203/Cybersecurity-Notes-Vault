
# Practice Questions

## Problem

> Create a database for your company named **XYZ**.
>
> **Step 1:** Create a table to store employee info (`id`, `name`, `salary`).
>
> **Step 2:** Add the following data:
> 1. "adam", 25000
> 2. "bob", 30000
> 3. "casey", 40000
>
> **Step 3:** Select & view all table data.

---

## Solution

```sql
CREATE DATABASE xyz;
USE xyz;

CREATE TABLE employee_info (
    id INT PRIMARY KEY,
    name VARCHAR(50),
    salary INT NOT NULL
);

INSERT INTO employee_info
(id, name, salary)
VALUES
(1, "adam", 25000),
(2, "bob", 30000),
(3, "casey", 40000);

SELECT * FROM employee_info;
```

## Design Decisions

| Column   | Type              | Reasoning                                                       |
| -------- | ----------------- | --------------------------------------------------------------- |
| `id`     | `INT PRIMARY KEY` | Unique identifier for each employee                             |
| `name`   | `VARCHAR(50)`     | Variable-length string for names                                |
| `salary` | `INT NOT NULL`    | Whole number; could also use `FLOAT` for decimals like 25000.25 |

---

## Improvement: Auto-Increment

If you want MySQL to generate IDs automatically:

```sql
CREATE TABLE employee_info (
    id INT PRIMARY KEY AUTO_INCREMENT,
    name VARCHAR(50),
    salary INT NOT NULL
);
```

With `AUTO_INCREMENT`, you don't need to specify `id` in `INSERT` — MySQL assigns it automatically.
