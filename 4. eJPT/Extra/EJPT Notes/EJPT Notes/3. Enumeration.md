#### SMB Enumeration:
SMB - Server Message Block
It is a Network file sharing protocol used to share files and peripherals(Printer) over LAN.
Its like a storage space, where all users can edit and file get synced. Whereas in FTP the users has to download the file first, then edit, then they re upload it.

SMB uses port 445.
It runs on top of NetBIOS using port 139.

Samba is the linux version of SMB, allows window system to access linux shares.

`nmap -p 445 --script=smb-enumshares,smb-enum-users <ip>` --> this gives us all shares and who have access , also if there is anonymous access.

We can use auxiliary modules to enumerate SMB version, shares, users and perform a brute-force attack.

`msf> setg RHOSTS <ip>` --> here we are setting a global variable. set RHOST as given ip for all modules. We don't have to memorize the target ip

`msf> search type:auxiliary name:smb` --> search for smb aux modules.

`scanner/smb/smb_version` --> this module is used to get the smb version.
set the rhost and run. Sometime gives us wrong OS. Take the result given in parenthesis.
Now we got samba version, we search for samba exploit for the target version

`scanner/smb/smb_enumusers` --> used to enumerate users. just set rhost and run. Take note of the users. It will be useful in later.

`msf> info` --> after selecting a module , use this info cmd to get info about the module.

`scanner/smb/smb_enumshares` --> used to enumerate the smb shares. just set rhost 

`msf(scanner/smb/smb_enumshares)> set ShowFiles true`
run the module . No need of user and pass as of now.

Samba share is nothing but a shared folder or a shared printer that is accessible to the users.

`scanner/smb/smb_login` --> used to bruteforce the user and pass of SMB.

Here we are trying to bruteforce the password only and we give the username.

`msf> set SMBUser admin` --> set username

`msf> set PASS_FILE /usr/share/metasploit-framework/data/wordlists/unix-passwords.txt` --> set password file

Run the module to get the password.
After getting username and password use the smbclient to login.

`smbclient -L \\\\192.91.23.22\\ -U admin` --> this will connect to the smb server . It'll ask for password. Here -U is the username and we are passing the target ip.

As the above command list all the shares. Lets say there is a share named 'public'. Then we can access that share using the below command.

`smbclient \\\\192.23.34.22\\public -U admin` --> now we get to interact with the smb share. we can use cd , ls commands for navigation.

`smb> get <filename>` --> download files from smb to our local machine.

`nmap -p 139,445 --script=smb-os-discovery <ip>` --> this script will give you the workspace name, OS.

`nmblookup -A <ip>` --> This will give you the Netbios name of Samba

`smbclient -L \\\\192.91.23.22\\ -U anonymous` --> do a anonymous login. This will list all the smb shares, if anonymous login exist.

`smbclient //<ip>/share -N` --> check if a share has anonymous login.

`rpcclient -U "" <ip>` --> used to give shell access where we can enum users, shares of samba etc.
