### 📟 Manual SMTP Interaction
- [ ] Connect to SMTP service:  
  - [ ] `nc <ip> <port>`  
  - [ ] or `telnet <ip> <port>`

- [ ] Run: `EHLO abc.com`
- [ ] Check user manually: `VRFY <username>`

### ✉️ Send Fake Email (Manual)
1. Connect to SMTP with `nc` or `telnet`
2. Run: `EHLO abc.com`
3. `MAIL FROM:<sender@gmail.com>`
4. `RCPT TO:<receiver@gmail.com>`
5. `DATA`
6. Enter:
    ```
    Subject: Test Mail
    From: sender@mail.com
    To: receiver@mail.com

    This is body.
    ```
7. Press Enter
8. Enter `.` on a new line
9. Press Enter again to send

## 💡 Important Tips

### 🔐 SMB Share Bruteforce
- [ ] Use a bash script to bruteforce hidden SMB shares:
    ```bash
    while read share; do
      echo "Trying: $share"
      smbclient //192.168.7.23/$share -N -c 'ls' 2>&1 | grep -v NT_STATUS
    done < shares.txt
    ```
- [ ] Try checking for shares with the same name as known usernames.

---

### 📡 FTP Bruteforce (Hydra)
- [ ] Use Hydra for efficient FTP bruteforcing:
    ```bash
    hydra -L users.txt -P pass.txt ftp://<ip>
    ```
    > You can also specify port like `ftp://<ip>:21` if needed.
