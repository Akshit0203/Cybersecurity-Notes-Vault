# How to Connect to the OffSec Proving Ground (PG) VPN

---

## 1. Download the VPN File

Go to the OfsSec Proving Ground website and download the `.ovpn` VPN configuration file.

![](attachments/Pasted%20image%2020260712210849.png)

---

## 2. Connect via OpenVPN

Open a terminal on your Kali machine and run:

```bash
sudo openvpn <filename>.ovpn
```

## 3. Verify the VPN Connection

Open a **new terminal tab** and run:

```bash
ip a
```

Look for the `tun0` interface in the output — if it appears, the VPN is connected.

![](attachments/Pasted%20image%2020260712213936.png)

![](attachments/Pasted%20image%2020260712214029.png)

After the machine starts, **copy the machine's IP address** — you'll need it for your attacks.

![](attachments/Pasted%20image%2020260712214210.png)

## 6. Confirm Connectivity to the Lab Machine

Ping the machine IP from your Kali terminal to verify reachability:

```bash
ping <machine-ip>
```
