## Passwordless `sudo su`

To configure `sudo su` so it **never asks for a password**, edit the sudoers file:

```bash
sudo nano /etc/sudoers
```

![](attachments/Pasted%20image%2020260711170906.png)

Change this line:

```
%sudo ALL=(ALL:ALL) ALL
```

To:

```
%sudo ALL=(ALL) NOPASSWD:ALL
```

Save and exit. Now `sudo su` will no longer prompt for a password:

```
┌──(kali㉿kali)-[~]
└─$ sudo su                      
┌──(root㉿kali)-[/home/kali]
└─# 
```

Verify with `sudo -l`:

```
┌──(kali㉿kali)-[~]
└─$ sudo -l
Matching Defaults entries for kali on kali:
    secure_path=/usr/sbin\:/usr/bin\:/sbin\:/bin

Runas and Command-specific defaults for kali:
    Defaults!/usr/sbin/visudo env_keep+="SUDO_EDITOR EDITOR VISUAL"

User kali may run the following commands on kali:
    (ALL) NOPASSWD: ALL
```

## Changing File Ownership (`chown`)

When you create a file, your user is the default owner:

```bash
touch abc.txt
```

```
└─$ ls -al abc.txt 
-rw-rw-r-- 1 kali kali 0 Jul 11 07:47 abc.txt
```

Use `chown` to change the **owner** and/or **group** of a file:

```bash
sudo chown root:root abc.txt
```

- First argument before `:` → **user**
- Second argument after `:` → **group**

```
└─$ ls -al abc.txt 
-rw-rw-r-- 1 root root 0 Jul 11 07:47 abc.txt
```

The owner is now `root`.

## Understanding the Permission String

The first character indicates the **file type**, not a permission. The remaining nine characters represent **read (r)**, **write (w)**, and **execute (x)** for owner, group, and others:

```
- rw- rw- r--
│ │   │   │
│ │   │   └── Others' permissions
│ │   └────── Group permissions
│ └────────── Owner permissions
└──────────── File type
```

### File Type Characters

| Character | Meaning                            |
| --------- | ---------------------------------- |
| `-`       | Regular file                       |
| `d`       | Directory                          |
| `l`       | Symbolic link (soft link)          |
| `c`       | Character device (e.g. `/dev/tty`) |
| `b`       | Block device (e.g. `/dev/sda`)     |
| `p`       | Named pipe (FIFO)                  |
| `s`       | Unix domain socket                 |

### Examples of Each File Type

Regular file:

```
-rw-r--r--
```

Directory:

```
drwxr-xr-x
```

Symbolic link:

```
lrwxrwxrwx
```

Character device:

```
crw-rw----
```

Block device:

```
brw-rw----
```

Socket:

```
srwxrwxrwx
```

Named pipe:

```
prw-r--r--
```

---

### Mounted Filesystems

A mounted filesystem **does not have its own file type character**. Mounting is a relationship between a filesystem (disk, USB, ISO, etc.) and a **mount point**, which is simply a **directory**.

```bash
sudo mount /dev/sdb1 /mnt/usb
```

After mounting, the mount point is still a directory:

```bash
ls -ld /mnt/usb
```

```
drwxr-xr-x
```

The first character is `d` because the mount point is a directory.

## Changing Permissions with `chmod`

### Syntax

```
chmod 000 abc.txt
│      │   │
│      │   └── File name
│      └────── Permission mode (three octal digits)
└───────────── Change mode (permissions)
```

> **Only the file owner or root can change a file's permissions.**

### Octal Permission Values

A permission mode has **three digits**: `Owner`, `Group`, `Others`. Each digit is the **sum** of:

| Permission   | Value |
| ------------ | ----- |
| Read (`r`)   | 4     |
| Write (`w`)  | 2     |
| Execute (`x`)| 1     |

### What `0` Means

`0` = no read, no write, no execute.

```
Owner   Group   Others
  0       0        0     → No permissions for anyone
```

### Example — Remove All Permissions

```bash
chmod 000 abc.txt
```

```
└─$ ls -al abc.txt        
---------- 1 root root 0 Jul 11 07:47 abc.txt
```

---

### All 7 Permission Levels (Group Digit Examples)

Each example below sets **only the group digit** (middle position) to demonstrate all possible values:

**`010` — Execute only:**

```
┌──(kali㉿kali)-[~]
└─$ sudo chmod 010 abc.txt
                                                                                                
┌──(kali㉿kali)-[~]
└─$ ls -al abc.txt        
------x--- 1 root root 0 Jul 11 07:47 abc.txt
```

**`020` — Write only:**

```
┌──(kali㉿kali)-[~]
└─$ sudo chmod 020 abc.txt
                                                                                                
┌──(kali㉿kali)-[~]
└─$ ls -al abc.txt        
-----w---- 1 root root 0 Jul 11 07:47 abc.txt
```

**`030` — Write + Execute:**

```
┌──(kali㉿kali)-[~]
└─$ sudo chmod 030 abc.txt
                                                                                                
┌──(kali㉿kali)-[~]
└─$ ls -al abc.txt        
-----wx--- 1 root root 0 Jul 11 07:47 abc.txt
```

**`040` — Read only:**

```
┌──(kali㉿kali)-[~]
└─$ sudo chmod 040 abc.txt
                                                                                                
┌──(kali㉿kali)-[~]
└─$ ls -al abc.txt        
----r----- 1 root root 0 Jul 11 07:47 abc.txt
```

**`050` — Read + Execute:**

```
┌──(kali㉿kali)-[~]
└─$ sudo chmod 050 abc.txt
                                                                                                
┌──(kali㉿kali)-[~]
└─$ ls -al abc.txt        
----r-x--- 1 root root 0 Jul 11 07:47 abc.txt
```

**`060` — Read + Write:**

```
┌──(kali㉿kali)-[~]
└─$ sudo chmod 060 abc.txt
                                                                                                
┌──(kali㉿kali)-[~]
└─$ ls -al abc.txt        
----rw---- 1 root root 0 Jul 11 07:47 abc.txt
```

**`070` — Read + Write + Execute (full):**

```
┌──(kali㉿kali)-[~]
└─$ sudo chmod 070 abc.txt
                                                                                                
┌──(kali㉿kali)-[~]
└─$ ls -al abc.txt        
----rwx--- 1 root root 0 Jul 11 07:47 abc.txt
```

> **Summary:** There are **7 possible permission combinations** (1–7) per digit. `0` means no permissions.

---

### Applying Permissions to Different Positions

**Others only (`007`)** — full permissions for others, none for owner/group:

```
└─$ sudo chmod 007 abc.txt
                                                                                                
┌──(kali㉿kali)-[~]
└─$ ls -al abc.txt        
-------rwx 1 root root 0 Jul 11 07:47 abc.txt
```

**Owner + Others (`707`)** — full permissions for owner and others, none for group:

```
└─$ sudo chmod 707 abc.txt
                                                                                                
┌──(kali㉿kali)-[~]
└─$ ls -al abc.txt        
-rwx---rwx 1 root root 0 Jul 11 07:47 abc.txt
```
