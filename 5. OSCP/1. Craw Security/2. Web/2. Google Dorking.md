# Google Dorking

**Google Dorking** (also called **Google Hacking**) is the practice of using **advanced Google search operators** to find publicly accessible information that isn't easily found through normal searches.

> **Key point:** Google Dorking searches content Google has **already indexed**. It does **not** hack into systems by itself. The search itself is **not inherently illegal**.

---

## Common Google Search Operators

| Operator | Purpose | Example |
| --- | --- | --- |
| `site:` | Search only one website | `site:example.com` |
| `filetype:` | Search specific file types | `filetype:pdf networking` |
| `intitle:` | Search page titles | `intitle:"index of"` |
| `inurl:` | Search text in URLs | `inurl:login` |
| `intext:` | Search page content | `intext:"cyber security"` |
| `cache:` | View Google's cached copy | `cache:example.com` |
| `related:` | Similar websites | `related:example.com` |
| `OR` | Match either term | `Linux OR Windows` |
| `-` | Exclude terms | `python -snake` |
| `"` | Exact phrase | `"Security Engineering"` |
| `*` | Wildcard | `"best * books"` |

---

## Examples (Safe and Educational)

### Search only one website

```
site:openai.com ChatGPT
```

Searches for pages about ChatGPT only on `openai.com`.

---

### Search for PDFs

```
filetype:pdf machine learning
```

Returns PDF documents about machine learning.

---

### Search by title

```
intitle:"cyber security"
```

Only pages with "cyber security" in the title.

---

### Search by URL

```
inurl:blog python
```

Finds URLs containing "blog".

---

### Exact phrase

```
"ethical hacking"
```

Finds pages containing exactly that phrase.

---

### Combine operators

```
site:edu filetype:pdf cryptography
```

Finds cryptography PDFs on educational websites.

---

## Why Is It Useful?

Google Dorking is widely used for **OSINT (Open Source Intelligence)**:

- Finding public research papers and documentation
- Finding manuals and presentations
- Finding source code repositories
- Discovering publicly indexed files
- Finding academic content

### In Cybersecurity (Authorized Testing)

During an **authorized** penetration test, Google Dorking can help identify publicly exposed information:

- Public documentation & employee directories
- Backup files unintentionally indexed
- Configuration files & log files
- Version information

This helps organizations understand what is publicly visible and reduce unnecessary exposure.

> **Remember:** Google Dorking vulnerabilities are most commonly found on **educational (`.edu`) and government (`.gov`) websites**.

### Example GHDB Query Breakdown

```
site:.edu filetype:xls "root" database
```

| Component | Meaning |
| --- | --- |
| `site:.edu` | Search only websites in the `.edu` domain (educational institutions) |
| `filetype:xls` | Return only Microsoft Excel (`.xls`) files |
| `"root"` | Search for the exact word **root** (quotes = exact match) |
| `database` | Search for pages/files containing the word **database** |

Google reads this as:

> "Find Excel spreadsheets on `.edu` websites that contain the exact word `root` and also contain the word `database`."

## Practical Example: Finding Exposed WordPress Configs via CVE

### Step 1 — Research a CVE

Search for a recent WordPress CVE, e.g., "2025 wp cve":

![](attachments/Pasted%20image%2020260712154843.png)

![](attachments/Pasted%20image%2020260712155551.png)

![](attachments/Pasted%20image%2020260712155612.png)

Results reveal that `wp-config.php` files are a known vulnerability target. Now craft a specific dork:

### Step 2 — Craft a Google Dork

![](attachments/Pasted%20image%2020260712161345.png)

```
intitle:"index of" "wp-config.php.old" | "wp-config.php.backup"
```

This searches for directory listings containing old/backup WordPress config files.

![](attachments/Pasted%20image%2020260712161820.png)

![](attachments/Pasted%20image%2020260712161837.png)

### Step 3 — Find and Download the Exposed File

![](attachments/Pasted%20image%2020260712162353.png)

Found a `wp-config.php.old` file on a website — download it:

![](attachments/Pasted%20image%2020260712162502.png)

### Step 4 — Read the Config

Change the extension to `.txt` so it becomes readable:

![](attachments/Pasted%20image%2020260712162545.png)

Open the file:

![](attachments/Pasted%20image%2020260712162628.png)

The file reveals **database username and password**. If MySQL (port 3306) is exposed, an attacker could log in directly.

It also contains the `AUTH_KEY` and other secret salts:

![](attachments/Pasted%20image%2020260712162712.png)

### Why Does This Happen?

- WordPress **themes have their own versions and vulnerabilities** — people install them but don't update them, leaving known CVEs exploitable
- People create **backups of config files inside the same web-accessible folder** (e.g., `wp-config.php.old`) without setting proper permissions — anyone can access and extract credentials from them

## Google Dorking in Social Engineering

Google Dorking can be combined with **social engineering** techniques:

- **OTP Bombing:** Find login pages via dorking → trigger mass password resets → flood the target with so many OTP/reset emails that they start ignoring all messages, including legitimate security alerts
- The target dismisses everything as spam, so a real password change or malicious action goes unnoticed
- These techniques are used to **bypass user awareness** — the victim thinks the flood of messages is normal and ignores the one that actually matters
