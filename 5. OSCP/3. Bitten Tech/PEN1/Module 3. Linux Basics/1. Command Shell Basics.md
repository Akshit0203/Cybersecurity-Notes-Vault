# Command Shell Basics


---

## What is a Command Shell?

- A **text-based application** for viewing, handling, and manipulating files on your computer
- Other names: cmd, CLI, prompt, console, or terminal
- **User-to-kernel interface** — interface to use operating system services
- Reads from input devices (keyboards) or from files
- The shell starts when the user logs in or opens the terminal

## Windows Command Line

- Windows has **two command shells**: the **Command Shell** and **PowerShell**
- Officially called **Windows Command Processor** — also referred to as the command shell, cmd prompt, or `cmd.exe`
- Sometimes (incorrectly) called the "DOS prompt"
- **PowerShell** was designed to extend the capabilities of the Command Shell by running PowerShell commands called **cmdlets**

| Shell            | Runs Windows Commands | Runs PowerShell Cmdlets |
| ---------------- | --------------------- | ----------------------- |
| **Command Shell** | ✅                    | ❌                      |
| **PowerShell**    | ✅                    | ✅                      |

## Linux Command Line

- Kali Linux uses the **Bourne Again Shell (Bash)**, created for the GNU project as a successor to the Bourne shell
- Bash can also read and execute commands from a file, called a **shell script**
- Bash command syntax includes ideas drawn from the **Korn shell (ksh)** and the **C shell (csh)**, such as command-line editing and command history
