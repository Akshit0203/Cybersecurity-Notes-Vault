# Linux User Administration


---

## Ownership of Files

| Owner Type | Description                                                              |
| ---------- | ------------------------------------------------------------------------ |
| **User**   | The owner of the file — the person who created it                        |
| **Group**  | A user-group containing multiple users; all share the same access permissions |
| **Others** | Everybody else — neither created the file nor belongs to an owning group |

---

## Permissions of Files

| Permission    | On Files                                  | On Directories                                  |
| ------------- | ----------------------------------------- | ----------------------------------------------- |
| **Read (r)**  | Authority to open and read a file         | Ability to list its contents                     |
| **Write (w)** | Authority to modify the contents of a file| Authority to add, remove, and rename files stored|
| **Execute (x)**| Required to run a program                | Required to enter (`cd` into) the directory      |

## Changing File Permissions

### Absolute (Numeric) Mode

Permissions are represented as numbers that you **add together**:

| Value | Permission     |
| ----- | -------------- |
| `0`   | No permission  |
| `1`   | Execute        |
| `2`   | Write          |
| `4`   | Read           |

> Example: `chmod 755 file` → Owner: rwx (4+2+1), Group: r-x (4+1), Others: r-x (4+1)

### Symbolic Mode

Uses operators and user-type identifiers:

| Operator | Meaning                       |
| -------- | ----------------------------- |
| `+`      | Add permission                |
| `-`      | Remove permission             |
| `=`      | Set and override permissions  |

| Symbol | User Type   |
| ------ | ----------- |
| `u`    | User/Owner  |
| `g`    | Group       |
| `o`    | Other       |
| `a`    | All         |

> Example: `chmod u+x file` → Add execute permission for the owner
