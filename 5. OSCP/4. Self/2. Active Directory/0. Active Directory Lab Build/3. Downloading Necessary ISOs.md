## Microsoft Evaluation Center

Search Google for **Microsoft Evaluation Center** and click the first result.

![](./attachments/image.png)

[Microsoft Evaluation Center](https://www.microsoft.com/en-in/evalcenter)

The Evaluation Center lets you download trial versions of Microsoft products — Windows 10, Windows Server, SQL Server, etc.

### Trial License Notes

> [!NOTE]
> - Trials are **90 days** for Windows 10 and similar for Windows Server.
> - For a **local lab**, you don't need to worry about expiration — it only matters if you try to use certain features or put it into production.
> - **Auto-shutdown caveat**: Unlicensed machines will **shut down on their own every 30–60 minutes** if not actively used. Just reboot them. Not a big deal, but save your work.

## Filling Out the Trial Form

![](./attachments/image-10.png)

You need to fill out a trial registration form to proceed. You do **not** need to use real information — any placeholder values work (e.g., `test` / `test@test.com` / `Test Company`). Walk through the form and hit **Submit** or **Download Now**.

## Selecting the Edition

When prompted, choose:
- **64-bit edition**
- **ISO** format
- Region: **United States** (or your preference)

> [!NOTE]
> Windows Server 2022 ISO is approximately **4.7 GB**.
