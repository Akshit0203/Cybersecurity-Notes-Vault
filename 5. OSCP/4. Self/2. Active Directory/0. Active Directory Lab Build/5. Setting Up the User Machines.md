> [!WARNING]
> **Turn off Wi-Fi / disconnect the network adapter before installing Windows**, otherwise the installer will force you to sign in with a Microsoft account.

> [!TIP]
> Use [Microsoft Activation Scripts (MAS)](https://massgrave.dev/) if you need to activate the evaluation copies.

We are building **two user machines** (Windows 10 and Windows 11) using nearly identical steps.
