### Website Recon or Footprinting:

### **Passive:**
- IP address
- Directories hidden from search engines
- Phone numbers
- Emails
- Physical address
- web technologies used

Step 1: Identify the ip address of the website
`host hackersploit.com`
Gives us the IP of the website. If it has more than one IP , then it means it is behind firewall/proxy. It also gives, mail server, IPv6 and IPv6 address

Step2 : Check robots.txt
`hackersploit.com/robots.txt`

Step3: Check sitemap.xml
`hackersploit.com/sitemap.xml`
Sitemap will tell the search engines what are the urls to be shown.

Step4: use builtwith and wappalyzer extension to identify the web technologies. Also you can use whatweb tool to find it.
`whatweb hackersploit.org`

Step5: HTTrack is used to download the website to local directory. Means we can easily get the source code to our machine of any website

### Active Information Gathering:
#### DNS Zone Transfer:

DNS interrogation is the process of enumerating DNS records for a specific domain.
In some cases the admin may copy or transfer the zone files from one DNS server to another. This is called as DNS zone transfers.

If it is misconfigured, it allows attackers to copy the zone file from those DNS servers.
In some cases, internal network addresses of the org can also be found in these servers.

/etc/hosts file will have local dns records.It also has internal network info.

`dnsenum zonetransfer.me`
This will enumerate the website and gives the dns records.
Also this will perform zone transfer on the particular server.

In real time we have to identify the name-servers of the domain. then we have to perform zone transfer for each name-server.

In result of zonetransfer we can sometime get new subdomains.

Note: These dns data we are getting through zone transfer are private dns server data and not publicly accessible. Due to misconfiguration, we are accessing it.

##### Dig:
`dig axfr @nsztm1.digi.ninja zonetransfer.me`
Here  "nsztm1.digi.ninja" is the nameserver.
zonetransfer.me is the domain name.
`axfr` --> Authoritative Zone Transfer
This command is used to perform zone transfer on the particular name server.

##### Fierce:
`fierce -dns zonetransfer.me`
It performs dns recons, including zonetransfer and enumeration.

### Nmap:

**Host Discovery:**
`sudo nmap -sn 192.168.2.0/24` --> this is used to identify active hosts within that subnet

`sudo netdiscover -i wlp3s0 -r 192.168.29.0/24` 
Netdiscover is another tool used to perform host discovery.
Here -i refers to the interface
-r refers to the ip range.

**Port Scanning:**
`nmap 192.168.2.29`
Nmap default scan will scan the top 1000 ports. It does SYN scan. Displays the services running on those ports.

**Note:** Windows usually blocks ICMP packets during nmap scan. So use -Pn flag means no ping.

`nmap -p- <ip>` --> this will scan all the ports.

`nmap -p 80,443 <ip>` --> this will scan only port 80 and 443

If state is filtered means, then there must be a firewall or maybe closed.

`nmap -F <ip>` --> this will scan only top 100 ports. (not 1-100 but common 100).

`nmap -sU <ip>` --> this will perform UDP scan.
combine both tcp and udp flags to get better results.

-v --> produces more detailed output

-sV --> perform service version detection

-O --> detect the OS that the ip is using (not that accurate).

`nmap -sC <ip>` --> this will run script scan. 

-A --> will do aggressive scan

-T4 --> this will do more aggressive scan and faster scan.

-oX <filename.xml> --> output the results in xml format

## Important Tips:

1. For search engine what to avoid and not , check the robots.txt
2. To check whats running on website and its version, try nmap version scan.
3. If they told to look for directories , then do directory traversal with gobuster.
4. If they said to look for backup files(in web), then check .bak files. You can be more precise like check the web tech and based on that look for specific bak.
5. When asked to mirror a website , try HTTrack to download the source. 
6. In wordpress site, check xmlrpc file.
7. For searching for backup files, we can use gobuster with -x flag to search for .bak files.
	`gobuster dir -u <url> -w <wordlist> -x .bak`
		this will search for .bak files in the url. Eg : wp-config.bak
8. ALways do recursive scanning during directory traversal. Most of times, it will be in subfolder. use `dirb <url>` . This will do recursive scanning too.
9. If you got a bunch of folders. Look at every folder. you might get it
