#### Host Discovery Techniques:

**Ping Sweep** : Here we send ICMP echo requests to a range of ips' to find the active host in any network. Windows block ICMP, so we go for other techniques. 

**ARP Scanning** : Here we use ARP requests to identify hosts on local network.

**TCP SYN Ping** : This send tcp SYN packets to identify active host. If host is alive it will send us SYN-ACK. More stealthier than ICMP (TCP half scan). May bypass firewalls.

**UDP Ping** : Sends udp packets to identify host. If both above techniques failed we can try this.

**TCP ACK Ping** : Send TCP ACK packets and if it responds with TCP RST(reset), then that host is alive.

**TCP SYN-ACK Ping** : If it responds with TCP RST(reset), then that host is alive.

**TCP SYN Scan:**
During syn scan, nmap will send a syn packet to the port 80 of target and if we receive SYN-ACk then it says the host is alive. If the port is closed then it will send us RST packet.
In some cases the firewall may block RST packet, which might affect the accuracy.

`nmap -sn -PS 10.2.3.129` --> This is used to do SYN scan. Here the -sn flag is to not for ping scan, it says that don't do port scan. 

`nmap -sn -PS22 10.2.3.22` --> -PS22 means send the packet to port 22.

`nmap -sn -PS1-1000 10.2.3.21` --> This will scan 1-1000 ports.

`nmap -sn -PS80,443 10.2.2.21` --> this will scan specific ports.

**TCP ACK Scan**:
During ack scan, nmap will send a ack packet to port 80 of target. If the target is active, it will send us a RST packet.

`nmap -sn -PA 10.2.3.23` --> this will do ACK ping scan. Some environments may configured to block ACK packets or RST packets. So try other techniques also.

> Other flag options are as same as TCP SYN scan.

`nmap -sn -PE 10.2.3.23` --> this will do only ICMP ping scan.

##### Firewall Detection and Evasion:
`nmap -sA -p445,3389 <ip>` --> if tells unfiltered then no firewall. If says filtered then there is a firewall. Sends ACK packets.

For Firewall evasion, we can do **Fragmentation**:
Most of the firewalls will analyze only the first fragment. So If we send a packet into multiple fragments, we may bypass firewall.
For eg: The firewall will block all SYN packets to port 22. If we fragment the packet to 3. In first fragment we only have tcp header, in next fragment we'll have SYN flag set. As the firewall is checking only the first fragment, it thinks its a valid packet and forward all fragments of the packet to the port. Later it will be re assembled at the port.

`nmap -Pn -sS -sV -p80,443 -f <ip>` -f flag is for fragmentation

`nmap -p80,443 -Pn -sS -sV -f --mtu 32 <ip>` --> we can specify the MTU also.
MTU - Maximum Transmitted Unit

**Decoy Scanning**:
`nmap -Pn -sV -p- -f --data-length 200 -D 10.4.23.1` --> -D is for decoy ips. 
So nmap will send the source as the decoy ip. We can also specify multiple decoys. By this way we can bypass firewall. As we set the decoy as gateway ip, the firewall thinks the router is making request so it'll allow.

`nmap -Pn -sV -p- -f --data-length 200 -g 53 -D 10.4.23.1` --> -g is for setting the source port. Sometimes firewall allow only dns packets. So we can set port as 53 to make it look like a dns request. By this way we can bypass firewall.
