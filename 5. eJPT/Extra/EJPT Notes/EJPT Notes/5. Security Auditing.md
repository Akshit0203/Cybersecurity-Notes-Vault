- Security auditing is the process of evaluating and measuring the security controls in the organization .
- Here we check the applications, network and also check whether everything is compliant with the orgs standard.


**Importance**:
1. It helps in identifying the vulnerabilities and weakness within the organization. Also ensures that the company is up-to-date in terms of security vulnerabilties.
2. It verify and ensures that organization comply with the regulatory standards such as GDPR, PCI DSS etc. Maintain trust with customers and stakeholders.
3. It enhances risk management by prioritising the risk based on the impact and tells us what to focus first.
4. Reviews the existing security policy and make sure it is efficient. Helpful in finding loopholes.
5. Supports the Business by having strong security posture and prevent data breaches.
6. It is a continuing process, so frequently security audit will happen , to make sure it is protecting against new threats too.

#### Security Auditing Lifecycle:

![[2025-06-12_17-30.png]]

**1. Planning and Preparation**:
- Define goals and objectives of audit
- Gather network diagram, previous audit reports and all other relevant information.
- Setup a audit team and timelines.

**2. Information Gathering**:
- Review existing policies.
- Interview the key personnel and get to know about the security controls in place.
- Gather info about the system configs and network information.

**3. Risk Assessment**:
- List all the critical assets and possible threats to it.
- Assess the existing vulnerabilities.
- Categorize the risks based on the impact and frequency.

**4. Audit Execution**:
- Perform Penetration Tests and review all configs.
- Check the Compliance in place.
- Check the effectiveness of existing controls.

**5. Analysis and Evaluation**:
- Here we will analyze the results and check its weakness.
- Compare it against the compliance.
- Prioritise the findings based on severity and frequency.

**6. Reporting**:
- Document the Findings.
- Provide Mitigation and recommendations.
- Share the report with stakeholders.

**7. Remediation**:
- Here we have to implement the mitigation techniques.
- Conduct Follow-up audits.
- Continuously monitor for security threats.

#### Phase 2:  Security Auditing with Lynis
![[2025-06-13_14-56.png]]

`./lynis audit system` -->this cmd will audit the entire system and give the results.
Will check whether firewall is enabled , vulnerability scanner is present or not etc.
We can use the results to fix the issues.

`./lynis audit system --tests "HRDN-7230"` --> test for malware authentication.
Likewise we can check whether, the specific control mechanism is implemented or not.
https://cisofy.com/lynis/controls/ -->here you can get the control ID for all controls you're looking for to test.

System Hardening means reducing the attacks and making the defence stronger in a system.
Lynis Hardening index will tell us how hardened the system is.

`./lynis audit system --auditor "Arul"` 

The output will be automatically stored in a file. You can check it in the results.
`--quiet` --> this flag is used to stop showing results to the screen.

We can perform security auditing using this tool.
