
# Database Related Queries

## `CREATE DATABASE`

```sql
CREATE DATABASE db_name;
CREATE DATABASE IF NOT EXISTS db_name;   -- Best practice
```

`IF NOT EXISTS` prevents errors when the database already exists — you get a **warning** instead of an **error**.

### Example

```sql
CREATE DATABASE college;            -- ✅ Success
CREATE DATABASE college;            -- ❌ Error: database already exists
CREATE DATABASE IF NOT EXISTS college;  -- ⚠️ Warning only (no error)
```

## `DROP DATABASE`

```sql
DROP DATABASE db_name;
DROP DATABASE IF EXISTS db_name;     -- Best practice
```

`IF EXISTS` prevents errors when trying to drop a database that doesn't exist.

### Example

```sql
DROP DATABASE company;              -- ❌ Error: database doesn't exist
DROP DATABASE IF EXISTS company;    -- ⚠️ Warning only (no error)
```

## `SHOW DATABASES`

Lists all databases on the server.

```sql
SHOW DATABASES;
```

![](../Apna%20College%20Youtube/attachments/Pasted%20image%2020260723212734.png)

> The bottom four databases (`information_schema`, `mysql`, `performance_schema`, `sys`) are MySQL's internal databases.

---

## `SHOW TABLES`

Lists all tables in the currently selected database.

```sql
USE college;
SHOW TABLES;
```

## Summary

| Command | Purpose |
| --- | --- |
| `CREATE DATABASE db_name;` | Create a database |
| `CREATE DATABASE IF NOT EXISTS db_name;` | Create only if it doesn't exist |
| `DROP DATABASE db_name;` | Delete a database |
| `DROP DATABASE IF EXISTS db_name;` | Delete only if it exists |
| `SHOW DATABASES;` | List all databases |
| `USE db_name;` | Switch to a database |
| `SHOW TABLES;` | List all tables in the current database |
