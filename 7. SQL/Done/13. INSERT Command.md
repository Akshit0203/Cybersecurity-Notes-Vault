
# INSERT Command

`INSERT INTO` adds new rows of data into a table.

## Syntax

### Multiple Rows (with column names)

```sql
INSERT INTO table_name
(column1, column2)
VALUES
(col1_val1, col2_val1),
(col1_val2, col2_val2);
```

### Single Row (shorthand — without column names)

```sql
INSERT INTO table_name VALUES (value1, value2);
```

> The shorthand works only when you provide values for **all columns in the same order** they were defined.

---

## Example

### Table Setup

The `student` table has two columns: `rollno` (INT, PRIMARY KEY) and `name` (VARCHAR).

### Inserting Multiple Rows

```sql
INSERT INTO student
(rollno, name)
VALUES
(101, "karan"),
(102, "arjun"),
(103, "ram");
```

## Key Rules

1. **Order matters** — values must match the order of column names defined in the `INSERT` statement (or the table definition for shorthand).
2. **Primary Key must be unique** — inserting a duplicate primary key causes an error.
3. **Multi-row syntax** is preferred for inserting multiple records; **shorthand** is convenient for single inserts in simple tables.
