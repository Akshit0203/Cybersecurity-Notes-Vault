
# Types of Databases

Databases have two main types:

| Type | Data Storage | Language | Examples |
| --- | --- | --- | --- |
| **Relational (RDBMS)** | Tables (rows & columns) | SQL | MySQL, PostgreSQL, Oracle, SQL Server |
| **Non-Relational (NoSQL)** | Documents, key-value, graphs, etc. | Not SQL | MongoDB, Redis, Cassandra |

![](../Apna%20College%20Youtube/attachments/Pasted%20image%2020260723004405.png)

- **Relational databases** store data in the form of **tables** (like a school register with roll numbers and names).
- **Non-relational databases** store data without tables — they are also called **NoSQL databases** because they do not understand SQL.
- Relational databases are also called **RDBMS** (Relational Database Management Systems).

> In this course, we focus on **relational databases** (specifically **MySQL**) because SQL only works with table-based data.

## What is SQL?

**SQL (Structured Query Language)** is a programming language used to interact with relational databases.

SQL is used to perform **CRUD operations** on databases:

| Operation  | Meaning                               | Example                       |
| ---------- | ------------------------------------- | ----------------------------- |
| **C**reate | Create databases, tables, insert data | `CREATE TABLE`, `INSERT INTO` |
| **R**ead   | Read/retrieve data from the database  | `SELECT`                      |
| **U**pdate | Modify existing data                  | `UPDATE`                      |
| **D**elete | Delete data, tables, or databases     | `DELETE`, `DROP`              |

> **Note:** SQL keywords are NOT case-sensitive. `select` is the same as `SELECT`.

### SQL vs Sequel

Both pronunciations are correct. Originally, SQL was called **SEQUEL** (Structured English Query Language) by IBM, which was later shortened to **SQL** (Structured Query Language).

## SQL vs MySQL

| SQL | MySQL |
| --- | --- |
| A **language** used to perform CRUD operations on relational databases | An **RDBMS** (software) that uses SQL |
