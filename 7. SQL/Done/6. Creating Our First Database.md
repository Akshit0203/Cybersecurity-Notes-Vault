
# Creating Our First Database

## MySQL Workbench Layout

![](../Apna%20College%20Youtube/attachments/Pasted%20image%2020260723151930.png)

- **Middle area:** Write SQL queries here
- **Left side — Schemas tab:** Shows all databases and their tables. The default `sys` database is MySQL's internal database — don't modify it.
- **Bottom — Action Output:** Shows whether queries succeeded or failed

**Tip:** Save your query file with `Ctrl+S` / `Cmd+S` as a `.sql` file (e.g., `classroom.sql`). You can also go to **File → Save Script As**.

![](../Apna%20College%20Youtube/attachments/Pasted%20image%2020260723152136.png)

### Running Queries

- **Run entire file:** Click the ⚡ lightning bolt icon
- **Run selected text only:** Highlight the query → click the ⚡ icon with cursor (second option)

## `CREATE DATABASE`

```sql
CREATE DATABASE db_name;
```

Creates a new database.

> SQL is **not case-sensitive** for commands — `create database` and `CREATE DATABASE` both work. But **uppercase is preferred** for readability.

### Example

```sql
CREATE DATABASE college;
```

![](../Apna%20College%20Youtube/attachments/Pasted%20image%2020260723181316.png)

After running, refresh the Schemas panel (right-click → Refresh All) to see the new database:

## `DROP DATABASE`

```sql
DROP DATABASE db_name;
```

Deletes a database permanently.

### Example

```sql
CREATE DATABASE temp1;
CREATE DATABASE temp2;

DROP DATABASE temp1;
DROP DATABASE temp2;
```

![](../Apna%20College%20Youtube/attachments/Pasted%20image%2020260723183227.png)

## `USE`

```sql
USE college;
```

Tells MySQL that all subsequent operations (creating tables, querying, etc.) should happen inside this database.

![](../Apna%20College%20Youtube/attachments/Pasted%20image%2020260723183521.png)

## Summary

```sql
CREATE DATABASE college;   -- Create a database
USE college;               -- Switch to this database
DROP DATABASE temp1;       -- Delete a database
```
