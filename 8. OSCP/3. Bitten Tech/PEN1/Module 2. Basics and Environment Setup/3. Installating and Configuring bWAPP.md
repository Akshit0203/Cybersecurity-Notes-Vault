# Installing and Configuring bWAPP

> **Module 2 — Basics and Environment Setup | EHCS (Bitten Tech)**

## What is bWAPP?

**bWAPP** (Buggy Web Application / "Bee-Web") is a PHP-based, intentionally vulnerable web application — similar to DVWA but with **significantly more major and minor attacks** and variations for testing.

> [!WARNING]
> **MySQL compatibility issue:** bWAPP relies on older MySQL syntax (`mysql_connect`, `mysql_query`). The newer `mysqli_connect` / `mysqli_query` syntax does not work with it out of the box. You must either:
> - **Manually modify the code** wherever old `mysql` functions are used, or
> - **Configure your server to use older MySQL syntax**

### 3. Prepare the Environment

```shell
cd ~/Downloads
mkdir bwapp
ls
mv bWAPPv2.2.zip bwapp
cd bwapp
```

### 4. Extract bWAPP

```shell
unzip bWAPPv2.2.zip
rm bWAPPv2.2.zip
```

### 5. Install MySQL

```shell
# Check if MySQL is installed
mysql -V

# Update system
sudo apt-get update -y

# Install MySQL
sudo apt install mysql-server

# Start and enable MySQL
sudo systemctl start mysql
sudo systemctl enable mysql

# Check status (press Q to exit)
sudo systemctl status mysql
```

### 6. Install Apache2

```shell
# Check if Apache2 is installed
apache2 -v

# Update system
sudo apt-get update -y

# Install Apache2
sudo apt install apache2

# Start and enable Apache2
sudo systemctl start apache2
sudo systemctl enable apache2

# Check status (press Q to exit)
sudo systemctl status apache2
```

### 7. Prepare bWAPP Directories

```shell
cd bWAPP
chmod 777 passwords/
chmod 777 images/
chmod 777 documents/
```

### 8. Configure MySQL User

```shell
sudo mysql
```

```sql
-- Replace 'akshit' and 'pass123' with your desired username and password
CREATE USER 'akshit'@'localhost' IDENTIFIED BY 'pass123';
GRANT ALL PRIVILEGES ON bWAPP.* TO 'akshit'@'localhost';
FLUSH PRIVILEGES;
exit
```

### 9. Edit bWAPP Database Credentials

```shell
mousepad admin/settings.php
```

Change the username and password to match the MySQL user you just created:

```php
$db_username = "akshit";
$db_password = "pass123";
```

Save (Ctrl+S) and close the file.

### 10. Replace `install.php` (Important Step)

bWAPP's original `install.php` uses deprecated `mysql_*` functions. You must replace it with a `mysqli`-compatible version.

1. Go to [this Google Drive link](https://drive.google.com/file/d/1LaABJUfjHgMZgYTfZvIltbvDfX5wYFJJ/view) and copy the content
2. Edit `install.php`:

```shell
mousepad install.php
```

3. Select all (Ctrl+A), paste the copied content (Ctrl+V), save (Ctrl+S), and close

## Installing bWAPP on Windows

### 1. Download and Install XAMPP

1. Go to the [XAMPP official website](https://www.apachefriends.org/)
2. Click "XAMPP for Windows" to download the latest version
3. Follow the setup instructions
4. Open XAMPP and **enable Apache & MySQL** services by pressing Start for each, then minimize

### 2. Download bWAPP

1. Go to the [bWAPP download page](http://www.itsecgames.com/download.htm)
2. Click "You can download bWAPP from here" → "Download Latest Version"

### 3. Prepare bWAPP

1. Create a new folder and move the bWAPP zip file to it
2. Unzip the bWAPP file and remove the zip file

### 4. Move Files to Local Server

1. Select all files (Ctrl+A), copy (Ctrl+C)
2. Navigate to `C:\xampp\htdocs`
3. Paste all files (Ctrl+V)

### 5. Edit `install.php` (Important Step)

1. Right-click `install.php` in `C:\xampp\htdocs\bWAPP` → Open with a text editor
2. Go to [this Google Drive link](https://drive.google.com/file/d/1LaABJUfjHgMZgYTfZvIltbvDfX5wYFJJ/view) and copy the content (Ctrl+C)
3. Back in the text editor: select all (Ctrl+A), paste (Ctrl+V), save (Ctrl+S), close

### 6. Install the bWAPP Database

Open in your browser and click to install: [http://localhost/bWAPP/install.php](http://localhost/bWAPP/install.php)

### 7. Login to bWAPP

Open: [http://localhost/bWAPP/](http://localhost/bWAPP/)

**Default credentials:**

```
Username: bee
Password: bug
```

## Using bWAPP

After logging in, the portal opens with a **"Choose Your Bug"** dropdown containing 100+ web vulnerabilities you can test. You can also select your security level on the login page or change it inside.

### Testing an Attack

1. Select a bug from the dropdown (e.g., LDAP)
2. Click **"Hack"**
3. The corresponding configuration for that specific attack will appear
4. Check your current security level on the page

![](attachments/Pasted%20image%2020260710211252.png)

**Other features available inside bWAPP:**
- Change your password
- Create users
- Select bugs
- Change security level

> **Use both DVWA and bWAPP in parallel** — this will make your web application testing skills very strong, as you'll practice across both environments. Both are PHP-based testing environments that work very well for local testing.
> 
> Always test within sandbox environments like these unless you have explicit authorization to test external systems.
