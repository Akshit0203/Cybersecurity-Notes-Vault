
# Database Structure

A database contains **multiple interrelated tables**, each storing a particular set of data.

![](attachments/Pasted%20image%2020260723150547.png)

### Examples

**College Database:**

| Table      | Stores                            |
| ---------- | --------------------------------- |
| `students` | Student names, roll numbers, etc. |
| `fees`     | Fee payment records               |
| `courses`  | Course details                    |

**Company Database:**

| Table         | Stores             |     |
| ------------- | ------------------ | --- |
| `employees`   | Employee details   |     |
| `salaries`    | Salary information |     |
| `departments` | Department data    |     |

> A database always contains **interrelated** data. You wouldn't store a company's employee data and a college's student data in the same database — they are unrelated.
