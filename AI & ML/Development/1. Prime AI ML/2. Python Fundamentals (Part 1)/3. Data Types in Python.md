data types
. Whenever we talk about any data inside Python, like for example here we have created these different-different variables that are storing different types of data, all of this data has some type or another inside Python
. Our most fundamental data types include:
Integer: This is the very first type, meaning any of our whole numeric values can be stored here, which can be a positive number, a negative number, or also zero
.
Float: This stands for floating point
. Inside floating point, all of our decimal values come, inside which some point something comes (such as 3.14 or 9.99)
. All such values come under our float type
.

For example, if we want to print the type of this age variable, we can simply write print
...
...using a function called type
. Just like we have a print function, in the same way, we have another function which is called type
. With type, we can print the type of any variable or any number
.
Like here, if I want to print the type of age, this is going to be int
. Int means integer

```python
name = "akshit"
age = 35
PI = 3.14

print(type(age))
```

```
<class 'int'>
```


Similarly, if I want to print the type for pi, because pi is a decimal value, it will print as float

```
name = "akshit"
age = 35
PI = 3.14

print(type(PI))
```

```
<class 'float'>
```

In the same way, if we print the type for name, our type is going to be str, which stands for string
. As we already discussed, we can create strings in Python using single quotes, double quotes, and even triple quotes
.
Along with this, we also have boolean variables
. Boolean variables are those which store True or False values
.
Inside a boolean variable, either a True value can come or a False value can come
.
In these values, T and F must always be capitalized; otherwise, it will not be a valid value because Python is a case-sensitive language
.
For example, if we want to store a true or false answer for whether a number is a prime number or not, and our number is 2, since we know 2 is a prime number, we can store is_prime as True
. When we print the type of is_prime, it is going to be of type bool (boolean)
. Similarly, if we have 6, which is not a prime number, and we print its value, we will get the same type, which is boolean
.

```
num = 2
isPrime = True

print(type(isPrime))
```

```
<class 'bool'>
```

```
num = 6
isPrime = False

print(type(isPrime))
```

```
<class 'bool'>
```


Along with this, we also have one more additional type which we won't use that much for now, which is called None
.
We assign the None value to a variable when we do not want to assign any other value to it
.
Whichever variable we do not want to assign a value to, we can simply give it None
. For example, if we don't have a number, we can assign None to is_prime
. Now, when we print its type, it will be NoneType
.

```
isPrime = None

print(type(isPrime))
```

```
<class 'NoneType'>
```
