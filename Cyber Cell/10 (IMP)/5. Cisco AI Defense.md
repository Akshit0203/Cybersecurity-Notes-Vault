# Cisco AI Defense

# 1. What is Cisco AI Defense?

**Cisco AI Defense** is Cisco's enterprise security solution designed to **secure the development, deployment, and use of Artificial Intelligence (AI) applications and Large Language Models (LLMs).**

It helps organizations manage the security risks introduced by AI systems.

Announced: **Cisco Live 2024**

---

# 2. Why is AI Defense Needed?

As organizations adopt Generative AI, new risks emerge:

- Prompt Injection
    
- Jailbreak attacks
    
- Data leakage
    
- Model misuse
    
- Shadow AI
    
- Sensitive data exposure
    
- AI supply chain risks
    
- Hallucinations affecting business decisions
    
- Unauthorized AI applications
    

AI Defense aims to reduce these risks.

# 5. Key Features

## AI Application Discovery (How Shadow AI is Discovered)

Cisco AI Defense discovers **Shadow AI** using multiple visibility and monitoring techniques:

### 1. Network Traffic Analysis

- Inspects outbound traffic to identify connections to known AI services.
    
- Detects domains and APIs associated with AI platforms (e.g., ChatGPT, Gemini, Claude).
    
- Uses DNS, HTTP/HTTPS metadata, and TLS fingerprinting.
    

### 2. Secure Web Gateway / Proxy Logs

- Monitors web access logs to identify users accessing AI tools.
    
- Detects usage patterns even if applications are browser-based.
    

### 3. Cloud Access Security Broker (CASB) Integration

- Identifies SaaS-based AI applications.
    
- Classifies applications as sanctioned or unsanctioned.
    
- Provides visibility into Shadow AI usage across cloud environments.
    

### 4. Endpoint Telemetry

- Detects installed AI applications or plugins (e.g., Copilot, AI extensions).
    
- Monitors application behavior on endpoints.
    

### 5. Identity and Access Correlation

- Maps AI usage to specific users and roles.
    
- Identifies unauthorized usage based on policy violations.
    

### 6. Behavioral Analytics

- Detects unusual or risky AI usage patterns.
    
- Flags abnormal data uploads or excessive interactions with AI tools.
    

---

### Outcome

Using these methods, Cisco AI Defense can:

- Identify unauthorized AI tools (Shadow AI)
    
- Track who is using them
    
- Understand what data is being shared
    
- Enforce policies (allow, restrict, or block)

# 8. Shadow AI

**Shadow AI** refers to employees using AI tools that are not approved by the organization.

## How Cisco AI Defense Detects Shadow AI

- Monitors network traffic for AI service usage
    
- Analyzes web and proxy logs
    
- Uses CASB to discover SaaS AI tools
    
- Collects endpoint telemetry
    
- Correlates user identity with AI activity
    
- Applies behavioral analytics to detect anomalies
    

## Risks include:

- Uploading confidential documents
    
- Source code leakage
    
- Intellectual property exposure
    
- Compliance violations
    
- Privacy risks
    

AI Defense helps organizations discover and govern such usage.
