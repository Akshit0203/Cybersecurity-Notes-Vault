
# ISP, Browser History and User-Agent

## Common Question

> Can an ISP see my browser history?

The answer is:

**Sometimes, but not always.**

It depends on:

- Whether the website uses HTTPS
    
- DNS configuration
    
- VPN usage
    
- Browser security settings
    

---

# What an ISP Can Always See

When you connect to the internet, the ISP generally knows:

### Subscriber Information

- Name
    
- Address
    
- Mobile number
    
- Account details
    

---

### IP Address Assignment

- Public IP assigned
    
- Session times
    
- Connection duration
    

---

### Data Usage

- Upload usage
    
- Download usage
    
- Total bandwidth consumption
    

---

### Destination IP Addresses

Example:

You connect to:

142.250.x.x

The ISP can usually see the destination IP.

---

### DNS Requests (Often)

Example:

youtube.com

google.com

facebook.com

If traditional DNS is used, the ISP may see DNS lookups.

Modern encrypted DNS can reduce this visibility.

---

# Can ISP See Browser History?

## HTTP Websites (Old Style)

Example:

```text
http://example.com/page1
```

ISP may see:

- Entire URL
    
- Exact pages visited
    

---

## HTTPS Websites (Modern Internet)

Example:

```text
https://example.com/page1
```

Typically ISP can see:

- Domain name
    
- Connection metadata
    

Usually cannot see:

- Exact page contents
    
- Form submissions
    
- Passwords
    
- Messages
    

---

# Can ISP See Google Searches?

Usually not directly.

Example:

Google Search:

```text
how to learn cybersecurity
```

ISP generally sees:

- Connection to Google
    

But not necessarily:

- Exact search query
    

because search traffic is encrypted.

---

# What Is a User-Agent?

A User-Agent is information sent by browsers and applications describing themselves.

Example:

```text
Mozilla/5.0
Windows NT 10.0
Chrome 137
```

This helps websites identify:

- Browser
    
- Operating system
    
- Device type
    

---

# Information Revealed by User-Agent

Examples:

### Browser

- Firefox
    
- Safari
    
- Edge
    

---

### Operating System

- Windows
    
- Linux
    
- Android
    
- iOS
    
- macOS
    

---

### Device Type

- Mobile
    
- Desktop
    
- Tablet
    

---

### Browser Version

Example:

Chrome 137

# Why User-Agent Is Important in Investigations

User-Agent logs can help determine:

- Which device was used
    
- Which browser was used
    
- Whether multiple accounts used the same device
    
- Suspicious login activity
    

---

# Example Investigation

Website Log:

IP:

49.37.x.x

User-Agent:

Chrome 137

Windows 11

Time:

8:15 PM

Another login:

Same IP

Same User-Agent

Same time window

Investigators may infer:

- Same device
    
- Same browser session
    
- Related activity
    

Further evidence is required for certainty.

# Can ISP See User-Agent?

Usually:

### Website

Can see:

- User-Agent
    
- Cookies
    
- Browser information
    

### ISP

Usually cannot directly see User-Agent inside encrypted HTTPS traffic.

However:

- Websites
    
- Servers
    
- CDNs
    
- Web applications
    

often log User-Agent information.

---

# Browser History vs ISP Data

### Browser History

Stored on:

- Device
    
- Browser profile
    

Contains:

- Exact URLs
    
- Search history
    
- Visited pages
    

---

### ISP Records

Typically contain:

- IP assignments
    
- Connection logs
    
- Traffic metadata
    
- Sometimes DNS information
    

Usually do not contain full browser history for HTTPS traffic.

---

# Key Takeaway

An ISP generally knows that you connected to a website and can identify the subscriber, IP address, timestamps, and data usage. However, modern HTTPS encryption prevents the ISP from seeing most webpage contents, passwords, messages, and detailed browsing activity. User-Agent information is typically visible to websites and servers rather than the ISP and can help investigators identify the browser, operating system, and device used during an online session.
