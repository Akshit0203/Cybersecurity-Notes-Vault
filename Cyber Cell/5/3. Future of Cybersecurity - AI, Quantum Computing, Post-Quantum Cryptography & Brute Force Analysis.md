# 2. Quantum Computing

## Classical Computing

Traditional computers use **bits**.

A bit can have only one value at a time:

```text
0

or

1
```

---

## Quantum Computing

Quantum computers use **quantum bits (qubits)**.

A qubit can exist in a quantum superposition, meaning it can represent combinations of the states **0 and 1 simultaneously** until measured.

This property enables certain computations to be performed much more efficiently than on classical computers.

---

## Simplified Representation

Classical Bit:

```text
0
or
1
```

Quantum Bit (Qubit):

```text
Superposition of 0 and 1
```

This does **not** mean the value is simply "between 0 and 1"; rather, it is a quantum state that can encode probabilities for both outcomes.

---

# 3. Why Quantum Computing Matters

Quantum algorithms may significantly speed up some problems that are difficult for classical computers.

Potential applications include:

- Drug discovery
    
- Material science
    
- Optimization
    
- Cryptography
    
- Machine learning
    
- Scientific simulation
    

---

# 4. Impact on Cryptography

Many public-key cryptographic systems rely on mathematical problems that are hard for classical computers.

Examples include:

- RSA
    
- Diffie–Hellman
    
- Elliptic Curve Cryptography (ECC)
    

Large-scale fault-tolerant quantum computers running algorithms such as Shor's algorithm could potentially solve these problems much faster than classical methods.

---

# 5. Post-Quantum Cryptography (PQC)

## Definition

Post-Quantum Cryptography consists of cryptographic algorithms designed to remain secure against attacks from both classical and quantum computers.

Unlike quantum cryptography, PQC runs on ordinary computers and networks.

---

## Goals of PQC

- Replace vulnerable public-key algorithms
    
- Maintain confidentiality in the quantum era
    
- Enable secure communication on existing hardware
    

---

## Common PQC Families

Examples include:

- Lattice-based cryptography
    
- Code-based cryptography
    
- Hash-based signatures
    
- Multivariate cryptography
    

Many organizations are actively migrating toward standardized PQC algorithms.

---

# 6. Brute Force Attacks

## Definition

A brute force attack systematically tries candidate passwords or cryptographic keys until the correct one is found.

Example:

```text
1234
1235
1236
...
9999
```

---

## Factors Affecting Brute Force Time

The time depends on:

- Password length
    
- Character set size
    
- Hashing algorithm
    
- Hardware performance
    
- Parallel processing
    

---

## Example Search Space

4-digit PIN:

```text
10^4 = 10,000 possibilities
```

8 lowercase letters:

```text
26^8 ≈ 208 billion possibilities
```

Long, random passwords become exponentially harder to guess.

---

# 7. Big-O Notation

## Definition

Big-O notation describes how the running time or memory usage of an algorithm grows as the input size increases.

It measures scalability rather than exact execution time.

---

## Common Complexities

|Complexity|Name|Example|
|---|---|---|
|O(1)|Constant|Array index access|
|O(log n)|Logarithmic|Binary search|
|O(n)|Linear|Single pass through a list|
|O(n log n)|Linearithmic|Efficient sorting algorithms|
|O(n²)|Quadratic|Simple nested loops|
|O(2ⁿ)|Exponential|Exhaustive subset search|
|O(n!)|Factorial|Brute-force permutation search|

---

# 8. Brute Force and Complexity

Brute force often has exponential complexity because the number of possibilities grows rapidly with input size.

Example:

Password length increases

↓

Possible combinations increase exponentially

↓

Attack time increases dramatically

---

# 9. Quantum Computing and Brute Force

Quantum computers do **not** instantly break all passwords.

However, quantum algorithms such as Grover's algorithm can provide a theoretical speedup for unstructured search problems, effectively reducing the search effort compared with classical brute force.

In practice:

- Longer keys and passwords remain highly effective.
    
- Doubling symmetric key sizes (for example, using 256-bit keys instead of 128-bit keys) helps maintain strong security against known quantum search techniques.
    

---

# 10. Estimated Brute Force Time (Illustrative)

|Password|Difficulty|
|---|---|
|4-digit PIN|Seconds to minutes on modern hardware|
|6-digit PIN|Very short with sufficient attempts allowed|
|8 random lowercase letters|Potentially substantial depending on rate limits and hardware|
|12–16 character random passwords|Extremely resistant to brute force when properly hashed and rate-limited|

Actual cracking time depends heavily on hashing algorithms, salting, hardware, and system protections.

# Key Takeaways

- **AI-powered cybersecurity** automates detection, response, and threat analysis, while attackers can also leverage AI for more sophisticated attacks.
    
- **Quantum computers** use **qubits**, which can exist in quantum superposition rather than being limited to a single classical value of 0 or 1.
    
- **Post-Quantum Cryptography (PQC)** aims to protect data against future quantum attacks using algorithms designed to be secure on both classical and quantum computers.
    
- **Brute force attacks** become exponentially harder as password length and complexity increase.
    
- **Big-O notation** helps describe how algorithm performance scales with input size and is fundamental for analyzing search and cryptographic algorithms.
