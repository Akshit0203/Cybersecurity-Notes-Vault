
# Tails OS, Tor Network and Investigation Techniques

# 1. What is Tails OS?

**Tails (The Amnesic Incognito Live System)** is a free, open-source Linux distribution designed to enhance user privacy and anonymity.

Key features:

- Routes internet traffic through the Tor network by default
    
- Leaves minimal traces on the host computer when used as a live system
    
- Includes privacy-focused applications
    
- Supports encrypted persistent storage (optional)
    
- Designed for journalists, researchers, activists, and privacy-conscious users
    

---

# 2. What is Tor?

**Tor (The Onion Router)** is an anonymity network that routes internet traffic through multiple volunteer-operated relays.

Typical path:

```text
User
  │
  ▼
Entry (Guard) Node
  │
  ▼
Middle Relay
  │
  ▼
Exit Node
  │
  ▼
Destination Website
```

Each relay knows only limited information about the route.

---

# 3. What Does the Website See?

When a user accesses a website via Tor:

The website generally sees:

- The Tor exit node IP address
    
- Browser headers sent by the client
    
- Request timestamps
    

The website does **not** normally see the user's home IP address.

---

# 4. What Does the ISP See?

The Internet Service Provider (ISP) may observe:

- The user's connection to the Tor network
    
- Connection time
    
- Data volume
    

The ISP generally cannot determine which websites the user visits through Tor solely from encrypted Tor traffic.

---

# 5. Entry Node vs Exit Node

## Entry (Guard) Node

Can observe:

- User IP address
    
- Connection timing
    

Cannot normally see:

- Final destination website content
    

---

## Exit Node

Can observe:

- Destination website
    
- Outgoing traffic leaving Tor
    

Cannot normally identify the original user's IP address based only on its position in the circuit.

---

# 6. How Investigators Analyze Tor-Related Cases

Law enforcement investigations typically rely on **multiple sources of evidence**, not merely Tor exit IP addresses.

Possible evidence includes:

- Device forensics
    
- Browser artifacts
    
- System logs
    
- Account activity
    
- Cryptocurrency records
    
- Cloud logs
    
- Email records
    
- Operational security (OPSEC) mistakes
    
- Financial evidence
    
- Witness statements
    

---

# 7. Reverse IP and ISP Records

If investigators identify a public IP address, they may seek subscriber information from the relevant ISP or hosting provider through lawful legal processes.

Typical correlation requires:

- IP address
    
- Date
    
- Time
    
- Sometimes source port (especially with Carrier-Grade NAT)
    

Example:

```text
Observed IP
      │
      ▼
ISP
      │
      ▼
Subscriber Records
      │
      ▼
Relevant Customer Account
```

An IP address alone is not sufficient without accurate timestamps and supporting evidence.

---

# 8. Browser Fingerprinting

Browser fingerprinting attempts to distinguish browsers using characteristics such as:

- User-Agent string
    
- Screen resolution
    
- Installed fonts
    
- Language settings
    
- Time zone
    
- Canvas/WebGL behavior
    
- Hardware characteristics
    

Example:

```text
Browser
   │
   ▼
Fingerprint Generation
   │
   ▼
Unique Combination of Attributes
```

A fingerprint is probabilistic and should not be treated as conclusive proof of identity.

---

# 9. Browser History

Browser history may reveal:

- Visited URLs
    
- Search activity
    
- Download records
    
- Cookies
    
- Cached resources
    

However:

- Tails is designed to minimize persistent local traces after shutdown unless persistent storage is explicitly enabled.
    

---

# 10. Device Forensics

If investigators obtain lawful access to a device, forensic examination may include:

- Memory analysis
    
- Log files
    
- User documents
    
- Network artifacts
    
- Application data
    
- Removable media
    
- Encrypted volumes (where accessible)
    

---

# 11. Operational Security (OPSEC)

Many investigations succeed because users inadvertently reveal information by:

- Reusing usernames
    
- Reusing email addresses
    
- Logging into personal accounts
    
- Linking identities across platforms
    
- Disclosing identifying details
    

These mistakes can correlate otherwise anonymous activity.

---

Suspicious Activity

---

# Key Takeaways

- **Tails OS** is a privacy-focused Linux distribution that routes traffic through the **Tor network**.
    
- **Tor** uses multiple relays (entry, middle, and exit nodes) to improve anonymity; websites typically see only the **exit node IP**.
    
- **ISPs** can generally observe that a user is connecting to Tor but not the final destination websites.
    
- **Browser fingerprinting** relies on combinations of browser and device characteristics and is only one possible investigative signal.
    
- Modern investigations rely on **correlating multiple sources of evidence**—such as logs, device forensics, account records, and operational mistakes—rather than expecting a Tor exit node alone to reveal a user's identity.
