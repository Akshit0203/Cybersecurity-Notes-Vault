
# Telecom Investigation Records – CDR, IPDR, ILD CDR, VOIP, SIP, TDR, USI

## Overview

Modern telecom investigations use multiple record types to identify:

- Subscribers
    
- Devices
    
- Locations
    
- Internet activity
    
- International communications
    
- VoIP activity
    

No single record tells the whole story.

Investigators correlate multiple datasets.

---

# 1. CDR (Call Detail Record)

CDR contains metadata related to:

- Voice calls
    
- SMS
    
- Cell tower usage
    

Typical fields:

- Mobile Number
    
- IMSI
    
- IMEI
    
- A Party
    
- B Party
    
- Date
    
- Time
    
- Duration
    
- Cell ID
    

Used for:

- Link analysis
    
- Location analysis
    
- Timeline reconstruction
    

---

# 2. IPDR (Internet Protocol Detail Record)

IPDR records internet activity metadata.

Contains:

- Source IP
    
- Destination IP
    
- Source Port
    
- Destination Port
    
- Session Time
    
- Data Usage
    

Used for:

- Internet attribution
    
- Online activity investigation
    
- WhatsApp/Telegram session correlation
    
- Subscriber identification
    

---

# 3. ILD CDR (International Long Distance CDR)

ILD stands for:

**International Long Distance**

ILD CDR records international telecom communications.

Examples:

India

↓

USA

↓

UK

↓

UAE

↓

Pakistan

These records help identify:

- International callers
    
- Call routing
    
- International fraud
    
- Spy networks
    
- Cross-border communication
    

---

# 4. VOIP (Voice over Internet Protocol)

VOIP allows voice communication through the internet instead of traditional telecom networks.

Examples:

- WhatsApp Calling
    
- Skype
    
- Zoom
    
- Telegram Calls
    
- SIP Phones
    

Advantages:

- Low cost
    
- Global connectivity
    
- Easy deployment
    

Challenges:

- Attribution
    
- Cross-border routing
    
- Virtual identities
    

---

# 5. Virtual Numbers

A Virtual Number is a phone number not directly tied to a physical SIM.

Examples:

- Cloud numbers
    
- VOIP numbers
    
- Temporary numbers
    
- Business communication systems
    

Examples:

USA Number

while user sits in India.

Uses:

- Business operations
    
- Call centers
    
- Fraud
    
- Scam operations
    

---

# 6. SIP (Session Initiation Protocol)

SIP stands for:

**Session Initiation Protocol**

It is one of the most common protocols used in VOIP systems.

Functions:

- Establish calls
    
- Manage calls
    
- Terminate calls
    

---

## SIP Records May Reveal

### Source

Who initiated communication.

### Destination

Who received communication.

### SIP Server

Which server routed communication.

### Carrier

Telecom or VOIP provider.

### Call Timing

Start and end times.

---

# Example SIP Flow

User A

↓

SIP Server

↓

VOIP Carrier

↓

User B

Investigators often analyze SIP logs to identify call paths.

---

# 7. USI (User Subscriber Information)

USI stands for:

**User Subscriber Information**

Contains subscriber-related details.

Examples:

- Name
    
- Address
    
- Mobile Number
    
- Customer ID
    
- KYC Information
    
- Activation Date
    

Used to identify:

- Who owns a number
    
- Registered subscriber details
    

---

# 8. SDR (Subscriber Detail Record)

SDR contains:

- Subscriber identity
    
- Service details
    
- Account information
    
- KYC data
    

Often used together with:

- CDR
    
- IPDR
    
- USI
    

to identify users.

---

# 9. TDR (Tower Dump Record)

TDR stands for:

**Tower Dump Record**

A Tower Dump contains details of all devices connected to a specific tower during a specific time window.

Example:

Tower Location:

Connaught Place

Time:

8 PM – 8:30 PM

Result:

Thousands of devices listed.

---

## Why TDR Is Useful

Suppose a crime occurs.

Investigators obtain:

Tower Dump

↓

Identify all phones present

↓

Filter suspects

↓

Cross-match with CDR/IPDR

This is commonly used in:

- Murder investigations
    
- Kidnapping cases
    
- Terrorism investigations
    
- Robbery cases
    

---

# 10. Data CDR

Data CDR focuses on internet sessions rather than traditional calls.

Contains:

- Internet usage
    
- Session information
    
- Data transfers
    
- Network activity
    

Often overlaps with IPDR records.

---

# 11. APP Signup Investigation

When a suspect creates:

- WhatsApp
    
- Telegram
    
- Instagram
    
- Facebook
    

Investigators may correlate:

### Mobile Number

### IP Address

### Device ID

### IMEI

### IMSI

### Signup Timestamp

### Virtual Number Usage

### VOIP Registration Data

to identify the user behind an account.

# Key Takeaway

Modern telecom investigations rarely rely on a single record. Investigators combine CDR, IPDR, ILD CDR, SIP logs, VOIP records, Tower Dumps, USI, SDR, and App Signup information to identify subscribers, reconstruct timelines, trace internet activity, analyze communications, and attribute online actions to specific individuals or devices.
