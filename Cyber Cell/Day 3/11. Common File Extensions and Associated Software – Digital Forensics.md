
# Common File Extensions and Associated Software – Digital Forensics

## Why File Extensions Matter

A file extension helps identify:

- File type
    
- Software used
    
- Possible contents
    
- Associated application
    

In digital forensics, file extensions can provide clues about:

- User activity
    
- Installed software
    
- Professional background
    
- Data stored on the system
    

---

# Engineering and Design Files

### .dwg

Software:

- AutoCAD
    

Used for:

- Engineering drawings
    
- Architectural plans
    
- Mechanical designs
    
- Technical diagrams
    

Commonly found with:

- Civil Engineers
    
- Architects
    
- Mechanical Engineers
    

---

### .dxf

Software:

- AutoCAD
    
- CAD software
    

Used for:

- Drawing exchange format
    
- Technical designs

# Image Files

Software:

- Microsoft Paint
    
- Windows Image Viewer

- Uncompressed image
    
- Large file size

# Forensics Importance

Investigators often examine file extensions to determine:

### Profession of User

Example:

- .dwg → Engineer/Architect
    
- .psd → Graphic Designer
    
- .pm5/.pmd → Publishing Professional
    

---

### Installed Applications

Extensions may indicate:

- AutoCAD installed
    
- Photoshop installed
    
- PageMaker installed
    

---

### Hidden Evidence

Sometimes:

```text
photo.jpg.exe
```

appears to be an image but is actually an executable file.

Investigators verify:

- File signature
    
- Magic bytes
    
- Metadata
    

instead of relying solely on the extension.

# Key Takeaway

Learning file extensions is important in digital forensics because extensions often reveal the type of content stored, the software used, the profession of the user, and potential sources of evidence. However, investigators always verify file signatures and metadata because file extensions can be renamed or spoofed.
