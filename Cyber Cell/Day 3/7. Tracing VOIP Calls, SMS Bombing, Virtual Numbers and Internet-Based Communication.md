
# Tracing VOIP Calls, SMS Bombing, Virtual Numbers and Internet-Based Communication

## Overview

Modern cybercrime investigations often involve:

- VOIP calls
    
- SMS bombing
    
- Virtual numbers
    
- Anonymous calling applications
    
- Internet-based communication services
    

Examples:

- TextNow
    
- TextFree
    
- Google Voice
    
- Skype
    
- SIP providers
    
- Cloud telephony platforms
    

The objective is to identify the real user behind the communication.

---

# Step 1 – Identify the Number Type

Investigators first determine:

Is the number:

- Mobile number
    
- Fixed line
    
- VOIP number
    
- Virtual number
    
- International number
    

Tools often used:

### Carrier Lookup

Can reveal:

- Carrier
    
- Country
    
- Number type
    
- VOIP provider
    

Examples:

- Twilio
    
- Bandwidth
    
- TextNow
    
- Google Voice
    

---

# Step 2 – Check Whether It Is a VOIP Number

VOIP stands for:

**Voice over Internet Protocol**

Instead of telecom towers, communication occurs through internet infrastructure.

Common indicators:

- Virtual number
    
- Cloud telephony provider
    
- SIP routing
    

---

# Step 3 – Obtain ILD and Carrier Information

ILD stands for:

**International Long Distance**

Investigators may determine:

- International routing
    
- Carrier information
    
- Call termination path
    

Questions:

- Which country issued the number?
    
- Which carrier owns it?
    
- Which provider routed the call?
    

---

# Step 4 – VOIP Company Notice

If a provider is identified:

Example:

- TextNow
    
- Twilio
    
- Skype
    

Law enforcement may seek records through legal process.

Possible records:

- Registration details
    
- Signup information
    
- Login timestamps
    
- IP logs
    
- Recovery email
    
- Associated devices
    

---

# Step 5 – Obtain User Subscriber Information (USI)

USI stands for:

**User Subscriber Information**

May include:

- Name
    
- Email
    
- Registered phone number
    
- Account creation details
    
- Recovery information
    

The amount of information depends on what the user provided during signup.

---

# Step 6 – Analyze IP Logs

Most VOIP services maintain:

- Login IP addresses
    
- Session IP addresses
    
- Signup IP addresses
    

Example:

TextNow Account

↓

IP Address

↓

ISP

↓

Subscriber

This is often one of the most important investigative steps.

---

# Step 7 – IPDR Analysis

IPDR stands for:

**Internet Protocol Detail Record**

Investigators correlate:

- Source IP
    
- Destination IP
    
- Ports
    
- Timestamp
    

to identify:

- Subscriber
    
- Internet connection
    
- Device usage timeline

# Step 9 – SIP Protocol Analysis

SIP stands for:

**Session Initiation Protocol**

Used by many VOIP systems.

SIP records may reveal:

### Source

Who initiated communication.

### Destination

Who received communication.

### SIP Server

Which server handled the call.

### Carrier

Which provider routed the communication.

### Call Timing

Start and end times.

---

VOIP traffic often passes through:

User

↓

VOIP Provider

↓

SIP Server

↓

Carrier

↓

Trunk Gateway

↓

Destination

Investigators may reconstruct the path to identify service providers involved.

# Step 11 – SMS Bombing Investigation

SMS bombing involves sending:

- Hundreds
    
- Thousands
    
- Tens of thousands
    

of messages to a target.

Investigation focuses on:

- Source IPs
    
- API usage
    
- Signup accounts
    
- Automation tools
    
- Service providers used
    

Logs may identify:

- The originating account
    
- Source network
    
- Automation platform
    

---

# Step 12 – App Signup Investigation

Applications often store:

- Signup email
    
- Signup IP
    
- Device identifiers
    
- Login history
    
- Recovery details
    

Examples:

- TextNow
    
- Telegram
    
- WhatsApp
    
- Signal
    

Investigators may use these records to identify the person operating the account.

# Key Takeaway

Tracing a VOIP call or virtual number usually involves identifying the provider, obtaining account records, analyzing SIP logs, reviewing IP addresses, correlating IPDR records, and linking the internet connection to a subscriber. Modern investigations rely on the combination of carrier information, VOIP logs, SIP records, USI data, ISP records, and application signup information rather than the phone number alone.
