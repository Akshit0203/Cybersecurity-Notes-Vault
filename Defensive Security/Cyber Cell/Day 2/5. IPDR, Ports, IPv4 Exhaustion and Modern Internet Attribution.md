
# IPDR, Ports, IPv4 Exhaustion and Modern Internet Attribution

## What Is IPDR?

IPDR stands for:

**Internet Protocol Detail Record**

While CDR records voice calls and SMS activity, IPDR records internet usage metadata.

IPDR may contain:

- Subscriber details
    
- IP address assigned
    
- Source port
    
- Destination IP
    
- Destination port
    
- Date and time
    
- Session duration
    
- Data usage
    

Investigators use IPDR to reconstruct internet activity timelines.

---

# Why Ports Became Important

## Early Internet (Around 2004)

Internet usage was relatively small.

Typical situation:

1 Public IP Address

↓

1 Subscriber

↓

1 Name

↓

1 Physical Address

Attribution was straightforward.

Example:

IP:

192.168.x.x

could be linked directly to a single subscriber.

---

## Social Media Era (2010)

Services expanded rapidly:

- Orkut
    
- Facebook
    
- Gmail
    
- YouTube
    

ISPs started facing IPv4 shortages.

A single IP address could no longer be dedicated to one customer all the time.

---

## Modern Internet (2026)

India has:

- Hundreds of millions of internet users
    
- Massive mobile internet usage
    
- Limited IPv4 address space
    

Approximate challenge:

- Billions of devices
    
- Limited IPv4 addresses
    

As a result:

One public IP may be shared by thousands of users.

---

# Why IPv4 Addresses Are Not Enough

Suppose investigators obtain:

IP Address:

1.2.3.4

Date:

10 June 2026

Time:

08:00 PM

Question:

> Which subscriber was using that IP?

The answer may be:

- Hundreds
    
- Thousands
    
- Tens of thousands
    

of users simultaneously sharing that IP.

Therefore:

IP Address alone is no longer sufficient.

---

# Role of Port Numbers

To solve this problem ISPs use:

### CGNAT

Carrier Grade Network Address Translation

CGNAT allows many customers to share one public IP.

To distinguish users, the ISP assigns:

IP Address

Port Number

---

# Why Investigators Need Port Numbers

If police send a notice to:

Jio

asking:

IP:

49.37.120.10

Time:

8:00 PM

Jio may respond:

> Multiple customers were using this IP.

Now investigators must provide:

- IP Address
    
- Date
    
- Time
    
- Source Port
    

Only then can the ISP identify the exact subscriber.

# WhatsApp, Telegram and Ports

Applications use network ports to communicate.

Examples:

- WhatsApp
    
- Telegram
    
- Signal
    
- Instagram
    
- Banking apps
    

The port itself does not reveal message content.

However it helps identify:

- Sessions
    
- Connections
    
- Attribution
    

Combined with:

- IP address
    
- Timestamp
    

it becomes valuable evidence.

---

# Bitcoin and Ports

Bitcoin nodes communicate using network ports.

Historically:

Default Bitcoin Port:

8333

However:

- Port usage alone does not prove Bitcoin activity.
    
- Modern applications can use multiple ports.
    
- Encryption often hides application content.
    

Investigators typically combine:

- IPDR
    
- Device forensics
    
- Wallet analysis
    
- Exchange records
    

rather than relying only on ports.

---

# What Police Usually Request

For internet attribution:

1. IP Address
    
2. Source Port
    
3. Date
    
4. Time
    
5. Time Zone
    
6. ISP Details
    

Without the port number, attribution may be impossible in CGNAT environments.

---

# Difference Between CDR and IPDR

### CDR

Records:

- Calls
    
- SMS
    
- Tower information
    

Examples:

- I/C
    
- O/C
    
- I/S
    
- O/S
    

---

### IPDR

Records:

- Internet sessions
    
- IP addresses
    
- Ports
    
- Data usage
    
- Online activity metadata
    

---

# Key Takeaway

In the early internet era, one IP address often identified one subscriber. Today, because of IPv4 exhaustion and Carrier Grade NAT (CGNAT), thousands of users may share the same public IP. Therefore modern investigations require:

**IP Address + Port Number + Date + Time**

to accurately identify the subscriber responsible for a specific internet session.
