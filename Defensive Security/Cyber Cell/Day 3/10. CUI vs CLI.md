
### CLI (Command Line Interface)

A CLI is specifically an interface where you type **commands**.

Example:

```
lscd Documentsnmap 192.168.1.1
```

---

### CUI (Character User Interface)

CUI is a broader term for any interface made up of text/characters.

It includes:

- Command-line interfaces
- Text menus
- Text-based applications

Example:

Old BIOS setup screens, text-based installers, and DOS menus are CUIs even if you are not typing commands all the time.

---

### In Practice

For cybersecurity, Linux, networking, and hacking:

> When people say **CUI**, they usually mean **CLI**.

So if someone asks:

> "Are you comfortable working in a CUI environment?"

They usually mean:

> "Can you use a terminal/command line?"

### Quick Note for Notes

- **CLI (Command Line Interface)** → User types commands.
- **CUI (Character User Interface)** → Any text-based interface.
- **All CLIs are CUIs, but not all CUIs are CLIs.**
