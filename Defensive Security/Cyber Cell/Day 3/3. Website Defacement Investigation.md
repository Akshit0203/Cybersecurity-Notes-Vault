
# Website Defacement Investigation

## What Is Website Defacement?

Website defacement occurs when a person modifies website content without authorization.

Examples:

- Homepage replacement
    
- Political messages
    
- Hacker signatures
    
- Malicious redirects
    
- Fake announcements
    

---

## Investigation Process

### Step 1 – Identify Hosting Provider

Determine:

- Hosting company
    
- Server location
    
- Hosting account
    

---

### Step 2 – Domain Registration Analysis

Investigators collect:

- Domain registrar information
    
- Registration records
    
- WHOIS history
    
- Administrative contacts
    

Questions:

- Who registered the domain?
    
- When was it registered?
    
- Which email was used?
    

---

### Step 3 – Server Log Analysis

Server logs may reveal:

- Login attempts
    
- Authentication events
    
- Administrative activity
    
- Source IP addresses
    

Examples:

- Apache logs
    
- Nginx logs
    
- IIS logs
    

---

### Step 4 – FTP Log Analysis

FTP stands for:

**File Transfer Protocol**

Modified files may be uploaded using:

- FTP
    
- SFTP
    
- SSH
    

Logs may reveal:

- Username
    
- Source IP
    
- Upload time
    
- Modified files
    

Questions:

- Which account uploaded the file?
    
- From which IP?
    
- At what time?
    

---

### Step 5 – File Transfer Analysis

Investigators examine:

- File upload timestamps
    
- Modified files
    
- File hashes
    
- Backup copies
    

Goal:

Identify how the content was placed on the server.

---

### Step 6 – IP Attribution

Once a suspicious IP is identified:

IP

↓

ISP

↓

Subscriber Records

↓

Possible Suspect

For attribution investigators typically require:

- IP address
    
- Date
    
- Time
    
- Port number (for CGNAT environments)
    

---

### Step 7 – Email Service Provider (ESP) Analysis

Many websites use email services.

Examples:

- Gmail
    
- Microsoft 365
    
- Zoho
    
- Proton Mail
    

Investigators may seek:

- Registration information
    
- Login logs
    
- Recovery email information
    

---

## MX Lookup

MX stands for:

**Mail Exchange**

MX records identify the email provider handling mail for a domain.

Example:

example.com

↓

MX Lookup

↓

Google Workspace

or

Microsoft 365

or

Zoho Mail

This helps investigators identify the email service provider.

## Key Takeaways

### Website Defacement Investigation

Key evidence sources include:

- Domain registration records
    
- Hosting provider logs
    
- Web server logs
    
- FTP/SFTP logs
    
- Email provider records
    
- IP attribution records
    

### Digital Attribution

Investigators often combine:

- IP address
    
- Date and time
    
- Port number
    
- Subscriber details
    
- Server logs
    
- Account records
    

to identify the individual responsible for unauthorized website modifications.

### Important Principle

A hacked website rarely identifies the attacker directly. Investigators usually follow the chain:

**Website → Server Logs → IP → ISP → Subscriber → Device → Suspect**

### Legal Principle

Whether a person can be investigated, prosecuted, or punished depends on the specific facts, evidence, applicable law, and the decision of a competent court.
