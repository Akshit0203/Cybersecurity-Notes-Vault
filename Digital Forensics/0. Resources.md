### forensics & stego: digging stuff out of files, memory & traffic

half of this skill is just _knowing the tools exist_. so. now you know.

| thing                                                                          | my take                                                                                                          |
| ------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------- |
| [Volatility](https://www.volatilityfoundation.org/)                            | the standard for memory forensics. half of forensics challenges secretly just want this.                         |
| [Autopsy](https://www.autopsy.com/) / [Sleuth Kit](https://www.sleuthkit.org/) | disk forensics: the "what's actually on this image" tools.                                                       |
| ★ [CyberChef](https://gchq.github.io/CyberChef/)                               | the cyber swiss army knife. encodings, ciphers, hashing, the magic wand, all drag-and-drop. you'll use it daily. |
| `binwalk`, `exiftool`, `steghide`, `zsteg`, `foremost`                         | the carving + stego starter kit. tiny terminal tools that save you constantly.                                   |
| [Aperi'Solve](https://www.aperisolve.com/)                                     | throws a whole pile of stego tools at an image at once. a great panicky first move.                              |
