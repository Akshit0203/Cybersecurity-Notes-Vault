# Authentication, Authorization and Accounting (AAA) — Notes & Check-In Quiz

## Key Concepts

| Term | Meaning | Example |
|---|---|---|
| **Authentication** | Verify **who someone is** | Password, fingerprint, badge |
| **Authorization** | Determine **what they can access** | Role-based permissions |
| **Accounting** | **Log and track** what they did | Login timestamps, access logs |
| **Least Privilege** | Give only the **minimum permissions** needed | Printer service account shouldn't be domain admin |
| **MFA** | Requires **multiple authentication factors** | Password + fingerprint (different factor types) |
| **SSO** | One login provides access to **multiple applications** | Google login grants access to Gmail, Drive, etc. |
| **IAM** | The broader system for **managing identities and access** | Azure AD, Okta |
| **JIT Authorization** | Access granted **temporarily/on demand** | One-time access code each time safe is opened |
| **RBAC** | Access set by **role** (teller, manager, HR) | Role-Based Access Control |
| **ABAC** | Access based on **attributes** (time, location, clearance) | Attribute-Based Access Control |
| **MAC** | Access based on **classification labels** set by authority | Mandatory Access Control (military/gov) |
| **DAC** | **Owner** of resource decides who gets access | Discretionary Access Control |

### MFA Factor Types

MFA requires factors from **different categories**:

| Factor Type | Example |
|---|---|
| **Something you know** | Password, PIN |
| **Something you have** | Phone, hardware token |
| **Something you are** | Fingerprint, face scan |

> ⚠️ A password + selecting a pre-set picture = **both "something you know"** = NOT valid MFA

## Check-In Quiz

> [!question] Q1: The security team is performing an audit of logs and notice a recurring login happening outside of normal business hours. This is an example of the benefits of ______ ?
> - [ ] Authentication
> - [ ] Authorization
> - [ ] Accounting
> - [ ] Regular Access Reviews
>
> <details><summary>Answer</summary>
> 
> **Accounting**
> </details>

> [!question] Q2: A service account is created at an organization for printers, the IT team is not able to get permissions working properly so as a workaround they give the service account domain admin permissions. Which security principle and best practice is not being followed here?
> - [ ] Using Service Accounts
> - [ ] Permissions Creep
> - [ ] Defense In-Depth
> - [ ] Least Privilege
>
> <details><summary>Answer</summary>
> 
> **Least Privilege**
> </details>

> [!question] Q3: At a bank, only the branch manager is authorized to open the safe. However, even the manager must first request a one-time access code each time they need to open it. This is an example of?
> - [ ] Multi-Factor Authentication (MFA)
> - [ ] Just-In-Time (JIT) Authorization
> - [ ] Single Sign-On (SSO)
> - [ ] Identity and Access Management (IAM)
>
> <details><summary>Answer</summary>
> 
> **Just-In-Time (JIT) Authorization**
> 
> The manager is **already authorized** to open the safe, but they receive a **temporary, one-time access code only when they need access** — that's JIT Authorization.
> </details>

> [!question] Q4: At the same bank, internal policy states that all users must set up and use MFA in order to access company resources. The IT team is receiving a lot of complaints about the MFA app on phones and decides to switch the authentication process to require a password and selecting a preselected graphic from a grid of other random graphics displayed on the screen. Is this new method a valid implementation of MFA?
> - [ ] Yes, because they are required to use two forms of authentication
> - [ ] No, because selecting a known picture from a grid is not a valid form of authentication
> - [ ] No, because MFA should use a phone authentication app
> - [ ] No, because a password and selecting a pre-set picture are both the same factor
>
> <details><summary>Answer</summary>
> 
> **No, because a password and selecting a pre-set picture are both the same factor**
> </details>

> [!question] Q5: At the bank, user access to different systems and data is set by their role, for example teller, sales, HR, manager. This is an example of which access control model?
> - [ ] RBAC
> - [ ] ABAC
> - [ ] MAC
> - [ ] DAC
>
> <details><summary>Answer</summary>
> 
> **RBAC**
> </details>
