# Digital Forensics and Incident Response (DFIR) — Notes & Check-In Quiz

## Indicators of Compromise (IoCs)

An **Indicator of Compromise (IoC)** is a **piece of evidence that suggests a system may have been compromised**.

Examples:
- 🦠 Known malicious file/hash
- 🌐 Malicious IP address
- 🔗 Malicious domain/URL
- 📁 Suspicious file or registry entry
- 👤 Unexpected account creation
- 🔑 Unusual login
- ⚙️ Suspicious process or persistence mechanism

### Example

```
Computer → connects to → 185.x.x.x (known malware IP)
```

That IP is an **IoC**.

> **IoC = "What evidence tells me an attack may have happened?"**

### IoCs vs TTPs

| | IoCs | TTPs |
|---|---|---|
| **What** | IP addresses, domains, file hashes, filenames | Tactics, Techniques, and Procedures |
| **Changeability** | **Easy** for attackers to change | **Hard** to change (requires changing overall approach) |
| **Persistence** | Short-lived | More persistent |

> **IoCs = easier to change**
> **TTPs = generally harder to change**

## Events vs Incidents

### Event

An **event** is **anything that happens on a system**:

```
User logged in
File created
File deleted
Program started
Firewall blocked connection
```

Most events are **not attacks**.

### Incident

An **incident** is an event or series of events that **indicates a security problem requiring investigation/response**:

```
10:00 → User logs in
10:01 → PowerShell starts
10:02 → Suspicious script executes
10:03 → Computer connects to malicious IP
```

Individually, some of these are normal events. Together, they could indicate a **security incident**.

### Comparison

| | Event | Incident |
|---|---|---|
| Meaning | Something happened | Security problem detected |
| Example | User login | Account compromised |
| Volume | Very large | Much smaller |
| Requires response? | Usually no | Usually yes |

> **Event = something happened.**
> **IoC = evidence of possible compromise.**
> **Incident = confirmed/suspected security problem that needs response.**

---

## Incident Response Team (IRT)

An IRT can include people from multiple areas:
- 🛡️ **Technical Security Practitioners** → investigate and contain the attack
- 💻 **IT** → manage affected systems, networks, endpoints
- 📢 **PR (Public Relations)** → handle external communications if the incident becomes public

---

## Digital Forensics

The most important consideration in digital forensics:

> **Ensuring a proper chain of custody of any evidence gathered**

> </details>
