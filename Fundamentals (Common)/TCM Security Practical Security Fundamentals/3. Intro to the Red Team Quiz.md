## Check-In Quiz

> [!question] Q1: What is the main purpose of a penetration test?
> - [ ] To provide a "gotcha" moment to managers or other leadership
> - [ ] To identify vulnerabilities so they can be fixed
> - [ ] To practice ethical hacking
> - [ ] None of the above
>
> <details><summary>Answer</summary>
> 
> **To identify vulnerabilities so they can be fixed**
> </details>

> [!question] Q2: You're reading a job description for a cybersecurity role and it mentions they're looking for someone with experience in advanced adversarial emulation, anti-virus evasion and writing custom tools. This posting is most likely describing which role?
> - [ ] A Penetration Tester
> - [ ] A Social Engineer
> - [ ] A Red Team Operator
> - [ ] An OSINT Researcher
>
> <details><summary>Answer</summary>
> 
> **A Red Team Operator**
> </details>

> [!question] Q3: Maysa is performing a penetration test on a web app, she has been given the full source code for the web app, internal documentation, an architecture diagram, an admin account password and a regular user password. What type of test is she most likely performing?
> - [ ] Announced Test
> - [ ] White Box
> - [ ] Grey Box
> - [ ] Overt
>
> <details><summary>Answer</summary>
> 
> **White Box**
> </details>

> [!question] Q4: Which of the following is an advantage of performing a covert or unannounced penetration test?
> - [ ] It's easier for the blue team to see what the penetration testers are performing
> - [ ] In some instances it can help prepare readiness or evaluation of a real-life scenario
> - [ ] It's a more advanced type of testing that will uncover more findings
> - [ ] The blue team generally appreciates the surprise
>
> <details><summary>Answer</summary>
> 
> **In some instances it can help prepare readiness or evaluation of a real-life scenario**
> </details>

> [!question] Q5: What should always be the first step in performing a penetration test?
> - [ ] Scanning
> - [ ] OSINT
> - [ ] Recon
> - [ ] Scoping
>
> <details><summary>Answer</summary>
> 
> **Scoping**
> </details>
