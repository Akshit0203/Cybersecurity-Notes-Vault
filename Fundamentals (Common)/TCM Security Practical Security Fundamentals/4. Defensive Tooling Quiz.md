# Defensive Tooling — Notes & Check-In Quiz

## Heuristic-Based Detection

A **heuristic** is a detection method that looks for **suspicious patterns or behaviour**, rather than matching one exact known signature.

> **Signature = "I know exactly what this attack looks like."**
> **Heuristic = "I don't know exactly what it is, but these behaviours look suspicious."**

### Example — Heuristic Detection in a SIEM

Suppose a user normally logs in from Delhi. Suddenly the SIEM sees:

```
Login from Delhi
↓
5 minutes later → Login from Russia
↓
Multiple failed logins
↓
Successful login
↓
Large number of files accessed
```

There may not be one specific rule saying *"this is attack X"*. A heuristic detection can recognise the **combination of unusual behaviours** and generate an alert such as:

```
Suspicious Account Activity
Risk: High
Reason:
- Unusual login location
- Multiple failed authentications
- Successful login
- Abnormal file access
```

### In Short

**Heuristic-based SIEM detection = detecting suspicious behaviour/patterns using rules, thresholds, or behavioural indicators rather than relying only on known attack signatures.**

```
10 failed logins + successful login
        ↓
Suspicious authentication behaviour
        ↓
SIEM Alert
```

This is particularly useful for detecting **new or modified attacks that don't have a known signature yet**.

## Check-In Quiz

> [!question] Q1: When writing firewall rules, which of the following is true?
> - [ ] You should place the most specific granular rules at the top and the most permissive catch-all rules at the bottom
> - [ ] You should add a deny all rule at the top of the ACL
> - [ ] You should add allow rules before deny rules
> - [ ] You should add deny rules before allow rules
>
> <details><summary>Answer</summary>
> 
> **You should place the most specific granular rules at the top and the most permissive catch-all rules at the bottom**
> </details>

> [!question] Q2: An endpoint protection software detected a process was attempting to access the area of memory that the LSASS process (responsible for authentication) resides in. Based on this the endpoint software detects this as malicious activity, what best describes this?
> - [ ] The endpoint protection software is most likely an antivirus
> - [ ] This is an example of a heuristic based detection
> - [ ] The endpoint is most likely a HIDS (host-based intrusion detection system)
> - [ ] This is an example of a signature based detection
>
> <details><summary>Answer</summary>
> 
> **This is an example of a heuristic based detection**
> </details>

> [!question] Q3: A company has employed a firewall, IPS, EDR and a robust security awareness training program, this is an example of?
> - [ ] A robust security program
> - [ ] A waste of resources
> - [ ] A protected network
> - [ ] Defense In-Depth
>
> <details><summary>Answer</summary>
> 
> **Defense In-Depth**
> </details>

> [!question] Q4: This tool is at the heart of the SOC and the main place the SOC analysts will interact with security tooling
> - [ ] EDR
> - [ ] AV
> - [ ] SIEM
> - [ ] Firewall
>
> <details><summary>Answer</summary>
> 
> **SIEM**
> </details>

> [!question] Q5: A network based security tool has detected malicious traffic originating from a host on the network and automatically quarantined the host by blocking network traffic to and from it. What tool is this most likely to be?
> - [ ] A firewall
> - [ ] An IPS
> - [ ] An IDS
> - [ ] A SIEM
>
> <details><summary>Answer</summary>
> 
> **An IPS**
> </details>
