# Linux Fundamentals — Check-In Quiz

> [!question] Q1: What does the command `pwd` do?
> - [ ] Prints the current working directory
> - [ ] Prints the current password
> - [ ] Lets you update the current user's password
> - [ ] Changes directory to the current user's home directory
>
> <details><summary>Answer</summary>
> 
> **Prints the current working directory**
> </details>

> [!question] Q6: What does the file permission `rwxr--r-- kali kali` mean?
> - [ ] The group kali can read, write, and execute the file. All other users can only read the file.
> - [ ] All users can read, write, and execute the file.
> - [ ] The file owner can read, write, and execute the file. Members of the kali group and all other users can only read the file.
> - [ ] Root can read, write, and execute the file. All other users and groups can only read the file.
>
> <details><summary>Answer</summary>
> 
> **The file owner can read, write, and execute the file. Members of the kali group and all other users can only read the file.**
> </details>
