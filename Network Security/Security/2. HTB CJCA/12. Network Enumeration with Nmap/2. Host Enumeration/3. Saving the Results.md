# Saving the Results

---

While running various scans, we should **always save the results**. They can be used later to examine differences between scanning methods, and for documentation and reporting.

---

## Output Formats

Nmap can save results in 3 different formats:

| Option | Format           | File Extension | Description                                  |
|--------|------------------|----------------|----------------------------------------------|
| `-oN`  | Normal output    | `.nmap`        | Human-readable, similar to terminal output   |
| `-oG`  | Grepable output  | `.gnmap`       | Easy to parse with `grep`, `awk`, `cut`      |
| `-oX`  | XML output       | `.xml`         | Structured, machine-readable, convertible    |
| `-oA`  | All formats      | all three      | Saves in all three formats at once           |

---

## Example: Save in All Formats

```bash
sudo nmap 10.129.2.28 -p- -oA target
```

```
PORT      STATE SERVICE
22/tcp    open  ssh
25/tcp    open  smtp
80/tcp    open  http
MAC Address: DE:AD:00:00:BE:EF (Intel Corporate)
Nmap done: 1 IP address (1 host up) scanned in 10.22 seconds
```

| Option        | Description                                              |
|---------------|----------------------------------------------------------|
| `10.129.2.28` | Target                                                   |
| `-p-`         | Scans all ports (1–65535)                                |
| `-oA target`  | Saves results in all formats with file prefix `target`   |

This creates three files:

```bash
ls
target.gnmap  target.xml  target.nmap
```

> If no full path is given, results are stored in the current working directory.


```bash
cat target.gnmap
```


### XML Output (`target.xml`)

```bash
cat target.xml
```

```xml
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE nmaprun>
<?xml-stylesheet href="file:///usr/local/bin/../share/nmap/nmap.xsl" type="text/xsl"?>
<!-- Nmap 7.80 scan initiated Tue Jun 16 12:14:53 2020 as: nmap -p- -oA target 10.129.2.28 -->
<nmaprun scanner="nmap" args="nmap -p- -oA target 10.129.2.28" ...>
<scaninfo type="syn" protocol="tcp" numservices="65535" services="1-65535"/>
<host>
  <status state="up" reason="arp-response"/>
  <address addr="10.129.2.28" addrtype="ipv4"/>
  <ports>
    <port protocol="tcp" portid="22"><state state="open" reason="syn-ack"/><service name="ssh"/></port>
    <port protocol="tcp" portid="25"><state state="open" reason="syn-ack"/><service name="smtp"/></port>
    <port protocol="tcp" portid="80"><state state="open" reason="syn-ack"/><service name="http"/></port>
  </ports>
</host>
</nmaprun>
```

## Converting XML to HTML Report

The XML output can be converted to a clean HTML report using `xsltproc`:

```bash
xsltproc target.xml -o target.html
```

This creates a clear and structured presentation of results that is easy to read, even for non-technical people. Very useful for documentation and reporting.
