|thing|my take|
|---|---|
|★ [wizardzines.com](https://wizardzines.com/) (Julia Evans)|tiny, adorable comic-zines on DNS, TCP, HTTP, all of it. genuinely the chillest networking explanations on the internet. start with the DNS one.|
|[How DNS Works](https://howdns.works/)|a cute comic walking the full DNS lookup. DNS is _always_ the problem, learn it once, save yourself forever.|
|[High Performance Browser Networking](https://hpbn.co/)|Ilya Grigorik's deep dive into HTTP/TLS/TCP/the browser stack. free online, kind of a bible.|
|[Beej's Guide to Network Programming](https://beej.us/guide/bgnet/)|the classic sockets guide, for when you wanna _feel_ networking by writing code that talks over it.|
|★ [Wireshark](https://www.wireshark.org/)|stop reading _about_ packets and just watch your own. the "ohhh THAT'S what's happening" tool.|
