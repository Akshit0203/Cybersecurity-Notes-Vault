## Introduction to Networks

Understanding how devices communicate — from inside our homes to across the globe — is fundamental for cyber security. This module covers **Local Area Networks (LANs)** and **Wide Area Networks (WANs)**.

---

### What is a Network?

A `network` is a collection of interconnected devices that can communicate — sending/receiving data and sharing resources. The individual endpoint devices are called `nodes`.

| **Concept**    | **Description**                                              |
| -------------- | ------------------------------------------------------------ |
| `Nodes`        | Individual devices connected to a network.                   |
| `Links`        | Communication pathways that connect nodes (wired or wireless). |
| `Data Sharing` | The primary purpose of a network is to enable data exchange. |

> [!EXAMPLE] Real-World Analogy
> Think of a group of friends chatting in a room. Each person = a `node`, their ability to talk and listen = `communication links`, and the conversation = `data` being shared.

---

### Why Are Networks Important?

| **Function**    | **Description**                                                    |
| --------------- | ------------------------------------------------------------------ |
| `Resource Sharing` | Multiple devices can share hardware (like printers) and software. |
| `Communication`    | Instant messaging, emails, and video calls rely on networks.     |
| `Data Access`      | Access files and databases from any connected device.            |
| `Collaboration`    | Work together in real-time, even when miles apart.               |

---

### Types of Networks

#### Local Area Network (LAN)

Connects devices over a **short distance** — home, school, or small office.

| **Characteristic**   | **Description**                                            |
| --------------------- | ---------------------------------------------------------- |
| `Geographical Scope`  | Covers a small area.                                       |
| `Ownership`           | Typically owned/managed by a single person or organization. |
| `Speed`               | High data transfer rates.                                  |
| `Media`               | Uses wired (Ethernet) or wireless (Wi-Fi) connections.     |

![](attachments/Pasted%20image%2020260720010131.png)

#### Wide Area Network (WAN)

Spans a **large geographical area**, connecting multiple LANs.

| **Characteristic**   | **Description**                                                          |
| --------------------- | ------------------------------------------------------------------------ |
| `Geographical Scope`  | Covers cities, countries, or continents.                                 |
| `Ownership`           | Often collective/distributed (e.g., ISPs).                               |
| `Speed`               | Slower than LANs due to long-distance data travel.                       |
| `Media`               | Fiber optics, satellite links, and leased telecommunication lines.       |

The Internet is the **largest WAN**, connecting millions of LANs globally.

![](attachments/Pasted%20image%2020260720010144.png)

#### LAN vs. WAN Comparison

| Aspect        | LAN                             | WAN                                   |
| ------------- | ------------------------------- | ------------------------------------- |
| `Size`        | Small, localized area           | Large, broad area                     |
| `Ownership`   | Single person or organization   | Multiple organizations/service providers |
| `Speed`       | High                            | Lower compared to LAN                 |
| `Maintenance` | Easier and less expensive       | Complex and costly                    |
| `Example`     | Home or office network          | The Internet                          |

---

### How Do LANs and WANs Work Together?

LANs connect to WANs to access broader networks. A **modem** (modulator-demodulator) bridges your home network and the ISP's infrastructure, converting digital signals into formats suitable for transmission over telephone lines, cable systems, and fiber optics.

> [!EXAMPLE] Home Network → Internet
> At home, devices (laptops, smartphones, tablets) connect to the home router, forming a **LAN**. The router communicates with the ISP's **WAN**, granting access to websites and services worldwide.

> [!EXAMPLE] Business Network
> Companies link multiple office LANs via WANs for unified communication and collaboration across different geographic locations — sharing info, accessing centralized databases, and working in real-time.

## Network Concepts

The incredibly complex technology stack in use today was built on the `TCP/IP` stack. This section covers the `OSI` and `TCP/IP` models, common network protocols, and `transmission methods`.

---

### OSI Model

The `Open Systems Interconnection (OSI) model` standardizes telecommunication functions into **seven abstract layers**, enabling interoperable devices and software.

#### Layer 1 — Physical Layer

Transmits **raw bitstreams** over a physical medium. Deals with hardware: Ethernet cables, hubs, repeaters.

#### Layer 2 — Data Link Layer

Provides **node-to-node data transfer** between two physically connected nodes. Handles synchronization, error detection/correction. Devices: **switches, bridges**. Uses [MAC addresses](https://en.wikipedia.org/wiki/MAC_address).

#### Layer 3 — Network Layer

Handles **packet forwarding** and routing through routers. Responsible for logical addressing and path determination using [IP addresses](https://usa.kaspersky.com/resource-center/definitions/what-is-an-ip-address). Devices: **routers**.

#### Layer 4 — Transport Layer

Provides **end-to-end communication** for applications. Handles segmentation, reassembly, flow control, and error checking.
- `TCP` — reliable, connection-oriented, with error recovery
- `UDP` — faster, connectionless, without guaranteed delivery

#### Layer 5 — Session Layer

**Manages sessions** between applications — establishes, maintains, and terminates connections. Essential for session checkpointing and recovery. Uses protocols and `APIs`.

#### Layer 6 — Presentation Layer

Acts as a **translator** between application and network format. Handles data encryption/decryption, compression, and format conversion.

#### Layer 7 — Application Layer

Provides **network services directly to end-user applications**. Protocols: `HTTP` (web), `FTP` (file transfer), `SMTP` (email), `DNS` (domain resolution).

![](attachments/Pasted%20image%2020260720010618.png)

#### Example: Sending a File Across Network Layers

1. **Application Layer** → Initiates file transfer request
2. **Presentation Layer** → Encrypts the file
3. **Session Layer** → Establishes communication session
4. **Transport Layer** → Breaks file into segments for error-free transmission
5. **Network Layer** → Determines best route
6. **Data Link Layer** → Encapsulates data into frames
7. **Physical Layer** → Transmits bits over the physical medium

---

### TCP/IP Model

A condensed, practical version of the OSI model with **four layers**.

#### Link Layer

Handles physical network hardware and media (Ethernet, Wi-Fi). Maps to OSI Layers 1 & 2.

#### Internet Layer

Manages logical addressing and packet routing. Protocols: `IP`, `ICMP`. Maps to OSI Layer 3.

#### Transport Layer

End-to-end communication: `TCP` (reliable) and `UDP` (fast, connectionless). Maps to OSI Layer 4.

#### Application Layer

Protocols for data communication services: `HTTP`, `FTP`, `SMTP`. Maps to OSI Layers 5, 6, & 7.

### Protocols

`Protocols` are standardized rules for formatting and processing data to facilitate device communication.

| **Protocol** | **Description**                                                                     |
| ------------ | ----------------------------------------------------------------------------------- |
| `HTTP`       | Transfers web pages (Application Layer)                                             |
| `FTP`        | Transfers files between systems (Application Layer)                                 |
| `SMTP`       | Handles email transmission (Application Layer)                                      |
| `TCP`        | Reliable delivery with error checking (Transport Layer)                             |
| `UDP`        | Fast, connectionless communication — ideal for streaming (Transport Layer)          |
| `IP`         | Routes packets across network boundaries (Internet Layer)                           |

---

### Transmission

#### Transmission Types

- **Analog** — Continuous signals (e.g., traditional radio)
- **Digital** — Discrete signals/bits (e.g., computer networks, digital telephony)

#### Transmission Modes

| Mode            | Description                                              | Example         |
| --------------- | -------------------------------------------------------- | --------------- |
| `Simplex`       | One-way only                                             | Keyboard → PC   |
| `Half-duplex`   | Two-way, but not simultaneous                            | Walkie-talkies  |
| `Full-duplex`   | Two-way, simultaneous                                    | Telephone calls |

#### Transmission Media

**Wired:**
- `Twisted pair` cables — Ethernet/LAN connections
- `Coaxial` cables — Cable TV, early Ethernet
- `Fiber optic` cables — Light pulses, high-speed internet backbones

**Wireless:**
- `Radio waves` — Wi-Fi, cellular
- `Microwaves` — Satellite communications
- `Infrared` — Short-range (remote controls)

## Components of a Network

| **Component**                           | **Description**                                               |
| --------------------------------------- | ------------------------------------------------------------- |
| `End Devices`                           | Computers, Smartphones, Tablets, IoT / Smart Devices          |
| `Intermediary Devices`                  | Switches, Routers, Modems, Access Points                      |
| `Network Media and Software Components` | Cables, Protocols, Management and Firewall Software           |
| `Servers`                               | Web Servers, File Servers, Mail Servers, Database Servers     |

---

### End Devices

An `end device` (or `host`) sends or receives data within a network. PCs, smart devices (phones, TVs) are common examples. They serve as the primary user interface to the web, enabling access via both wired (Ethernet) and wireless (Wi-Fi) connections.

> [!EXAMPLE]
> A student uses a notebook to connect to a school's Wi-Fi, accessing online learning materials, submitting assignments, and communicating with instructors.

---

### Intermediary Devices

`Intermediary devices` facilitate data flow between end devices — within a LAN or between networks. They are responsible for:
- **Packet forwarding** — directing data by reading network addresses
- **Traffic management** — preventing congestion via protocols
- **Security** — incorporating firewalls to protect from unauthorized access

Routers operate at **Layer 3** and switches at **Layer 2** of the OSI model.

#### Network Interface Cards (NICs)

Hardware enabling a device to connect to a network. Each NIC has a unique **MAC address** for Layer 2 identification. Can be wired (Ethernet) or wireless (Wi-Fi adapter).

#### Routers

Forward data packets **between networks** and direct internet traffic (Layer 3). Use routing tables and protocols like `OSPF` and `BGP` to find optimal paths.

**Key functions:**
- Examine incoming packets and forward based on IP addresses
- Connect multiple networks
- Traffic management — select optimal paths to prevent congestion
- Security — firewalls and access control lists

> [!EXAMPLE]
> A home router connects all household devices to the internet via the ISP, directing incoming and outgoing traffic efficiently.

#### Switches

Connect multiple devices **within the same LAN** (Layer 2). Use MAC addresses to forward data only to the intended recipient, reducing congestion.

> [!EXAMPLE]
> In a corporate office, switches connect employees' computers for quick file sharing and shared resource access.

#### Hubs

Basic (antiquated) device that broadcasts incoming data to **all connected ports** regardless of destination (Layer 1). No intelligent traffic management — causes collisions. Replaced by switches in modern networks.

---

### Network Media and Software Components

#### Cabling and Connectors

Physical materials linking devices — cables and connectors like the **RJ-45** plug. Quality affects performance, reliability, and speed.

#### Network Protocols

Rules controlling data formatting, transmission, reception, and interpretation. Cover:
- `Data Segmentation`, `Addressing`, `Routing`, `Error Checking`, `Synchronization`

Common protocols:
- `TCP/IP` — ubiquitous across internet communications
- `HTTP/HTTPS` — web traffic standard
- `FTP` — file transfers
- `SMTP` — email transmissions

> [!EXAMPLE]
> When browsing a website, HTTP/HTTPS dictates how the browser communicates with the webserver — requesting and receiving web pages with correct formatting and security.

#### Network Management Software

Tools for monitoring, controlling, and maintaining network operations:
- Performance monitoring
- Configuration management
- Fault analysis
- Security management

#### Software Firewalls

Security application on individual devices that monitors/controls traffic based on predefined rules. Also called **Host-based firewalls**. Prevents unauthorized access and blocks suspicious/malicious data.

> [!EXAMPLE]
> Most operating systems include a built-in software firewall that can block incoming connections from untrusted sources.

### Servers

A `server` is a powerful computer providing services to clients over a network. Functions:

| Role                 | Description                                             |
| -------------------- | ------------------------------------------------------- |
| `Service Provision`  | Hosting web pages, email services                       |
| `Resource Sharing`   | Multiple users access files, printers                   |
| `Data Management`    | Central storage simplifying backup and security         |
| `Authentication`     | Controlling user access and permissions                 |

Servers use the **Client-Server Model**: the server waits for client requests and responds accordingly.

> [!EXAMPLE]
> When you access a website, your browser sends a request to the web server, which processes it and sends back the web page data.
