## 🔍 Port Scanning Checklist

### ✅ Basic Port Scanning

- [ ] `nmap 10.3.21.2` → Default SYN scan on top 1000 ports
- [ ] `nmap -Pn -F 10.23.2.34` → Fast scan (top 100 ports)
- [ ] `nmap -p 80 <ip>` → Scan single port
- [ ] `nmap -p 80,443,3389,8080 <ip>` → Scan specific ports
- [ ] `nmap -Pn -p80-100 <ip>` → Scan port range
- [ ] `nmap -T4 -Pn -p- <ip>` → Scan all ports with increased speed
- [ ] `nmap -Pn -sS -F <ip>` → SYN (stealth) scan
- [ ] `nmap -Pn -sT 10.23.2.12` → TCP connect scan (3-way handshake)
- [ ] `nmap -sU <ip>` → UDP port scan

> 🔺 **Note**: If port is marked *filtered*, there may be a firewall.

---

### 🔎 Service & OS Detection

- [ ] `nmap -T4 -sS -sV -p- <ip>` → Service version detection on all ports
- [ ] `nmap -O -sV <ip>` → OS and version detection
- [ ] `nmap -sS -sV -T4 -O --osscan-guess <ip>` → Aggressive OS guessing
- [ ] `nmap -T4 -sS -sV --version-intensity 8 -p- <ip>` → Aggressive version detection

---

### 🧠 Nmap Scripting Engine (NSE)

- [ ] `ls -al /usr/share/nmap/scripts/` → View available NSE scripts
- [ ] `nmap -sS -sV -sC -p- -T4 <ip>` → Default scripts with service detection
- [ ] `nmap --script-help=mongodb-info` → Get help on specific script
- [ ] `nmap -sS -sV --script=mongodb-info <ip>` → Run a specific script
- [ ] `nmap --script=ftp-anon <ip>` → Check for FTP anonymous login
- [ ] `nmap --script=ftp-* <ip>` → Run all FTP-related scripts
- [ ] `nmap -A <ip>` → All-in-one: version, OS, script, and traceroute

> ✅ Run `-A` with `sudo` for full results.

## 🔥 Firewall Detection & Evasion – Nmap Checklist

### 🚧 Firewall Detection

- [ ] `nmap -sA -p445,3389 <ip>` → Detect if firewall exists  
    - 🔹 *"unfiltered"* = no firewall  
    - 🔹 *"filtered"* = firewall present

---

### 🪓 Firewall Evasion Techniques

#### 🔹 Fragmentation
- [ ] `nmap -Pn -sS -sV -p80,443 -f <ip>` → Send fragmented packets
- [ ] `nmap -p80,443 -Pn -sS -sV -f --mtu 32 <ip>` → Customize MTU (Max Transmission Unit)

#### 🕵️ Decoy Scanning
- [ ] `nmap -Pn -sV -p- -f --data-length 200 -D 10.4.23.1` → Use decoy IP (e.g., gateway)
- [ ] `nmap -Pn -sV -p- -f --data-length 200 -g 53 -D 10.4.23.1` → Source port spoofing (DNS)

---

### 🚀 Optimizing Nmap Scans (Optional)

- [ ] `-T0` to `-T5` → Set scan speed (default is `-T3`, fast = `-T4`)
- [ ] `--scan-delay 15s` → Delay between each packet
- [ ] `nmap -Pn -sS -F --host-timeout 5s 10.10.23.0/24` → Timeout per host (good for large subnets)

---

### 📄 Nmap Output Formats (Optional)

- [ ] `nmap -Pn -p- -oN normal.txt` → Save in normal text
- [ ] `nmap -Pn -p- -oX nmap.xml` → Save in XML format (used with Metasploit)
    - [ ] `msf> db_import nmap.xml` → Import Nmap results into Metasploit
    - [ ] `msf> db_nmap -Pn -sS -sV -O <ip>` → Run Nmap directly from MSF console
- [ ] `nmap -Pn -p- -oG nmap_grep.txt` → Save in grep-able format
