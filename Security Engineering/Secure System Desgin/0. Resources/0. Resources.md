# Order of grokking :

- [ ] 1️⃣ <span style="color:rgb(255, 0, 0)"><b>Grokking System Design Fundamentals</b></span>
- [ ] 2️⃣ **Grokking the System Design Interview**
- [ ] 3️⃣ **Grokking Scalable Systems for Interviews**
- [ ] 4️⃣ **Grokking Microservices Design Patterns**
- [ ] 5️⃣ **System Design Interview Crash Course**

🟡 Advanced (Do Later)
- [ ] 6️⃣ Grokking the Advanced System Design Interview
This is **very useful for FAANG**, but only after you understand basics.
- [ ] 7️⃣ Grokking the System Design Interview Volume II

🟠 Optional (Low Priority)
- [ ] 8️⃣ Grokking SOLID Design Principles
More about **clean code architecture**, not distributed systems.
Useful for software engineers but **not critical for security engineers**.
- [ ] 9️⃣ Grokking Design Patterns for Engineers
Classic programming design patterns.
Not very relevant for your goal.
- [ ] 🔟 Grokking Object Oriented Design Interview
Mostly used for **SWE interviews**.
Not relevant for security architecture.
