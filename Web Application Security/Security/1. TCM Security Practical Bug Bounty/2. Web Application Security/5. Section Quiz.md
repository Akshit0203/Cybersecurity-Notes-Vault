
# Section Quiz — Web Application Security

---

## Questions

### Q1. The impact of a finding is considered very important when doing Bug Bounty

- ✅ **True**
- Bug bounty = impact is everything. You must prove exploitable impact to get a payout.

---

### Q2. Bug Bounty is primarily to meet compliance requirements

- ✅ **False**
- **Pentesting** is primarily compliance-driven. Bug bounty is impact & payout-driven.

---

### Q3. Scope only applies to Penetration Testing and NOT Bug Bounty

- ✅ **False**
- Scope applies to **both**. Bug bounty programs define what is in-scope and out-of-scope. You must stay within the program's defined scope.
